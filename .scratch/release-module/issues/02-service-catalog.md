# 02: 服务目录

**What to build:** 用户能在「基础配置 → 服务」里长期维护服务目录：新增服务（名称、类型、默认分支）、编辑、删除；名称重复会被拒绝；删除需二次确认；目录内容重启后保留。

**Blocked by:** 01 可折叠侧边栏树 + 模块骨架

**Status:** ready-for-agent

- [ ] 「基础配置」下存在「服务」页，列出所有服务，每行显示名称、类型（后端 / PC 前端 / 移动前端）、默认分支
- [ ] 新增服务必须填名称；名称与已有服务重复时保存被拒绝并给出「名称已存在」提示，列表不新增
- [ ] 类型只能取后端 / PC 前端 / 移动前端三选一，三种类型都能保存并正确回显
- [ ] 默认分支填写后原样保存与回显，不做格式校验
- [ ] 编辑已有服务的名称、类型、默认分支后保存，列表立即更新，重启应用后仍是新值
- [ ] 删除服务弹二次确认；取消则服务保留；确认后服务从列表消失，重启后不再出现
- [ ] 无服务时显示空状态，新增第一个服务后空状态消失
