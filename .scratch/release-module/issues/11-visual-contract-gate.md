# 11: 视觉契约门禁

**What to build:** 一张自动化的视觉契约门禁：用真窗口探针打开任务列表与执行清单，在默认与最小窗口两档截图并做几何与配色断言，把上线模块的视觉契约锁死，防止后续改动把布局或状态标记改坏。

**Blocked by:** 05 任务列表瀑布流, 08 执行清单

**Status:** ready-for-agent

- [ ] 门禁可用一条命令运行，自动在 1600×1000 与 1000×640 两种窗口下打开任务列表和执行清单，各生成一张真实帧截图（共 4 张）；截图非全黑且非空页
- [ ] 1600×1000 下任务列表呈至少 2 列瀑布流；1000×640 下不出现横向滚动，所有卡片与清单行的右缘不超过内容区右缘
- [ ] 1000×640 下执行清单每行的步骤名、状态、操作入口三者在几何上互不重叠且全部可见
- [ ] 五种任务状态（配置中、待执行、执行中、已完成、已作废）与「已超时」标记在两档窗口下均可见，且呈现颜色两两不同
- [ ] 状态与标记的颜色取自主题语义色 token；模块源码中不存在硬编码颜色字面量（门禁扫描零命中）
- [ ] 状态标签文字与底色对比度 ≥ 4.5:1
- [ ] 任一断言失败时门禁退出码非零并打印失败条目；全部通过时退出码 0
- [ ] 同一构建连续运行门禁两次，结论一致
