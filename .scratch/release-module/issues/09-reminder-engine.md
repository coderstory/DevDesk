# 09: 提醒引擎

**What to build:** 应用运行期间，提醒引擎把「已到期但未完成」的项聚合成一个独立全屏提醒窗，按环境分组、红/橙/黄分级；窗里只列和跳转，不能勾选；关闭后 5 分钟重弹直到完成；应用关闭期间到期的，重开补弹。

**Blocked by:** 08 执行清单

**Status:** ready-for-agent

- [ ] 同一时刻存在多个到期未完成项（可跨多个环境）时，只弹一个窗，不弹多个
- [ ] 窗内条目按环境分组展示
- [ ] 红色：环境开始时间已到而该环境部署未完成；或任务计划日期已到而任务仍停在「配置中」
- [ ] 橙色：到达「时间基准 − 1 小时」而提测单、CAB 单、nacos 工单、数据库工单中任一项未完成
- [ ] 黄色：到达公告时间而公告未发
- [ ] 一个窗里混有多档颜色时，窗口整体取最高优先级色；每个条目自带各自颜色标记
- [ ] 提醒窗是独立全屏新窗口，不是应用内遮罩
- [ ] 窗内不能直接勾选完成；点击某条后窗口关闭并跳到执行框对应位置
- [ ] 关闭提醒窗后 5 分钟（测试时钟推进）若该项仍未完成则重新弹出
- [ ] 所有到期项都完成后不再弹窗
- [ ] 应用关闭期间到期的项，应用重开后立即弹出，不等下一个计时周期
- [ ] 任务处于「配置中」且未到时间基准时，不弹任何提醒
- [ ] 应用完全退出后不再有提醒行为（不安装后台服务、不随开机自启）
