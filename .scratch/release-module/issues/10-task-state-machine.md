# 10: 任务状态机

**What to build:** 任务状态随提交与时间自动流转（配置中 → 待执行 → 执行中 → 已完成），提前勾选不改变状态；超时只是标记；已完成不可单步撤回；已作废停提醒、进度冻结、可恢复且不占当天名额。

**Blocked by:** 08 执行清单

**Status:** ready-for-agent

- [ ] 新建但未提交的任务状态为「配置中」
- [ ] 提交校验通过后状态变为「待执行」
- [ ] 提前勾选前置项、分支等任何步骤，状态仍是「待执行」，只有进度变化
- [ ] 时间到达任务内最早环境的开始时间后，状态自动变为「执行中」
- [ ] 过了时间窗仍未完成时状态保持「执行中」，只增加「已超时」标记，不产生新的状态值
- [ ] 所有环境完成且任务级前置项全部完成后，状态变为「已完成」
- [ ] 「已完成」任务的任何步骤不能撤回、不能重新勾选，整单只读；要改只能作废后重建
- [ ] 配置中 / 待执行 / 执行中 的任务都能作废；作废后停止提醒，进度冻结但保留
- [ ] 作废任务可恢复；恢复后按当前进度与时间回到对应状态：从未提交 → 配置中；已提交且未到最早环境开始时间 → 待执行；已过开始时间 → 执行中；进度已全部完成 → 已完成
- [ ] 作废不占当天名额：原任务作废后，可以为同一计划日期新建第二个任务
- [ ] 应用重启后状态按当前时间与进度重新判定，与重启前一致
