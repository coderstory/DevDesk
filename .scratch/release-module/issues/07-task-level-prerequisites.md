# 07: 任务级前置项

**What to build:** 任务详情里有任务级前置项区：提测单、CAB 单、按内容出现的 nacos / 数据库工单卡、上线公告；每项都是「填单号/内容 + 勾完成」，单号或内容为空时完成复选框不可勾；公告时间自动等于当天最早环境的开始时间；前置项可提前完成。

**Blocked by:** 04 新建任务与快照

**Status:** ready-for-agent

- [ ] 任务详情固定显示提测单、CAB 单两项；每项含单号输入框与「已通过」复选框
- [ ] 任务内任一后端服务的 nacos 配置内容非空且未勾跳过时，出现一张 nacos 工单卡；没有此类内容时不出现
- [ ] 任务内任一后端服务的数据库配置内容非空且未勾跳过时，出现一张数据库工单卡；没有此类内容时不出现
- [ ] 提测单、CAB 单、nacos 工单、数据库工单：对应单号为空时完成复选框处于禁用状态；填入单号后复选框可用
- [ ] 上线公告任务级唯一，含内容输入框与「已发」复选框；内容为空时「已发」复选框禁用，填入内容后可用
- [ ] 公告的到期时间自动等于任务内所有环境开始时间中的最小值，用户不可手改
- [ ] 提测单、CAB 单、nacos 工单、数据库工单的到期时间为时间基准 − 1 小时（时间基准 = 所有环境开始时间的最小值）
- [ ] 前置项在到期时间之前也能勾选完成（可提前完成）
- [ ] 清空已填单号后，对应完成复选框回到禁用状态
