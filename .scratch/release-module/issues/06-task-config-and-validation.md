# 06: 任务配置与校验

**What to build:** 用户能逐项填写任务里每个服务的配置内容（仅后端有 5 项），纯文本粘贴；某项本次没有可勾跳过；点校验随时检查完整性、不合格项标红并列出清单；提交时自动校验，不通过不让提交；提交后仍能改配置并自动重新校验。

**Blocked by:** 04 新建任务与快照

**Status:** ready-for-agent

- [ ] 后端服务的配置区固定显示 5 项：nacos、数据库、定时任务、菜单、网关；不能逐服务勾选或增删配置项
- [ ] PC 前端与移动前端服务的配置区显示 0 项配置，不出现上述 5 项
- [ ] 配置内容为纯文本：多行粘贴内容原样保存并回显，不做解析、格式化或语法校验
- [ ] 某项勾选「跳过」后，该步显示「已跳过」并划掉；校验时该项不报缺
- [ ] 校验规则：未移除服务的分支为空时报错；未勾跳过且内容为空的配置项报错
- [ ] 点「校验」随时可跑：不合格项标红，并列出全部不完整项清单
- [ ] 校验不检查分支是否真实存在、配置内容是否正确：任意文本分支与任意文本内容都能通过
- [ ] 点「提交」自动跑一次校验；存在不合格项时提交被拒绝，任务仍停留在「配置中」
- [ ] 全部合格时提交成功
- [ ] 提交后仍可修改配置与分支；每次修改后自动重新校验，结果即时更新
