# 01: 可折叠侧边栏树 + 模块骨架

**What to build:** 主侧边栏升级为可折叠树（通用能力）：用户能在主侧边栏看到「上线」父项并展开/收起，展开后点击「任务」「基础配置」两个子项进入对应页面；没有子项的既有模块渲染结果与改动前完全一致；设置页的模块开关能关闭/开启上线模块，父项与子项一起消失/恢复。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 主侧边栏出现「上线」父项，带展开/收起箭头
- [ ] 展开后出现「任务」「基础配置」两个缩进子项，点击可进入对应页面
- [ ] 收起后子项隐藏，父项仍在
- [ ] 既有 8 个模块（首页 / 笔记 / 待办 / Claude / 智能体 / 壁纸 / 设置 / 关于）的侧边栏渲染结果与改动前完全一致（无箭头、无缩进、顺序与间距不变）
- [ ] 设置页出现「上线」模块开关卡，默认开启；关闭后父项与子项一起消失
