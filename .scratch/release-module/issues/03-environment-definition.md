# 03: 环境定义

**What to build:** 用户能在「基础配置 → 环境」维护环境：命名、从服务目录挑选包含的服务、设置上线时间窗（开始 + 结束，支持跨零点）；环境定义全局共用并持久保存；删除被环境引用的服务时需要二次确认并自动从环境摘除。

**Blocked by:** 02 服务目录

**Status:** ready-for-agent

- [ ] 「基础配置」下存在「环境」页，列出所有环境，每行显示名称、包含的服务数量、时间窗
- [ ] 新建环境可填写名称，并从服务目录勾选任意多个服务；保存后列表显示所选服务
- [ ] 时间窗保存开始与结束时间；开始 22:00、结束 02:00 能保存成功，并展示为跨零点（22:00–次日 02:00 或等价明确标识）
- [ ] 开始 09:00、结束 09:00 按「结束 ≤ 开始视为次日」解释为次日 09:00（24 小时窗口），不报错
- [ ] 编辑环境修改名称、服务清单、时间窗后保存并重启应用，改动仍在
- [ ] 从服务目录删除一个被某环境引用的服务时，弹二次确认并说明会从环境摘除；取消则服务和环境引用都保留
- [ ] 确认删除被引用服务后，该服务从目录消失，相关环境的服务清单自动去掉它，环境其余配置不变
