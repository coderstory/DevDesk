# 05: 任务列表瀑布流

**What to build:** 用户打开上线模块「任务」页，看到任务卡片瀑布流；向下滚动自动加载更多，不用翻页；点击卡片进入任务详情；无任务时有空状态。

**Blocked by:** 04 新建任务与快照

**Status:** ready-for-agent

- [ ] 「任务」页以瀑布流多列展示任务卡片；卡片显示计划上线日期、当前状态、完成进度
- [ ] 首次进入加载 10 条任务卡片
- [ ] 滚动到底部自动追加接下来 10 条；共 25 条时第三次到底追加剩余 5 条
- [ ] 追加过程中卡片不重复、不丢失；25 条最终全部可见
- [ ] 数据取完后继续滚到底部不再追加
- [ ] 点击任意卡片打开对应任务的详情页
- [ ] 默认窗口 1600×1000 下卡片呈至少 2 列；最小窗口 1000×640 下不出现横向溢出、卡片内容不被裁剪
- [ ] 无任务时显示空状态提示，不显示任何任务卡片
