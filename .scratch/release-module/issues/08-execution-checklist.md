# 08: 执行清单

**What to build:** 任务执行清单按「服务 × 环境」逐条列出步骤，用户可自由推进任意可做步骤并获得「下一步」引导；步骤可勾完成、可撤回（任务完成前，撤回二次确认并留日志）；超时项标红但仍可继续；服务与配置项顺序可拖拽；环境与任务完成按规则自动判定。

**Blocked by:** 06 任务配置与校验, 07 任务级前置项

**Status:** ready-for-agent

- [ ] 后端服务 × 环境生成 8 个步骤，顺序为合并分支 → 5 项配置（nacos、数据库、定时任务、菜单、网关）→ 部署 → 验证完成
- [ ] 前端服务 × 环境只生成 3 个步骤：合并分支 → 部署 → 验证完成
- [ ] 「合并分支」在任务创建后即可勾选；配置项、部署、验证完成在所属环境开始时间到达前不可操作，到达后可用
- [ ] 任意服务的任意可做步骤都能直接勾选完成，不要求按顺序
- [ ] 界面提供「下一步」引导，指向当前第一个未完成的可用步骤
- [ ] 过了环境时间窗仍未完成的步骤标红「已超时」，且仍可继续勾选
- [ ] 勾完成与撤回都记日志（哪一步、何时、确认/撤回）
- [ ] 任务未进入「已完成」前任何步骤都能撤回；撤回弹二次确认，确认后该服务退回未完成
- [ ] 任务已完成后整单只读：所有步骤不可勾选、不可撤回
- [ ] 修改某项配置内容或某个分支后，该步原有的完成标记自动撤回，并新增一条日志说明内容已变更
- [ ] 服务顺序可拖拽，调整结果保存在任务里、重启后保持
- [ ] 配置项顺序可拖拽，仅在「配置中 / 待执行」阶段允许；进入「执行中」后锁定不可拖
- [ ] 某个环境里所有未移除服务都完成（含验证完成）时该环境判为完成；环境内服务被全部移除时该环境直接判为完成
- [ ] 所有环境完成且任务级前置项全部完成时，任务判为完成
- [ ] 被移除的服务不出现在执行清单中，也不计入进度
