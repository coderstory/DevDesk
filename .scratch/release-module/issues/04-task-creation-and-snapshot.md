# 04: 新建任务与快照

**What to build:** 用户能新建上线任务：选计划日期（默认只放行周二/周四，其他日子二次确认）、同一天只允许一个任务（重复新建直接打开已有）；给任务加入环境时做快照，之后基础配置怎么改都不影响已建任务；每个服务可填分支（纯手填不校验）、可整体移除服务或环境（二次确认）。

**Blocked by:** 03 环境定义

**Status:** ready-for-agent

- [ ] 新建任务时计划上线日期必填；未选日期提交被拒绝并提示
- [ ] 常规可选日期只有周二、周四；选择周一、周三、周五、周六、周日时弹出二次确认「非常规发布日，确定要建吗？」
- [ ] 二次确认中取消则不创建任务；确认后任务按所选日期创建成功
- [ ] 同一计划日期已有任务时，再次新建并选该日期，直接打开已有任务，任务列表数量不增加
- [ ] 加入环境时可一次选择多个环境；同一环境重复加入不会产生第二条
- [ ] 环境加入任务后展示环境名称、时间窗、服务清单；每个「服务 × 环境」的分支预填该服务的默认分支
- [ ] 分支为纯手填文本：填写任意非空文本（含空格、中文、特殊字符）都能保存，不做真伪与格式校验
- [ ] 任务建好后，在基础配置修改该环境的名称/时间窗/服务清单、修改服务默认分支、删除服务或环境，已建任务展示与已填值完全不变
- [ ] 移除单个服务弹二次确认；取消则保留；确认后该服务从任务中消失，不占进度、不参与提醒
- [ ] 移除整个环境弹二次确认；确认后该环境及其全部服务从任务移除
- [ ] 重启应用后任务与其快照内容完整保留
