## Critical Anti-Patterns

| 模式 | 这次怎么出现的 | 严重度 | 结构性防范 |
|--------|--------------|--------|-----------|
| 两个子任务同时跑 build | T3c1 与 T7a 都可能触发 `build-test-run.sh` | blocking | 派单前先确认没有别的构建在跑；排队的任务明确写「等构建位」 |
| 凭记忆写 git 状态 | handoff 若凭印象写 `uncommitted_files: []`，会丢 14 个计划的工作量 | blocking | `uncommitted_files` 必须来自实际 `git status --porcelain`（本文件已实测） |
| 让模型猜绝对时间 | 「每天 17 点」「明天 8 点」必须宿主解析 cron / 本地时间 | advisory | 草稿 schema 让模型只输出 cron 串或 `onceLocal` 文本，宿主用既有解析器转 epoch |
| UI 新增区块改弹窗高度 | 弹窗 500 高有 3 处常量断言 + 2 处 `+224` 断言 | advisory | 新增能力走子弹窗/overlay，不动主弹窗纵向预算 |
| 通知 worker 线程直接调 UI | `app::showAppNotice` 只能 UI 线程 | advisory | worker 只入队（带 mutex），UI 线程取走 |

## Critical Anti-Patterns（不要重复）

- 不要为了加 UI 能力去改弹窗高度：那会撞 3 处 `500` 常量断言 + 2 处 `+224` 断言；用子弹窗。
- 不要让 LLM 输出 epoch/绝对时间戳：让模型输出 cron 串或 `YYYY-MM-DD HH:MM`，宿主复用 `parseOnceAtLocalText` 转换。
- 不要在 worker 线程调 `app::showAppNotice`：只入队，UI 线程消费。
- 不要读/回显 profile 密钥：用 `claude.test_connection` 工具验证连通性。
- 不要 push 到任何远端：DevDesk 与 EUI-NEO 都只本地提交。
