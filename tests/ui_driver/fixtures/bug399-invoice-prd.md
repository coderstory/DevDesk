# 南非索赔发票模板布局微调 PRD

> 版本：v3（2026-11-17，四批全部验收）｜需求池：#20/#22/#23（已关）｜交付 commits：00e6065a0 + 04402735a + e2599ccfe

## 1. 背景

南非（ZA）索赔发票（Warranty 索赔链路专用发票，前批已用 WPS 反排基底模板替代 WPS 导出格式）在样张评审中收到 PM 布局反馈（2026-11-17，分四批）。本需求为前批「PM 反馈共调批」的续反馈，随 feature/20261126 分支交付。

## 2. 需求内容

| # | PM 反馈原文 | 最终实现 |
|---|---|---|
| 1 | 表头下方新增一行空白，增加间距（澄清后定位：模板顶部、手机号下面） | 顶部 Telephone 手机号行下新增 20pt（约 7 毫米）空白行，其下标签信息网格整体下移 |
| 2 | Invoice Date 这一列右移一点（升级：Invoice Date 到 Customer TEL 整列都要右移，值跟着动） | 右列 21 个格（11 组标签+值）统一右移约 10.4 毫米，整列如一块平移 |
| 3 | Code / Descriptions 两列的值与表头左右没对齐（疑值左对齐） | 两列值改居中与表头对齐；删 Descriptions 表头导出残留空格 |
| 4 | 底部签字表格不要跨页 | 垫行找补恢复旧算法校准：≤4 条桶垫空行 30→23pt 抵 20pt 空隙预算，样张回 1 页、签字表格连同备注完整在第 1 页 |

## 3. 关键决策记录

- **D1 位置语义**：用户口中的「表头」= 模板顶部块（大字标题 + 经销商信息 + 手机号）——以「手机号下面」为锚。
- **D2 幅度与分页**：20pt 空隙吃掉页高预算致 2 页，用户初拍板接受；批 4 以垫行找补收回 1 页（终态）。
- **D3 右移机制**：四方案实测择优——纯 nbsp 塌缩（禁用）、mso-spacerun（污染文本）、padding-left（单位异常）、**mso-char-indent-count:3 定稿**（每级≈3.5mm，必须整数）。
- **D4 对齐方式**：Code/Descriptions 值居中（随表头）。
- **D5 跨页治理路线**：先试「恢复旧算法」（垫行重校准，S 级）并验收通过；Java 渲染层保块（分页线切签字区则整块推下页）留作后备——旧算法对长描述撑行高、4 条满行、多页桶仍脆，真出现再上。

## 4. 范围边界

- 不修存量问题：Arrival Time 断言红（独立待办 #21）。
