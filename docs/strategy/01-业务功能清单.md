## 五、智能体（可禁用，默认关）

| 功能 | 行为说明 | 成熟度 |
|------|---------|--------|
| 任务列表 | 任务名/状态点/徽章（配置异常/限次/已停用）/下一步触发时间，hover 命中层 | 可用 |
| 新建任务 | 弹窗填目标+六选一触发类型+模型槽位+迭代上限(1-50)+破坏性操作开关+限次/只跑一次+任务级记忆 | 可用 |
| **触发：手动** | 仅点「启动」运行，不自动调度 | 可用 |
| **触发：定时 cron** | 按 cron 表达式周期调度（分/时/日/月/周），4 个内置模板（工作日9点/每天9点/每小时/每周一9点）+ 自由输入+实时预览下次触发 | 可用 |
| **触发：常驻** | 不自动运行，点列表「入队」立即执行一轮 | 可用 |
| **触发：事件** | 三种事件可选（新建待办/完成待办/保存笔记），事件发生时自动触发，带 300s 默认冷却且同任务不同事件互不压制 | 可用 |
| **触发：每天** | 不指定时刻，当天首次打开后的首个调度周期跑一次，跨天恢复 | 可用 |
| **触发：闹钟** | 指定本地 YYYY-MM-DD HH:MM 时刻触发一次后自动停用，错过不补 | 可用 |
| 限次开关 | 任务可设「只跑一次」或自定义次数上限（1-1000），跑满自动停用 | 可用 |
| AI 草稿生成 | 任务弹窗点「AI 生成」→输入自然语言一句话→后台 LLM 生成 goal/cron/触发配置草稿预填表单，人工确认才保存 | 可用 |
| 任务启停 | 行内开关禁用/启用任务，Scheduler 跳过禁用任务 | 可用 |
| 启动任务 | 行内「启动」按钮手动跑一次（ActiveRun 线程+单一闸防并发），自动开详情弹窗实时刷新 | 可用 |
| 停止任务 | 详情弹窗「停止」chip 设 cancel 位，当前轮结束后生效 | 可用 |
| 删除任务 | 单事务级联删（messages←runs→tasks），运行中禁删 | 可用 |
| 详情弹窗 | 三摘要卡（计划vs实际/墙钟/token）+配置头（可折叠）+按天分组的 run 列表（20条/天）+消息展开/复制全文 | 可用 |
| 运行审计查看 | 每条 run 可展开全部消息（text/工具名/工具输出错误态），最近 assistant 默认展开 | 可用 |
| 可用工具列表 | 头部展开列出全部注册工具的 name/描述/参数 | 可用 |
| 工具执行 | run 中真实调用 md.*/todo.*/claude.*/app.*/hot.list 等工具，落库或出网 | 可用 |
| 双通道通知 | run 失败/受限时应用内 toast 4.5s + OS 系统通知，同 runId 只发一次，成功/取消静默 | 可用 |
| 页内错误引导 | run 因「LLM 配置不可用」（缺 Profile/未配 URL/未配 Key/槽位未配置）失败时，页内错误行+「去 Claude 页→」引导 | 可用 |
| 运行资源上限 | 单次运行墙钟预算 min(迭代×60s, 30min) + 200K token 上限，AgentLoop 检查点强制 | 可用 |
| 任务级记忆 | task 表单「执行记忆」开关，开启后每次 run 的 conversation 追加进下次 system prompt | 可用 |
| 破坏性授权 | task 表单「允许破坏性操作」开关，关闭则拒绝高危工具（如 md.delete/claude.switch_profile） | 可用 |
| 配置异常标记 | trigger_config 坏 JSON/非法值在任务列表挂可见徽章，防止 Scheduler 静默跳过 | 可用 |
| 悬挂 run 兜底 | 外部直写库插入 running run 后，15s 轻查询命中补进常规观测 | 可用 |
| LLM 直连 | 代理未开时智能体经激活 Profile 直连端点（DirectLlmClient），与代理路径解耦 | 可用 |
| Scheduler | cron 匹配+每天首次+闹钟+事件路由四路派发，同 task 不并发，stopAll 收口顺序（先停常驻后停 run） | 可用 |
| Tool: app.stats | 返回应用四项统计数据 | 可用 |
| Tool: app.notify | 发送系统通知（支持 level/info/success/warning/error 四级） | 可用 |
| Tool: hot.list | 四源串行降级热榜（微博热搜→热榜→百度→头条），冷却 5 分钟 | 可用 |

| Tool: md.* | 创建笔记(md.create)/列标签(md.list_tags)/删除笔记(md.delete，受破坏性授权管控) | 可用 |
