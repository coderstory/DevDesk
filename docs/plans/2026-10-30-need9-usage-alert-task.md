## 目标
token 消耗超阈值时主动桌面通知：日阈值、月阈值两档。

## 范围要点（以 spec 为准，此为验收锚点）
1. 阈值判定：读现有用量统计面数据，日/月两档阈值可配置（设置页入口，持久化）
2. 通知出口：复用 M3 run 终态桌面通知基建（module_agent 通知通道），不新建通知机制
3. 防骚扰：同一天同一档只提醒一次（触发后置位，跨日/跨月复位）
4. 通知文案含：当前用量、阈值、档位（日/月）

## 非目标
不做用量预测、不做多级阈值、不做通知渠道扩展（邮件/webhook 后置）

## 验收标准（回单自证）
- F-01 用量超日阈值 → 触发一条通知，文案含用量/阈值/档位
- F-02 同日重复超阈值不再重复提醒（置位防骚扰）
- F-03 跨日复位：模拟次日用量再超 → 再提醒
- F-04 月阈值独立于日阈值各自置位
- F-05 阈值改动持久化，重启后生效
- F-06 定向用例全绿 + 先红后绿证据（变异可红）
