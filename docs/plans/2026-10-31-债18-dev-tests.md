## 偏离方案卡之处

1. **驱动装配从「uat62 全表直注册」改为「main.cpp 门控注册复刻」**：uat62_page_shots_probe 的全表直注册不模拟 enabledModules 门控，侧边栏全条目在场——settings-toggle 场景的种子证明（seed 关 memory → 条目不在场）在该形态下不成立。改为真 SettingsStore 读 appDatabase + `buildGatedEntries` 门控注册 + `app::toggle::setToggleHandler`（module_toggle_sidebar_probe 同款 handler 形态），F-06/F-08 因此更贴近真 app。
2. **场景从 3 条扩为 4 条**（方案卡 §7.1 写 smoke/todo/settings 三条）：补 todo-drag-move 以满足 AC-3「五动作各 ≥1 条在库场景」（drag 需独立场景）。
3. **`check-windows-cross-compile.sh` 两处接线**（方案卡 §7.1 涉及文件清单未列）：四纯函数单测 TU 进守卫受编集合需要 vendored GLFW 常量头 include；ui_driver_main.cpp（probe 族、拖 png/glad 生成面）显式排除在语法守卫外。
