## 一、现状声明（不回避）

**DevDesk 当前不支持屏幕阅读器。**

- 界面由 EUI-NEO 自绘（非系统原生控件），目前没有向操作系统无障碍基础设施
  （Windows UIA / macOS Accessibility）暴露任何元素、名称、角色或焦点状态——
  VoiceOver / NVDA / Windows 讲述人读不出 DevDesk 的界面内容。
- 全键盘导航同样**未达成**：EUI-NEO 的 Tab 焦点循环未实现（`InputKey::Tab`
  枚举存在但框架不调度，见 EUI-NEO-CAPABILITIES.md「隐藏陷阱」），Tab 逐元素
  导航需要应用层自建；docs/UI-UX-DESIGN.md §10.3 的键盘导航条目是目标形态，
  不是已实现能力。
- 本文只声明现状与边界，**不承诺任何时间点**；下方动作清单按 P2 随常规迭代推进。
- docs/UI-UX-DESIGN.md §10 与本文件的口径冲突时，**以本文件（实现现状）为准**。

## 二、范围与边界

- **覆盖**：EUI-NEO 渲染的 DevDesk 主界面（侧边栏导航 / 首页 / Markdown 笔记本 /
  Todo 看板 / Claude 切换器 / 设置页）及各 modal、弹层。
- **不覆盖**：系统原生 UI 面（托盘原生菜单等平台控件——若确有原生控件，屏幕阅读器
  的可用性由平台保证，不进本清单；以实际核查为准）。
- **不覆盖**：屏幕阅读器桥接的**实现**（见 A3——先评估后立项，本立项不承诺做）。

## 三、先行动作清单（每条可裂变为独立实现票）

> 裂变规则：实现票直接搬走对应「验收雏形」作验收标准，票面回填来源
> （`docs/ACCESSIBILITY.md §三.Ax`）互链；一项一票，不打包。

### A1 EUI-NEO 全键盘导航（先行动作一）

**目标**：不碰鼠标完成全部常用操作。

**验收雏形**（裂变时逐条搬走）：
- [ ] Tab / Shift+Tab 焦点循环：应用层实现 Tab 调度（EUI-NEO 不调度 Tab），
      焦点按视觉顺序在侧边栏导航项与主区可交互元素间循环，Shift+Tab 反向，
      首尾循环不丢失、焦点不落到不可见元素。
- [ ] 焦点始终可见：任一获得焦点的元素有可辨识的焦点视觉态（对齐
      UI-UX-DESIGN §10.3 的 WCAG 2.4.7 要求）。
- [ ] 模块入口 + 核心动作纯键盘可达：五个模块页切换、新建笔记、移动待办卡片、
      切换/启用 Claude profile、打开设置——逐模块给出实际键位表，与
      UI-UX-DESIGN §8 的键位表逐条核对，缺的补齐、冲突的裁决。
- [ ] Escape 语义统一：modal / 弹层 Esc 关闭，焦点归还触发元素。
- [ ] 验收工具：用 A2 的焦点顺序暴露写 probe 断言（A2 是 A1 的前置）。

**依赖事实**（EUI-NEO-CAPABILITIES.md 实测口径，实现票必须遵守）：
程序式聚焦必须以 `<input id>.hit` 为目标 id（发基 id 时组件判定未聚焦）；
焦点元素从帧树消失时框架不清 `focusedId_`（陈旧焦点陷阱）——Tab 序表需应用层兜底移除。

### A2 焦点顺序暴露（先行动作二）

**目标**：把「当前焦点在哪 / Tab 遍历顺序」变成程序可查询、可断言的状态——
既是 A1 的验收工具，也是将来任何无障碍桥接（A3）的地基。

**验收雏形**（裂变时逐条搬走）：
- [ ] 每个 focusable 元素有稳定 id（id 是 EUI-NEO 焦点的唯一身份，见 §A1 依赖事实）。
- [ ] 运行时可查询两个量：当前 `focusedId`；全局 focusable 元素的 Tab 序注册表
      （应用层维护，顺序 = 视觉顺序）。
- [ ] probe 可断言：给定界面状态下，Tab 序注册表 = 预期序列——无重复 id、
      无预期外元素、无键盘不可达元素。
- [ ] 陈旧焦点守卫：元素消失（帧树卸载 / scope 释放）即从注册表移除；
      `releaseStateScope` 前缀命中清焦点的行为有单测覆盖。

### A3 屏幕阅读器桥接（后续裂变候选，不在首批）

**说明**：自绘界面要支持屏幕阅读器，需向 OS 无障碍树暴露元素树——工作量与风险
显著高于 A1/A2（EUI-NEO 是否具备 accessibility API、不具备时是否 fork 上游，均未评估）。
**先评估再立项**：A3 的第一张票是评估票（产出现状报告 + 可行方案 + 工作量），不是实现票。
A1/A2 完成前不启动 A3。

## 四、明确不做 / 暂不做（防过度设计）

- 不承诺 WCAG 2.2 全档达标时间点（对比度等视觉项已随 design token 落地，
  行为层键盘/读屏项未达——达标项与未达标项以本文件 + UI-UX-DESIGN §10 为准）。
- 不在 A1/A2 完成前启动 A3 实现；不做无评估结论的 fork EUI-NEO 决策。
