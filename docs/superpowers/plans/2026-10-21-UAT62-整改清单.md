## 状态机（铁律）

```
⬜ 待开发 → 🔵 已开发·待核验 → ✅ 已核验·完成
                    ↓ 核验不通过
               回到 ⬜（附缺陷记录）
```

**「✅ 已核验·完成」的唯一判定条件**：核验通过。核验 = 以下之一：
1. 渲染/几何断言测试实际执行并通过（**2026-10-21 用户解锁：任意 UI test 允许执行**）；
2. 业务流程全链 UI 测试实际跑通并核对结果（见 G 节）；
3. 用户真机目检确认通过；
4. 非 UI 纯逻辑用例实际执行并通过。

**纸面推导、代码审阅、「编译过了」一律不算核验**——0.4.3 的「文字跑出弹窗」就是推导声称在界内的产物。
