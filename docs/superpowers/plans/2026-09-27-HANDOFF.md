## 0. 工作方式铁律（用户已定，不得违反）
1. **主会话禁止直接修改项目文件**（源码/配置/文档）；写入一律派子任务。commit 属仓库记账，主会话可自己做（用户 2026-09-27 明确"commit 又不修改文件"）。
2. **并发子任务上限 7**；空槽即补。**build 目录是单点资源**：同一时刻只一个 agent 编译/测试，撞 `cannot open output file ...: Permission denied` 就 `sleep 20` 重试 ≤5 次。
3. **每个任务完成 → 主会话审计（读 diff + 复跑验收）→ 立刻原子 commit → 立刻合 master**，不攒批。前提：**同一文件同一时刻只有一个写者**（派单按文件排他）。
4. 实现类任务在**基座提交后**优先走 **git worktree 并行**（各自独立 build 目录 + `-DEUI_NEO_DIR=D:/project/gui/EUI-NEO`），产物审计后合回。
5. 子代理报结论先证伪：读原文行核实（禁窄 grep 一行定论），只修 CONFIRMED。
6. **worktree 用完即清**：临时 worktree（`wt-*` / `.claude/worktrees/*` / 隔离用的分支工作树）在任务合并后**立即** `git worktree remove <path>`（有未跟踪文件先看内容、必要时先备份到仓库外再 `--force`），并跑一次 `git worktree prune`。禁止留残留（2026-09-27 一次清出 12 个 EUI-NEO 残留 worktree）。
7. **子任务只跑定向测试，禁全量**（2026-09-27 用户："进度太慢了"）：派单时明确要求——**只编译受影响的目标 + 只跑与改动功能相关的测试**（用测试二进制子串过滤，如 `./tests/devdesk_tests.exe markdown`），**禁止 cmake 全量重建、禁止跑全量用例套件**。全量只在里程碑收尾/提交前由主会话统一跑一次（或明确指定"这次要全量"时）。
8. **涉及编译/测试的子任务必须走 worktree**（2026-09-27 用户定）：派单时用 worktree 隔离（`isolation: "worktree"`，或手动 `git worktree add`），**禁止在主工作树里跑构建**——主工作树脏、且 build 目录是单点资源。worktree 需要独立配置（`-DEUI_NEO_DIR=D:/project/gui/EUI-NEO` + 项目既有 OPENSSL/ZLIB 参数），首次为全量编译，属预期成本。
   **收尾三步**：① agent 在自己分支上**原子 commit** 并在报告里给 sha；② **合并进 master 由主会话串行执行**（多 agent 同时 merge 会撞 `index.lock`；且主会话要过审计关）；③ 合并后**立即 `git worktree remove <path>` + `git worktree prune`**，禁止残留目录。
