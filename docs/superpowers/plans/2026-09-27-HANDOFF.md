## 0. 工作方式铁律（用户已定，不得违反）
1. **主会话禁止直接修改项目文件**（源码/配置/文档）；写入一律派子任务。commit 属仓库记账，主会话可自己做（用户 2026-09-27 明确"commit 又不修改文件"）。
2. **并发子任务上限 7**；空槽即补。**build 目录是单点资源**：同一时刻只一个 agent 编译/测试，撞 `cannot open output file ...: Permission denied` 就 `sleep 20` 重试 ≤5 次。
3. **每个任务完成 → 主会话审计（读 diff + 复跑验收）→ 立刻原子 commit → 立刻合 master**，不攒批。前提：**同一文件同一时刻只有一个写者**（派单按文件排他）。
4. 实现类任务优先走 **git worktree 并行**（各自独立 build 目录），产物审计后合回。worktree 里**直接** `bash scripts/build-test-run.sh [--no-run]` 即可：脚本自动定位 EUI-NEO（优先级 `EUI_NEO_DIR` 环境变量 → 同级 `../EUI-NEO` → `git rev-parse --git-common-dir` 反推的主工作树同级）并作为 `-DEUI_NEO_DIR` 传给 configure，`build/` 未初始化时自动 configure —— **不再需要手敲 `-DEUI_NEO_DIR=D:/project/gui/EUI-NEO`**（PAB-01 已修）。**编译缓存已接进脚本**：三件套（`CCACHE_DIR`/`CCACHE_BASEDIR`/`CCACHE_NOHASHDIR`）已落 ccache **持久配置**（`%LOCALAPPDATA%\ccache\ccache.conf` + 缓存目录同名文件，`ccache -p` 可查来源），**不需要任何 `CCACHE_*` 环境变量**；脚本只负责传 `-DCMAKE_{C,CXX}_COMPILER_LAUNCHER=ccache`（未装 ccache 自动降级）。**手工 configure 的最小用法 = 在原有 `-D` 上多带这两个 launcher 参数即可**（"完全裸的 `cmake -B build`"本仓库本来就跑不通：缺 `-DOPENSSL_ROOT_DIR` 会 find_package(OpenSSL) 失败；masquerade/编译器 shim 方案已验证不可用——理由见 CLAUDE.md「编译缓存」段）。worktree 首建即吃跨树缓存命中。**并行度封顶 `DEVDESK_JOBS=3`**（脚本默认，12 核机器多 worktree 并发时的经验值；单条独占机器可 `DEVDESK_JOBS=8` 覆盖）—— **派单模板一律带这个上限**，避免多条 agent 各自 `-j12` 互拖。**实测（2026-09-27，两个全新 worktree、-j3）：worktree 首建从冷缓存 647 s 降到热缓存 35 s（239 次查找 237 命中 = 99.2%，全 direct），缓存产物 `devdesk_tests.exe` 589/589 全绿** —— 即"worktree 首建贵"这个瓶颈已消除，并行开 worktree 的成本不再是障碍。
5. 子代理报结论先证伪：读原文行核实（禁窄 grep 一行定论），只修 CONFIRMED。
6. **worktree 用完即清**：任务合并后**立即** `git worktree remove <path>` + `git worktree prune`，禁留残留。
7. **子任务只跑定向测试，禁全量**（用户："进度太慢了"）：只编译受影响目标 + 测试二进制子串过滤（如 `./tests/devdesk_tests.exe markdown`）；全量只在里程碑/提交关口由主会话跑一次。
8. **涉及编译/测试的子任务必须走 worktree**，禁止在主工作树里跑构建。收尾三步：① agent 在自己分支原子 commit 并报 sha；② **合并进 master 由主会话串行执行**（并发 merge 撞 `index.lock`）；③ `git worktree remove` + `prune`。
9. **子任务意外终止**（网络/API 死亡、产出为零）→ **唤醒原 agent 续跑**，不重派新 agent（2026-09-27 晚用户拍板）。
