## 〇、铁律（用户指令，凌驾一切工艺考量）

1. **不改任何功能**：所有工单 diff 只允许视图/样式/布局/文案层代码；审阅者专查业务逻辑改动，发现即打回。
2. **全量实地取证，禁止估算与抽样**：影响面=全量调用方普查；"没有"必须穷尽可证；每份调查附覆盖度声明。
3. **具体开发一律 worktree 子代理执行**：主会话只编排、派单、验收、合并；并发 ≤4（用户 2026-10-19 拍板），构建槽全局唯一。
4. **所有产出中文**（文档/注释/commit message）。
5. **EUI-NEO 上游零改动**：13 项中本次整改所需能力全部有实现路径；骨架屏无现成组件（已被 v1.0 空状态哲学排除，不需要）；FA 问号字形可用性存疑（W2 闭环验证）；图标走 SVG 通道或沿用 FA 实心体重着色（P-02）。

## 二、防跑偏机制（四闸门，任何代码进场前必过）

| 闸门 | 机制 |
| ---- | ---- |
| 1. 证据关 | 设计文档/规范的每条交互规范必须引审计证据（file:line）；审计未覆盖的标"待核"，不许写成定论 |
| 2. 基线关 | W0 采集改前 7 区全量截图存档 + 全量测试基线；一页一分支一提交链，任何页可独立回滚，严禁混页提交 |
| 3. 影响面关 | 共享资产（令牌/ui_kit 组件/导航壳）改动前全量使用方普查；测试影响面审计的受影响断言清单直接进各页工单白名单——改前就知道哪些测试会红 |
| 4. 验收关 | 实现者不自证：探针截图逐项对清单 + 每页关键交互实跑 + 独立审阅代理核 diff 零业务逻辑 + 断言更新方向审查（**测试断言只许换期望值不许删覆盖**，删装饰类用例必须改写为"无装饰"反证断言） |
