# QA 手测清单：终端模块 v2 Windows 真终端（need:127）

> 依据：PRD `2026-11-04-terminal-windows-impl` v2「用户操作流程」第 1–11 步 + 功能矩阵 F-01~F-05 边界。
> 机器：老板 Windows 机（本需求唯一真机验证面；macOS 侧由实现会话与 QA 在 mac 完成，见 F-06）。
> 前置：安装含 v2 的 Windows 产物（Debug 覆盖复制口径装 build/DevDesk.exe + assets/）。
> 每步记录：通过 / 不通过（现象+截图）/ 不适用。截图归 evidence/ 并回填本清单。
> 判定：第 1–11 步全过 = v2 终态关闭的必要证据达成（F-05 差异项按「记录不阻塞」处理）。

## 第 1 步 · 提示符出现（F-01/F-02）

- 操作：装产物 → 启动 DevDesk → 侧边栏点「终端」。
- 预期：数秒内出现 PowerShell 提示符（pwsh 优先，未装 pwsh 则 powershell.exe；均带 -NoLogo 无横幅），徽标「运行中」，页面与 mac 同形态（工具栏/网格/主题）。
- 对照基准：Windows Terminal 新开 PowerShell 标签的首屏观感。
- 失败判据对照：spawn 失败应显示「启动失败」覆盖卡 + 错误文案 + 重试按钮（F-01 边界），而非空白/崩溃；OS<1809 应显示版本门槛文案（F-01）。

## 第 2 步 · 基础命令（F-01）

- 操作：依次输入 `echo hello` 回车、`dir` 回车、`git status` 回车（任一 git 仓库内）。
- 预期：输出正确、颜色正常（dir 的目录高亮、git 的分支色）、退格/光标移动正常。
- 对照基准：Windows Terminal 同命令输出。

## 第 3 步 · 中文路径与列宽（F-03）

- 操作：`cd` 进任一含中文名目录（如 `mkdir 测试目录` 后进入）→ `dir` 列出中文文件名。
- 预期：中文字符宽字占 2 列、表格列对齐不乱码；中文目录名输入/回显正确。
- 对照基准：Windows Terminal 同操作。

## 第 4 步 · IME 中文输入（F-03）

- 操作：切中文输入法 → 在终端输入中文目录名（候选词组合期间观察）→ 上屏回车。
- 预期：组合期候选串以 overlay 呈现在光标位、**不进终端网格、不误发字符**；上屏后命令正确执行。
- 失败判据对照：组合期字符直接落进命令行 = F-03 红。

## 第 5 步 · 粘贴与选区复制（F-03，Windows 惯例键位）

- 操作①：复制一条多行命令（如 `echo a\r\necho b`）→ 终端内 **Ctrl+V** 粘贴。
- 预期①：与 Windows Terminal 行为一致（bracketed paste：多行文本整块进入、不逐行立即执行；未开 bracketed 的 shell 退化行为记录差异）。
- 操作②：鼠标拖选一段输出 → **Ctrl+C**（有选区）→ 到记事本 Ctrl+V。
- 预期②：粘贴内容与选中内容一致（所见即所得；行尾无多余空白）。
- 操作③：**无选区按 Ctrl+C** → 预期发送中断（正在跑的 `ping -t` 被打断 / 命令行出现 `^C`）。
- 已知留缝（不阻塞，记录）：Ctrl+V 依赖 EUI pasteText 链路，若 Windows 下不产 pasteText 则粘贴不动——记录现象，转 pool 另立（page 侧补剪贴板读拦截）。

## 第 6 步 · 回滚与 resize（F-02，坑⑤）

- 操作①：`dir` 大输出刷满屏 → 滚轮上翻回滚 → 回到底部。
- 预期①：回滚内容完整、行序正确；回到底部后跟随新输出。
- 操作②：拖拽窗口从小到大、大到小各数次（含拖拽时终端无输出、仅提示符静止态）。
- 预期②：行列实时重排跟随、无花屏卡死（resize 在读侧暂停窗口执行 + CancelIoEx 唤醒，技术卡 §3.1）；极小窗口不崩可恢复。
- 操作③：resize 后跑 `cls` + `dir` 确认重绘正常。

## 第 7 步 · 页面切换保活（F-04）

- 操作：终端起 `Start-Sleep 10; echo done` → 立即切到其它模块页 → 等 10s+ 切回。
- 预期：切回后 done 已上屏且顺序完整；画面/回滚保持；徽标仍「运行中」。

## 第 8 步 · 全屏进出（F-02）

- 操作：点「全屏」→ 侧边栏消失终端铺满 → 右上悬浮半透按钮退出回常规。
- 预期：双向可逆；全屏态内覆盖卡（若会话结束）与悬浮按钮并存；对照 v1 UI 契约 #3。

## 第 9 步 · 会话结束与新建（F-04）

- 操作：输入 `exit` → 观察 → 点「新建会话」（或覆盖卡「重新开始」）。
- 预期：「已结束 (退出码 N)」覆盖卡 + 输出保留；新建后新提示符可用、徽标回「运行中」。

## 第 10 步 · Claude Code 首验收（F-05，老板拍板用例）

- 操作：DevDesk 终端页输入 `claude` 启动 Claude Code 交互式 TUI；**Windows Terminal 并排各跑一次**同操作对照。
- 预判：会话可正常交互（输入/滚动/退出）、界面色彩与布局可辨识可用、无花屏卡死。
- 判定：以「日常可用」为门槛，不追求逐像素一致；TUI 高级特性缺失项（undercurl 等 ConPTY/terminfo 类）记录为已知差异清单、不阻塞。
- 交互子项：方向键选择、回车确认、Esc 退出、中文输入（回到第 4 步链路）、长输出滚动（回到第 6 步链路）。

## 第 11 步 · 退出无残留（F-04 硬验收，坑②③⑦）

- 操作①：跑 `Start-Sleep 60` 长任务 → 直接关闭 DevDesk 主窗。
- 操作②：终端会话运行中 → 关闭 DevDesk。
- 操作③：shell 启动后立即关闭 DevDesk（坑③启动期关闭面）。
- 预期：任务管理器中无残留 powershell/pwsh/cmd/conhost 孤儿进程（等 10s 再查一次；taskkill 树杀→排空→Close→join→探活兜底链，技术卡 §3.2）；宿主全程不崩。

## 附 · 失败/异常面抽查（F-01/F-04 边界）

- `DEVDESK_TERMINAL_SHELL=Z:\不存在\shell.exe` 环境变量启动 → 「启动失败」覆盖卡 + 错误文本 + 重试可用（与 mac 注入口同语义）。
- conhost 崩溃面（可选，任务管理器杀 OpenConsole/conhost）→ 页面走「会话已结束」态、DevDesk 不崩（坑⑦崩溃隔离）。
