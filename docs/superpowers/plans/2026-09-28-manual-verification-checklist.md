## 6. 认证字段（commit dbb720a）

### 6.1 鉴权头三态：双发 / 只发 Bearer / 只发 x-api-key

- **步骤**：同一 profile 依次分别设为「双发」「只发 Bearer」「只发 x-api-key」；每种状态都点「测试连通」+ 实发一轮请求，并在上游侧（API 网关/服务端日志）确认收到的头形态。
- **期望**：三种设置下上游实际收到的头与设置一致（双发 = Bearer 与 x-api-key 都带；只发 = 仅对应头）。
- **验证环境**：需真实上游（上游侧确认头形态）

### 6.2 编辑回显：重开表单下拉显示当前值

- **步骤**：编辑某 profile 后保存，重新打开该 profile 的表单。
- **期望**：认证字段下拉回显当前保存的值，不丢、不重置。
- **验证环境**：本机可验

### 6.3 导入自动推断：仅 ANTHROPIC_API_KEY 的粘贴配置 → 「只发 x-api-key」

- **步骤**：复制只含 `ANTHROPIC_API_KEY`（无 Bearer 类字段）的配置走导入流程。
- **期望**：认证字段下拉自动变为「只发 x-api-key」。
- **验证环境**：本机可验

### 6.4 二段保存不覆盖：高级 env 页保存不动认证字段

- **步骤**：先在表单设好认证字段，再去高级 env 页做修改并二段保存，回来看认证字段。
- **期望**：认证字段没被覆盖回默认值。
- **验证环境**：本机可验
