# 终端指针交互补齐（三端）·需求卡

**来源**：老板 2026-11-26 实测报告（终端里跑 opencode）
**状态**：复现中（探针 `terminal_pointer_probe` 编写中），未修

## 症状

1. **终端页顶部 TAB 无法点击**（本软件标签栏，非 opencode 内部 UI）。
2. **文本选中后右键无法复制**：期望「有选区时右键即复制」（opencode 里的选文复制依赖终端的选区 + 剪贴板支持）。
3. 补充口径：**点击/触摸的选中与复制效果，App / PC 网页 / 手机网页三端都要成立**。

## 关键背景（已核）

- opencode 这类 TUI 会开启鼠标上报（DECSET 1000/1002/1006）。终端一旦转发鼠标事件，本地拖选就失效——必须提供 **Shift 覆盖本地选区** 才能选中文本。
- 当前实现（本批 M2）已有：拖选、选即复制（松开即写剪贴板）、右键菜单（复制/清屏/搜索）。
- 疑点（待探针证实）：
  - TABS：标签 `.bg` 同时挂了 `onDrag`（本批 M2 Task 4 加）与 `onClick`；EUI 只把点击给「最上层 interactive 元素」，若拖拽手势链抢走按下/松开，click 不触发。
  - 右键：`onRelease` 对所有按键生效，右键松开会把选区重算成「锚点==落点」→ 选区被清空，菜单里的「复制」自然无内容可复制。

## 目标行为（三端）

| 行为 | App | PC 网页 | 手机网页 |
|---|---|---|---|
| 标签/工具栏点击 | 单击即切换/生效，可拖拽排序 | 点击切换 | 点击切换（不启用拖拽） |
| 有选区时右键 | **直接复制，不弹菜单**（终端惯例） | 右键/长按菜单含「复制」 | 长按菜单含「复制」 |
| 无选区时右键 | 弹菜单（复制/清屏/搜索） | 浏览器菜单或自定义菜单 | 长按菜单 |
| 应用请求鼠标时选文 | Shift+拖选走本地选区 | 同左（Shift+拖） | 长按+拖选（触屏） |
| 选即复制 | 拖选松开即复制 | 拖动结束即复制 | 长按选中后复制按钮/菜单 |

## 验收（先红后绿）

1. `terminal_pointer_probe` 三条断言：标签点击切换、拖选产生选区且复制回调收到非空文本、右键后选区仍在。
2. 网页端 e2e：点击标签切换、长按/右键复制（Playwright 可模拟 button: 'right' 与 touch）。
3. 真机：在终端里跑 opencode，Shift+拖选可选中文本，右键直接复制，粘贴到别处内容一致。

## 非目标

- 不实现 terminal 里「双击选词」之外的语义选择（列选/块选）。
- 不改 opencode 自身行为；只补终端侧能力。
