# 需-3 实现细则：记忆类型前缀约定（2026-10-30 裁决 ③ 批准）

结论：结构化记忆不动 telemem 存储 schema，**类型编进记忆正文前缀**，DevDesk 侧约定解析。

## 前缀约定

- 四类：`[踩坑|决策|契约|环境]`，写入格式 `[踩坑|分库分表] @Transactional 不生效…`（`[类型|标签] 正文`）。
- 无前缀正文合法（兼容存量与云端提炼未打标产物），渲染归「未分类」。

## 落点

- 入库：`addDirect` 文本按上式带前缀；infer 提炼产物两条路——① telemem infer prompt 经 `TELEMEM_CONFIG` 定制（mem0 系支持 custom prompt，实现期核实）让云端直接打标；② 不可定制则 DevDesk 侧对提炼产物后处理补前缀。
- 注入：`assembleContext`（`src/module_memory/hook/inject.cpp:32`）解析前缀按类型分组渲染（如「⚠ 踩坑 2 条 / 📌 决策 1 条」），踩坑置顶；无前缀入未分类尾组。
- 抗坑：telemem `search_memories` 返回融合段落时逐条 metadata 不可得（`telemem_client.h:57`），前缀在正文内不依赖 metadata，天然免疫。

## 验收口径

1. 直存带前缀记忆 → hook 真跑注入 → 注入文本按类型分组（截图留痕）。
2. infer 真调一次 → 产物落库带前缀 + 控耗面板 token 计数非零。
3. 无前缀存量记忆 → 注入不报错、归未分类组。
