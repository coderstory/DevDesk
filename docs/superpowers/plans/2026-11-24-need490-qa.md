## 5. 问题与建议

1. **P1（门禁阻断）**：`web_auth.cpp` 补 `#include <system_error>`；这是 Windows CI 风险（MSYS2 libstdc++ 不传递包含）。
2. **P1（待技术确认）**：SSE 并发受 HTTP 线程池 9 限制，64 上限与 503 分支实操不可达，且可能饿死其他 API；建议并发开流探针复核（8/9/10 条分界）后定修法（扩大/隔离 task queue 或流式连接专用处理）。
3. **P2**：网页侧 `bind.revoke` 只清票据不广播 `revoke`，其他在线端不会 5 秒内收到「绑定已撤销」；桌面删除绑定路径才有广播。若 PRD 允许网页自撤销需同步广播，请产品裁决。
4. **P2（口径）**：票据满/登录锁定为「密文内 s=409/429 + HTTP 200」，握手 429 与会话满 409 是真实 HTTP 状态；与 PRD「409/429」字面不完全一致，建议在技术卡明确「信封内状态码」口径。
5. 既有红 bug#495 单独跟踪，不计入 need#490。
