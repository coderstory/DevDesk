## 0. 执行协议（铁律）

1. **worktree 隔离**：涉及编译/测试的子任务必须走 worktree，开发完毕合并后立即 `git worktree remove` + `prune`。
2. **子代理派发**：具体开发任务一律派子代理，主会话只做编排、方案裁决、结果验收。
3. **编译/测试仅定向**：子任务只跑定向编译 + 受影响模块的定向测试，禁全量重建与全量套件。全量收在主会话里程碑关口跑一次。
4. **编译/测试同时只许一个**：构建槽仅 1，并发上限 8。
5. **修复类任务先修后统一验证**：子任务只改码 + commit，不跑测试；全量验证主会话统一收口跑。
6. **spec 走独立审计不经用户检阅**：spec 写完派 skeptic agent 证伪，不回用户过目。
7. **派单前锁死 URL→类→DTO 链路**：grep 前端真实 URL + method → 按 URL 段名反推后端类 → 返回 DTO → 明细 DTO 类名；每环有 file:line 证据后才派活。
8. **台账先行（2026-10-22 立，A2 漏派教训）**：任何批次的清单必须先写成台账行（如 H 表）再派发——台账行就是派发契约；批次完成通知回主会话后必须按台账逐行对账核销（报告 vs 清单），缺项立即唤醒补做。
