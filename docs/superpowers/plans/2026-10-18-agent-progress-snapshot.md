## 六、仍然有效的硬约定（没变，别踩）

- 构建一律 `bash scripts/build-test-run.sh`，禁手敲 cmake；probe 单独跑（`ctest -L probe`），build-test-run 不含它。
- 日期由宿主注入 system prompt（模型没时钟）；显式 `app.notify` 走系统通知，run-end 仍走应用内 toast。
- AI 草稿三原则：宿主做确定性校验 / 单项失败只降级警告 / 生成结果永不自动保存。
- 明确不做：闹钟不补跑；通知不推 OS 级定时（launchd / 任务计划程序）；热榜不合并多源；不改 `listOverdue` 归档语义。
- 不 push 任何远端；绝不读取或回显 profile 密钥，连通验证只用 `claude.test_connection`。
- 业务代码禁平台宏（`#ifdef _WIN32` / `__APPLE__`），平台差异拆文件 + CMake 选源；`module_*` 间不互依赖；不抛异常，错误走 `Result<T>`。
