## 二、H13 架构债（必查）

### 事实链

1. `71ce7d4c`：`fluidPhaseSeconds()` 改 `steady_clock` 壁钟。`g_fluidPhase`（app_sidebar.cpp:71）**变为只写死状态**——onFrame 回调（:611-613）仍在 `g_fluidPhase += clamp(dt)`，但无任何读者（grep 全仓仅 3 处：定义/复位/回调写）。:68-70 注释仍描述旧的 onFrame 相位钟语义，已 stale。
2. 探针 `h13_fluid_background_probe.cpp` 头注释宣称「额外帧泵采样：md.tree.anim.driver / splash.ink」——**实际未实现**，探针只采 `fluidPhaseSeconds`（151818f9 的原始设计在 71ce7d4c 被缩水）。
3. 壁钟化丢弃两项文档化语义（:68-70 与 :605-610 注释明示）：(a) 隐藏/托盘期间相位冻结、恢复从冻结处继续；(b) dt 钳 0.1s 防休眠恢复时间跳变。现改为壁钟后：休眠恢复相位跳变数小时、隐藏期间相位照走。行为变更无台账/注释裁决。
4. **md.tree.anim.driver 静止**：markdown_module.cpp:462-465 泵已整段注释掉，注释自认「真机收敛泵待 EUI-NEO runtime/layout cycle 修复后重新启用」。真机上树折叠 lerp 只在 compose 推进、无泵即无持续帧 → 回到 UAT5 原症状（逐输入步进）。无头测试 40 帧直泵掩盖。
5. **隐藏耦合（新发现）**：`drawFluidBackground` 门控 `if (!fluidBackgroundEnabled()) return`（:546）——fluid 开关关闭时 `app.fluid.anim.driver` 不挂载。该 driver 的 onFrame 是**全 Runtime 唯一的常驻持续帧源**（置 `animating_` 保持 compose 循环）。因此 md 树折叠动画**仅在流体背景开关开启时因旁路效应正常工作**，fluid 关即逐输入步进。跨功能隐性依赖，无文档。
6. splash.ink.anim.driver：**不静止**。泵在场（splash.cpp:168-171）+ 进度源本身是 steady_clock（`elapsed/kInkDurationSec`）+ `app::requestUpdate` 双保险，且仅启动 2.3s 生命周期，无需修复。

### 根因证据评估

「onFrame 运行时断投」作为普遍结论**证据链可疑**：EUI 侧 `pollOnce` = `runtime.update` → `updateElementTree` → `updateFrameCallback`（runtime_update.h:407/666）链路健全；探针旧帧循环（151818f9 版 `beginFrame/render/present`）根本不调 update，红因在 harness；71ce7d4c 同时改帧循环+改壁钟，未做「只改帧循环、保留 onFrame」的对照实验，且壁钟后探针 `delta>0` 恒真不可证伪。md 侧 bad_function_call 是另一个具体缺陷（update/layout 期回调生命周期），非「onFrame 普遍不投」。

### 修法评估与推荐

- (a) app 侧三处同款 elapsed 绕过：快，但产生三份绕过债 + 必须自行补回冻结/钳制语义，且**修不了 md 树**（md 树问题不是时间源是帧源——没有持续 compose，壁钟也推不动 lerp）。
- (b) EUI 侧修根因：符合「EUI 上游优先」，但根因未被静态定位——当前证据不支持「onFrame 普遍断投」，贸然「修投递」会修错对象。

**推荐：有界 EUI 定位优先**（≤1 次派单时间盒）：
1. 先在 EUI 复现 md 侧 bad_function_call（onFrame 回调在 update/layout 期元素 move/destroy 的生命周期缺陷——这是唯一有实锤的 EUI 缺陷）；
2. 复现成功 → 单点修 EUI，md 泵恢复、fluid 可回退 onFrame 或保留壁钟但统一封装；
3. 时间盒内定位失败 → 退 (a)，但必须满足三条：(i) 单一 `kAnimClock` helper（wall-clock + 显式 freeze gate）供三处消费，禁三份复制；(ii) md 树走 wall-clock + `requestUpdate`（自持帧源），不得依赖 fluid driver 的旁路泵；(iii) 隐藏冻结/休眠钳制语义作为明示裁决写入台账，不默认丢弃。
