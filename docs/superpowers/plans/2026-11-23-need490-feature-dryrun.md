# need#490 网页终端功能走查（feature dry-run）

- 日期：2026-11-24
- 基线：PRD `2026-11-23-web-terminal` v11 / 技术卡 `2026-11-23-web-terminal-tech` v9 / ADR 0009、ADR 0010 v2 / 实现计划 W1–W7
- 方法：只读推演。按真实使用场景走查 6 组生命周期，对照 PRD 条款与仓库现有代码；**未启动服务、未跑测试、未抓包**，结论以推断为主。
- 口径：`有` = PRD 有明确条款与验收；`部分` = PRD 一句带过或规则有但体验缺口；`无` = PRD 未提。成本粗估三档：小（≤1 人日、不动协议）、中（改协议/后端/新 UI，2–5 人日）、大（新机制或跨仓能力，>5 人日）。

## 0. 结论先行

1. **功能覆盖率高、实现率为零**：F-01～F-26 共 26 项全部有 PRD 条款与验收，服务端代码 0 行；可复用实物只有二维码编码器（含单测）、前端主界面/配置页 mock 骨架、Playwright 冒烟与 HTTP 底座能力。
2. **最大落地缺口不在协议，在移动键盘**：PRD 明确不做快捷键条，但手机软键盘没有 Esc / Ctrl / Tab / 方向键；主用途「手机上跑 claude code」的中断、权限选择、补全三件事在手机上不可达（P0）。
3. **断线韧性只覆盖了「连不上」，没覆盖「连上后丢什么」**：重连期间输入丢弃、重连后滚动位置回底、手机切后台回前台不主动重连，PRD 均无条款（3 条 P1）。
4. **生命周期缺一段**：桌面应用重启后所有 PTY 会话消失，但 PRD 只定义了「服务关闭 / 网络中断 / 进程退出」，网页端会看到空态而无任何解释（P1）。
5. **运维与安全各有一处可利用面**：握手限流是全站 32 次/分钟，局域网任意人可耗尽导致合法用户被 429；二维码截图转发可被他人抢先绑定且桌面无告警（各 1 条 P1）。

## 2. Top5 缺失项

1. **P0 C1 手机软键盘缺 Esc/Ctrl/Tab/方向键** — 主用途（手机跑 claude code）实际不可用；需产品复核裁决 14。
2. **P1 B1 重连期间输入丢失** — 断线时敲的内容静默消失，无待发队列。
3. **P1 B2 重连后滚动位置回底** — 回看历史被拉走，长日志场景高频。
4. **P1 A1 桌面重启会话全灭无说明** — 用户以为会话还能回来。
5. **P1 F1 握手全局限流可被他人耗尽** — 单点把所有人挡在登录页外。

## 3. 走查记录（场景 → 结论）

1. **首启 → 扫码 → 绑定 → 登录 → 用 → 关 → 再用**：流程 A/B/C 节点闭环完整；隔天复用的真实阻碍是 P-02 默认关（A4）与桌面重启丢会话（A1）；换网络/换端口文案误导（A2）；清缓存回登录页无解释（A3）。
2. **连接韧性**：PRD 对「连不上/服务关/撤销/票据失效」覆盖到位；对「重连过程中丢什么」基本空白（B1 输入、B2 滚动、B3 回前台、B5 过期感知、B6 半开）。重连后光标由整屏帧给出，不丢；滚动位置丢。
3. **终端能力**：滚动、复制、粘贴、宽字符、颜色、字号、tab 增删切、会话重开、启动目录、shell 选择均有条款；缺口集中在移动键位（C1）、tab 可辨识性（C2）、回看质量（C4）、emoji 宽度（C5）、共享字号的跨端摩擦（C6）。
4. **多端协同**：同时输入/切 tab/改设置均有明确裁决；未覆盖的是尺寸回落（D1，裁决本身即缺口）、resize 抖动（D2）、并发关 tab（D3）。
5. **运维可观测**：只有登录失败日志与可选在线数；自诊链路（最近错误、日志入口、防火墙提示、服务存活）全部缺失（E1/E2/E3）。
6. **安全边角**：撤销绑定、票据保护、明文抓包要求覆盖完整；薄弱点是二维码截图抢先绑定（F2）、全站握手限流可被滥用（F1）、时钟漂移文案（F3）。
