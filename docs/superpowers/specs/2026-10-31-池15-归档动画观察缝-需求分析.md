# 池 15 · 归档折叠动画「重复触发禁止」观察缝 · 需求分析（M 级）

> 来源：池 15（buglist 编号 BUG-8，2026-10-29 登记「测试缺口，低」）；老板 2026-10-31 令「现在补」。
> 定性：**测试缺口，非功能缺陷**——行为本身已实现且在跑，只是不可观测、无法自动化断言。

## 一、背景与现状

- todo_module 的归档折叠动画带「动画期重复触发禁止」守卫（动画进行中再触发归档/展开被私有状态机拒绝）。该状态机为模块私有，无外部查询缝 → agent_e2e / QA 无法断言此守卫存在且有效（测试红不了也绿不了）。
- 既有测试设施先例：EUI-NEO aba0079 公开 `hitTestInteractiveAt` 只读命中查询「测试驱动设施用」；债-18 已交付场景 JSON 驱动入口（点击/键入/滚轮/拖拽 + 逐步报告）。本缝与两者同构：**只读观察，不改变行为**。

## 二、目标 / 非目标

**目标**（90% 核心）：给 todo_module 归档动画状态机开一个**只读观察缝**（状态查询接口 + 测试钩子），使「动画期重复触发禁止」可被自动化断言；QA 据此补断言用例。
**非目标**：不改动画行为/时序/手感；不做通用动画测试框架；不为其他动画批量开缝（后续同类缺口各自入池）。

## 四、状态集（自查清单）

- **空态**：无任何动画进行时查询 → 返回空闲态（非错误）。
- **边界**：动画最后一帧重触发（守卫应仍拒）；动画刚完成的瞬时重触发（应放行新动画）。
- **错误**：todo 模块未加载/数据空时查询 → 空闲态或明确「模块未就绪」，不得崩溃。
- **平台差异**：动画时长/帧率 macOS 与 Windows 可能不同 → 断言用条件轮询（等待状态迁移）而非固定 sleep；两平台断言口径一致（AGENTS.md §三 双平台一等公民）。

## 五、关联影响与验收标准

- 关联：todo_module（改动唯一落点）；agent_e2e 驱动入口（断言用例载体，复用债-18 设施）；EUI-NEO 无涉（缝在 DevDesk 侧）。
- 验收：
  - **F-01**：查询缝可用（测试代码能读到状态迁移），且对生产行为零改变（动画表现 diff 为零）。
  - **F-02**：断言用例落地且**会红**——临时注释守卫代码时用例必红（会红性判据，见评测任务 C2）；守卫在位时绿。
  - **F-03**：四类帧边界断言全过，双平台口径一致（Windows 侧可按等环境注记挂账，同债-19 F-08 口径）。
- 证据：`evidence/` 归档 + 路径写回测试清单卡。
