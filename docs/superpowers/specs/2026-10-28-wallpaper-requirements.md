## 术语（人话版）

- **模块**：DevDesk 里的一个可选页面。在「设置 → 模块」里打开，侧边栏就多一个入口；关掉就消失。
- **WorkerW**：Windows 桌面上「图标后面那一层」的窗口。壁纸要垫在图标后面，就是把画面挂到这一层。
- **mpv**：一个开源播放器程序（好比“隐形的视频播放机”）。DevDesk 把它随安装包一起分发，用它来播视频和图片，但界面上看不到它。
- **IPC 管道**：两个程序之间传话的专用管道。DevDesk 通过它指挥 mpv（播哪条、暂停、音量）。
- **让路**：特定系统事件发生时（锁屏、全屏看视频、用电池……）壁纸自动暂停，把资源让给正事；事件解除后从断点继续播。
- **轮换**：片库里有多条视频/图片时，按设定的间隔（如每 10 分钟）自动换下一条。
- **档位过滤**：分辨率太低的图片（小于 2K 档）不放进轮换池——拉满屏会糊。

## 永久不做清单

照原始交接文档 §1.3（原文已灭失，经 P1 spec §5 转录，两处一致）：

1. **转码 / 降帧**：不为素材做格式转换或降帧率处理，播不了就是不入池。
2. **维护 / 删除当前壁纸**：不提供对正在播放素材的管理操作（改名/删除/移动）。
3. **多显示器壁纸**：只做主显示器，多屏扩展不做。
4. **玻璃 / 半透效果**：壁纸层不做毛玻璃、半透明等视觉特效。
5. **独立应用与安装器**：壁纸永远是 DevDesk 的内嵌页面模块，不拆独立程序、不做自己的安装器（DevDesk 本体的安装器是另一回事，壁纸只随包走）。

## macOS 本阶段口径（明确）

- 代码**未写**：没有任何 macOS 平台实现（无 .mm 文件、无能力为 true 的路径）。
- 用户在 macOS 上：侧边栏无壁纸入口、设置里无壁纸格——一切不可达，这是**设计行为**而非缺陷。
- 「仅保证构建通过」不等于「macOS 可用」；第二阶段（P8）需平台实现 + 真机 UAT 双过关后才可改变此口径。
