# 调度规则编辑弹窗 UI 设计（R3 UI 接线波）

- 日期：2026-10-29。作者：UI/UX 设计师。
- 依据：spec §4.2/4.3/4.4、审计报告 `2026-10-29-schedule-audit-A-report.md` P1-3/P2-6、`schedule_ui_edit.h` 既有契约。
- 交付：本文档 + 自包含 HTML demo `docs/mockups/schedule-edit-dialog-demo.html`（交互原型载体，不代表实现技术）。
- 门控结论：新功能级 UI（新增操作路径），走完整设计阶段，不可跳过。

## 0. 结论先行

弹窗本体（表单/校验/预览，`schedule_ui_edit.*`）已实现且契约冻结，本次设计只解决三件事：

1. **入口接线**：列表页用户段加「新建」主按钮 + 行级「编辑 / 启停 / 删除」三操作（删除二次确认）。
2. **actionJson 三字段**：按 actionKind 动态出输入控件；`run_task` 的 key 用**注册表下拉**而非自由文本，从根上消灭键名错写。
3. **键名统一**：定为 `"key"`（改 `schedule_ui_edit.h:77` 的 `"task_key"` 一行对齐 `action_runner.cpp:60`，一行改动，不动 runner）。

顺手修：P2-6 两处摘要键名（`nth_weekday_nth`→`nth_weekday`、year 的 `month`→`month_day`）。

## 1. 列表页入口（schedule_ui_list）

用户定时段每行两段式：主体区域点击 = 打开编辑；行尾操作区固定三项。

| 操作 | 形态 | 行为 |
|---|---|---|
| 新建规则 | 工具条右上**主按钮**（40-44px 高，主色填充）| 打开空表单弹窗（kind 默认 Once）|
| 编辑 | 行内**文字按钮**「编辑」| 打开 `formFromRecord` 回填的弹窗 |
| 启用/暂停 | 行内 **switch**（现成 `wswitch`）| 走已有 `setRuleEnabled`；暂停态整行文字降为 `--text-tertiary` |
| 删除 | 行内**文字按钮**（警示红 `--error` 文字，非红底）| 弹二次确认小弹窗（Standard 460）：正文含规则名 + 「彻底删除」复选项（勾选 = 物理删除，默认软删）|

系统定时段：无任何操作控件（只读，§4.2），不加锁图标以外的装饰。

## 2. 编辑弹窗布局（沿用 drawEditDialog，宽 Form 760）

自上而下四区，间距 16，卡内边距 16：

1. **基本信息**：名称输入（必填，1 行）+ 启用开关。
2. **触发规则**：kind 六选用**分段选择**（Once/间隔/日历/Cron/事件，一次只显一个的字段区，切换保留各自已填值）。动态字段区按 `EditFormState` 既有字段渲染，不新增字段。
3. **动作**（§4.3）：actionKind 四选下拉；下方动态出载荷控件——
   - `remind`：无控件，灰字说明「仅提醒，按所选渠道投递」。
   - `remind_open`：deeplink 输入框 + 提示文案（格式 `页面标识[:参数]`），旁挂「常用页面」下拉快捷填入。
   - `run_task`：**任务下拉**，选项来自任务注册表（内部任务 key + 人话标题），禁自由输入；选中的 key 写入 `{"key": ...}`。
   - `webhook_only`：无控件；保存时校验渠道必含企业微信，否则红字提示。
4. **通知渠道 + 错过策略**：渠道多选（`EditDialogHost.channels` 注入）；错过策略三选 radio（once/skip/all），`once` 选中时出「迟到窗口」小输入（默认 24h）。

**预览区**（既有 `previewNextFires`）：弹窗底部固定一条「接下来 5 次触发」时间列表，随表单实时刷新；校验红字（`errorText`）就地显示在预览区上方，红字出现时保存按钮置灰。

**按钮区**：右对齐 [取消(文字)] [保存(主)]；落库失败红字（`saveError`）就地显示。

## 3. 设计 token（对照 spec §6.5.1，不改任何值）

主色 `#D97757`、正文 15px、标题 18px（弹窗内）、说明 12px、间距 8/16、圆角按钮 10 / 弹窗 14；错误用 `--error #CF2D56`（Dark）。浅底文字用加深档保 ≥4.5:1。

## 4. 交互细节

- kind 切换不清空各 kind 已填字段（`EditFormState` 本就分字段持有）。
- 校验失败不关弹窗、不落库（既有契约）。
- 弹窗关闭态常驻构建（既有约定），列表开关弹窗无动画依赖，过渡 ≤200ms 缓出。
- 删除确认弹窗焦点默认在「取消」，防误回车删规则。
