## 0. 已拍板定案（本文出发点，不再论证）

路线：**A telemem 面板起步**——引擎能力全用第三方，DevDesk 只做治理层；从第一天预留两条缝（写入拦截点、检索接口，见 §2），短板暴露后按 §4 触发线升级 C，实测全绿则 A 独跑不升级。

七项定案：

1. **提炼走云端大模型**：记忆提炼（把对话读成一条条记忆）调云端大模型，复用 DevDesk 网关配置注入；本机大模型档（Ollama + qwen3:8b，约 5GB 下载）出局。
2. **脱敏默认开启，面板可关**：数据出机（发给任何云端接口）默认必先过脱敏；关闭入口在面板，需二次确认并显式警示「敏感信息将原样出机」。红队验证资产照常保留——关闭态 = 验证通过的能力未启用，风险由用户自担。
3. **外部依赖版本迭代不计风险**：telemem 钉死 mem0ai 旧小版本一类上游依赖问题，不作为路线否决项。
4. **向量化与提炼均走云端**：embedding（把文字转成向量的模型）调云端 OpenAI 兼容接口，与提炼同样经 DevDesk 网关注入；DevDesk 侧无任何本机模型组件。端点已定案：智谱 paas/v4，见下方「端点与消耗控制」块。
5. **卡片 = DevDesk 侧记账**：提案、状态机、撤销链全套落在自家 proposals 表（B4 原设计），telemem 的修改/删除由卡片代理层执行。
6. **Python 分发 = 首跑安装**：面板检测本机缺 Python 3.10~3.12（实际要求区间，口径以本条与 §1 为准）时引导安装，DevDesk 安装包不捆绑解释器。检测按区间实现：3.13 及以上同样在检测步即拦截引导，不放行到 pip 安装步才失败。
7. **升级触发线**：冻结评测集转测 telemem 检索，Recall@5（前 5 条命中率）< 85%，或 2 字中文词命中低于自研基线 5/3/11 → 升级 C 补全文通道；P0 自研规格书（`docs/superpowers/specs/2026-10-27-memcpp-p0-core-spec.md`）自本文起降级为触发线备用图纸。

### 端点与消耗控制（2026-10-27 追加定案，落在七项定案之上）

**端点（智谱 paas/v4 OpenAI 兼容通道）**：

- base_url = `https://open.bigmodel.cn/api/paas/v4`（智谱开放平台标准接口，OpenAI SDK 直接可调）；提炼 chat 模型 = `glm-5.3-flash`；向量化 embedding 模型 = `embedding-3`，显式 `dimensions=1024`（该模型没有 768 维档；维度在建索引前定死，换档即全量重嵌）。
- key 取自用户既有 Claude Code 配置中的智谱 key：运行时读取注入 telemem 配置，绝不写入仓库与日志，不新增凭据来源（呼应 §2 ⑥）。
- 单价等计费事实以调研文档为准（`docs/superpowers/research/2026-10-27-memcpp-zhipu-endpoint-research.md`），本文不复抄；§5-1「网关 embedding 接口可用性」推测项由本块关闭。

**消耗控制（一等设计，五条即验收判据）**：

| # | 措施 | 验收判据 |
|---|---|---|
| 1 | 只对新增内容提炼：去重水位（记录已提炼到的会话位置，水位之后的内容才调云端） | 同一段已入库内容被重复摄取时，云端提炼调用次数为 0 |
| 2 | 提炼批处理节流：每小时云端调用/桶数上限可配置，默认保守值 | 达上限后调用排队顺延到下一窗口，不报错、不丢采集数据 |
| 3 | 月度 token 预算上限，软/硬两档（token=模型计费的最小文本单位） | 软档：逼近预算时面板出现黄条提醒；硬档：触发后暂停提炼（新采集入队暂存），检索不受影响 |
| 4 | 面板消耗页 | 展示今日/本月 token 用量与估算金额、最近调用记录，数字与内部账面一致 |
| 5 | embedding 每条记忆仅计算一次（维度固定，不重嵌） | 已入库记忆的检索/读取操作不产生新的 embedding 调用 |

风险注记：套餐 key 用于后台常驻提炼偏离智谱套餐使用条款（官方限「指定工具与产品环境」），用户 2026-10-27 知悉并接受。

## 1. 目标与形态

一句话：DevDesk 新增一个「记忆面板」，形态 = telemem 的安装 / 配置 / 启动管理 + 一层治理（脱敏强制、注入预算、卡片人审）。

telemem（Python 写的第三方长期记忆库，自动把对话抽成记忆条目并提供检索，Apache-2.0）与 DevDesk 的进程关系：

| 环节 | 形态 |
|---|---|
| 安装 | pip 安装（Python 官方包管理器拉取第三方包）。DevDesk 不捆绑解释器：面板首跑检测本机 Python 3.10~3.12（telemem 要求区间），缺失则引导用户安装后继续 |
| 配置 | DevDesk 生成配置文件，经 `TELEMEM_CONFIG` 环境变量（telemem 官方配置注入口）喂入；不写用户家目录、不改 telemem 默认配置 |
| 运行 | 常驻进程：默认本机回环 HTTP（只绑 127.0.0.1:8421，外部机器连不上），备选 stdio（标准输入输出上的 JSON-RPC 对话）；DevDesk 托管拉起/终止/健康检查 |
| 懒加载 | telemem 的 Memory 实例首次调用才创建，配置错误表现为工具级结构化报错而非进程崩溃——壳按「进程活着但报错」处理，不误杀进程 |

## 2. 架构（文字图）

```
Claude Code 会话（jsonl 尾读；jsonl=每行一个 JSON 对象的文本文件，尾读=只读文件新追加的部分）
   │ ① 采集：DevDesk 增量尾读会话记录
   ▼
② 脱敏闸（默认开，面板可关；定案 2）
   │ 提炼与向量化两次出机均过闸；面板关闭时两次出机同样旁路直连网关（敏感信息原样出机，用户已经二次确认）
   ▼
③ telemem 入库（add()，提炼走 ⑥ 注入的云端大模型）
   │
   │      ┌──────────────────────────────────────────┐
   │      │ telemem 常驻进程（127.0.0.1:8421 回环）  │
   │      └──────────────────────────────────────────┘
   ▼
④ hook 同步注入（UserPromptSubmit 预载，预算 ≤5 条 ≤500 字）
   │ 壳不直连引擎，走「检索接口缝」：一层 DevDesk 内部接口
   │ A 阶段实现 = 转发 telemem search + 逐条预算重排版；
   │ 升级 C 时替换实现 = 查自家全文库，调用方零改动
   ▼
⑤ 卡片人审（定案 5）
   │ 提案落 DevDesk 自家 proposals 表（B4 全套：状态机/撤销链/版本校验）
   │ 接受后由卡片代理层调 telemem 的 update/delete 工具执行
   ▼
⑥ 网关配置注入
   复用 DevDesk Claude 代理模块的 profile 管理，
   把用户已配好的网关地址/密钥注入 telemem 的 OpenAI 兼容配置，不新增凭据来源
```

两条缝（升级 C 的预埋点，A 阶段零额外成本）：

- **写入拦截点**：入库前必经 ② 脱敏闸；闸开启时 telemem 拿不到未脱敏原文，闸关闭时原文按用户决定原样通过。
- **检索接口缝**：④ 只调 DevDesk 内部接口，不 import/直连 telemem；接口后端可换。

### 卡片记账细节（定案 5 展开）

- 唯一真相 = DevDesk proposals 表：B4 §1 的 kind / targetIds / baseVersion / undoOf 等契约原样落地。
- telemem 侧无待审状态：卡片代理层在「接受」之后才调 `update_memory` / `delete_memory`；执行失败重试，成功后回写 `appliedAt`。
- 撤销链完整：撤销走 `undoOf` 新提案再审一次（B4 §1.2/§1.3），telemem 侧按逆操作再执行一次；telemem 的 history.db 只作对账参考，不当真相源。
- 注入预算只约束 hook 静默档；卡片通道不走 hook、不占预算（B4 §4 不变）。

## 4. 触发线与降级

### 升级 C 的量化条件（定案 7，预先写死避免临场扯皮）

S1-4 / S5 中冻结评测集转测 telemem 检索，任一命中即升级：

- Recall@5 < 85%（自研全文基线 1.00）；或
- 2 字中文词「端口/配置/模块」命中数低于基线 5/3/11。

升级动作：在检索接口缝后补自家全文通道（SQLite FTS5=其内置全文检索引擎，双字分词 + 短查询 LIKE 兜底，按 P0 规格书 §2.3/§2.4 施工——该规格书已降级为触发线备用图纸）；治理层（脱敏闸/预算/hook 壳）与面板零返工；卡片代理层重接自家库，telemem 存量记忆经其列表接口导出回填。

反向出口：实测全绿（向量方案扛住 2 字中文）→ A 继续独跑，不升级。

### telemem 故障降级线

- **引擎挂**（进程崩 / 端口不通 / 依赖损坏）：停止新抽取（采集暂停、入队待恢复），面板显式提示故障与恢复入口；已入库记忆不丢（本地 FAISS 向量索引库 + SQLite 文件仍在）。
- **云端链路失败**（网关 key 失效 / 断网 / 提炼或 embedding 报错）：采集不丢——入队暂存待恢复，面板显式提示外发失败原因；恢复后自动补跑，全程不静默漏采（验收判据落在 S3）。
- **注入路径**：检索接口缝已接自家库（升级 C 之后）→ 全文通道独跑，只停抽取不停检索；A 阶段缝后只有 telemem → 注入静默失败（失败开放：用户只丢预载、不被打断）。
- **hook 通道本身故障**：按钉版契约处理——任何内部错误吞掉并 exit 0，绝不阻断用户提问（exit 2 是 hook 唯一能打断用户的路径，禁用）。
