## 0. 结论速览

- **布局**：两栏。左=目录树与变更列表**纵向合一栏**（变更列表上、目录树下，树段可折叠）；右=内容/diff 视图。
- **合并方式取舍**：选「树下列表」纵向堆叠，弃 tab 切换（理由见 §2）。
- **密度主张**：diff 行高 20px / 变更条目 30px / 树行 26px，全页零分页器、外壳不滚、四区内滚。
- **主题**：色名 token 化浅/深两套成对映射（§4），demo 一键切换。
- **demo 覆盖**：主路径 N1→N3→N7→N8 + 空/加载/错误/成功四态 + 记忆仓失效回 N2 + 中文路径 + 二进制/超大占位 + hunk 折叠 + 刷新过期条。

## 2. 两遍法记录

### 2.1 第一轮（只定构图与骨架）

- 核心色板：基线 14 值 token 全量沿用（§4），本页新增三类信息色族：git 状态色、diff 底色、语法高亮色（均随主题映射，先例 `md_highlight.cpp` 的 mdHighlightColors 走主题 token）。
- 布局概念一句话：**左栏是工作清单不是文件浏览器——变更在上、树在下、树可折叠让位；右栏一切尺寸为 diff 密度服务。**
- 草图两案比较：
  - 甲「树下列表」：左栏纵向两段，变更列表 flex 占大头、树固定默认 38% 可折叠。
  - 乙「tab 切换」：左栏顶部「变更｜文件」二选一，单区全高。
- 本页独特性原则句：*「打开这一页的前 3 秒是扫变更列表，不是逛目录树——所以列表永远可见、树学会让位。」*

### 2.2 第二轮（对照简报自审 + 改向记录）

| 自审点 | 初稿 | 判定 | 改向 |
|---|---|---|---|
| 合一方式 | 甲乙并陈 | 给同类工具页也会答「tab」= 默认脸；本简报主路径 N7→N8 要求列表常显，树着色联动（F-06⑤）若被 tab 藏起来，五件动线的「树着色」感知归零；且树区自身还有「全部/仅修改」模式切换，一栏两层切换=认知负担 | **选甲树下列表**，树段可折叠作空间让位机制（§5.4） |
| 变更/树谁在上 | 初稿树在上（文件浏览器惯性） | 主路径是 N7→N8（变更→diff），高频信息权重最高（基线四原则·操作高效）；树是次频动线 N4→N6 | **变更列表在上**，树在下 |
| 大胆单点 | 初稿想在顶栏/状态标签上做装饰性强调 | 记忆点应花在核心价值=diff 密度上 | **唯一记忆点=右栏 unified diff 三色行区**；其余全部安静：无插画、无渐变、无多余底色 |
| AI 五 tell | — | 无暖米色/暗夜霓虹/报纸排版/SaaS 卡片套件（白卡带边框是基线组件家族原样）/模板镀铬 | 通过 |
| 状态标签是否引入琥珀色 | 想全用基线四色 | 四态可区分（PRD F-06 硬验收）在绿红蓝灰内凑不出四个互斥色相（新增绿与修改不可同色） | 新增**一枚**新色相：修改=琥珀（§4 有论证），其余状态色全部锚在基线既有值 |

| 区块 | 锚定 | 尺寸 | 内容 |
|---|---|---|---|

| A 顶栏 | 顶缘通宽，固定 | h48 | 仓库名+完整路径（中截断）｜自动刷新指示位｜「切换仓库」次按钮｜「刷新」次按钮 |
| B 左栏 | 顶栏下、左缘，固定宽 | w300（窄档 264），内纵向两段 | B1 变更列表（上，flex≥200，内滚）；B2 目录树（下，默认高=栏高 38%、clamp(160,320)，可折叠为 36px 头条，内滚） |
| C 右栏 | 顶栏下、左栏右，自适应 | flex≥520 | C1 路径条 h40 固定；C2/C3 视图区占余高，纵横内滚 |
| D 空态页 | 替换 B+C 整区 | 居中块 | N2 选择仓库（§5.8） |

### 3.2 构图三问

1. **滚动模型**：外壳不滚（整页 100vh）；应用侧栏不滚（条目少）；A 顶栏、B 两段头、C1 路径条固定；B1/B2/C2/C3 四个容器各自内滚。与全站同类页一致（基线：长内容区内滚动、外壳不滚、无分页器）。
2. **无效空白**：无。左栏两段贴邻、组头行本身承担分组留白；右栏行高 20px 满密度；空态居中但必配就近操作（基线：空状态极简文字+就近操作）；无定宽空列、无弹性稀疏区。
3. **密度与权重**：高频=变更列表（主路径 N7→N8），占左栏上半与最大弹性；次频=树（N4→N6），固定 38% 且可折叠让位——最小窗 800×600 折叠树后 B1 仍有 ≈300px。宽档右栏 ≈956px 可见 diff 约 29 行，窄档 ≈468px 约 15 行，两档主体区/辅助区比例均成立。

### 3.3 信息密度预算（行高账）

| 表面 | 行高 | 720px 窗可见行数（宽档） |
|---|---|---|
| B1 变更条目 | 30 | ≈11（树折叠时 ≈17） |
| B2 树行 | 26 | ≈6（默认 38%） |
| C3 diff 行 / C2 内容行 | 20 | ≈29 |
| 组头行 / hunk 头 | 28 / 24 | — |
