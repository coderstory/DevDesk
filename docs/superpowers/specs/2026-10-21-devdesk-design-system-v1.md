# DevDesk 统一设计规范 v1.0（原文存档，2026-10-21）

> 用户交付的权威设计规范，逐字保留。本规范是 UAT6.2 设计规格与实现波的**最高值源**；与审计意见文档（`plans/2026-10-21-UAT62-用户UIUX审计意见.md`）不一致处，一律以本文档为准。

## 一、设计总原则
产品定位：面向开发者的轻量化效率工具，核心风格为**清新柔和、低视觉干扰、高信息效率**。
所有页面、组件必须遵循以下核心原则：
1. **一致性优先**：全App共用一套色彩、组件、交互规则，杜绝每页一套样式
2. **可读性达标**：文字与背景对比度严格满足WCAG 4.5:1标准，禁止浅灰文字配浅底色
3. **轻量化质感**：低饱和色彩、柔和阴影、圆润边角，减少视觉压迫感
4. **操作效率**：主操作位置固定、样式突出，培养用户肌肉记忆

## 二、基础设计令牌（Design Tokens）
所有组件、页面必须基于以下基础参数构建，禁止私自定义色值、字号、间距。

| 色值 | 名称 | 使用场景 |

| `#36D399` | 主色-默认 | 主按钮、选中态、强调文字、图标主色 |
| `#2EC48F` | 主色-hover | 可点击元素悬浮态 |
| `#23B07F` | 主色-点击 | 按钮点击态 |
| `#E6FBF2` | 主色-浅背景 | 选中态背景、高亮区块背景 |

#### （2）辅助色（首页数据卡片专用，统一饱和度20%、明度95%）
保证所有卡片视觉重量均衡，无某一张特别突兀。
| 色值 | 名称 | 使用场景 |
|------|------|----------|
| `#E6FBF2` | 浅绿卡片 | Token速率类数据卡片 |
| `#E0F4FF` | 浅蓝卡片 | 笔记类数据卡片 |
| `#FFF1E0` | 浅橙卡片 | 待办任务类卡片 |
| `#F3E8FF` | 浅紫卡片 | 逾期任务类卡片 |
| `#DFFAF6` | 浅青卡片 | API调用类卡片 |

#### （3）功能语义色（低饱和版）

| `#6B7280` | 三级文字 | 辅助说明、时间、标签、次要信息 |

|------|------|----------|
| `#FAFAF9` | 页面底色 | 全局页面背景 |

| 主色10%透明度 | 装饰圆形 | 页面背景装饰元素，统一透明度 |

### 2. 字体系统
- 字体栈：`Inter, "Microsoft YaHei", "PingFang SC", sans-serif`
- 行高规则：标题类1.3倍，正文类1.5倍，辅助文字1.4倍

| 字号 | 字重 | 行高 | 应用场景 |
|------|------|------|----------|
| 24px | 600 | 32px | 页面大标题（首页、一级页面标题） |
| 20px | 600 | 28px | 弹窗标题、区块大标题 |
| 16px | 600 | 24px | 二级标题、卡片标题、Tab文字 |
| 14px | 400 | 20px | 正文、按钮文字、列表文字 |
| 14px | 600 | 20px | 强调正文、数据标题 |
| 12px | 400 | 18px | 辅助说明、时间、标签、提示文字 |
| 28px | 600 | 36px | 首页数据卡片核心数字 |

### 3. 间距系统（8px栅格原则）
所有间距必须为8px的整数倍，保证视觉节奏统一。
| 尺寸 | 名称 | 使用场景 |
|------|------|----------|
| 4px | 超小间距 | 图标与文字间距、内边距微调 |
| 8px | 小间距 | 列表行间距、并排按钮间距 |
| 12px | 中间距 | 卡片内边距、表单元素间距 |
| 16px | 常规间距 | 页面内边距、卡片之间间距 |
| 24px | 大间距 | 大区块间距、弹窗内边距 |
| 32px | 超大间距 | 页面顶部与标题间距、大模块间距 |

### 4. 圆角与阴影
#### 圆角规范
| 尺寸 | 使用场景 |
|------|------|
| 6px | 小型控件：输入框、开关、小标签 |
| 8px | 常规控件：按钮、小型卡片 |
| 12px | 中型容器：数据卡片、任务卡片、弹窗 |
| 16px | 大型容器：首页大卡片、内容区块 |
| 50% | 圆形：头像、图标按钮、状态点 |

#### 阴影规范（柔和低对比）
| 层级 | 参数 | 使用场景 |
|------|------|----------|
| 轻微阴影 | `0 1px 3px rgba(0,0,0,0.04), 0 1px 2px rgba(0,0,0,0.02)` | 普通卡片、列表项悬浮 |
| 中等阴影 | `0 4px 12px rgba(0,0,0,0.06), 0 2px 4px rgba(0,0,0,0.03)` | 弹窗、下拉面板 |
| 深层阴影 | `0 10px 25px rgba(0,0,0,0.08), 0 4px 10px rgba(0,0,0,0.04)` | 顶级弹窗、拖拽元素 |

## 三、通用组件规范
### 1. 按钮组件
全App仅保留4种按钮类型，**常规高度统一为40px**（首页底部大按钮可使用44px），内边距水平16px，文字14px/600，圆角8px。

| 类型 | 默认态样式 | Hover态 | 禁用态 | 使用场景 |
|------|------------|---------|--------|----------|
| 主按钮 | 主色填充 + 白色文字 | 主色-hover填充 | 主色40%透明度 + 白色文字 | 核心操作：新建、保存、启用、下一步 |
| 次按钮 | 白色填充 + 主色边框 + 主色文字 | 主色-浅背景填充 | 灰色边框 + 灰色文字 | 次要操作：取消、测试、导入、上一步 |
| 文字按钮 | 透明背景 + 主色文字 | 主色-浅背景填充 | 灰色文字 | 三级操作：编辑、删除、查看更多 |
| 危险按钮 | 浅红背景 + 红色文字 | 红色填充 + 白色文字 | 浅红背景 + 红色40%文字 | 删除、危险操作 |

> 并排按钮规则：
> 1. 弹窗底部：右对齐，主按钮在最右侧，次按钮在左侧
> 2. 同级操作并排：宽度均等，间距8px
> 3. 页面主操作：固定在右上角，统一主按钮样式

### 2. Tab切换组件
全App**统一使用块面式Tab**，彻底淘汰所有下划线式Tab，保证视觉语言一致。

#### 页面级大Tab（设置页、切换器详情页）
- 高度40px，单个Tab内边距水平16px
- 未选中：二级文字 + 透明背景
- 选中：主色文字 + 主色-浅背景 + 圆角8px
- Tab之间间距4px

#### 弹窗级小Tab（编辑Profile弹窗内）
- 高度32px，单个Tab内边距水平12px
- 文字13px，其余样式规则与大Tab完全一致

### 3. 输入框与文本域
- 基础尺寸：单行输入框高度40px，文本域最小高度80px
- 基础样式：白色背景 + `#E5E7EB`边框 + 圆角6px + 内边距水平12px
- 文字规则：正文14px，占位符使用四级文字
- 状态规范：
  - 聚焦：主色边框 + 主色浅阴影
  - 禁用：浅灰背景 + 灰色边框 + 置灰文字
  - 错误：红色边框 + 下方12px红色提示文字（间距8px）

### 4. 弹窗组件
- 结构：顶部标题栏 + 中间内容区 + 底部操作栏
- 样式：白色背景 + 圆角12px + 中等阴影
- 内边距：内容区上下左右24px；底部操作栏上下16px、左右24px
- 标题：20px/600，左对齐，右侧可放置关闭按钮
- 底部按钮：右对齐，主按钮在最右，次按钮在左，按钮间距8px

### 5. 列表与选中态
全App所有列表（左侧导航、文件列表、Profile列表）必须遵循同一选中规则：
- 未选中：透明背景 + 二级文字
- 悬停：浅灰背景
- 选中：主色-浅背景 + 左侧3px主色竖线 + 主色文字
- 列表项统一高度40px，内边距水平16px

### 6. 数据卡片（首页顶部）
- 布局：所有卡片等宽等高，间距16px均匀排列
- 样式：对应辅助色背景 + 圆角16px + 无描边
- 内部排版（从上到下）：
  1. 指标名称：12px/三级文字
  2. 核心数据：28px/600 + 一级文字
  3. 辅助说明：12px/三级文字
- 内边距：20px

### 7. 任务卡片（Todo看板）
- 样式：白色背景 + 圆角8px + 轻微阴影
- 内边距：12px
- 色彩规则：**仅用左侧色条标识优先级**，卡片主体保持白色，禁止整卡涂色
  - 高优先级：左侧红色条
  - 中优先级：左侧橙色条
  - 低优先级：左侧绿色条
- 文字：标题14px/一级文字，时间/标签12px/三级文字

### 8. 开关组件
- 尺寸：高度24px，宽度44px，圆角12px
- 关闭态：`#D1D5DB`背景 + 白色滑块
- 开启态：主色背景 + 白色滑块
- 过渡动画：0.2s平滑过渡

## 四、页面布局规范
### 1. 全局框架
- 左侧导航栏：固定宽度200px，浅绿底色（`#F0FDF7`），全程固定展示
- 主内容区：自适应宽度，左右内边距32px，顶部内边距32px
- 页面标题：统一左对齐，24px/600，下方间距24px

### 2. 操作区规范
- **页面级主操作**：固定在页面右上角，统一主按钮样式
- **区块级操作**：放在区块标题右侧，使用次按钮或文字按钮
- **底部操作栏**：仅首页等特殊页面使用，按钮按优先级排布，主操作视觉最突出

### 3. 空状态规范
所有空白区域必须遵循统一空状态样式，禁止大面积留白：
- 居中排布：线性图标（主色）+ 标题文字 + 辅助说明 + 主操作按钮
- 文字层级：标题16px/二级文字，说明12px/三级文字
- 必须包含引导操作，降低空状态的失落感

## 五、交互与反馈规范
1. **Hover反馈**：所有可点击元素悬浮时统一有背景色/透明度变化，过渡时长0.2s
2. **点击反馈**：按钮点击时有0.98倍轻微缩放 + 颜色加深，过渡0.1s
3. **错误提示**：表单错误统一展示在输入框下方；全局提示使用右上角Toast
4. **长文本提示**：文字截断、图标按钮、次要说明，hover时通过Tooltip展示完整内容
5. **滚动样式**：可滚动区域展示细滚动条，hover时变粗，滑块颜色为主色

- ✅ 文字对比度全部达标，无浅灰文字配浅底色
- ✅ 首页数据卡片色彩明度、饱和度均衡，无突兀色块
- ✅ 弹窗结构、按钮位置、内边距完全统一
- ✅ 页面主操作固定在右上角，形成肌肉记忆
- ✅ 所有空状态均有引导内容，无大面积空白
