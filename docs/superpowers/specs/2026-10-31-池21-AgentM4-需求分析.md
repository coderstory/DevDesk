## 二、目标 / 非目标

### 目标（= 决策 R-3~R-6 的交付面，均已落地）

1. **事件触发**：core 层进程内 EventBus；todo/markdown 业务点 emit；Scheduler 订阅入队起 run；冷却窗口防风暴。
2. **任务级记忆**：任务可携带执行记忆，注入 system prompt；run 正常结束自动记录回复（**注：后半已被 W4 C3 裁撤，见 §四矩阵 F-08 与开放问题 Q2**）。

### 非目标（R-7 不做清单，硬边界；依据=用户拍板 YAGNI）

- 持久化事件队列 / 补发（与 cron「错过的触发不补跑」语义一致，spec §5.1）
- 状态事件（todo.overdue 等需轮询判定，成本不对称）
- 批量聚合（窗口内攒批合并 run——留 M5 评估，先要真实场景数据）
- 自动 LLM 摘要（对记忆做 LLM 提炼）
- 多 agent 编排 / MCP / 流式响应 / OpenAI function_calling（spec §13 同口径）
- 按事件粒度细分冷却配置（M4 计划裁决：落任务级 `cooldown_sec` 够用，无真实需求不建）
- **本 PRD 自身非目标**：EventBus 他线扩展事件（github-sync dirty 触发源等）、daily/once 触发类型（调度线产物）——均已有各自 spec/计划归属，本文只登记边界。

## 三、用户操作流程（验收照走）

1. agent 页 → 新建/编辑任务 → 触发类型选「事件」→ 勾选订阅事件（todo.created / todo.completed / md.saved，至少 1 个）→ 冷却留空（默认 300 秒）或自定义 → 保存。
2. 切到待办页新建一条待办 → 事件型任务自动起 run（不点手动）。
3. 300 秒内再建一条待办 → **不再**起 run（窗口内丢弃）；窗口过后再建 → 再次起 run。
4. run 详情可查：事件触发的 run 与手动/cron 触发同样落 agent_runs 三表可审计。
5. 编辑任务填「系统提示词」（执行记忆现行形态）→ 手动或事件触发 run → 该提示词注入本次请求。

## 五、完整状态集（自查）

**任务表单（事件分支）**
- 空态：events 未勾 → 保存拦截；冷却留空 → 默认 300s；systemPrompt 空 → 不发 system 字段。
- 错误：外部写入的坏 trigger_config → 点名 task WARN + 跳过，不崩不静默；UI 侧 triggerConfigProblem 标「配置异常」。
- 边界：事件风暴（连续保存笔记）→ 冷却窗口兜底（丢弃非排队）；app 未运行期间事件错过不补发；重启冷却清零；同任务事件/手动/cron 不并发（单闸）。
- 成败可见性：保存成败走既有表单反馈；误触发 run 可 cancel（M1 既有）；任务可禁用/删除撤销自动化。

**EventBus（core，非用户面）**
- 无订阅者 / 多订阅者 / token 析构 / handler 异常四态全测（test_event_bus.cpp 4 用例 + 后续补的派发序契约）。

**执行记忆（systemPrompt，W4 C3 形态）**
- 超长态：**无长度上限防护**（原 4KB 滚动未迁移）——登记为 Q6 待确认，当前依赖用户自律。
- 首次态：新建任务默认空串，行为与无记忆一致。

**平台差异**
- 本能力为纯进程内逻辑 + 既有 EUI-NEO 组件（dropdown/textarea/switch），**无平台差异面**；双平台（macOS arm64 / Win11）验收统一走 `bash scripts/build-test-run.sh` 全量绿即覆盖。历史上唯一平台相关事故（event_bus.h:108 try/catch vs Release -fno-exceptions）已于 2026-10-17 经 EUI-NEO `KEEP_EXCEPTIONS_RTTI` 豁免收口（backlog §四点七在案）。

## 六、关联影响

- **模块隔离**：module_todo / module_markdown 各加一行 emit、module_agent 只订阅，三者经 `core/event_bus.h` 解耦，模块间零依赖——`check-module-isolation.sh` 必须持续绿。
- **EventBus 已成跨线公共设施**：github-sync 线以它为 dirty 触发源扩了 8+ 事件。本 PRD 范围锁定 R-4 首批三事件；扩展事件的归属与契约登记见 Q7。
- **schema 遗留**：context_note / auto_note 两列停读写但仍在库（带 DEFAULT 保留），删除归 W6——届时 test_schema 列断言、补列迁移白名单（schema.h:606-607）同步收链。
- **触发类型面扩张**：现行 6 种（manual/schedule/resident/event/daily/once，task_draft_job.h:44-47），event 只是其一；本 PRD 只对 event 负责称。
- **下游消费**：run 落库三表（M1 语义）不变；事件触发 run 与其他触发 run 在 UI/审计面无差别。
