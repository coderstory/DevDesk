# DevDesk 用户指南

> 面向最终用户的使用说明。**测试用例数以运行输出 `Total:` 为准，不在文档写死**（最近一次记录：2026-10-03 macOS `Total: 1259 / Passed: 1253 / Failed: 0`）。
> 凭据与配置存放：API Key 与全部 app 配置存于本机 SQLite 数据库（见 §5）。
> 旧版指向的 `KNOWN_LIMITATIONS.md` 已删除——现存边界见 `DevDesk/CLAUDE.md`。

## 1. DevDesk 是什么

DevDesk 是一个**本地优先**的开发者桌面工具集（C++ 原生应用，单 exe），包含 8 个 Router 页面（其中可被设置页模块开关插拔的是 笔记 / 待办 / Claude / 智能体 / 壁纸 五项，壁纸默认关闭）：

| 模块 | 用途 |
|------|------|
| **首页** | 仪表盘：今日笔记 / 待办 / 逾期 / API 调用四张统计卡 + 最近编辑列表 |
| **Markdown 笔记本** | 笔记就是普通 `.md` 文件：FTS5 全文搜索（支持中文）、目录树 / 标签 / 大纲、编辑·双栏·实时(Live)·预览四态 + 键盘流、自动保存 |
| **Todo 看板** | 多列任务看板：拖拽跨列、优先级、截止日期、标签、搜索 / 逾期视图、右键列头管理列 |
| **Claude 切换器** | 多套 Claude API 配置（Profile）管理 + 本地流式代理（默认不启动；启动即自动接管 Claude Code settings.json，停止还原） |
| **智能体** | 任务（cron 触发）/ 运行记录 / 工具调用；有单次运行的时长与 token 上限 |
| **壁纸** | 桌面动态壁纸（P1 骨架，默认关闭；片库 / 播放后续版本接入） |
| **设置** | 外观（主题 / 字号 / 窗口效果）/ 模块开关 / 笔记目录 / Claude 代理（自启 · 端口 · Token · 接管）/ 日志保留 |
| **关于** | 版本号与项目信息 |

所有数据都保存在本机 `%USERPROFILE%\DevDesk`（macOS 为 `~/DevDesk`；见 [§5 数据都在哪](#5-数据都在哪)），不上传任何内容。

## 2. 启动与界面导航

启动 `DevDesk.exe` 后进入首页。应用启动时会自动完成：

1. 创建数据目录、初始化日志（损坏的 config.json 自动回退默认值）；
2. 打开本地数据库 `devdesk.db`（首次启动自动建表、创建默认看板列），按设置执行一次调用日志清理；
3. **Claude 代理默认不启动**（端口不监听，见 [§4.1](#41-代理如何工作)）——只有设置页开了「随应用启动代理」才会启动并接管 Claude Code 配置；异常退出遗留的接管快照会在启动时补还原；
4. 按「模块开关」装配页面与侧边栏（关闭的模块代码不再执行、侧边栏不显示其入口）。

**导航**（左侧常驻侧边栏，展开 260px / 折叠 72px）：

- **侧边栏**：列出全部**已启用**的页面模块入口（显示名：首页 / 笔记 / 待办 / Claude 切换器 / 设置 / 智能体，含图标），当前页高亮，点击即切换。模块开关关闭的模块入口同步消失。
- **Ctrl+B 折叠 / 展开侧边栏**：折叠后只显图标（宽 72px、顶部只剩「D」、悬停有名称 tooltip），左下角另有折叠/展开按钮，折叠状态跨重启记忆。注意：焦点在 Markdown 编辑器内时 Ctrl+B 被「加粗」占用，需先点出编辑器或用底部按钮。
- **首页是导航枢纽**：四张统计卡片、最近编辑列表、底部快捷按钮都可点击，跳转到对应模块（快捷按钮还会在目标页自动弹出新建对话框）。
- 首页右上角另有「⚙ 设置」按钮，点击直达设置页（与侧边栏「设置」等效）。
- **系统托盘**：主窗口点 ✕ 隐藏到托盘（进程不退出）；**左键单击托盘图标唤起主窗**，右键弹样式化菜单，只有两项——「显示主窗口 / 退出 DevDesk」。点「显示主窗口」等于左键单击（把隐藏的主窗唤回前台），「退出 DevDesk」结束整个进程。

## 3. 各模块怎么用

### 3.1 首页

- **四张统计卡**（真实数据）：今日笔记（今日修改过的笔记数）、待办任务（未完成总数）、逾期任务（已过截止时间）、API 调用（今日代理调用）。点击卡片跳转到对应模块。
- **最近编辑**：最近编辑过的前 5 篇笔记，显示标题（无标题时显示文件名）、相对时间、所在目录。点击整行跳转 Markdown 页并**直接打开那一篇笔记**。
- **右上角「刷新」**：重新查询全部统计。每次**进入首页**（含同页重入）都会自动重查一次；停留在首页期间不自动更新，需要时手动点「刷新」。
- **底部快捷按钮**：`+ 新建笔记` → Markdown 页并自动弹出新建笔记弹窗；`+ 新建任务` → Todo 页并自动弹出新建任务弹窗；`📋 切换 Claude Profile` → Claude 页（Profile 列表在该页）。

### 3.2 Markdown 笔记本

**三态视图**：顶部分段按钮 `编辑` / `双栏` / `预览`，或快捷键 **Ctrl+Shift+P** 循环切换。左栏常驻（搜索 + 标签 + 目录树），编辑态 = 左栏 + 编辑器，双栏 = 左栏 + 编辑器 + 预览，预览态 = 左栏 + 预览。视图模式**不跨重启记忆**（启动回到编辑态）。

- **左栏**：顶部搜索框（占位「搜索笔记…」，FTS5 全文索引——拉丁词走索引排名、中文走子串匹配兜底，都支持；输入即过滤，清空恢复目录树）。其下「标签」区：全部标签 chip（带笔记数），点击过滤树、再点取消。树为两级结构（文件夹 → 笔记，根目录散文件单独一组置顶），底部两个按钮「+ 笔记」「+ 文件夹」。
- **新建笔记**：点「+ 笔记」弹「新建笔记」弹窗——提示「支持子目录，例如 工作/周会.md」，**支持多级子目录**（自动建目录，拒绝绝对路径 / 盘符 / `..`）；无 `.md` 自动补全；**名字留空直接回车即秒建「无标题笔记.md」**（撞名自动加编号「无标题笔记 2.md」…）；显式输入撞名则直接打开已有文件（toast「笔记已存在 / 已直接打开 <路径>」）。创建后**编辑器自动获得焦点**，直接开写。
- **大纲**：顶部「大纲」开关弹浮动面板（`#` 开头的标题行自动成树）；点标题——编辑 / 双栏态把光标移到该行（编辑器滚动、预览经同步滚动跟随），纯预览态直接滚到该节。空态提示「用 # 开始一行即可加入大纲」。
- **键盘流**（编辑器内）：
  - `Ctrl+B` 加粗 / `Ctrl+I` 斜体：有选区在两端包标记（`**` / `*`），**再按一次去包裹**；无选区在光标处插标记、光标落在中间。
  - `Ctrl+K` 链接：插入 `[文本](链接)` 骨架并选中待替换的占位（有选区时选区作链接文本、选中「链接」占位）。
  - `Tab`：普通行插入 4 空格（多行选区整行缩进），`Shift+Tab` 反缩进；**光标在表格行内时 Tab / Shift+Tab 改为单元格跳格**（首格连上一行末格，跳格后选中目标格内容）。
  - `Enter`：列表项行末回车自动续列表（`- ` 延续符号、有序列表自动编号 `N. `），空列表项回车退出列表。
  - 无 Ctrl+S——保存全靠自动保存（见下）。
- **表格**：编辑器右键 → 级联「插入表格」→ 选 `1 行`–`6 行` × `1 列`–`8 列`，在光标处插入 GFM 表格模板（表头 + 分隔行 + 数据行），光标落进表头首格，Tab 逐格填写。
- **重命名 / 删除笔记**：树中笔记右键 →`重命名` / `删除笔记`。重命名对话框预填当前相对路径，**填带 `/` 的路径即同时移动**（如 `工作/新名.md`，无 `.md` 自动补全）；删除有确认弹窗，**删的是磁盘文件本身**（连同索引），不是仅移出列表。
- **自动保存**：停止输入约 400ms 后自动写盘，编辑器底部状态栏显示「`文件名` ● 未保存 / ✓ 已保存 HH:MM / ✕ 保存失败，自动重试中」（保存失败按指数退避自动重试；切页 / 退出前会先落盘）。
- **没有「重扫」按钮（W8 起移除）**：应用每 5 秒自动比对笔记目录磁盘文件与索引——外部新增 / 删除 / 修改的文件自动同步进树。当前笔记被外部修改：本地无编辑时静默重载；有冲突时弹 toast「文件已被外部修改」+「重载磁盘版本」按钮二选一（不自动超时）。文件被外部删除且本地有编辑时保留编辑器内容，保存即重建文件。
- **从外部打开文件**：资源管理器对 `.md` / `.markdown` 文件右键「打开方式 → DevDesk」——文件已在笔记目录内则直接打开对应笔记；在目录外则**自动复制到笔记目录根**（强制 `.md` 扩展名、撞名追加「 2」「 3」）再打开。
- **文件即笔记**：所有笔记都是磁盘上的普通 `.md` 文件（目录见 [§5](#5-数据都在哪)），可以用任何外部编辑器打开、同步盘同步、git 管理。笔记标签存在数据库中，**不写入 md 文件正文**。

### 3.3 Todo 看板

页面副标题就是静态操作说明：`点击卡片查看详情 · Ctrl+↑/↓ 移动选中任务 · 右键卡片/列头更多操作 · 拖动卡片跨列移动`。

- **默认四列**：待办 / 进行中 / 已完成 / 已归档（首次启动自动创建，列头带色点）。空看板时提示「还没有任何列，点击右上角「+ 列」开始」。
- **「+ 列」（右上角）**：弹出**新建列**命名弹窗（不是直接建列）——提示「输入列标题，留空回车则用「新列 N」」；留空提交即按默认名秒建；名字撞列时弹窗内嵌红字「该列名已存在，请换一个」，不关窗。
- **列管理（右键列头）**：`重命名列` / `左移列` / `右移列` / `改色`（预设六色：Claude 橘 / 暖琥珀 / 鼠尾草绿 / 暖灰 / 雾蓝 / 玫瑰红）/ `删除列`。列头另有 **✎** 按钮直达重命名弹窗。**注意：删除列直接级联删除其下全部任务，没有二次确认**（旧说法「列的删除无 UI 入口」已过期）。
- **新建任务**：两个入口——某列列头的「+」建到**该列**、右上角「+ 新建任务」建到**第一列**；弹窗都会显示「将创建在「列名」列」。
- **任务详情（点卡片主体打开）**：字段有 标题、描述、优先级（`无` / `●低` / `●中` / `●高`）、截止日期（日期选择器，可清除）、标签、「移动到」（全部列按钮，当前列高亮）。底部三个动作：`删除`（需二次确认）、`标记完成`/`取消完成`（两态切换）、`保存`。「移动到」「标记完成」「删除」都会**先把弹窗里正在编辑的表单落库再执行动作**（保存失败则弹窗保持打开）；有未保存修改时点遮罩关闭，第一次只警告「有未保存修改：点「保存」落库，或再点一次遮罩放弃」。
- **完成 / 撤销完成**：卡片上**没有**可点的 ✓ 按钮（已完成任务的标题只是透明度降低）；在详情弹窗点「标记完成」→ 任务自动移到已完成类列，「取消完成」→ 移回待办类列。
- **任务右键菜单**：`编辑` / `上移` / `下移` / `移动到「其他列名」`（每个其他列一项）/ `删除`（弹「删除任务」确认框）。另有键盘流 `Ctrl+↑/↓` 移动选中任务。
- **拖拽**：按住卡片拖到任意列，**松手才落库**（拖动中卡片半透明、目标列描边高亮）；在板外松手自动回原位，拖完不会误开详情弹窗。
- **搜索**：右上角搜索框（占位「搜索任务…」），实时按标题 / 描述包含过滤，各列只显示命中卡片（无命中列显示「无命中任务」）；Enter 或 Esc 清空恢复全量。
- **逾期视图**：右上角「逾期 N」按钮（N 为逾期数，0 时置灰），弹窗「逾期任务（N）」列出**未完成**且已过截止的任务——行内容「任务名 · 所属列 · 截止 · 逾期N天」（最多 12 条），点击一行直达该任务详情。
- **标签**：只在任务详情弹窗里编辑——输入框「输入标签，回车添加…」，chip 带 × 移除，随「保存」落库；卡片上最多显示 2 个标签，超出显示「+N」。
- 任务数据存在 `devdesk.db`（SQLite）。

### 3.4 Claude 切换器

管理多套 Claude API 配置（Profile），并在本地跑一个带鉴权的流式代理，让 Claude Code 之类的客户端经代理调用 API。

**代理默认不启动**：应用启动时 8888 端口不监听（供应商配置设计硬性需求），需在本页手动启动；未启动时副标题提示「代理已停止，点右上角启动」。要开机常驻，可在设置页开「随应用启动代理」（见 §3.5）。

页面上能看到的信息（全部为真实数据）：

- **代理状态**：右上角圆点与文字（绿点「运行中 :<端口>」/ 灰点「已停止」，端口默认 8888、可配）。
- **Profile 列表**（左栏）：名称、Base URL、模型，激活行带 **ACTIVE** 徽章；选中未激活的 Profile 时详情面板显示「未激活」徽章。
- **当前 Profile 详情**（右栏）：名称、模型、Base URL、API Key（脱敏提示：前 6 + `***` + 后 4，带 `[本机库]` 标记；密钥存本机 SQLite 的 `claude_profiles.api_key_encrypted` 列，保护级别按平台——macOS/POSIX 为文件权限 `0600`，Windows 为 DPAPI 加密后入库）、「Claude Code 接管」状态行（「● Claude Code 已接管 <路径>」/「○ Claude Code 未接管（启动代理后自动接管，停止时还原）」）、最近调用表（时间 / 方法·路径 / 状态 / 耗时）。
- **调用日志面板**：详情底部「查看全部 →」打开**「调用记录」弹窗**——搜索框（占位「搜索路径 / 方法…」）、状态码过滤下拉（全部状态 / 2xx 成功 / 3xx 重定向 / 4xx 客户端错误 / 5xx 服务端错误 / 错误（超时等））、分页每页 20 条（「← 上一页」「下一页 →」「第 N / M 页」）。

页面上可以做的操作（已全量接线，底层真调 `ClaudeService`）：

- **+ 新建 Profile**：弹窗填名称 / Base URL / 模型 / API Key（Key 加密落本机数据库，见 [§5](#5-数据都在哪)）。**若当前没有任何激活 Profile，新建的会自动激活**（toast「已创建并启用」）；已有激活则不抢占，提示点「启用」。
- **导入当前配置**：一键读 `~/.claude/settings.json`、解析 env 托管键后**预填新建表单**（名称建议取 Base URL 主机名，可改）。
- **启用**：把选中的 Profile 设为代理转发的当前配置（代理运行中会立即按新配置重新接管 settings.json）。
- **编辑**：弹窗预填现有值；API Key 留空表示沿用原 Key 不更换。
- **删除**：「确认删除？」弹窗（「将删除 Profile「<名称>」及其保存的 API Key，不可恢复。」）。**删除的是当前激活 Profile 时会同时停止代理并还原 Claude Code 的 settings.json**（toast「删除的是激活 Profile，已停止代理并还原 Claude Code 配置」）。
- **测试连通**：后台对 `<Base URL>/v1/models` 发一次 GET（15 秒超时，带 x-api-key），toast 显示 HTTP 结果；上一轮未结束时再点提示「测试进行中」。
- **启动代理 / 停止代理**：右上角按钮随状态切换文字，启停同时接管 / 还原 Claude Code 配置（见 §4.2）。

操作结果统一以页面底部 toast 提示，失败时显示中文错误信息。

### 3.5 设置

进入方式：左侧侧边栏点「设置」（或首页右上「设置」）。卡片区可滚动，部分卡**按模块开关动态显隐**：笔记目录卡仅 Markdown 开启时出现，代理卡仅 Claude 开启时出现。

| 卡片 | 设置项 | 生效范围 / 时机 |
|------|--------|----------------|
| **外观** | 主题（「深色」/「浅色」，默认深色）；字号缩放（「小 85%」「标准 100%」「大 115%」「特大 130%」，正文基准 15px，**全局生效**）；窗口效果（「关闭（默认）」「半透」「磨砂（Mica）」，系统不支持自动回退并提示） | 全部即时生效（下一帧，含窗口底色），持久化 |
| **模块** | 5 个开关：Markdown 笔记本 / Todo 看板 / Claude 配置切换器 / 智能体 / 壁纸（壁纸默认关闭；首页与设置恒开、无开关） | **重启应用生效**——卡内提示「关闭模块后需重启应用生效（关闭 = 该模块代码不再执行、侧边栏不显示入口）」 |
| **Markdown 笔记目录（只读）**（仅 Markdown 开启时） | 路径展示 + **「打开目录」**按钮（目录不存在会先创建，再打开资源管理器） | 修改目录属于后续功能，迁移笔记 = 「打开目录」后手动拷贝文件 |
| **Claude 代理**（仅 Claude 开启时） | 「随应用启动代理」开关（默认**关**）；「代理端口」输入框（回车或点「应用」）；认证 Token（只读 · 默认脱敏，眼睛按钮临时显形、离开本页即恢复掩码；「重新生成」换新 Token）；「Claude Code 接管」状态行 | 自启开关下次启动生效；改端口**代理运行中自动重启（Token 不变）** |
| **调用日志保留** | 下拉：「永久保留」「7 天」「30 天」「90 天」「180 天」「365 天」（默认 30 天；永久 = 不清理） | **切换立即执行一次清理**并反馈「已清理 N 条历史日志」（旧说法「下次启动才生效」已过期） |

配置持久化在 `%USERPROFILE%\DevDesk\config.json`（共 11 键，与 `SettingsStore::save` 一一对应：`theme` / `themeMode` / `editorFontSize` / `logLevel` / `fontScalePercentV3` / `logRetentionDays` / `claudeProxyAutoStart` / `claudeProxyPort` / `windowEffect` / `sidebarCollapsed` / `enabledModules`。`themeMode` 是用户意图档（`auto`/`light`/`dark`，默认 `auto` 跟随系统），`theme` 与其双写、存当前解析出的深浅档供启动路径直读；字体缩放只认 `fontScalePercentV3`，旧键 `fontScalePercent` / `fontScalePercentV2` 刻意不读、写了也无效；文件损坏或字段缺失时自动回退默认值，数值越界收敛到合法范围）。

## 4. Claude 代理配置流程

### 4.1 代理如何工作

- **代理默认关闭，不随应用启动**（避免在你不知情时改写 Claude Code 配置）。启动方式二选一：Claude 页点「启动代理」，或设置页「Claude 代理」卡打开「随应用启动代理」后重启。
- 监听地址 `http://127.0.0.1:<端口>`，端口默认 8888，设置页「代理端口」可改（运行中改端口自动重启代理，Token 不变）。
- 客户端调用必须带 **Bearer 鉴权**：`Authorization: Bearer <token>`。
- 代理把请求转发到**当前启用 Profile** 的 Base URL，自动注入该 Profile 的 API Key（密钥存本机 SQLite，保护级别见 [§5](#5-数据都在哪)）。流式（SSE）与非流式响应都支持。
- 没有启用任何 Profile 时，调用返回 `503` + `no_active_profile`（中文错误信息会指引去 Claude 页新建 / 启用 Profile）。

### 4.2 配置步骤（推荐：接管模式，无需手抄 token）

1. **建 Profile**：在 Claude 切换器页点「+ 新建 Profile」填名称 / Base URL / 模型 / API Key，保存即落本机数据库；或直接点「导入当前配置」从 `~/.claude/settings.json` 一键预填。当前没有激活 Profile 时，新建的会自动激活。
2. **验证上游**：点「测试连通」（对 `<Base URL>/v1/models` 发一次带 Key 的 GET，最长 15 秒），toast 显示 HTTP 结果。
3. **启动代理**：点「启动代理」。启动瞬间 DevDesk **自动接管** Claude Code 用户级配置 `%USERPROFILE%\.claude\settings.json`——把托管键 `ANTHROPIC_BASE_URL`（指向本地代理）、`ANTHROPIC_AUTH_TOKEN`（代理 Token）、`ANTHROPIC_MODEL` 及各 `ANTHROPIC_DEFAULT_*_MODEL` / `CLAUDE_CODE_SUBAGENT_MODEL` 写入，写入前对原值做快照。你 settings.json 里的**其他键与 env 之外的字段原样保留**。
4. **直接用 Claude Code**：无需在 Claude Code 侧抄写任何地址或 token，它经被接管的托管键直连本地代理（官方规范支持运行中会话随配置变更热重载）。切换激活 Profile 时接管内容同步重写。
5. **还原**：停止代理、删除当前激活 Profile、正常退出应用都会**按快照自动还原** settings.json 原值；异常崩溃时下次启动检测到残留快照会补还原。接管状态可在设置页「Claude Code 接管」行与 Claude 页详情随时核对。

### 4.3 手工配置（不想让 DevDesk 碰 settings.json 时的备选）

- **Base URL**：`http://127.0.0.1:<端口>`（端口看 Claude 页「运行中 :<端口>」状态）
- **Token**：到设置页「Claude 代理」卡点眼睛按钮显形查看（离开本页恢复掩码），手动抄录。
  > ⚠ **旧版此处写「打开 `%USERPROFILE%\DevDesk\proxy_token.txt`」——该文件已不存在**（Token 现在随代理启动在进程内生成、不落盘）。旧版同时写「应用没有复制按钮（无剪贴板 API）」也已过期——剪贴板能力早已接入；**但 Token 行本身是否有复制入口，本次未核**。
- **验证**：手工发一次请求，能收到 JSON 响应即通：

  ```bash
  curl -X POST http://127.0.0.1:8888/v1/messages \
    -H "Authorization: Bearer <你的-token>" \
    -H "Content-Type: application/json" \
    -d '{"model":"claude-sonnet-4-5","max_tokens":64,"messages":[{"role":"user","content":"hi"}]}'
  ```
- 注意：手工模式下代理运行时 settings.json 仍会被接管（当前版本无「不接管」开关，启动即托管、停止即还原）。

## 5. 数据都在哪

全部在本机 `%USERPROFILE%\DevDesk`（即 `C:\Users\<用户名>\DevDesk`，`core/paths_win.cpp` 定义；macOS 为 `~/DevDesk`，`core/paths_macos.cpp` 定义）——刻意放在用户主目录下（Finder / 资源管理器里默认可见），不再用系统惯例的 `%APPDATA%\DevDesk` / `~/Library/Application Support/DevDesk`：

| 路径 | 内容 | 说明 |
|------|------|------|
| `%USERPROFILE%\DevDesk\notes\` | **所有笔记** | 普通 `.md` 文件树，可直接备份 / 同步 |
| `%USERPROFILE%\DevDesk\devdesk.db` | **SQLite 数据库（几乎所有状态都在这里）** | Todo 列与任务、Profile 元数据**与 API Key 密文**、笔记索引（FTS5）与笔记标签、代理调用日志、**应用配置（`app_config` 表）**、Markdown / Todo 视图状态 |
| `%USERPROFILE%\DevDesk\logs\devdesk.log` | 运行日志 | 排查问题先看这里；调用日志的保留天数在设置页配置 |
| `%USERPROFILE%\.claude\settings.json` | Claude Code 用户配置（接管） | **代理运行期间** DevDesk 只写托管键（`ANTHROPIC_*` 等），其余键原样保留；停止代理 / 退出应用自动还原（见 [§4.2](#42-配置步骤推荐接管模式无需手抄-token)） |

**凭据存在哪 / 保护到什么程度**（2026-10-02 起，取代原「Keychain + `keychain/` 目录」口径）：

- **API Key 与供应商额外凭据（如火山 AK/SK）存放在 `devdesk.db` 的加密列里**，一对一绑定 profile；**不再写入系统钥匙串，也没有 `keychain\` 目录**。
- 保护级别**按平台不同**（应用内「本机数据库存储」的说明文案会如实反映当前平台）：
  - **macOS / Linux**：数据库列里是明文，靠**文件权限**保护（打开数据库时把数据根与 `devdesk.db`、`devdesk.db-wal`、`devdesk.db-shm` 校正为 `0600`，仅本用户可读）→ **保护级别 = 文件系统权限级**。应用内文案：「本机数据库存储（文件权限 0600，仅本用户可读）」。
  - **Windows**：入库前经 **DPAPI 加密**（密文存列，绑定当前 Windows 用户）→ **保护级别 = 加密级**，换用户 / 换机器读不出。应用内文案：「本机数据库存储（DPAPI 加密，仅本机本用户可解）」。
- **数据根里还有一份 `.gitignore`**（应用会自动维护）：`*.db` / `*.db-*` / `config.json*` / `run-settings/` / `claude_settings_snapshot.json` / `logs/` / `pets/` 都在屏蔽名单里。**若你打算把 `~/DevDesk` 做成 git 仓库，请保留它**——凭据在 db 与其 `-wal` 里，一次 `git add .` 提交上去就等于泄密。
- `run-scripts/`（macOS 用「运行」按钮时生成的临时启动脚本，仅含路径、不含密钥）会被 24 小时启动清扫兜底清理。

**备份**：拷走整个 `%USERPROFILE%\DevDesk` 目录即可（含 `devdesk.db` 及其 `-wal` / `-shm`；Windows 上的凭据密文只能在同一 Windows 用户账号下解出，macOS 上的凭据靠文件权限、换个用户就读不到）。

> **从旧位置升级**：旧数据位置（如 `%APPDATA%\DevDesk` / `~/Library/Application Support/DevDesk`）的数据**不做自动迁移**——新位置从头开始，旧数据原样留存。想保留旧配置 / 笔记 / 看板，手动把旧目录里的 `config.json` / `notes/` / `devdesk.db`（连同 `-wal` / `-shm`）拷进新目录即可（拷贝前先退出 DevDesk）。

## 6. 常见问题

- **打开应用代理却没在跑？** 这是设计行为：代理**默认不随应用启动**。去 Claude 页点「启动代理」，或设置页「Claude 代理」卡开「随应用启动代理」（下次启动生效）。
- **代理端口被占用？** 默认 8888、可配：设置页「代理端口」改后回车或点「应用」，代理运行中会自动重启（Token 不变）。启动失败的中文提示见 toast 与日志（`logs\devdesk.log`）。
- **Claude Code 调用返回 503 no_active_profile？** 没有启用任何 Profile，或 Profile 的 Base URL / API Key 配置不完整。（新建 Profile 时若当前无任何激活项，会自动激活。）
- **接管会不会弄乱我的 Claude Code 配置？** 只重写托管键（`ANTHROPIC_BASE_URL` / `ANTHROPIC_AUTH_TOKEN` / `ANTHROPIC_MODEL` 等），写入前先存原值快照；停止代理、删除激活 Profile、正常退出都自动还原，崩溃后下次启动补还原。你的其他键与字段不动。
- **改了调用日志保留要重启才生效吗？** 不用——切换保留档位**立即清理一次**并提示「已清理 N 条历史日志」；「永久保留」不清理。
- **中文搜索搜不到？** 搜索走 SQLite FTS5（拉丁词索引）+ 中文子串兜底（构建时已验证启用）；确认笔记已保存（编辑器底部状态栏显示「✓ 已保存」）。没有手动重扫——磁盘改动约 5 秒内自动同步进左栏树。
