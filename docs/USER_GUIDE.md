# DevDesk 用户指南

> 面向最终用户的使用说明。基线版本：2026-09-22（Windows 11，124/124 测试全绿）。
> 如实记录的边界清单见 [KNOWN_LIMITATIONS.md](KNOWN_LIMITATIONS.md)。

## 1. DevDesk 是什么

DevDesk 是一个**本地优先**的开发者桌面工具集（C++ 原生应用，单 exe），包含五个模块：

| 模块 | 用途 |
|------|------|
| **首页** | 仪表盘：今日笔记 / 待办 / 逾期 / API 调用四张统计卡 + 最近编辑列表 |
| **Markdown 笔记本** | 笔记就是普通 `.md` 文件，SQLite FTS5 全文搜索（支持中文） |
| **Todo 看板** | 四列任务看板：拖拽移动、优先级、截止日期、标签 |
| **Claude 切换器** | 多套 Claude API 配置（Profile）管理 + 本地流式代理 |
| **设置** | 主题 / 字号 / 代理 token / 日志保留策略 |

所有数据都保存在本机 `%APPDATA%\DevDesk`（见 [§5 数据都在哪](#5-数据都在哪)），不上传任何内容。

## 2. 启动与界面导航

启动 `DevDesk.exe` 后进入首页。应用启动时会自动完成：

1. 创建数据目录（不存在时）；
2. 打开本地数据库 `devdesk.db`（首次启动自动建表、创建默认看板列）；
3. 启动本地 Claude 代理 `http://127.0.0.1:8888`。

**导航方式**（当前版本没有常驻侧边栏，同一时间只显示一个模块页面）：

- **首页是导航枢纽**：四张统计卡片、最近编辑列表、底部快捷按钮都可点击，跳转到对应模块。
- **右下角浮动齿轮 ⚙**：任何页面点它进入设置页；在设置页它变成返回箭头 ←，点击回到首页。
- 从 Markdown / Todo / Claude 页面回首页：点齿轮进设置页，再点箭头回首页（更直接的返回入口属于后续改进，见已知限制）。
- 首页右上角的「⚙ 设置」按钮当前为**置灰不可用**状态，设置入口请用右下角浮动齿轮。

## 3. 五个模块怎么用

### 3.1 首页

- **四张统计卡**（真实数据）：今日笔记（今日修改过的笔记数）、待办任务（未完成总数）、逾期任务（已过截止时间）、API 调用（今日代理调用）。点击卡片跳转到对应模块。
- **最近编辑**：最近编辑过的前 5 篇笔记，显示标题（无标题时显示文件名）、相对时间、所在目录。点击整行跳转到 Markdown 页。
  - 注意：点击**只做页面跳转**，不会自动打开那一篇笔记，需要在 Markdown 页左侧文件列表里再点一次（详见已知限制）。
- **右上角「↻ 刷新」**：重新查询全部统计。统计在进入首页时查询一次，平时不会自动刷新。
- **底部快捷按钮**：`+ 新建笔记` → Markdown 页；`+ 新建任务` → Todo 页；`📋 切换 Claude Profile` → Claude 页。
  - 注意：这三个按钮当前**降级为纯导航**——跳过去之后新建/切换动作还需要在目标页面里自己完成（跨模块弹窗属于后续改进）。

### 3.2 Markdown 笔记本

三栏布局：左栏（搜索 + 文件列表）、中栏（编辑器）、右栏（实时预览）。

- **搜索**：左栏顶部搜索框，输入即搜（FTS5 全文索引，支持中文）；清空搜索框恢复显示全部笔记。
- **新建笔记**：点「+ 新建笔记」（或左栏底部「+ 新建」），弹窗输入文件名。**支持子目录**，例如输入 `inbox/ideas.md` 会创建 `notes\inbox\` 子目录。
- **重扫**：点「↻ 重扫」重新扫描笔记目录（在外部编辑器改动文件结构后使用）。
- **编辑**：左栏选一篇笔记，中栏直接编辑（停止输入片刻后自动保存，标题栏显示「编辑中（自动保存）」），右栏渲染 Markdown 预览。
- **文件即笔记**：所有笔记都是磁盘上的普通 `.md` 文件（目录见 [§5](#5-数据都在哪)），可以用任何外部编辑器打开、同步盘同步、git 管理。

### 3.3 Todo 看板

- **默认四列**：待办 / 进行中 / 已完成 / 已归档（首次启动自动创建）。点右上角「+ 列」可增加自定义列。
- **新建任务**：点某列列头的「+」，任务直接创建到该列（弹窗里会显示目标列名）；右上角「+ 新建任务」则创建到第一列。
- **任务卡片**：
  - 点 ✓ 完成：任务自动移到「已完成」列；再点一次撤销，自动移回「待办」列。
  - 点卡片主体：打开**任务详情**弹窗——标题、描述、优先级（🔴高 / 🟡中 / 🔵低 / ⚪无）、截止日期、移动到其他列、删除、保存。
- **拖拽**：按住卡片向左 / 向右拖，移动到相邻列。
- 任务数据存在 `devdesk.db`（SQLite）；看板列可通过「+ 列」增加（列的删除当前无 UI 入口）。

### 3.4 Claude 切换器

管理多套 Claude API 配置（Profile），并在本地跑一个带鉴权的流式代理，让 Claude Code 之类的客户端经代理调用 API。

页面上能看到的信息（全部为真实数据）：

- **代理状态**：标题旁的圆点与文字（运行中 `:8888` / 已停止）。
- **Profile 列表**（左栏）：名称、Base URL、模型、ACTIVE 标记。
- **当前 Profile 详情**（右栏）：名称、模型、Base URL、API Key（脱敏显示 + `[Keychain]` 标记；明文密钥只存在 DPAPI 加密的本地 keychain 存储，绑定当前 Windows 用户）。
- **最近调用**：最近 3 次代理调用（时间、方法 / 路径、状态、耗时）。

> **如实说明（当前版本边界）**：页面上的操作按钮——`+ 新建 Profile`、`启用`、`测试连通`、`编辑`、`删除`、`⏸ 停止代理`——目前是**展示样式，尚未接线点击事件**。Profile 的增删改 / 启用 / 切换能力在底层服务已经完整实现并有单元测试覆盖，但 UI 交互接线是后续任务（见 [KNOWN_LIMITATIONS.md](KNOWN_LIMITATIONS.md) 跨平台限制第 4 条）。因此 [§4 配置流程](#4-claude-代理配置流程)中的第 1、2 步暂时无法在界面上完成。

### 3.5 设置

进入方式：任意页面右下角浮动齿轮 ⚙；设置页内齿轮变返回箭头。

| 设置项 | 怎么用 | 生效范围 / 时机 |
|--------|--------|----------------|
| **主题** | 「🌙 深色」/「☀ 浅色」二选一 | 切换即时生效（下一帧全页生效） |
| **字号缩放** | 档位选择，正文基准 15px，范围 85%–130% | **当前仅作用于设置页自身文字**（配置已持久化，全局接线见已知限制） |
| **Markdown 笔记目录** | 只读展示 | 修改目录属于后续功能 |
| **认证 Token** | 只读显示 Claude 代理 token；「↻ 重新生成」换新 token | 重新生成会重启代理（同端口 8888）并同步重写 `proxy_token.txt` |
| **调用日志保留** | 天数（0 = 永久保留，默认 30 天，上限 3650 天） | **下次启动时**执行清理 |

配置持久化在 `%APPDATA%\DevDesk\config.json`（theme / fontScalePercent / logRetentionDays 三个字段；文件损坏或字段缺失时自动回退默认值，数值越界自动收敛到合法范围）。

## 4. Claude 代理配置流程

### 4.1 代理如何工作

- 应用启动即自动在 `http://127.0.0.1:8888` 启动本地代理（无需手动开）。
- 客户端调用必须带 **Bearer 鉴权**：`Authorization: Bearer <token>`。
- 代理把请求转发到**当前启用 Profile** 的 Base URL，自动注入该 Profile 的 API Key（密钥明文只存 DPAPI 加密的本地 keychain 存储，见 [§5](#5-数据都在哪)）。流式（SSE）与非流式响应都支持。
- 没有启用任何 Profile 时，调用返回 `503` 与 `{"error":"no_active_profile", ...}`。

### 4.2 配置步骤

1. **建 Profile**：在 Claude 切换器页新建 Profile，填名称 / Base URL / 模型 / API Key。
   （当前版本该按钮未接线，见 3.4 的说明。）
2. **启用**：在 Profile 上点「启用」，使其成为代理转发的当前配置。
   （同上，当前版本暂不能在 UI 上完成。）
3. **把代理配给 Claude Code**：
   - **Base URL**：`http://127.0.0.1:8888`
   - **Token**：打开 `%APPDATA%\DevDesk\proxy_token.txt`（每次启动 / 重新生成时自动重写），内容形如：

     ```ini
     # DevDesk Claude 代理凭据（自动生成，请勿提交到版本控制）
     port=8888
     token=<你的-token>

     # 用法：
     # curl -X POST http://127.0.0.1:8888/v1/messages \
     #   -H "Authorization: Bearer <你的-token>" \
     #   -H "Content-Type: application/json" \
     #   -d '{"model":"claude-sonnet-4-5","max_tokens":64,"messages":[{"role":"user","content":"hi"}]}'
     ```

   - 应用目前**没有复制按钮**（无剪贴板 API），需要手动从该文件抄录 token。
4. **验证**：用文件里自带的 curl 命令测试，能收到 JSON 响应即通。

## 5. 数据都在哪

全部在本机 `%APPDATA%\DevDesk`（即 `C:\Users\<用户名>\AppData\Roaming\DevDesk`，`core/paths_win.cpp` 定义）：

| 路径 | 内容 | 说明 |
|------|------|------|
| `%APPDATA%\DevDesk\notes\` | **所有笔记** | 普通 `.md` 文件树，可直接备份 / 同步 |
| `%APPDATA%\DevDesk\devdesk.db` | SQLite 数据库 | Todo 列与任务、Profile 元数据、笔记索引（FTS5）、代理调用日志 |
| `%APPDATA%\DevDesk\config.json` | 应用配置 | theme / fontScalePercent / logRetentionDays |
| `%APPDATA%\DevDesk\keychain\` | 凭据密文 | `<service>\<account>.key`，DPAPI 加密（绑定当前 Windows 用户），存 API Key 明文的唯一位置 |
| `%APPDATA%\DevDesk\logs\devdesk.log` | 运行日志 | 排查问题先看这里；调用日志的保留天数在设置页配置 |
| `%APPDATA%\DevDesk\proxy_token.txt` | 代理凭据 | port + token，见 [§4.2](#42-配置步骤) |

**备份**：拷贝整个 `%APPDATA%\DevDesk` 目录即可（keychain 密文只能在同一 Windows 用户账号下解密）。

## 6. 常见问题

- **代理端口被占用？** 代理固定使用 8888，被占用时启动失败，日志（`logs\devdesk.log`）里可见错误；关掉占用进程后重启 DevDesk。
- **Claude Code 调用返回 503 no_active_profile？** 没有启用任何 Profile，或 Profile 的 Base URL / API Key 配置不完整。
- **改了设置里的日志保留天数没立刻生效？** 清理在**下次启动**时执行；`0 = 永久保留` 会跳过清理。
- **中文搜索搜不到？** 搜索走 SQLite FTS5（构建时已验证启用）；确认笔记已保存且在左栏「↻ 重扫」后重试。
