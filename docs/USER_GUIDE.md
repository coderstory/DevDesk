# DevDesk 用户指南

> 面向最终用户的使用说明（2026-11-18 以打磨审计手册底稿重写，基线见文末附录）。
> **测试用例总数以运行输出 `Total:` 为准，不在文档写死。**
> 凭据与配置存放：API Key 与全部 app 配置存于本机 SQLite 数据库（见 [§5 数据都在哪](#5-数据都在哪)）。
> 现存实现边界见 `DevDesk/CLAUDE.md`。

## 1. DevDesk 是什么

DevDesk 是一个**本地优先**的开发者桌面工具集（C++ 原生应用），数据全部保存在本机 `~/DevDesk`（Windows 为 `%USERPROFILE%\DevDesk`），不上传任何内容。

侧边栏页面模块（按注册顺序）：首页 / 笔记 / Git / 待办 / 定时 / Claude 配置 / 智能体 / 记忆 / 壁纸 / MCP / 终端 / 上线（分组：任务 + 基础配置两个子页）/ 设置 / 关于。其中 **11 个模块可被设置页模块开关插拔**（笔记 / Git / 待办 / 定时 / Claude / 智能体 / 记忆 / 壁纸 / MCP / 终端 / 上线；壁纸默认关闭），恒开仅首页、设置、关于。

| 模块 | 用途 |
|------|------|
| **首页（工作台）** | 仪表盘：5 张统计卡（Token 速率 / 今日笔记 / 待办任务 / 逾期任务 / API 调用）+ 今日 token 图表 + 快捷按钮 |
| **笔记** | 笔记就是普通 `.md` 文件：目录树 / 标签 / 中文全文搜索 / 大纲跳转，编辑·实时·双栏·预览四态视图，自动保存，写盘后后台静默 git 自动提交 |
| **Git** | 本地仓库**只读查看器**：文件树、工作区变更与 unified diff、全仓内容搜索；无 stage/commit/分支操作、无网络功能 |
| **待办** | 固定四列看板（待办 / 进行中 / 已完成 / 已归档）：拖拽与键盘移动、优先级、截止日期、标签、搜索、逾期提示、归档 |
| **定时** | 定时规则（一次性 / 间隔 / 周期 / cron 表达式 / 事件 / 常驻六类）+ 运行历史与失败重试 |
| **Claude 配置** | 多套 Claude API 配置（Profile）+ 本地鉴权流式代理（默认不启动；启动即自动接管 Claude Code settings.json，停止还原） |
| **智能体** | 提示词 + 触发（cron / 手动）+ 工具配成任务，自动或手动运行，带完整运行记录与三重硬上限 |
| **记忆** | telemem 记忆引擎：Claude 对话自动采集 → 提炼提案 → 你逐张审核入库 → 对话自动注入 + MCP `memory_search` 查询 |
| **壁纸** | 桌面动态壁纸（默认关闭）：视频 + 图片混合轮换、系统事件自动让路暂停（锁屏 / 熄屏 / 睡眠 / 全屏窗口 / 用电池）、断点续播；macOS 一键「从花見导入」 |
| **MCP** | 本机 MCP hub 服务：把内置工具（`memory_search` / `md.*` 笔记检索读写 / `web_fetch_markdown` 等）以标准 MCP 协议开放给 Claude Code 等客户端；工具试跑、一键安装到 Claude Code |
| **终端** | 多标签内嵌终端：字体配色可调、全屏模式、会话结束 / 失败覆盖卡 |
| **上线** | 按日期跟进发布准备：「任务」子页管任务与步骤确认，「基础配置」子页维护服务目录 + 环境定义；到期事项弹「上线提醒」 |
| **设置** | 外观（字号 / 窗口效果）/ 模块开关 / Claude 代理 / MCP 服务 / 提醒弹窗 / 日志（保留·级别·查看）/ GitHub 同步等 |
| **关于** | 版本、构建信息与许可（纯展示页） |

## 2. 启动与导航

启动后先看到约 1.2 秒的启动画面，随后进入首页。应用启动时会自动完成：

1. 创建数据目录与日志；
2. 打开本地数据库 `devdesk.db`（首次启动自动建表、创建默认看板列）——库损坏但有备份时**自动还原**（损坏库隔离留盘），还原失败弹「备份还原失败，应用即将退出」后退出；数据库迁移失败时弹窗说明原因（不再无声闪退）；
3. **Claude 代理默认不启动**（端口不监听）——只有 Claude 页手动「启动代理」，或设置页开了「随应用启动代理」才会启动并接管 Claude Code 配置；异常退出遗留的接管快照会在启动时补还原；
4. 按模块开关装配页面与侧边栏（关闭的模块代码不再执行、侧边栏不显示入口；壁纸等平台能力不支持时整页不注册）。

**导航**：

> 本文快捷键统一写作 **⌘/Ctrl+X**：macOS 按 **⌘**，Windows 按 **Ctrl**；界面内的快捷键提示同一口径。

- **侧边栏**：展开宽 200px / 折叠宽 72px，列出全部已启用模块入口，当前页高亮，点击切换。「上线」是**分组父项**：点击只展开 / 收起分组，要点子项「任务」「基础配置」才进页。
- **⌘/Ctrl+B 折叠 / 展开侧边栏**：折叠后只显图标（图标含义见展开态名称，折叠态暂无悬停提示），折叠状态跨重启记忆。注意：焦点在 Markdown 编辑器内时 ⌘/Ctrl+B 被「加粗」占用，需先点出编辑器或用左下角按钮。
- **首页是导航枢纽**：统计卡、底部快捷按钮都可点击跳转对应模块（快捷按钮还会在目标页自动弹出新建对话框）。
- **系统托盘**：主窗口点 ✕ 隐藏到托盘（进程不退出）；**左键单击托盘图标唤起主窗**；右键弹菜单——「显示主窗口 / 退出 DevDesk」，壁纸模块开启时菜单多一组「下一张 / 暂停壁纸（继续壁纸）/ 停止壁纸 / 打开壁纸页」。托盘菜单点「退出 DevDesk」才是真正退出进程。退出时有未保存编辑会先弹确认弹窗；主窗处于隐藏 / 最小化态时，确认弹窗弹出前会**先唤起主窗**（批次收尾修复了隐藏态「Exit 静默失灵」）。
- **单实例**：再次启动程序不出第二个实例，只唤起已有实例（关联打开 .md 时主窗保持托盘态、仅开查看器）。

## 3. 各模块怎么用

### 3.1 首页（工作台）

**能做什么**：一屏看清今日开发状态并一键跳转；全部数据直读本机库。

**怎么操作**：

- 页面标题「工作台」，右上角「刷新」按钮——每次进入首页自动重查一次统计；停留期间数字不自动更新，需要时手动点「刷新」。
- **5 张统计卡恒显**（与模块开关无关）：`Token 速率`（最近一次成功代理调用的速率 tok/s，无成功调用显 `--`，流式进行中数字主色 + 实时曲线）、`今日笔记`、`待办任务`、`逾期任务`、`API 调用`。点卡片跳对应模块（Token 速率与 API 调用 → Claude 页，今日笔记 → 笔记页，待办 → 待办页，逾期 → 待办页并直接弹逾期列表）。
- **今日 token 图表卡**：小时用量分布图；点卡内折叠钮收起 / 展开，折叠状态跨重启记忆。
- **底部快捷按钮**（按模块开关显隐）：`+ 新建笔记`、`+ 新建任务`（Claude Profile 切换入口已收敛到 Claude 页右键「设为当前」，首页不再提供快捷按钮）。

**出错了看哪**：数字显 `--` 且 Token 速率卡带红色「加载失败」badge = 统计查询失败，点「刷新」重试；「数据加载失败：数据库未初始化」= 数据库异常，重启应用；全部正常但模块被关闭时统计卡仍显示历史数据，仅对应快捷按钮消失。

### 3.2 笔记（Markdown）

**能做什么**：笔记就是磁盘上的普通 `.md` 文件——目录树 + 四态视图 + 标签 + 中文全文搜索 + 大纲跳转，400ms 自动保存，写盘后在后台静默 git 自动提交。

**怎么操作**：

- **四态视图**：页头 Tab `编辑 / 实时 / 双栏 / 预览`，或 **⌘/Ctrl+Shift+P** 循环切换。实时态可点击渲染块就地编辑；预览态点块跳回编辑器对应行。
- **新建笔记**：页头「新建笔记」或 **⌘/Ctrl+N**——名字可带子目录（如 `工作/周会.md`，自动建目录、自动补 `.md`）；名字留空直接回车秒建「无标题笔记.md」。**文件名预检**（批次 E）：Windows 保留名（CON、NUL 等）与超 255 字节的名称会在提交前被拦截提示，不再等系统级报错。
- **目录树右键**：文件 = `重命名 / 删除笔记`（删除有确认，删的是磁盘文件本身）；文件夹 = `新建子目录 / 新建子笔记 / 重命名 / 删除`；**根目录右键可直接「新建子目录」**（批次 E）。重命名对话框填带 `/` 的路径即同时移动（如 `工作/新名.md`）。
- **编辑器**：停止输入约 400ms 自动落盘，底部状态栏 `● 未保存 / ✓ 已保存 HH:MM / ✕ 保存失败，自动重试中`；`⌘/Ctrl+B` 加粗（再按一次去除）、`⌘/Ctrl+I` 斜体、`⌘/Ctrl+K` 链接、`Tab / Shift+Tab` 缩进（表格行内变跳格）、`Enter` 自动续列表、`⌘/Ctrl+S` 显式落盘；右键编辑器可插入 GFM 表格模板。
- **标签**：编辑器标签区输入回车添加，点标签筛选左栏；标签存数据库，**不写入 md 正文**。
- **搜索**：左栏搜索框，标题 / 正文全文过滤（拉丁词走 FTS5 索引、中文走子串匹配兜底）。
- **大纲**：页头「大纲」开关弹浮动面板，`#` 标题自动成树，点标题跳转。
- **外部修改**：应用约 5 秒自动比对磁盘与索引——外部新增 / 删除 / 修改自动同步进树；当前笔记被外部修改时 toast「检测到外部修改，已自动重载」；与未保存的本地编辑冲突时提示二选一，✕ 关闭 = 保留本地编辑。
- **git 自动提交**：写盘成功后后台静默 `git add -A + commit`（5 分钟节流）；git 不在 PATH 时功能整体静默禁用，笔记功能不受影响。
- **退出保护**（批次 B，2026-11-26 强化）：退出应用时若有未保存的编辑，会先同步保存；保存失败则**阻止本次退出**，弹「重试保存 / 放弃并退出」，不再静默丢稿。

**出错了看哪**：

| 提示 | 含义 / 处置 |
|------|------|
| `✕ 保存失败，自动重试中` | 磁盘满 / 只读等写入失败，按指数退避自动重试；切页 / 退出前会再尝试落盘 |
| `笔记已被删除` / `笔记已被外部删除：保留的本地编辑会在保存时重新创建该文件` | 文件在应用外被删 |
| `无法打开: <路径>` | 文件访问被拒 |
| `名称不合法：不支持绝对路径、盘符（如 C:）或 ..` | 新建 / 重命名输入含非法路径成分 |
| 保留名 / 名称超 255 字节红字 | 文件名预检拦截（批次 E），改个合法名字即可 |
| `自动重扫失败` | 笔记目录运行中丢失，检查目录是否存在 |

### 3.3 Git（只读查看器）

**能做什么**：选择一个本地 git 仓库后浏览文件树、查看工作区变更与 unified diff、全仓内容搜索。**本模块是只读查看器：不做 stage / unstage / commit，没有分支操作，也没有任何网络功能**——所有仓库修改请在终端或专业 git 工具里完成。

**怎么操作**：

1. 侧边栏「Git」→ 空态页点「选择仓库目录」（系统目录选择器）→ 校验通过进入三栏主界面；上次选择的仓库会自动记忆并打开。
2. 左栏文件树（Tab `全部文件 / 仅修改`）；中栏变更列表（`变更 / 未跟踪` 两组）；右栏 `内容 / diff` 双 Tab。顶栏为仓库路径 + 搜索框 + 「↻ 刷新」+「切换仓库」。
3. 「↻ 刷新」手动刷新；在应用内保存文件后变更列表自动更新（1 秒节流）。
4. diff 查看：unified diff 帧行号与六类高亮；点折叠条展开早期未变更行；重命名文件显示 `old → new`。
5. 全仓搜索：顶栏搜索框输入，**Enter** 提交、**Esc** 取消——先显扫描进度，再出命中列表（文件:行 + 高亮预览，点击跳转）；单文件最多 5 条，全仓超 200 条提示细化关键词。
6. 「切换仓库」重新走目录选择器。

**出错了看哪**：`该目录不是 git 仓库` / `没有权限访问该目录`（选目录被拒）；`上次打开的仓库不可用：<原因> 已清除该条记忆，请重新选择仓库`（记忆仓失效）；`文件过大，未加载内容（>1 MiB）` / `二进制文件，不预览二进制内容` / `暂不支持该编码`（内容页占位说明）；`工作区无变更` / `无可显示文件`；`未找到匹配内容`。

### 3.4 待办（Todo 看板）

**能做什么**：固定四列看板（待办 / 进行中 / 已完成 / 已归档）管理任务全生命周期：新建、拖拽 / 键盘 / 右键移动、优先级、截止与逾期、标签、搜索、归档。

> 列为**固定四列**，没有新建列 / 重命名列 / 删除列入口（旧版的列管理已移除）。

**怎么操作**：

- **新建任务**：右上「新建任务」（建到「待办」列，按列语义定位，不依赖列序）；弹窗填标题（回车直达创建）/ 描述 / 优先级（无·低·中·高）/ 截止日期（今天 / 明天 / 选择…）/ 标签。列头没有独立「+」入口，创建入口只有这一处。
- **移动**：按住卡片拖到目标列松手落位；右键卡片 `编辑 / 上移 / 下移 / 移到「某列」/ 删除`；或点卡片选中后 **⌘/Ctrl+↑ / ⌘/Ctrl+↓** 上移下移。归档列不可拖出。
- **任务详情**（点卡片打开）：标题 / 描述 / 优先级 / 截止日期 / 标签 / 关联文档（选一篇笔记作详细说明，需 Markdown 模块开启）；底部 `删除`（有确认）/ `标记完成·取消完成` / `保存`。有未保存修改时点遮罩会先警告。
- **完成流转**：详情弹窗「标记完成」任务自动移入已完成类列；拖入 / 拖出「已完成」列等效。
- **智能体操作**（2026-11-26 裁决）：智能体经工具可在待办 / 进行中 / 已完成列自由新建、修改、移动、完成、删除，不做列白名单限制；工具「标记完成」只记完成时间、不自动搬列，搬列由调用方决定。
- **逾期**：卡片截止按自然日口径——截止日=当天整卡橙黄（不算逾期），过期未完成红色；页头「逾期 N」chip（0 时置灰）弹逾期列表，行内含所属列与逾期天数，点行直达详情。
- **自动归档（应用启动时；从 GitHub 同步导入数据库后也跑一次）**：会把「已完成」列里**完成时间早于当天零点**的任务自动搬进「已归档」列——归档本身不弹确认框，但启动时若有任务被自动归档，会弹一条「自动归档」提示 toast 告知条数（可在归档列查看），所以「昨天点了完成、今天开机就没了」就是这么发生的；放进「已完成」列但从未打过完成标记（无完成时间）的任务同样会被搬走。搬走之后：归档列默认折叠成窄条、点列头才展开；展开后只渲染最近 20 张（更早的显示「另有 N 张较早归档未展示」）；归档任务详情**只读**，标题 / 描述 / 优先级都不能改。想弄回来：右键卡片选「移动到「某列」」搬出归档列——搬到待办 / 进行中 = 取消完成（完成时间清空），不会再被自动归档；**把它搬回「已完成」列不算复活**（归档前的完成时刻被保留），下次启动照样再被归档。
- **搜索**：页头搜索框实时按标题 / 描述 / 标签过滤，无命中列显「无命中任务」。
- **归档**：拖入「已归档」列即归档（另有上条的自动归档规则）；归档列折叠为窄条，点列头展开；按归档时间倒序、不支持手动移动、只渲染最近 20 张（超出提示「另有 N 张较早归档未展示」）；已归档任务卡带「归档」chip 标识（批次 E）。

**出错了看哪**：`数据加载失败：<原因>（点击重试）` / `数据库尚未就绪，数据未加载`（打不开库）；`任务标题不能为空`；`移动失败 / 删除失败 / 保存失败 / 新建任务失败：<原因>`（写操作失败走页头状态条）；`归档任务按归档时间排序，不支持手动移动`；`关联文档需要 Markdown 模块启用`。

### 3.5 定时（Schedule）

**能做什么**：管理定时规则——六类触发（一次性 / 间隔 / 周期 / cron 表达式 / 事件 / 常驻），触发后按动作仅提醒、提醒并打开页面、静默执行已注册任务或仅投递到企业微信；运行历史可查状态、投递明细并重试；「系统定时」Tab 里的系统级规则只读。

**怎么操作**：

1. 「新建」→ 弹窗「定时规则」：启用开关、名称、类型六选一、按类型填字段（如一次性 = 触发时刻、周期 = 周几 + 第 N 天或第 N 个周几 + 时刻、表达式 = 五段 cron）、动作四选一、错过策略（补一次 / 跳过 / 全部补）、通知渠道多选（企业微信渠道凭据存本机数据库 `app_secrets` 专表）；底部「接下来 5 次」触发预览可即时验证配置。
2. **编辑已有 cron 规则**：表达式会正常回显（批次 A 修复了旧版「编辑即清空表达式、保存即损坏规则」的问题）。
3. 弹窗支持键盘：**Enter / Esc**（批次 E）。
4. 启停：编辑弹窗「启用」开关；停用后行卡显「已停用」。点击行卡进入编辑。
5. **运行历史**：「运行历史」按钮开抽屉——汇总「共 N 条 · 成功 X · 失败 Y · 错过 Z」；每条含状态（成功 / 失败 / 已错过 / 运行中 / 待执行 / 已跳过 / 已抑制）、计划 / 实际时刻、耗时、尝试次数与投递明细；失败 run 有「重试」按钮。

**出错了看哪**：保存校验红字（如 `calendar.time 必须为 HH:MM 且小时 0-23、分钟 0-59`、`静默执行动作必须选择一个已注册任务`、`仅投递动作必须勾选「企业微信」渠道`——按提示改字段即可）；`定时列表加载失败：<原因>`；`暂无运行记录`（空态提示，批次 E 起为统一空态组件）；停机 / 睡眠错过的触发按错过策略补跑（停机窗口过大仅记前 100 个错过点，遗漏超 100 次合并为摘要并告警）；投递连续失败弹本地告警「提醒投递失败」，渠道永久失效会自动停用并告警「调度渠道已停用」。

### 3.6 Claude 配置切换器

**能做什么**：管理多套 Claude API 配置（Profile），本地跑一个带鉴权的流式代理，让 Claude Code 经代理调用 API；启动代理即自动接管 Claude Code 的 settings.json，停止即按快照还原。

**怎么操作**：

- **代理默认不启动**：需本页点「启动代理」，或设置页开「随应用启动代理」。未启动时页面有引导条说明接管行为。
- **+ 新建 Profile**（⌘/Ctrl+N）：三页签表单（基础信息 / 模型配置 / 环境变量）；首个 Profile 提交时先做导入预检（「正在验证可用性…最长 5 秒」）；当前没有任何激活 Profile 时，新建的会自动激活。
- **导入当前配置**：读 `~/.claude/settings.json` 解析托管键后预填新建表单；保存后的 API Key 与全部凭据统一存本机数据库 `app_secrets` 专表（应用不读写系统钥匙串）。
- **测试连通**：对 `<Base URL>/v1/messages` 发一次 1-token 探测（**15 秒超时**）——注意不是旧版的 GET /v1/models。结果 toast：成功「连通成功」；失败「连通异常」+ 分类提示（401/403 = API Key 被上游拒绝；404 = 接口不存在或模型不可用，检查 Base URL 与模型配置；其余 = 检查 API Key 或 Base URL）。
- **启动代理**：先做启动前置校验（激活 Profile 存在 + 对上游连通探测 2 秒超时），通过后监听 `http://127.0.0.1:<端口>`（默认 8888）并接管 Claude Code 配置；「停止代理」停止监听并按快照还原。
- **Profile 右键菜单**：`编辑 / 复制配置 / 删除 / 设为当前`；删除激活 Profile 会同时停止代理并还原配置。启用 / 切换 Profile 会弹确认，代理运行中立即按新配置重新接管。
- **模型配置页签**：槽位 / 上游模型名 / 显示名；「1M 上下文」勾选即时生效。
- **调用记录**：详情底部「查看全部 →」开弹窗——搜索框、状态码过滤、分页每页 20 条。
- **流式看门狗**（批次 A）：流式转发对上游空闲超 **300 秒**自动断开并向客户端发 error 帧，不再无限挂起；可用环境变量 `DEVDESK_PROXY_STREAM_IDLE_TIMEOUT_MS`（毫秒）调整。
- 快捷键：⌘/Ctrl+N 新建、⌘/Ctrl+S 保存表单、⌘/Ctrl+Enter 启停代理。

**出错了看哪**：`启动代理失败`（端口被占用，或前置校验不过——先修配置再启）；`连通异常` 分类提示（见上）；调用返回 `503 no_active_profile`（没有启用任何 Profile）；`服务未就绪（ClaudeService 未注册）`（会话内刚开启模块，重启应用）；接管 / 还原失败会进详情警告行与设置页「同步警告」区。

### 3.7 智能体

**能做什么**：把「提示词 + 触发（cron / 手动）+ 可用工具」配成任务，由应用内调度到点自动跑或手动跑；LLM 直连当前激活 Profile；带完整运行记录与三重硬上限。

**怎么操作**：

- 「+ 新建任务」→ 新建弹窗第一步可**一键套用 13 张出厂模板**（日报草稿 / 发版 Changelog / 测试环境巡检 / 变更雷达晨报 / 日期笔记 / 逾期待办巡检 / Profile 可用性巡检 / 定时任务报错巡检 / 智能体报错巡检 / 记忆模块统计 / MCP 连通巡检 / 记忆引擎健康巡检 / 一键系统晨检；巡检类默认每天 09:00，记忆统计每周一），套用后名称 / 触发 / 提示词预填可改。
- 任务卡右下「启动」立即手动跑一次；运行中按钮变「运行中…」防重复点击。运行结束发系统通知（失败 / 受限 / 正常结束）。
- 「试运行」= 创建临时任务跑一轮后自动删除，不落正式任务。
- 点任务卡开详情：运行记录列表（状态 / 起止 / 迭代数 / token / 错误），可看逐条消息与工具调用明细。
- 「可用工具」弹窗查当前全部工具（随各模块启用自动注册：`schedule.runs` / `agent.runs` / `memory.stats` / `memory.health` / `mcp.health` / `net.fetch` / `app.*` / `claude.*` 等；模块关闭后工具消失）。工具异常会回喂模型自纠，不中止运行。
- **硬上限**（触达时 run 状态为「受限」而非失败，并发通知）：迭代数 ≤50、墙钟 ≤30 分钟、token 累计 200K。

**注意**：调度依赖应用进程存活——应用没跑就不触发；**一次性任务错过不补跑并自动停用；cron 任务跨重启不补跑**。无可用 Profile 时页面有「去 Claude 页 →」引导。

**出错了看哪**：任务卡「配置异常」/「已停用」徽章；`启停切换失败：<原因>`；`读取任务失败` 等红字；「智能体任务失败 / 受限」系统通知（详情以运行记录为准）。

### 3.8 记忆

**能做什么**：在 Claude 对话时自动采集片段，经云端 LLM 提炼成「提案」，你在「记忆审核」TAB 逐张裁决入库；之后 Claude 对话自动注入检索到的记忆，外部客户端也可经 DevDesk MCP `memory_search` 主动查询。

**怎么操作**：

- **首次安装**：主控台引擎状态带点「首次安装向导」，四步清单（① Python 3.10~3.13 检测 → ② venv + pip 安装 → ③ embedding 本机包（首次约 26MB 联网下载）→ ④ 引擎拉起与健康检查），底部「开始安装 / 重试」；完成后引擎绿点「运行中」。
- **配置 TAB**（四个折叠组）：
  - 提炼端点：点「从 DevDesk 网关一键导入当前 profile」绑定 Claude 页当前激活 Profile；**提炼 API key 只存本机数据库 `app_secrets` 专表**（不进系统钥匙串、不写配置与日志）；向量化全部落本机（`127.0.0.1:11435`，零 API 费）。
  - 触发线：升级阈值与两字词提炼基线滑条。
  - 用量告警：日档 / 月档软硬档滑条，越线弹桌面提醒（每档每天最多一条），月硬档触发后提炼暂停。
  - 安全与隐私（常显）：脱敏开关**默认开**（关闭需红色二次确认）；「导出全部记忆（JSON）」落盘数据目录；「清除全部…」需输入「清除」二字武装确认——只清本机面板库，引擎侧记忆不在范围。
- **记忆审核 TAB**：待审提案卡流（类型徽章 新增/遗忘/失效/合并、置信度、证据链、正文预览），每张三选一：`接受` / `拒绝` / `编辑后接受`；「批量处理」模式（仅遗忘 / 新增可批量接受）；切「已处理」chip 查看已裁决卡并可「撤销」（生成一张撤销卡回到待审再审一次）；默认渲 50 条，尾部可「再显示 50 条」。引擎未运行时顶部黄条提示当前为未经提炼的原始片段。
- **对话注入**：每次对话最多注入 5 条、合计 500 字；hook 检索 800ms 超时，不阻断提问。
- **MCP 查询（对外唯一入口）**：MCP 客户端只需配置 DevDesk hub 一个 server 地址（见 [§3.10](#310-mcp)），调 `memory_search` 工具（参数 limit 1~10 默认 5，超时 3000ms，输出 20000 字顶）；该工具是否开放由 **MCP 页「记忆」模块行开关**控制（设置页无此开关）。记忆引擎内部的 `127.0.0.1:8421` 是实现细节，**不作为接入方式**。
- **健康监视**：主控台健康四格（脱敏闸 / 触发线评测 / 注入预算 / 存储概览）+ token 消耗带 + 最近调用记录与动态流；「跑评测」冻结 15 条查询本机自测（零 API 费）。

**出错了看哪**：引擎状态点灰 `未启动` / 黄 `准备中` / 绿 `运行中` / 红 `故障`（故障时点「详情」看原因）；`面板数据通道异常：<错误>`（面板库打不开，不留白）；向导第③步 `失败：<原因>（可重试）` / `下载中断`（慢网空闲超时判死，重跑一轮即可）；端点组头黄字「未导入——提炼不可用」。

### 3.9 壁纸

**能做什么**：视频 + 图片混合的动态桌面壁纸：单循环 / 顺序循环 / 随机播放、系统事件（锁屏 / 熄屏 / 睡眠 / 全屏窗口 / 电池供电）自动让路暂停、解除后**断点续播**；片库页管理素材，macOS 可一键「从花見导入」。

**怎么操作**（模块默认关闭，设置页开启并重启后出现）：

- **播放页**：状态卡（继续 / 暂停 / 下一个）、播放模式卡（单循环 / 顺序循环 / 随机）、轮换间隔、音频折叠组（静音开关）、「这些情况会让路」规则组（前四项不可关，电池项可关；让路发生时组内亮显「让路中」与原因，解除自动续播）。
- **片库页**：选择壁纸文件夹（视频 / 图片）+ 重新扫描；macOS 额外「从花見导入…」（同名同大小自动跳过，完成后自动重扫）；分辨率筛选（1080P / 2K / 4K 档）与图片适配（填充 / 适应 / 居中 / 平铺）。
- **格式边界**：视频仅扫描 `mp4 / mov / m4v`，图片仅 `jpg / jpeg / png / webp / heic`——MKV / AVI / WEBM 等不会出现在片库也不会转码，需自行转成 mp4。多显示器仅主屏生效。

**出错了看哪**：路径行 `目录不见了`（文件夹被移走）；播放错误显示在状态卡；`无法读取花見` 弹窗（未装完整或未授予完全磁盘访问权限，弹窗可直达系统设置）；计数行 `参与轮播 0 / 低于档位 N`（素材全被过滤）。

### 3.10 MCP

**能做什么**：本机 MCP hub 服务，把内置工具（`memory_search` / `md.*` 笔记检索读写 / `web_fetch_markdown` / `app.read_settings` / `project_info` 等）经 `http://127.0.0.1:<端口>` 以标准 MCP 协议开放给 Claude Code 等客户端；页面可启停、试跑工具、一键安装到 Claude Code。

**怎么操作**：

1. **服务区**：端口与运行状态（`运行中 127.0.0.1:<端口> / 已停止 / 启动失败：<原因>`）；改端口回车或点「应用」，运行中自动重启。设置页「MCP 服务」卡与本页同源。
2. **工具卡**：点卡开详情弹窗——工具名 / 描述、按 schema 生成的参数表单（必填 / 可选）、参数 schema JSON 原文、「试一下」后台试跑并把结果显示在「运行结果」区。
3. **安装到 Claude Code**：写入 `~/.claude.json` 的 mcpServers 键（写前先备份），提示「已写入，重启 Claude Code 后生效」；已安装时按钮变「从 Claude Code 卸载」。
4. **记忆卡**：开关控制 `memory_search` 是否出现在工具清单。
5. **工具总闸**（批次 A）：每个工具调用有外层超时（默认 **600 秒**），慢工具不再挂死请求线程；环境变量 `MCP_TOOL_TIMEOUT_SECONDS`（秒）可调。
6. **破坏性工具开关**（页头「破坏性工具」行，**默认关闭**）：关闭时 7 件有不可逆副作用的工具一律拒绝，客户端收到 `isError` 结果（文案 `破坏性工具 <名> 未授权：MCP 页「破坏性工具」开关为关闭状态`）、不进入执行——`fs_write`（写文件）/ `fs_edit`（改文件）/ `bash_run`（执行命令）/ `git_commit`（Git 提交）/ `claude_switch_profile`（切 Profile，会改写代理配置）/ `md_delete`（删笔记）/ `todo_delete`（删待办）。开关是**总开关**：打开 = 这 7 件全开（没有逐工具白名单），关闭 = 全关；状态持久化，重启后保持。
7. **并发上限**：同时执行的 `tools/call` 默认最多 **8** 个，超限立刻拒绝并回 `-32603 并发已达上限`（不排队，客户端自行重试）；环境变量 `MCP_MAX_CONCURRENT_CALLS` 可调（1~1024，非法 / 越界值回落 8）。被超时放弃的调用线程会继续跑到自己结束并占着槽位，服务重启也不清零——挂死调用攒满上限时需重启应用。

**出错了看哪**：`启动失败：<原因>`（多为端口占用）；`请先启动 MCP 服务`（未启动就点安装）；`未检测到 Claude Code（~/.claude.json 不存在）`；`~/.claude.json 的 mcpServers 是非对象形态…拒绝写入`（按提示先手工修正该键）；`缺少必填参数：<名>` 等试跑校验红字；`破坏性工具 <名> 未授权…`（页头开关没开）；`并发已达上限`（同时调用过多，等前面的跑完）；客户端侧协议错误：`-32601 未知方法` / `-32602 参数错误` / `-32603 内部错误` / JSON 非法 HTTP 400。

### 3.11 终端

**能做什么**：多标签内嵌终端（ConPTY / 伪终端）：字体配色可调、回滚行数可配、全屏模式、会话结束 / 失败覆盖卡。

**怎么操作**：

- 「新建」（TAB 栏右侧）或空态中央「+ 新建会话」→ 按设置的默认 shell 启动新会话；TAB 标题「终端 N」。
- TAB 栏「设置」→「终端设置」弹窗两组：**外观**（字体 / 字号 / 配色主题——跟随应用或独立亮暗 ANSI）与 **会话**（默认 shell / 启动目录 / 回滚行数 / 光标块线与闪烁）；弹窗内多处标注「**对新会话生效**」；底部「恢复默认」「完成」。
- 全屏切换钮：侧栏全隐、TAB 栏保留、终端铺满；再点退出。冷启动直接全屏可用环境变量 `DEVDESK_TERMINAL_FULLSCREEN`。
- 会话退出 / 失败出覆盖卡：正常退出「会话已结束，退出码 N」+「重新开始 / 关闭标签」（输出保留）；启动失败「终端启动失败」+ 错误详情 +「重试」。

**出错了看哪**：启动目录行红字 `目录不存在`（实际启动会回退用户主目录）；回滚行数过大警示 `较大回滚占用内存`；`终端启动失败`（shell 路径无效等，按详情排查后「重试」）。

### 3.12 上线（任务 + 基础配置）

**能做什么**：按日期跟进发布准备。「任务」子页管「哪个服务、哪天、走到哪一步」；「基础配置」子页维护服务目录 + 环境定义；到期事项弹「上线提醒」。

**怎么操作**：

1. **先到「基础配置」**建服务与环境（新建任务依赖环境）：服务 = 名称 / 类型 / 默认分支；环境 = 名称 / 包含服务多选 / 时间窗（支持跨零点，如 22:00–02:00(次日)；09:00–09:00 = 24 小时窗）。
2. 「任务」子页「新建任务」→ 计划上线日期 + 常规发布日 chip（周二 / 周四）+ 加入环境多选；选了**非常规发布日**会先弹二次确认。
3. 任务卡显状态 chip（草稿 / 待执行 / 执行中 / 已完成 / 已作废）+「下一步 · 步骤名」+ 迷你进度条；点卡进详情，按环境分节确认 / 跳过步骤；**修改已确认步骤的内容会自动撤回旧确认**（notice「配置已修改，已自动撤回 N 项旧确认」）。
4. **上线提醒弹窗**（默认关闭，需在设置页「提醒弹窗」卡开启）：到期时全屏置顶列出「上线日 / 环境」分组与「去处理」按钮；Esc 或右上角关闭，全部处理完自动关。

**出错了看哪**：新建任务弹窗 `基础配置里还没有环境`（先去基础配置建环境）；表单红字 `名称已存在，请换一个` / `开始/结束时间格式应为 HH:MM（00:00–23:59）`；删除被引用服务时确认弹窗会说明「被 N 个环境引用；删除后将自动从这些环境摘除」；`无法加载任务列表 + 重试`。

## 4. 数据都在哪

全部在本机数据根 `%USERPROFILE%\DevDesk`（macOS 为 `~/DevDesk`；环境变量 `DEVDESK_DATA_ROOT` 可整体覆盖，`DEVDESK_NOTES_DIR` 可单独覆盖笔记目录）——刻意放在用户主目录下，资源管理器 / Finder 默认可见：

| 路径 | 内容 | 说明 |
|------|------|------|
| `<数据根>\notes\` | **所有笔记** | 普通 `.md` 文件树，可直接备份 / 同步 / git 管理 |
| `<数据根>\devdesk.db`（+ `-wal` / `-shm` / `*.db.backup-*` / `*.db.corrupt-*`） | **SQLite 主库（几乎所有状态都在这里）** | **应用配置（`app_config` 表）**、Todo 列与任务、定时规则与运行历史、Profile 元数据与凭据密文（`app_secrets` 专表）、笔记索引（FTS5）与标签、代理调用日志、智能体任务与运行记录、Markdown / Todo 视图状态 |
| `<数据根>\memory\` | **记忆模块全部自家库** | venv、embedding 本机包、faiss 索引、提案 / 账面库等，随数据根隔离 |
| `<数据根>\logs\devdesk.log` | 运行日志 | 排查问题先看这里；保留天数在设置页配置 |
| `<数据根>\.gitignore` | 应用自动维护的屏蔽名单 | `*.db` / `*.db-*` / `config.json*` / `run-settings/` / `claude_settings_snapshot.json` / `logs/` 等；若把 `~/DevDesk` 做成 git 仓库请保留它 |
| `%USERPROFILE%\.claude\settings.json` | Claude Code 用户配置（接管） | **代理运行期间** DevDesk 只写托管键（`ANTHROPIC_*` 等），其余键原样保留；停止代理 / 删除激活 Profile / 正常退出自动还原，异常退出下次启动补还原 |

> **`config.json` 已退役**：旧版指南写「配置持久化在 `%USERPROFILE%\DevDesk\config.json`」——该文件已不再读写，全部配置现存在 `devdesk.db` 的 `app_config` 表；数据根里的 `config.json*` 属旧配置残骸（已被 .gitignore 屏蔽）。

**凭据存在哪 / 保护到什么程度**：

- 全部密钥统一存放在 `devdesk.db` 的 `app_secrets` 专表（加密列）：Claude Profile 的 API Key 与供应商额外凭据、记忆模块的提炼 LLM key、定时企业微信渠道凭据——应用**不读写系统钥匙串**，也没有独立的 keychain 目录。
- 密钥表不进 SQL dump：导出 / 转储内容不含 `app_secrets` 表，密文只随整个数据根目录（含 `devdesk.db` 本体）一起备份。
- 保护级别按平台不同：**macOS / Linux** 为文件权限级（数据根与库文件校正 `0600`，仅本用户可读，应用内文案「本机数据库存储（文件权限 0600，仅本用户可读）」）；**Windows** 为 DPAPI 加密级（密文绑定当前 Windows 用户，换用户 / 换机器读不出，文案「DPAPI 加密，仅本机本用户可解」）。

**备份**：拷走整个 `<数据根>` 目录即可（含 `devdesk.db` 及其 `-wal` / `-shm`）。**从旧位置升级**：旧数据不做自动迁移——手动把旧目录里的 `notes/` / `devdesk.db`（连同 `-wal` / `-shm`）拷进新数据根即可（拷贝前先退出 DevDesk）。

## 5. 常见问题

- **打开应用了，代理却没在跑？** 设计行为：代理**默认不随应用启动**。去 Claude 页点「启动代理」，或设置页「Claude 代理」卡开「随应用启动代理」（下次启动生效）。
- **「测试连通」连的不是 /v1/models？** 现行探测口径为对 `<Base URL>/v1/messages` 发一次 1-token 请求（15 秒超时）——旧版 GET /v1/models 会把部分网关误报「连通异常」，已改。401/403 = Key 被拒；404 = 接口或模型不可用。
- **代理端口被占用？** 默认 8888、可配：设置页「代理端口」改后回车或点「应用」，代理运行中会自动重启（Token 不变）；失败提示见 toast 与日志。
- **Claude Code 调用返回 503 no_active_profile？** 没有启用任何 Profile（新建首套时会自动激活），或 Base URL / API Key 配置不完整。
- **接管会不会弄乱我的 Claude Code 配置？** 只重写托管键（`ANTHROPIC_BASE_URL` / `ANTHROPIC_AUTH_TOKEN` / `ANTHROPIC_MODEL` 等），写入前先存原值快照；停止代理、删除激活 Profile、正常退出都自动还原，崩溃后下次启动补还原。你的其他键与字段不动。
- **模块开关关了要重启吗？** 不用——开关**即时生效**，侧边栏入口与页面当帧更新。唯一例外：会话内重新开启 Claude 模块时代理服务可能未装配，页面会提示需重启。
- **主题（深 / 浅色）在哪切换？** 当前深浅色**随系统自动**；设置页暂无手动切换控件，「主题手动切换入口规划中」（2026-11-18 现状）。字号缩放与窗口效果在设置页「外观」卡即时可调。
- **改了调用日志保留要重启才生效吗？** 不用——切换档位**立即清理一次**并提示「已清理 N 条历史日志」；「永久保留」不清理。
- **中文搜索搜不到？** 搜索走 FTS5（拉丁词索引）+ 中文子串兜底；确认笔记已保存（编辑器底部「✓ 已保存」）。磁盘改动约 5 秒内自动同步，无手动重扫按钮。
- **退出时编辑会丢吗？** 不会——笔记停止输入约 400ms 自动落盘；退出应用时若有未保存编辑会先弹确认（批次 B 交付）。
- **数据怎么备份？** 拷走整个数据根目录（见 [§4](#4-数据都在哪)）；Windows 凭据密文只能在同一 Windows 用户账号下解出。若把数据根做成 git 仓库，务必保留应用自动维护的 `.gitignore`。
