# 需-9 用量告警（日/月两档阈值 + 通知出口搭 M3 便车）— spec 草案

日期：2026-10-30 ｜ 需求池编号：需-9 ｜ 定级：**S 级**（判定是纯阈值比较，出口全搭既有基建） ｜ 状态：草案，批准前零代码
上游：`docs/superpowers/research/2026-10-30-需求场景支撑.md` 场景 M4 / A3；表结构参考 `docs/specs/2026-10-29-三池mcp业务方案.md`。

## 1. 一句话需求

在既有用量账面上加「日 / 月两档阈值判定」，越线走 M3 已建的通知出口主动提醒——把「用户自己去看卡片」变成「越线了来提醒我」。不采集新数据、不新建通知通道、不加任何限流动作。

## 3. 需求定义

### 3.1 两档阈值

| 档 | 判定输入 | 默认阈值 | 提醒语义 |
|---|---|---|---|
| **日档** | 记忆消耗账本「今日 token」（估算口径） | 500,000 token/日（可配） | 「今日云端消耗已达阈值——若有批量提炼/长会话，考虑收一收」 |
| **月档·token** | 账本「本月 token」对预算档 | 软档（默认 200 万）→ 警告级；硬档（默认 300 万）→ 严重级 | 软档：「本月用量已进黄档」；硬档：「本月已达硬档，提炼已暂停（检索不受影响）」 |

- 阈值均可配：token 档沿用记忆配置页既有预算阈值（不另起一套数）。
- 提醒文案统一带「估算口径」字样（token 为码点估算，不是引擎真值——既有已知限制，不因本需求装作精确）。

### 3.2 触发与节流（防轰炸）

- 判定挂在**既有周期点**上，零新增常驻循环：token 两档都挂在消耗账本写入路径（每次云端调用记账后顺手判）。
- **每档每日至多提醒一次**：日档 1 条/日、月档 1 条/日；跨档同日可各响（日档与月档语义不同，不合并）。越线状态未解除次日不重响（阈值上调或用量回落再进位后重新武装）。
- 严重级（硬档）允许穿透勿扰预期之外的普通提醒排序——沿用 platform::notify 的 level 通道（warning / error），不新建优先级机制。

### 3.3 通知出口依赖（搭 M3 便车，不新建通道）

- 出口统一走 **M3 run 终态通知基建的应用级 toast 链路**（`app::showAppNotice`，跨页可见）；需要系统级触达的场景（用户不在 app 内）按既有 `platform::notify` 通道发，失败自动降级回应用内 toast——两级出口都已在库，本需求只做「入队」，不做「送达」。
- 模块隔离约束下的接线：判定方（记忆账本写入路径）不直接依赖 module_agent 或 UI；入队走 app 层装配（函数指针桥先例：`mcp_service_bridge` / `memory_mcp_bridge`）。具体桥形态与挂点属实现方案，本 spec 只锁两条——**不新建通知通道、不允许 module 互相 include**。
- 点击行为 v1 不做路由（与 M3 / app.notify 既有决策同口径：通知只负责「叫人」，不负责「带路」）。

## 4. 非目标

- 不做新用量采集与真值对账（引擎真 token 对账是记忆线既有欠账，结构已留好，不随本需求扩面）。
- 不做任何自动限流/暂停动作——硬档「暂停提炼」是记忆线既有行为，本需求只加「提醒」，不改任何动作语义。
- 不做通知历史 / 通知中心 / 已读管理（app.notify 设计 §2.2 同口径非目标）。
- 不做用量预测与趋势（「按当前速率月底会超」留后续，v1 只判当刻越线）。
- 不做按任务/按模型粒度细分（v1 两档：日 token、月 token；再细等真实需求）。
- 不做供应商余量百分比档（如月窗 80%/95%）——余量功能现为摘除态、数据面不在库（见 §2 表）；若日后回迁，沿本 spec 同一通知接线开小迭代，不重新立项。
- 不改 M3 run 终态通知既有语义（failed/limited 迁移检测一行不动，用量提醒是独立入队源）。

## 6. 依赖与风险

- 依赖：M3 通知基建（已实施）与 platform::notify（已实施 T1a–T1e）——均为在库状态，无排产前置。
- 风险 1：估算口径误报（码点估算 vs 真值）→ 文案明示「估算」；阈值可调；UAT 期用真值对账欠账收口后自动变准（取数结构已留）。
- 风险 2：账本只覆盖记忆线云端调用，代理直连会话消耗不进本判定 → 文案与 UAT 口径明示「判定面 = 记忆消耗账本」，不装作全量；代理侧全量口径待真值对账欠账收口后再议。
- 风险 3：用户被提醒烦 → 每档每日一条的节流底线 + 阈值全可调 + 提醒只升不降级为弹窗阻塞（toast 自动消失）。
