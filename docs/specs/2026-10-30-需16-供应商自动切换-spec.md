# 需-16 供应商自动切换 spec（技术合成稿 · 实现任务书）

日期：2026-10-30 ｜ 业务：惨品（池条目需-16）｜ 技术：老学究（`docs/superpowers/research/2026-10-30-provider-auto-switch-技术面.md`）｜ **授权来源：老板娘依「电脑随你们操作」在案授权代批（2026-10-30），批全自动版** ｜ 状态：已批，本稿即任务书，实现归元气小萝莉（今晚免费窗口执行）

## 1. 目标

每晚 23:05 与每早 9:05 各探测一次 ZCode Start Plan（免费档）可用性：可用即切免费档、不可用/余额不足即切回付费档；切换条件 = 可用性状态变化，不是钟点表（白嫖到底）。切换动作失败必须告警，不静默。

## 2. 已批口径

- **全自动版**：授权写 `~/.zcode/v2/provider_config.json`（授权来源见文头）。
- 探测失败重试 1 次再切（防网络抖动误切）；切回方向同理。
- 两个时点同一逻辑「探测即判断」。

## 3. 技术方案（实锤依据见技术面文档）

- **切换点**：`~/.zcode/v2/provider_config.json` → `config.defaultModelSelection.providerId`，免费 = `account:bigmodel-start-plan`；付费 = credentials 里 `bigmodel-individual-coding-plan` 对应 providerId（实现时从 credentials 键 `account-provider:account:bigmodel-individual-coding-plan:identity` 现读现用，不硬编码猜测值）。写回必须原子（tmp + rename）。
- **探测**：zcode CLI 最小真实回合（极小 prompt，几十 token）；成功 = 可用；报文含 quota / 402 / 余额类错误 = 不可用。
- **执行器**：薄脚本（读字段 → 探测 → 决定 → 原子写回 → status_log 一行），挂 DevDesk agent 定时调度（23:05 / 9:05，时区本机）。modelId 维持 `GLM-5.3-Flash` 不变。
- **告警兜底**：写回失败 / 探测两连败 / 切换后验证回合失败 → 群告警，绝不静默停在原档。

## 4. 验收（老板明早验真实效果）

- V-01 人工把 providerId 置为付费 → 跑脚本 → Start Plan 可用时切到免费档，provider_config.json 字段变更 + status_log 记录。
- V-02 免费档在用再跑脚本（23:05 后场景）→ 不切，status_log 记「可用，维持」。
- V-03 探测注入失败（断网模拟或错误配额信号）→ 切回付费档且告警触发。
- V-04 credentials 失效场景 → 脚本报告错误并告警，不写坏配置文件（原子性验证：中断后文件仍合法 JSON）。
- V-05 两个 cron 点注册成功（调度列表可见 23:05 / 9:05 两条）。

## 5. 非目标

不动 DSH / bridge 层；不做多供应商泛化（就免费↔付费两档）；不做 web UI。
