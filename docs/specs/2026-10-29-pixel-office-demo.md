# PRD：像素办公室 Demo（Claude-Office 换皮）

日期：2026-10-29 ｜ 级别：S（小需求，拿来主义，免重 PRD 流程） ｜ 状态：草稿，待老板拍板 4 个开放项后定稿

## 背景
原手搓像素办公室 demo 被判「小孩子涂鸦」。调研已锁定开源现成方案 W17ant/Claude-Office（300 星，等距像素办公室 + 事件驱动 + 换肤机制），两道可行性门已验证通过：
- 门1（纯静态页）：前端为 Vite 静态资源；需给数据接入层加轮询（或桥接），渲染层不动，改动量小。
- 门2（status.json 桥）：仓库自带 REST 接口 `POST /status` / `GET /status`（字段含 sessionId/model/cost/context），DevDesk 侧起假端点或加 status.json 轮询补丁均可通。

## 目标
1. 用 Claude-Office 作为唯一前端，零渲染层开发，展示 DevDesk 智能体运行状态。
2. 数据源打通：DevDesk 状态（任务/会话/成本）→ 办公室小人行为与状态气泡。

## 非目标
- 二次元风格：无整装开源；Live2D 与该仓库渲染引擎不兼容；chibi 立绘与像素房间混搭违和风险高。真要二期单独立项，不塞本 demo。
- 换肤机制（The Office 主题一键切换）是原生能力，可留可关，不作为本 demo 验收项。
- 自研美术素材、手搓办公室场景。

## 功能矩阵
| ID | 功能点 | 优先级 | 状态 |
|----|--------|--------|------|
| F1 | 办公室场景静态页可打开可浏览 | P0 | 仓库自带 |
| F2 | DevDesk 状态 → status 桥接（假端点或轮询补丁，二选一由开发定） | P0 | 小改 |
| F3 | 小人状态气泡 / inspector 卡片（点小人查看） | P1 | 仓库自带，待老板拍板是否保留 |
| F4 | 任务白板 | P1 | 仓库自带，待老板拍板是否保留 |
| F5 | 权限审批卡（办公室内 Allow） | P2 | 仓库自带，默认关闭不阻塞 demo |
| F6 | 工资/电量仪表 | P2 | 仓库自带 |

## 用户操作流程
启动 → 浏览器/窗口打开办公室页 → 小人随智能体事件走动、冒状态气泡 → 点小人看任务详情卡（若 F3 保留）。

## 验收标准（用户视角）
- A1：办公室页在老板机器上正常打开，无空白/报错（对照仓库 README 四张截图：Day-Mode、inspector、task-board、meters）。
- A2：DevDesk 侧触发一次智能体任务，办公室内能看到对应小人状态变化（F2+F3 联动）。
- A3：改动仅限数据接入层与桥接，不改仓库渲染层代码（省钱红线）。
- A4：验收人：老板先看（真机点验）；截图对照由产品预审一遍再交。
