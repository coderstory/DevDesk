UI 设计体系 v1.0

最后编辑 2 分钟前1,284 字

玻璃质感成立需要三个条件同时具备：底层有对比、顶层有半透、边缘有高光。缺任何一个，玻璃就会退化成一张白卡。

为什么之前的半透看不出来

背景光晕的峰值透明度只有 0.11，卡面是 0.92。0.92 的白叠在「几乎白色的底」上，结果仍然是白——透出来的是「白透白」。

kMaxAlpha = 0.11f; // 背景峰值
kCardGlassAlpha = 0.92f; // 卡面峰值
// 0.92 × 0.11 → 视觉等同纯白

所以修复顺序必须是先加强底层，再降低卡面。alpha 调反了，怎么调都看不出来。

三层玻璃的定义

不是所有容器都该用同一个透明度。层级越靠近用户手指，越要不透明；越靠底，越要透。本方案定义了四层：

L3 浮层 0.97 + 强阴影 → 弹窗 / 菜单 / toast
L2 卡片 0.72 + 高光边 → 内容卡 / 统计卡 / 行卡
L1 面板 0.55 + 弱边框 → 看板列 / 侧栏浮层
L0 背景 7 个光晕漂移 → 全窗流体层

为什么不用真模糊

EUI-NEO 没有 backdrop-filter。与其等框架支持，不如用「1px 白色高光边 + 半透 + 冷阴影」三者组合——人眼会自动把「边缘发亮 + 背后透光」解读成玻璃。这是用设计原理绕开技术缺口，不是妥协。

配色的克制纪律

一屏只允许出现一个饱和绿色，就是主操作按钮。其余绿色一律退到软底或文字档。之前统计卡用五种颜色区分指标，结果五个焦点互相打架，反而没有一个能聚焦。
