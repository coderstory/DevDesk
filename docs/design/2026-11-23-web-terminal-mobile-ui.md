# 网页终端移动端 UI 设计（need#490）

- 角色：ui-ux-designer（设计端 Owner）
- 日期：2026-11-23
- 依据：PRD v3（池文档 `2026-11-23-web-terminal`）、ADR 0009（`docs/adr/0009-web-terminal-lan-exposure.md`）、视觉 token 唯一权威 `src/core/theme.h`（浅色档）
- Demo：`docs/design/2026-11-23-web-terminal-mobile-ui-demo.html`（单文件、零外部请求；**仅设计验证，非产品实现**）
- 门控结论：**必经**。新增绑定页、登录页、终端主界面、配置页四个网页界面 + 桌面「网页访问」专区，属新页面设计，不适用微调/纯文案级跳过。

## 1. 设计原则与两遍法自审

**原则句：这是一台装在手机里的终端监视器——屏幕让给终端，控件退到边缘，唯一的高饱和绿只出现在「主操作」和「已连接」上。**

AI 五 tell 自查：① 暖米色/衬线/陶土橙：未用（底色 #F5FAF7 为项目 token，无衬线）；② 暗夜霓虹：界面控件是浅色中性，深色仅存在于终端画布本体；③ 报纸排版：未用（圆角 10/14）；④ SaaS 卡片阵列：未用（终端页零卡片，画布满铺；认证页单卡；桌面专区单卡）；⑤ 模板镀铬：无全大写眉标、无中点元信息串、无箭头字符按钮。

两遍法第二轮：给同类页出方案会得到的默认答案是「顶栏 pill 页签 + 底部快捷键条 + 卡片式画布」。本设计逐条改掉：页签用**贴边方形页签**（工作台标签，不是导航按钮）；底栏只放「粘贴」+ 连接状态（PRD 明令不做快捷键条）；画布满铺到边，不做卡片浮起。大胆只花在一处：**终端画布**——它是唯一深色、唯一无圆角、唯一占满的区域。

## 2. 页面级构图

### 2.1 全局外壳与滚动模型

```
┌ safe-area-top（env；有刘海 47pt，无则 0）┐
├ 固定顶栏 48px ───────────────────────────┤  ← 永不滚动
├ 内容区 flex:1 ───────────────────────────┤  ← 唯一滚动区（按页面各自内滚）
│                                          │
├ 固定底栏 40px ───────────────────────────┤  ← 永不滚动
└ safe-area-bottom（有手势区 34pt，无则 0）─┘
```

- 外壳高度：正常 `100dvh`；软键盘弹起时改为 `visualViewport.height`，外壳随键盘收缩，顶栏与底栏不移动出视口。
- `html, body { overflow:hidden; position:fixed; inset:0 }`——**页面整体永不滚动**。
- 滚动归属：终端画布纵向内滚（网格宽于视口时额外横向内滚）；配置页 body 内滚；认证页卡片内滚（键盘弹起时）。外壳、顶栏、底栏、覆盖层不滚。
- 认证页（登录 / 绑定）不用顶/底栏，内容区独占并在卡片内滚动。

### 2.2 页面清单与导航

```
打开访问地址
 ├ 127.0.0.1 ────────────────────────→ 终端主界面
 └ 局域网
    ├ 携带有效绑定令牌 ─→ 绑定页 ─成功─→ 终端主界面
    ├ 已验证器 + 有效 cookie ────────→ 终端主界面
    └ 其他 ─→ 登录页 ─6 位码成功─→ 终端主界面
终端主界面 ⇄ 配置页（顶栏菜单进入，左上返回）
终端主界面 ─菜单「退出登录」→ 登录页
全屏覆盖（服务关闭 / 绑定已撤销）是终态层，不在导航栈内。
```

### 2.3 构图三问

1. **滚动模型对吗**：外壳固定、内容区内滚，与桌面端「窗户外壳不滚、内容区自滚」一致；终端画布横滚只在服务端下发网格宽于视口时出现（正常连接时手机按自身尺寸请求网格，见 §9）。
2. **有无无效空白**：终端页画布撑满剩余区域，无卡片内边距空框；认证页卡下留白是键盘安全区；配置页六行占满首屏，无定宽空列。
3. **密度与权重平衡**：375×667 下画布占 549px（82%），顶+底栏 88px；横屏画布 287px（76%）。配置页高频项（字号、启动目录）居中，低频项（字体、色板）靠边。认证页同视口只有 1 个主按钮。

### 5.2 终端画布

| 元素 | 参数 |
|---|---|
| 容器 | flex:1，底 = 终端色板底，内边距 8，`overflow:auto`（x/y 同一容器），原生惯性滚动 |
| 文本层 | 等宽字体栈 `ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`，字色/字号/行高按设置；`user-select:text`，`white-space:pre` |
| 光标 | 1ch × 行高实心块，底 = 光标 token；闪烁 1s step-end；减弱动效下不闪 |
| 选区 | 背景 = 选区 token，字色不变 |
| 点击 | 聚焦隐藏输入承接软键盘；隐藏输入字号 16px（防 iOS 聚焦缩放），`inputmode=text`、`autocapitalize=off`、`autocorrect=off`、`spellcheck=false` |
| 长按 / 拖选 | 交给浏览器原生选择；不自绘选择手柄、不拦截 `touchstart` 长按 |
| 纵向滚动 | 原生；用户停在底部时新快照自动贴底；用户上翻后保持偏移不跳（v1 不加「回到底部」按钮） |
| 横向滚动 | 仅当网格列宽超过视口时；光标列自动保持可见（横向 nearest） |

| 骨架 | 12 条圆角条（高 8、圆角 4、色 `rgba(250,249,245,0.12)`），宽度 62/84/46/70/38/88/54/76/40/66/82/50%，透明度 0.6↔1 呼吸 1.2s；减弱动效静态 |

## 11. 禁止项自查

- 旧橙 `#D97757`：全文与 demo 零出现；绿为唯一强调色。
- 红色只用于告警/错误/删除；蓝色未用于控件；灰为中性。
- 无框架/库名（demo 为原生 HTML/CSS/JS，单文件零依赖）。
- 无「大气美观」类描述；参数全部落到 px / 色值 / ms。
- 无快捷键条、无复制按钮、无上传/插画/emoji/装饰渐变；二维码仅桌面端。
- 无设备列表/设备名；无目录浏览；无手势退出全屏覆盖（防假象）。
- 触控目标 ≥44（关闭钮经热区外扩）；错误/成功文字走深色档满足 AA。
- 尊重 `prefers-reduced-motion`；iOS 输入承接 16px 防聚焦缩放。

## 12. 未决点与偏差

1. **关闭钮热区**：可见 32×32，经不可见外扩到 44×48；若实现层裁剪伪元素，需改用外层包裹按钮，外观不变。
2. **原生 select 外观**：iOS/Android 系统下拉样式不同，设计接受系统样式（不自绘下拉），仅统一高度/边框/字号。
3. **真机键盘时序**：`visualViewport` 在 iOS Safari 的 resize 抖动、Android 输入法高度差异由技术卡验证；布局规则（外壳随可视高、底栏贴键盘）不变。
4. **终端历史行数上限与虚拟化**：由技术卡定量，UI 规格（滚动、贴底、光标定位）不变。
5. **「当前在线数」**：设计给出显示规格；PRD P-16 允许成本高时整行省略，省略不影响其它行。
6. **demo 限制**：剪贴板/验证器/网络均为静态模拟；键盘、安全区、横屏为开关模拟；不代表真机行为。
