## 0. 构图门禁结论（参数批，三问逐答）

四条均为**参数级/局部几何修订**，不新增页面、不改区块划分与锚定关系：

1. **滚动模型**：不变。全站「外壳不滚、内容区各自内滚」维持；MCP 页唯一滚动区仍是工具网格（池 144 口径），md 树满高/编辑列内滚（池 130 口径）不受影响。
2. **无效空白**：净收敛。池 164 消灭 md 顶区 8px 浮空带；池 156 给 MCP 卡间补 24px 垂直节奏（16px 现值是 340–420 宽 × 120 高大卡的拥挤距，属密度缺陷非留白）。
3. **密度与权重**：TAB 放大后高频导航权重上升，与页头 40 档归一（kWtabHeight 40 = kHeaderH 40，metrics.h:12）；两处紧预算页（settings 通用 / release 基础配置）给出一比一补偿规则，最小窗零滚动保持。

## 2. 参数方案（核心交付：旧值 → 新值 → 落点）

### F1 卡片色相 白→浓绿（池 166；池 127 实度零回退）

**派生式（规格唯一口径，禁裸 hex）**——新增派生常量走 primary 派生（wtab.h:31-35 选中底同款先例，4 档强调色主题自动跟随）：

```
kGlassGreenMix = 0.75f                          // 品牌绿→白收敛比（Light）
greenBase.c = primary.c × (1 − 0.75) + 1.0 × 0.75   // 逐通道，c ∈ {r,g,b}

glassFill(Light)        = { greenBase, 0.94f }   // alpha 与池127 定稿逐字符一致
glassPanelFill(Light)   = { greenBase, 0.80f }   // 同上
glassFill(Dark)         = 不变（surface, 0.95）
glassPanelFill(Dark)    = 不变（surface, 0.78）
```

| 参数 | 旧 | 新 | 落点 |
|---|---|---|---|
| Light 填充基色 | surface×0.97 + {0.001, 0.023, 0.011}（绿染 3%） | **greenBase 派生式**（k=0.75），染式删除 | glass.h:14-17、:23-25 |
| 两层 alpha | 0.94/0.95、0.80/0.78 | **不动**（池 127 定稿） | glass.h:15、:17、:24、:25 |
| glassBorder | 白 0.60 / 0.12 | 不动 | glass.h:30-33 |
| glassShadowColor | 冷绿黑 0.09 / 黑 0.34 | 不动 | glass.h:37-40 |
| hover/pressed 派生 | materials.h 混黑 0.05/0.09、0.10/0.16 | 不动 | materials.h:13-17 |

- **可读性硬门槛**：卡面 textSecondary 对比 ≥ 4.5:1。k=0.75 时 greenBase 亮度 L≈0.785，对 #666666 = **4.56:1 达标**；k 每降 0.05 约 −0.22，故 k 不得低于 0.73。textPrimary ≈13.9:1 ✓。
- **三级字记录在案**：textTertiary 由 ≈2.7:1 降至 ≈2.3:1（白卡→绿卡），沿用池 127「三级字限提示用途」裁决；卡面三级字加深一档属另开需求，不在本轮。
- **Dark 不动理由**：老板反馈对象是「白色半透」观感，暗主题卡面本为深底无此问题；若后续要暗色绿染，方向 = `surface×0.92 + primary×0.08` 另行提案。
- **demo 校准参考（仅 demo 内允许的换算值，验收以派生式为准）**：mint 主色 #07C160 按 k=0.75 → rgb(193,240,215)；更浓参考档 k=0.62 → rgb(161,231,195)（对比 4.1:1，不达标仅作老板裁决参照）。

### F3 MCP 已注册工具卡垂直间距（池 156）

| 参数 | 旧 | 新 | 落点 |
|---|---|---|---|
| 卡**垂直**间距 | 16（flow 单 gap 横竖同轴） | **24**（spacingXLarge 档） | mcp_page_module.cpp:277 |
| 卡**水平**间距 | 16 | **16 不变** | 同上 + gridColumns gap 参（:272）保持 16 |
| 卡高/卡宽/列数 | kCardH=120、340–420、≤5 列 | 不动 | mcp_page_module.cpp:48-51 |

- 现状定性：340–420 宽 × 120 高的大卡以 16px 垂直距堆叠，行间节奏被压扁；24px 与全站组间距档对齐，滚动区（listH 下限 scaled(120)，:146-148）容量影响每屏约半张卡，网格自滚功能不回归。
- 实现路径二选一（框架能力缺口走 EUI-NEO fork，AGENTS.md §一）：① flow 增设 rowGap（行间 24 / 列间 16）；② 行包 row 容器（行内 gap 16、行间 gap 24）。视觉验收以 **24/16** 为准，不绑定实现方式。

### F4 md 顶区「新建笔记→编辑框」间隙（池 164）
