## 1. 页面级构图（构图三问）

### 1.1 构图三问
① **滚动模型**：弹窗为固定 460×348 模态框，内部**零滚动**——4 行步骤 + 1 块说明 + 1 行按钮全部静态排布，总高预算 348px 内闭合；外壳（主窗口）不因弹窗滚动。与全站弹窗一致（drawDialogFrame 固定高档位）。
② **无效空白**：无。行距 28px 为既有节奏不可压缩；底部留白 30px 恰为按钮呼吸区；说明块 44-60px 恰容 2-3 行文案。插入第 4 行后各区块依次下移一行距，不产生新空档。
③ **密度与权重**：4 行步骤是唯一高频信息，占视觉主体（y 56-162）；说明块为辅助信息按需变色（完成绿/失败红/引导灰）；按钮行收底。窄档（460px）下：名称列定宽 180（结构性列，不伸缩），状态列自适应 222px——最小窗与宽窗两档下主次比例不变（弹窗为固定档位，无宽窗形态）。

- 步骤区 4 行 × 28 = 112px（56→168）；说明块 ≤60px；按钮行 40px；合计内容 212px + 标题区 56 + 底留白 30 + 间距 50 ≈ 348。

## 3. 状态机衔接（①→④ 顺序、失败停步、不跳步）

```
①Python检测 ──✓→ ②venv+pip ──✓→ ③embedding就位 ──✓→ ④拉起+健康 ──✓→ 完成态
   │✗停             │✗停            │✗停（下载失败）      │✗停（拉起/健康超时）
   └─────────────────┴───────────────┴────────────────────┴──→ 失败态（红块+主按钮=重试）
```

- **顺序执行，失败停在该步**：后续行保持灰`待开始`，不跳步。
- **不设跳过**：telemem 侧「llama 缺失不拦引擎」是引擎行为现状（PRD §5），向导作为开箱即用保证场景不提供「跳过③」入口；唯一动作=重试（startAsync 全管线重跑，①②已就位秒过）。数据根旧模型命中③即绿，真缺资产才可能卡③。
- **③即时检查**：打开向导即做本地文件检查（不依赖引擎启动）——随包/数据根命中直接绿；全缺则灰`需下载（联网，首次约 26MB）`，等「开始安装」管线内下载。①②在 idle 态维持既有文案（`未检测到——安装后重试`/`待开始`）。
- **关闭出口**：任何态可关向导；失败退出后由主控台缺失行（F-06 文案 `本机模型文件缺失——语义档不可用，见首次安装向导 第③步`）回引。

## 4. ③步四态 ↔ 引擎 Snapshot 字段映射（验收锚）

| 设计态（简报口径） | Snapshot 需求字段 | 行文案 | 色 |
|---|---|---|---|
| assets 存在且可用 | `embedReady=true` + `embedSource=Pkg/DataRoot`（**新增**） | 已就位（随包）/（数据根） | 绿 |
| assets 缺失（引导重装） | `embedState=NeedDownload`（idle）/`=Failed`（尝试后） | 需下载（联网，首次约 26MB）/ 失败：…（可重试） | 灰 / 红 |
| embedding 启动中 | `embedState=Downloading`（Preparing 期间，detail 带进度） | 进行中… / detail | 黄 |
| 健康失败可重试 | `embedState=Failed` + engine.state=Failed | 行红 + ④行红 + 失败块 | 红 |

> 实现约束（交 developer）：现有 Snapshot（state/detail/pythonFound/pythonVersion/llamaMissing）无 embedding 专属字段，需按上表新增 `embedReady / embedSource / embedState / embedDetail`，向导渲染只读这些字段，不自行探测文件系统。

## 5. 交互流程（失败重试）

1. 失败态：③/④ 行红字短原因（>18 字省略号截断）→ 失败块红字完整原因 + 指引 → 主按钮=`开始安装 / 重试`（主档绿）。
2. 点重试 → 全管线重跑：①→④ 依次刷新，已就位环节秒过；期间主按钮禁用`安装中…`。
3. 恢复 → 完成态绿块；再失败 → 回失败态，可无限重试。
4. 完成态主按钮变次档`重新运行安装检查`（既有逻辑，不改）。

## 9. 对话框高度 320→348 裁定与理由

**348 = 320 + 28（一行行距）**。理由：既有行距节奏 28 不可压缩（压缩会破 8px 网格与三步档位一致性）；底部按钮 y 250→278、底留白 30px 恰好保持原比例（320-290=30 → 348-318=30）；说明块/按钮整体下移一行距，零其它改动。348 仍在弹窗五档（420-760）之内，1080P 无溢出。
