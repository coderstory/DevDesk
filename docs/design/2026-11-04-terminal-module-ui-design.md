## 1. 页面级构图（先整体后参数）

### 1.1 区块划分与锚定

```
┌────────────────────────────────────────────────────────────┐
│ ┌──────┐ ┌───────────────────────────────────────────────┐ │
│ │      │ │ 终端工具栏（锚顶·高 44px·不滚）                 │ │
│ │ 侧边 │ │  [●状态徽标]            [新建会话][全屏]       │ │
│ │ 栏    │ ├───────────────────────────────────────────────┤ │
│ │(外壳, │ │ 终端内容区（fill·唯一内滚容器）                 │ │
│ │ 不归  │ │  ~ user@mac ~ % echo hello                    │ │
│ │ 本页  │ │  hello                                        │ │
│ │ 管)   │ │  ~ user@mac ~ % ▌                             │ │
│ │      │ │                                               │ │
│ │      │ │  [结束/失败覆盖卡：锚内容区居中·按需]           │ │
│ │      │ │                                    [退出全屏]↖ │ │← 仅全屏态
│ └──────┘ └───────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────┘
```

- **终端工具栏**：锚顶，宽 100%，高 44px 固定。左：会话状态徽标（状态点+文字）；右：操作组（新建会话、全屏）。
- **终端内容区**：fill 剩余空间，等宽字符网格，页面唯一滚动容器（回滚缓冲上翻/回底）。
- **覆盖层**（非独立区块，内容区之上的叠层）：结束态卡 / 失败态卡，锚内容区水平垂直居中；全屏态「退出全屏」悬浮按钮，锚内容区右上角。三者互斥出现（覆盖卡与悬浮按钮可并存：全屏态内会话结束 → 覆盖卡 + 悬浮按钮同屏，见 1.4）。
- **Windows 占位态**：整页单区构图分支——不渲染工具栏，页面级居中占位卡（见 §6）。

### 1.2 滚动模型

外壳不滚（与全站同类页一致）：侧边栏与页面容器固定；终端内容区是唯一内滚容器——输出超屏后内容区上翻，回滚缓冲上限由会话层决定（PRD F-02），滚动条样式跟随全站。工具栏永不滚。

### 1.3 空间节奏与信息密度预算

- 工具栏 44px = 高频操作带，视觉权重最高（四原则·操作高效）：状态一眼可见、全屏/新建一次可达。
- 内容区 100% 让给终端网格，无任何常驻装饰（四原则·信息优先/低干扰）。
- 无大段无效空白：内容区恒被网格填满；覆盖卡仅在异常态出现，出现时即该态最高权重。
- 无定宽空列、无弹性稀疏区：唯一弹性区就是终端网格本身。

### 1.4 全屏态构图

- 侧边栏、工具栏全部隐藏，终端内容区铺满主窗内容区（窗体内全屏，非系统全屏）。
- 「退出全屏」悬浮按钮锚右上（top 16 / right 16），z 序全页最高，唯一常驻控件。
- 全屏态内会话结束/失败：覆盖卡照常呈现（构图降级为「scrim + 居中卡」），悬浮按钮保留且仍可点——退出全屏的通路不因会话态消失。

### 1.5 构图三问

1. **滚动模型对吗**：外壳不滚、终端区内滚，与全站同类页（Markdown/待办等：外壳固定+内容区滚动）一致。✅
2. **有无大段无效空白**：无。留白仅覆盖卡内边距与网格行距，均服务分组可读性。✅
3. **密度与权重平衡**：主体区（网格）与辅助区（工具栏）比例 = 100%:44px，最小窗 720×480 与宽窗 1920×1080 两档下均成立（工具栏 <1080px 时按钮收图标，见 §9）。✅

## 4. 全屏态

### 4.1 进入/退出

- 入口仅工具栏「全屏」按钮（v1 不加快捷键，避免新增未验证能力）。
- 进入：侧边栏与工具栏隐藏，内容区 Frame 200ms 缓出铺满；悬浮按钮淡入。
- 退出：点悬浮按钮，200ms 缓出还原（侧边栏、工具栏回原位）。
- 全屏态内窗口 resize：终端跟随铺满，行列重排。

### 4.2 「退出全屏」悬浮按钮（参数表）

| 参数 | 值 |
|---|---|
| 位置 | 锚内容区右上角，距顶 16px / 距右 16px，不随内容滚动 |
| 尺寸 | 高 32px，宽 wrap 内容（图标 14px + 间距 6px + 文字 12px「退出全屏」+ 水平内边距 12px，约 92px） |
| 圆角 | 6px |
| 背景 | textPrimary 半透：常态 α0.12（亮 `#1F2937@0.12` / 暗 `#FAF9F5@0.12`） |
| 图标/文字 | textPrimary α0.85；图标 `0xF066`（fa-compress，⚠️ 需真机确认字形） |
| hover | 背景 α0.12→0.22，100ms 缓出；指针 pointer |
| 按压 | 果冻：缩至 0.96，松手 150ms 弹性回弹 |
| 边框 | 1px borderDefault α0.5（亮 `#E5E7EB@0.5` / 暗 `#3A3735@0.5`），保半透底在两种主题下的轮廓可辨 |
| z 序 | 全页最高（高于覆盖卡 scrim），永远可点 |
| 过渡入场 | 淡入 + 上移 4px→0，150ms 缓出 |

### 4.3 避让规则（不覆盖光标所在行关键区）

终端滚动锚定使光标行常态保持在可视区内、提示符常态在底部——按钮与光标相交是低频态（用户主动上翻且停在最顶部时才可能）。规则按「可用性优先 + 视觉让位」设计：

1. 按钮位置固定右上，永不避让位移（退出全屏通路不可中断）。
2. 当光标行与按钮矩形外扩 8px 的区域相交时：按钮背景 α0.12→0.06、边框与图标文字 α0.85→0.45，200ms 缓出——轻提示不硬挡，光标行文字仍可辨读；
3. 光标行离开相交区后 200ms 还原常态；
4. 相交期间按钮仍可正常点击退出全屏。

### 4.4 全屏态下页切走 ↔ 切回状态保持（审计备注补定义）

| 场景 | 行为 |
|---|---|
| 全屏态 → 切走终端页（去 Markdown 等） | 全屏布局状态**保持**（页面隐藏非销毁，与会话保活同源）。shell 继续后台跑、输出继续累积 |
| 切回终端页 | **直接以全屏态呈现**，无进入动画重放（首帧即全屏，≤1 帧）；画面与回滚完整还原；悬浮按钮随全屏态一并呈现 |
| 全屏态内已出现结束/失败覆盖卡 → 切走切回 | 覆盖卡状态同样保持（会话态 + 全屏态都不丢失） |
| 全屏态是否跨进程生命周期 | 否。退出 DevDesk 会话终止；重启后进终端页 = 新会话 = 常规态，全屏态不持久化 |
| 全屏态内 resize | 终端实时跟随铺满（PRD F-05 验收项） |

## 5. 结束态与失败态（覆盖卡）

两态共用一套覆盖卡结构：内容区先铺 scrim 再居中卡片，终端画面在 scrim 下仍隐约可见（回滚历史不丢）。

### 5.1 共用结构

| 参数 | 值 |
|---|---|
| scrim | 终端区上层铺页面底色半透：暗 `#1A1816@0.55` / 亮 `#F5FAF7@0.55` |
| 卡片 | 底 surfaceElevated（亮 `#FFFFFF` / 暗 `#2C2A28`）、圆角 14px、内边距 24px、外阴影（全站面板阴影）、宽 wrap 内容 max 420px（窄窗时 = 内容宽 − 32px） |
| 图标 | 24px，置于卡内顶部，与标题间距 12px |
| 标题 | 16px textPrimary |
| 正文 | 13px textSecondary，行高 1.6，与标题间距 8px |
| 按钮 | 与标题间距 20px；高 32px / 圆角 6px / 字 14px；主按钮绿填充白字（primary，hover primaryHover，按下 primaryPressed），同视口唯一 |
| 入场动效 | scrim α0→0.55 + 卡片 opacity 0→1 / scale 0.98→1，180ms 缓出 |

### 5.2 结束态（用户敲 exit / 会话正常退出，退出码 N）

| 项 | 值 |
|---|---|
| 图标 | `0xF05A`（fa-circle-info）色 info（亮 `#3B82F6` / 暗 `#60A5FA`）⚠️ 需真机确认字形（`0xF05A` 项目已用过「详情」，低风险） |
| 标题 | 「会话已结束」 |
| 正文 | 「退出码 {N}。输出历史已保留，可上翻查看；新建会话即可继续使用。」 |
| 按钮 | 主按钮「新建会话」 |

### 5.3 失败态（shell 启动失败）

| 项 | 值 |
|---|---|
| 图标 | `0xF071`（fa-triangle-exclamation，项目已验证字形存在）色 errorText（亮 `#B91C1C` / 暗 `#F87171`） |
| 标题 | 「终端启动失败」 |
| 正文 | 首行：后端给出的具体失败原因（动态）；次行固定建议：「请确认默认 shell 可用后重试，或检查 $SHELL 配置。」 |
| 按钮 | 主按钮「重试」 |

### 5.4 加载态（spawn 进行中，无独立覆盖卡）

- 终端区居中显示 13px textTertiary 文案「正在启动 shell …」，无 spinner（全站无骨架屏组件，文案即状态）。
- 超过 3s 未完成 → 转失败态（文案换错误卡），不给无限加载。
- 页面无独立空态（进页即自动开会话，PRD 已定）。

## 7. IME 组合期呈现

| 项 | 规格 |
|---|---|
| 组合窗口定位 | 跟随光标：终端网格把光标所在 cell 上报为 IME 锚定矩形（x=列×cell宽，y=行×cell高，宽=cell宽，高=cell高，元素局部坐标，平台桥自动叠加元素 frame 与滚动位移）；候选窗由系统输入法按此锚点弹出 |
| 组合文本 overlay | 组合串绘制于光标 cell 起点：等宽同字号、前景色 fg；底衬 selection 半透（primary α0.18 亮 / α0.30 暗）+ 下划线 1px primary——视觉上「未上屏」 |
| 不进网格不进 PTY | 组合期文本只存在于 overlay 层，不写入字符网格、不发给 shell（对齐上游对照实现语义） |
| 组合期光标 | 保持块状但透明度降至 0.5（与闪烁暂停），上屏（commit）后恢复 |
| 边界 | 组合中按 Esc = 取消组合（平台默认行为）；组合串超出右边界不换行，随网格裁剪；组合期间收到新输出 → overlay 锚点跟随光标 cell 重算 |

> 能力自洽：锚定矩形上报是既有焦点元素能力（`imeRect`，元素局部坐标，平台桥定位已实测可用）；终端网格为新增自绘组件时挂接同一能力，**需技术卡实测确认**（见 §10）。

## 8. 交互流程（验收照走）

1. 点侧边栏「终端」→ 自动启动会话：加载文案（≤3s）→ 常规运行态。
2. 输入命令 → 字符进网格 + 光标跟随；回车执行。
3. 上滚看历史 → 内容区内滚；回到底部。
4. 点「全屏」→ 200ms 铺满 → 悬浮按钮出现；点悬浮按钮 → 200ms 还原。
5. 全屏态内输 exit → 结束覆盖卡 + 悬浮按钮并存 → 点「新建会话」→ 回常规运行态（全屏态保持）。
6. spawn 失败 → 失败覆盖卡 → 点「重试」→ 加载 → 常规。
7. 切走页面 → shell 保活；切回 → 画面/全屏态/覆盖卡状态完整还原。
8. 中文输入法组合 → overlay 呈现、候选窗跟光标；上屏进网格。
9. 亮/暗主题切换 → 终端配色 150ms 平滑跟随。
10. Windows → 占位页静态呈现。

| 加载 | 终端区居中「正在启动 shell …」 | 成功→常规；>3s→失败 |
| 成功（运行中） | 网格+光标+工具栏徽标「运行中」 | exit→结束态；全屏→全屏态 |
| 错误（失败态） | 覆盖卡+scrim+「重试」主按钮 | 重试→加载 |
| 结束态 | 覆盖卡+scrim+「新建会话」主按钮 | 新建→加载（新会话） |
| 空态 | 无独立空态（进页即开会话） | — |
| Windows | 占位页（终态，无交互） | — |

### 9.2 自适应行为表

| 断点/条件 | 行为 |
|---|---|
| ≥1080px 宽 | 工具栏按钮图标+文字全显 |
| <1080px 宽 | 「新建会话」「全屏」收为纯图标按钮（配 tooltip，白底、纯图标按钮必带——基线纪律） |
| 最小可用窗口 | 720×480：工具栏 44 + 内容区 436 ≥ 6 行网格（20px 行高），不破版不溢出 |
| 终端网格极小 | 最小 20 列 × 6 行可渲染（PRD 边界：不崩、可恢复）；低于此按最小值渲染并裁剪 |
| 内容区伸缩 | 终端区是唯一弹性区（fill）；工具栏高固定、侧边栏宽固定（结构性栏位不伸缩） |

| 字号档切换 | 终端字号×fontScale，cell 尺寸重算，网格重排 |
| 1080P 外壳 | 页面无横向滚动，终端区 clip，外壳不溢出 |

## 12. 能力自洽性核对（对照 EUI-NEO 能力盘点，正文不引用）

| 设计点 | 能力结论 |
|---|---|
| 等宽字体 | 有系统等宽 fontFamily 别名支持，直接可用 |
| IME 锚定矩形跟随 | 焦点元素 imeRect 能力已有（元素局部坐标+平台桥定位，已实测）；终端网格为新组件，挂接同能力**需技术卡实测确认** |
| 悬浮按钮置顶/透明度/hover/果冻 | 透明度、hover 态色平滑、按压缩放、z 序控制均有现成能力；悬浮按钮需自绘（现成按钮组件无 z 序属性，包进叠层容器抬层级即可，非缺能力） |
| 半透底+backdrop 模糊 | 半透纯色底可用；矩形背景模糊能力存在但**本设计不依赖**（α0.12 纯色半透已达标，避免能力风险） |
| 帧过渡（全屏铺满/还原） | Frame 过渡动画现成能力，200ms 缓出可用 |
| 光标闪烁 | 定时器驱动重绘为现成能力，无新增框架要求 |
| 图标字形 | `0xF120`/`0xF065`/`0xF066`/`0xF067` 需真机确认字形；`0xF071`/`0xF05A`/`0xF021` 项目已验证存在 |
| 全屏=页内布局状态 | 纯页面构图态，非窗口系统 API，无能力缺口 |
| 页切走保活+状态保持 | 页面切换为同进程内视图切换，布局状态属模块内存态，无能力缺口 |
