## 四、统一规划

### 4.1 六条硬规则（新增规范）

| # | 规则 | 依据 |
|---|---|---|
| R1 | **Tab 只有一种：块面式（`ui_kit::wtab`）**。下划线式全站淘汰（含 `components::tabs`）。选中态必须「底色块 + 主色字 + 600 字重」三件套齐备，底色需在近白页面底上可辨 | `ui_kit/wtab.h` 已定「淘汰下划线式」；F-04/F-05 |
| R2 | **页头不加壳**：标题行（40px）直接落在页面底上；tab 行作为独立行随内容滚动，不与标题连体 | F-08 |
| R3 | **空态只有一种**：图标（可选）+ 主句 + 引导句 + 行动按钮，全部居中，**不套大白卡**；一律走 `ui_kit::emptyState` | F-06/F-14/F-15 |
| R4 | **卡片只有两档材质**：① 玻璃（页面级浮层：统计卡、面板、看板列）② 实心（表格卡、工具卡、输入框）。两档都带 1px 描边 + 低阴影，卡片在浅底上边界必须可见 | F-02/F-07 |
| R5 | **反馈只有一套**：右下通知式 toast 承载「有 title 的重要反馈」，居中微信轻提示承载「无 title 的轻反馈」（复制成功/保存成功）。toast 图标、时长、底部避让全站统一；补「信息」第三态 | F-09/F-10/F-11 |
| R6 | **调色板不越界**：purple/pink/blue 仅用于用户选定的强调色主题，不得借用为类别标签色；类别标签用中性灰底 + 主色字 | F-12 |

### 4.2 组件规格补充（本次新增 token / 参数）

| 项 | 规格 | 落地位置 |
|---|---|---|
| Tab 选中底 | 新增 `primarySoftBgStrong #D3F0DE`（页面底 #F5FAF7 上亮度差 ≥ 8%）；未选中无底 | `core/theme.cpp` + `ui_kit/wtab.cpp` |
| Tab 选中字重 | 600（未选中 400） | `ui_kit/wtab.cpp` |
| Toast Level | `Info/Success/Warning/Error` 四态；图标 `info 0xF05A / check 0xF00C / warn 0xF071 / error 0xF06A` | `ui_kit/toast.h` |
| Toast 底部避让 | 统一 `bottomInset`：页面底部有按钮行时 = 按钮行高 + 16，否则 0 | 各调用点 |

| 卡片描边 | 记忆/MCP/settings 卡片补 `border(1, borderDefault)`；记忆卡补低阴影 | 各模块 |

### 6.2 实施中发现并修掉的两个「文档之外」的真缺陷

1. **空态组件缺根节点 + 在 column 下位置被流式游标接管**（`ui_kit/empty_state.cpp`）
   原实现把图标/主句/引导句/按钮作为散件直接画在父级上：① 调用方按根 id 定位空态（`md.editor.hint`）时找不到节点；② 父级若是 column，子元素 x/y 被流式游标覆盖、会被竖着摞起来。
   修法：整组包一层 stack 根（id = 传入 id），子元素坐标相对根。

2. **release 列表页计数文字压住下一个 Tab**（`release_list_ui.cpp`）
   见 S1 说明。这是审计清单里没记到的、截图实证出来的真缺陷。

3. **空态引导句在窄盒里横向溢出**（`ui_kit/empty_state.cpp`）
   todo 看板列宽约 300px，引导句「这个分类下还没有任务，点页头「新建任务」加一条。」
   长度接近盒宽、左右几乎无留白，读起来挤；更长时还会越出列边界。
   修法：组件按测量宽度自适应——超盒宽则折两行（行高 16、Clip），不超则单行 + Ellipsis；
   主句一律 Ellipsis 截断。todo 三处引导句文案同步收短。
