## 0. 全局约定

1. **token 唯一权威 = `src/core/theme.cpp` 实值**（§3 表，与只读查看器同源，不出现裸 hex 新值；demo 的桌面模拟底色属 OS 领域模拟，非产品 token）。
2. **字重两档制落地注记**：语义档位按两档制标 400 / 600；实现注记——框架运行时仅打包 Bold 一份重档，**600 一律以 Bold 渲染**，明细一律默认 400，无第三档。
3. **字号是否走 `core::theme::scaled()`**：工具条/状态栏 12–13（走 scaled）；**编辑区正文字号不走 scaled**——编辑字号是用户显式设置值（12–20，本窗内步进），缩放叠加会破坏「所见即所设」。
4. **与设置页关系**：设置页将新增「记事本」开关（开关本体 UI 归设置页设计，不在本文档范围），开启后系统文件打开方式指向记事本。**本窗不需要主程序入口、不依赖主窗**：主窗是否运行、是否托盘态，均不影响记事本窗的打开与使用；关闭开关时已打开的记事本窗不受影响，仅新的双击不再进入记事本。

## 1. 窗口级构图

### 1.1 构图三问

| 问 | 答 |
|---|---|
| ① 滚动模型 | **OS 标题栏（mac 28pt / Win ~32px 内容偏移）+ 工具条 44 + 状态栏 28 钉死**（提示条 32 条件插入）；编辑区是唯一内滚容器——自动换行开=软换行不产生第二滚动容器（框架 multiline 恒 horizontalScroll=0，`input_model.h:150`），关=超宽行横向滚动；预览态由预览区接任。窗内无页头导航带：原「页头 64」取消——窗口标题由 OS 标题栏承担，窗内不放「记事本」大标题，文件操作按钮并入工具条（§4.2）。与全站「外壳不滚、内容区各自内滚」一致。 |
| ② 无效空白 | 编辑区满宽铺满；工具条「文件操作组→文档语义组→视图组」三段锚定（左链显式常量 + 右锚成组，R1/R3），组间间隔被最小窗宽 720 钳制（44px 细带内不构成空洞，R6 判定非内容容器）。预览态 760 列居中——留白服务阅读行宽（沿用查看器口径）。 |
| ③ 密度与权重 | 高频信息=编辑区正文，最大面积最高权重；窗内无 L1 大标题（标题栏文件名是窗的身份，OS 层级）；工具条控件 13px 明细档；状态栏 12px 明细档。最小窗 720×480：T1 档工具条控件链 ~700px 放得下（§9.2），编辑区净高 ≥ 364（≥240 底线）✓；宽窗 1600：增量全进编辑区，预览态 760 封顶 ✓。 |

### 1.2 窗口构图（ASCII）

```
┌─ 独立记事本窗（默认 900×640，最小 720×480，多窗并存）──────────────┐
│ ● ● ●   • notes.md        ← OS 标题栏：mac 28pt / Win ~32px       │
│           （红绿灯系统绘制；• = 脏态前缀；窗圆角 16 OS 承担）        │
├───────────────────────────────────────────────────────────────────┤
│ 工具条 44（2+40+2，水平内边距 16）                                  │
│  [打开…][保存][另存为][更多] ·16· [语言▾][格式化][字体▾][A-14A+]    │
│  ··················结构间隔···················· [⌕][编辑|预览]      │
├─ 提示条 32（条件出现：只读/高亮关闭）──────────────────────────────┤
├───────────────────────────────────────────────────────────────────┤
│ 编辑区 flex（唯一内滚区；自动换行默认开）     ┌ 搜索替换浮层 ─────┐ │
│  正文（字号×1.2 行高）                       │ top12 right16 r10 │ │
│                                              └───────────────────┘ │
├───────────────────────────────────────────────────────────────────┤
│ 状态栏 28：notes.md ● 未保存  [只读]   UTF-8·LF·12:80·2,341 字     │
└───────────────────────────────────────────────────────────────────┘
```

- 区块划分与锚定：① OS 标题栏（窗级）② 工具条（文件操作组→文档语义组左链 + 视图组右锚）③ 提示条（条件层）④ 编辑区（flex-1 唯一弹性区）⑤ 搜索替换浮层（锚编辑区右上，不占布局流）⑥ 状态栏（左锚文件身份 + 右锚元数据组）。
- 窗内固定带 = 44 + 28 = 72（有提示条 104）；编辑区高 = 窗内容高 − 72/104。
- **入口与退出**：入口仅 OS 双击关联文件 / 打开方式（一窗必有一文件，无空窗态）；出口 = 逐扇关窗，关最后一张 = 记事本真退出，主进程留托盘。

### 1.3 本窗独特性原则句

**「一张纸」**：整窗只有一个信息主体——被编辑的文件本身；工具条与状态栏是纸的尺规；多窗时每扇窗都是独立的一张纸，互不渗透（一文件一窗，无标签无合并）。

## 2. 窗口级行为规格（v2 新增节）

| 项 | 规格 | 依据/来源 |
|---|---|---|
| 窗口标题 | = 文件名（永不含路径）；超长**中段省略号截断保头尾**（查看器窗同款）；脏态前缀「• 」（macOS 文档编辑惯例，Win 同文字前缀）；错误态仍显文件名 | 〔沿用〕查看器窗标题规则（2026-11-10 文档 §3.1）＋〔新定〕脏态前缀依据 OS 文档脏标记惯例 |
| 窗口尺寸 | 默认 **900×640**（对齐查看器窗档）；**最小 720×480**；可缩放无上限；宽窗增量全进编辑区 | 〔沿用〕查看器 900×640 默认档；〔新定〕最小值采纳裁决建议 720×480 |
| 尺寸记忆 | 记忆**上一次**尺寸与位置（应用级一份，非 per-file）；首次打开 = 900×640 屏幕居中；记忆位置越界（屏外）拉回主屏可视区 | 〔新定〕记事本窗是工作面，用户会形成固定窗位；per-file 记忆会多窗互踩，取应用级一份 |
| 多窗并存 | 一文件一窗，可并存多扇；每扇独立生命周期（关闭/尺寸/滚动/撤销栈互不影响）；新打开请求若目标文件**已有窗口** → 不开新窗，**聚焦已有窗**（防同文件双窗编辑冲突）；新窗按记忆位/居中出现 | 老板裁决 3/5；〔新定〕同文件聚焦是「一文件一窗」的反向约束 |
| z 序与切换 | z 序由 OS 窗口管理器承担；openWindow `focusOnShow` 用于同文件聚焦；窗间切换走系统 Cmd`/Alt`＋任务栏，应用内不做窗列表 UI（v1） | 老板裁决 3；EUI-NEO DslWindowConfig 能力 |
| 关窗保护 | 关闭（红绿灯 / × / ⌘W / Ctrl+W）脏态窗 → **三选确认**（保存 / 不保存 / 取消，§4.9 弹窗）；保存失败不关窗；干净态直接关 | 老板裁决 5 |
| 主窗托盘态 | 主窗关到托盘 / 最小化 / 切页，**不影响已开记事本窗**；双击文件只出记事本窗，主窗不出面 | 老板裁决 1/4/5 |
| 退出语义 | 关掉最后一张记事本窗 = 记事本模块真退出（释放模块资源）；主进程留托盘 | 老板裁决 6 |
| 任务栏 | 记事本窗为正常任务栏项（不 hideFromTaskbar）——独立生命周期需要 OS 级可达性 | 〔新定〕 |
| 窗口配置 | decorated 独立子窗：resizable、不 modal、不 alwaysOnTop；**最小尺寸 720×480 需框架补通道**（见下方勘误 F-1） | EUI-NEO DslWindowConfig 已暴露字段 + 主会话实测勘误 |

## 7. 状态机与错态（v2：删「无文件空态」——没有窗就没有 UI）

### 7.1 文档状态机

```
（OS 双击/打开方式）──► 已打开（干净）⇄ 已打开（未保存）
                          │  ▲              │
                          │  └──保存成功─────┤
                          ├──保存失败──► 已打开（保存失败）──重试成功──► 干净
                          ├──只读降级──► 只读态（编辑类全禁用）
                          ├──打开失败──► 错误态（窗存在；仅打开/关窗可用）
                          └──换文件成功──► 载入新文件（干净）──编辑──► 未保存
```

| 预览态 | 可用 | 可用 | 可用 | 禁用 | 禁用 | 禁用 | 可用（切回） | 可用 |

## 9. 自适应行为表（v2：容器=窗口，尺寸约束重算）

### 9.1 尺寸公式

- 窗默认 **900×640**、最小 **720×480**（§2）；resizable 无上限。
- 纵向预算（窗内容高 = 窗高 − 标题栏 28/32）：工具条 44 ＋ 状态栏 28 ＋（提示条 32）＝ 72/104；编辑区高 = 其余，底线 240。
- 预览列宽 = `min(窗宽 − 80, 760)`；编辑区宽 = 窗内容宽（无上限）。

### 9.2 断点档（按窗宽；900 宽即全参数档）

| 档 | 窗宽 | 语言下拉 | 字体下拉 | 格式化钮 | 块面 Tab | 状态栏 |
|---|---|---|---|---|---|---|
| T0 全参数档 | ≥ 900 | 140 | 160 | 文字钮「格式化」h28 | 段宽 62（总 128） | 全项 |
| T1 最小档 | 720–899 | 120 | 140 | 24×24 图标钮＋tooltip | 段宽 56（总 116） | 隐 `UTF-8`/`LF`，保 行:列 · N 字 |
| < 720 | 不支持（min 钳制） | — | — | — | — | — |

- T0 宽度预算：文件组 120 ＋16＋ 文档组 ~472 ＋ 视图组 160 ＋ padding 32 ≈ 800 ≤ 900 ✓（结构间隔仍有余量）。
- 高度挤压顺序（窗高 <640）：编辑区先让（底线 240）→ 提示条保持 → 工具条/状态栏恒高。
- 横向挤压顺序：字体下拉宽度 → 语言下拉宽度 → 格式化降图标 → Tab 段宽 → 状态栏隐编码/行尾；stepper 与 Tab 文字不缩（高频）。
- 单窗 1600×1000：增量全进编辑区；预览态 760 封顶居中。

### 勘误 F-1（主会话 2026-11-16 实测）：`DslWindowConfig` 无 `minSize`

- **设计稿原文（有误）**：多处引用「DslWindowConfig 能力清单含 minSize」。
- **实测事实**：`EUI-NEO/include/eui/dsl_app.h:243-266` 的 `DslWindowConfig` 字段清单中**无** `minWidth`/`minHeight`/`maxWidth`/`maxHeight`；`include/eui/detail/dsl_app_impl.h` 也无对应透传。但底层链路已就绪：`core/window/window_types.h:42-43` 的 `WindowCreateRequest` 有 `minWidth`/`minHeight`，`core/window/window_backend.cpp:1380` 已调 `glfwSetWindowSizeLimits`。
- **影响**：窗口最小尺寸约束当前无法通过 DSL 设置。记事本窗若需 720×480 下限，有两条路：①在 EUI-NEO 给 `DslWindowConfig` 补 `minSize(w,h)` 透传（小改动，推荐）；②v1 不做最小尺寸约束，仅在布局层按 720×480 做断点适配（窗口可被拖得更小，布局按最小档渲染）。
- **建议**：走①，属框架小补齐（与 FD-1/FD-3 同批次性质）。已登记为待办。
