Todo 看板 · 四列归档

宽度公式

contentW = 模拟窗口宽 − 208 侧栏 − 2×40 页边距
展开列宽 W = (contentW − 3×16) / 4
折叠归档宽 = W × 25%
折叠三列 = (contentW − 3×16 − 折叠归档宽) / 3

折叠态就是同一根普通列被收窄，容器底色、边框、圆角与其余三列一致，没有独立白色竖条组件；展开后的归档列与其余三列同宽同款。动画在 W×25% ↔ W 之间插值。

页头读数显示展开列宽 W、折叠归档宽与当前三列宽；动画过程中三列宽逐帧变化。

动画

  • 展开 240ms，收起 200ms，ease-out cubic（cubic-bezier(.215,.61,.355,1)）。
  • 归档列宽度在 W×25% ↔ W 之间插值，其余三列同步重排。
  • 归档内容在进度 40%（96ms）后淡入 120ms；收起前 30%（60ms）淡出。
  • chevron 旋转 180°，收窄列标签淡出 / 淡入。

交互

  • 点击收窄归档列任意位置展开；收起按钮、Esc 收起。
  • 收窄列 tabindex=0，Enter / Space 切换；focus 2px 主色 outline。
  • 拖卡悬停收窄列 300ms 自动展开；drop 归档；取消或拖离自动收回（200ms）。
  • 归档卡可拖回任一主列恢复；归档最多渲染最近 20 张。
  • 搜索框按标题 / 描述 / 标签实时过滤；无命中列显示「无命中任务」，归档命中自动展开并显示命中数，清空搜索恢复原展开状态。
  • 页头「新建任务」打开富创建弹窗（标题 / 描述 / 优先级 / 截止日期 / 标签），空标题创建时显示红字提示；取消或 Esc 不插入。
  • 「逾期」chip 切换逾期高亮。
