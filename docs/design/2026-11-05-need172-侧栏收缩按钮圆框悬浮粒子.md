## 1. 页面级构图（构图门禁）

### 1.1 区块划分与锚定（沿用现侧栏，零变化声明）

侧栏为垂直五锚定区块，外壳不滚；本设计只动最底部「按钮预留区」区块的内部，其余区块仅作让位关系声明：

```
┌─侧栏 W=220（展开）/ 72（折叠）──────┬─页面区────────────┐
│ ┌─品牌区 56（锚顶）───────────────┐ │                    │
│ │   logo 48/44/40（居中）          │ │                    │
│ └─────────────────────────────────┘ │                    │
│ ├─导航滚动区（内滚，锚顶随品牌区）──┤ │                    │
│ │   行高 40（极紧档 36），行满即内滚 │ │                    │
│ │   ↑ 让位线 foldLimit = H−区高−4   │ │                    │
│ ├─让位 gap 4（恒定，粒子禁越线）────┤ │                    │
│ ├─按钮预留区 48/44（锚底）──────────┤ │                    │
│ │      ◯32/28  ← 圆框按钮 + 粒子    │ │                    │
│ └─────────────────────────────────┘ │                    │
└─────────────────────────────────────┴────────────────────┘
（全屏态：侧栏 W=0 整列不渲染，含按钮与粒子）
```

- **锚定关系**：品牌区锚顶、按钮预留区锚底、导航区占中间并内滚（滚动模型沿用全站纪律：外壳不滚、导航区内滚，滚动条视觉隐藏）。
- **让位线守卫**：`foldLimit = H − toggleZoneH − 4`，导航行物理画不进预留区（现实现已守卫，`app_sidebar.cpp:507,595`）；本设计新增：**粒子同样禁越让位线**（§5 包络顶边 = foldLimit）。
- **滚动模型一致性**：与全站同类页一致 ✅；按钮不随导航滚动（锚底独立区）✅。

### 1.2 构图三问

| 问 | 答 |
|---|---|
| ① 滚动模型对吗 | 外壳不滚 + 导航区内滚，按钮锚底不随滚——与全站侧栏一致 ✅ |
| ② 有无大段无效空白 | 预留区填充率 32/48=66.7%（正常档）、28/44=63.6%（紧凑档），低于 2/3 阈值不多、恰好服务「悬浮钮呼吸感」；粒子仅 hover 瞬态出现，无常驻空洞 ✅ |
| ③ 密度与权重平衡 | 导航是高频区权重最高（40px 触达行高不动）；底部按钮是低频辅助区，常态低对比 1px 圆框 + 透明底，hover 才浮起——辅助区不抢高频区 ✅；最小窗 1200×720（侧栏内容高 650，紧凑档）与 1080P 最大化（正常档）两档下均成立 ✅ |

### 1.3 两态位置锚定（「220 与 72 位置不跳」口径）

| 态 | 水平 | 垂直 | 切换位移 |
|---|---|---|---|
| 展开 220 | `toggleX = padX = 16`（对齐导航左缘，钮中心 x=32/30） | `toggleY = H−40 / H−36`（区顶+8 垂直居中） | **垂直零位移**；水平 +4（正常）/+6（紧凑），随宽度瞬时切换同帧完成 |
| 折叠 72 | `toggleX = (72−S)/2 = 20 / 22`（图标列居中） | 同上 | 反向同量 |

> 侧栏宽度无动画档（全站瞬时切换，终端页动效表同口径），两态间无中间帧，不存在「跳动过程」；按钮始终落在底部同一视觉带内。

## 3. 悬浮样式三态 + focus（「改成悬浮样式」）

悬浮感 = 底色浮起 + 描边高亮 + 微缩放 + 单层微阴影（F6 能力已证）；阴影用克制中性值，非「填充按钮」，不违基线「填充按钮禁阴影」条款。

| 态 | 底色 | 描边 | 图标色 | 形变 | 阴影 |
|---|---|---|---|---|---|
| 常态 | 透明 | 1px borderDefault（圆框） | textSecondary | scale 1.0 | 无 |
| hover | primarySoftBg | 1px primaryHover | primary | scale 1.09 | blur 8 / offsetY 2 / rgba(26,26,26,0.10) |
| pressed | primarySoftBg | 1px primary | primary | scale 0.90 | 无（贴回桌面） |
| focus（新） | 透明 | 1.5px primary | textSecondary | scale 1.0 | 无 |
| focus+hover 叠加 | primarySoftBg | 1.5px primary | primary | scale 1.09 | 同 hover |

- 阴影仅 hover 态出现（浮起），按下消失（贴回）——「悬浮」语义与操作反馈同源，非常驻装饰。
- focus 态服务键盘/程序化聚焦；不染色底、不变图标色，仅描边加粗为 1.5px primary。
- 深色主题：底/描边/图标色走主题 token 对应值，阴影同值（深底上 10% 黑自然加重，不改参）。

## 5. 粒子系统规格 v3（「弥漫开的绿色粒子」）

### 5.1 运动模型：椭圆弥漫 + 安全包络

v2 径向弥散在现几何下两处越界（F8），v3 改为**垂直压缩椭圆 + 包络兜底**：

- **发射角**：i×30° 均布 + hash ±10° 抖动（12 颗全周分布，沿用 v2）
- **垂直压缩 Ky=0.55**（新）：`dy = sin(a) × d × 0.55`——顶部最大触达压入让位线内，横向全幅保留「弥漫」感
- **包络兜底裁剪**（新）：粒子中心 clamp 于 `[3, W−3] × [foldLimit, H−3]`——压缩已保上向不越线，兜底只拦「直下/左向最大 hash」个别 1~4px 触发，防参数回归越界

### 5.2 参数表

| 参数 | 值 | 沿用/新 |
|---|---|---|
| 颗数上限 | **12**（一次性迸发，非持续发射） | 沿用 |
| 生命 | **1600ms** + 每颗 hash 延迟 0~80ms，≤1760ms 全灭尽自止（v3.1：老板 2026-11-05「粒子太短暂」800→1600） | v3.1 改 |
| 粒径 | 4~6px 正圆（半宽 2~3），末端缩放 ×0.7 | 沿用 |
| 透明度曲线 | 0.75 → 0（**InQuad 平缓衰减**：前段保浓度、半程仍 ~56%、后段渐隐；v3.1 老板令②弃 OutCubic 早期即淡） | v3.1 改 |
| 位移缓动 | OutCubic（同行程铺满 1600ms 速度减半=「不嗖一下就没」；透明度改独立 InQuad 不再共用 eased） | v3.1 改 |
| 起点半径 r0 | 钮半径+2：正常 18 / 紧凑 16 | 沿用 |
| 弥散距离（展开 220） | 14~26px（hash） | 沿用 |
| 弥散距离（折叠 72） | **10~16px（hash）降档** | 新 |
| 垂直压缩 Ky | **0.55** | 新 |
| 包络 | **[3, W−3] × [foldLimit, H−3]** | 新 |
| 浅色三色轮替 | #07C160 / #34D399 / #06AD56（第三色深档拉开明度，弃近底色浅档） | 沿用 |
| 深色双色 | primary / primaryHover 交替 | 沿用 |
| 发射时机 | hover 进入沿一次；移出不补发；点击不重触发 | 沿用 |

### 5.3 几何预算表（各向触达校验，包络推导依据）

| 档×态 | 中心 | 上向预算（至让位线） | 上向最大触达 (r0+26)×0.55 | 下向预算（至 H−3） | 左向预算（至 x=3） | 结论 |
|---|---|---|---|---|---|---|
| 正常·展开 | (32, H−24) | 28 | 24.2 ✅ 余 3.8 | 21 | 29→行程限幅 27（左向弥散实际 ≤9） | 不越线 ✅ |
| 正常·折叠 | (36, H−24) | 28 | 18+16=34 → 34×0.55=18.7 ✅ | 21 | 横预算 33→限幅 31（34 超出 ≤3 由兜底拦） | 不越线 ✅ |
| 紧凑·展开 | (30, H−22) | 26 | (16+26)×0.55=23.1 ✅ 余 2.9 | 19 | 27→限幅 25（左向弥散 ≤9） | 不越线 ✅ |
| 紧凑·折叠 | (36, H−22) | 26 | (16+16)×0.55=17.6 ✅ | 19 | 横预算 33→限幅 31（32 超出 ≤1 由兜底拦） | 不越线 ✅ |

- 左向限幅说明：展开态按钮贴左（padX=16），左向粒子行程被包络限短（≤9px 弥散），透明度曲线不变、只是行程短——视觉上左侧光晕贴钮、右向全量 44px，「向内容区弥漫」重心反而正确；同时修复 v2 左向越缘 12px 缺陷（F8）。
- **不与导航项重叠**：上向最大触达全部压在让位线之下（含 4px 让位 gap 不入），即使导航满行也零重叠。

### 5.4 性能口径（硬边界）

- **粒子上限 12 颗 / 每次迸发**，为矩形元素一次性成本；**同屏最多一轮迸发**（hover 进入沿触发，持续 hover 不循环）。
- **生命周期 ≤1760ms 自止**（v3.1）：到期帧起粒子分支整体不建元素；帧泵（fluid driver 同款）仅在 1760ms 生命期内出帧，**非活跃帧 0 粒子元素、0 帧泵**。
- 非持续动画、无常驻帧泵；全屏 0 宽整块不注册（含帧泵元素）。
- EUI 无 GPU 粒子系统，走 DSL 逐帧元素——12 元素 × 1760ms 是上限包络，任何后续调参**不得突破 12 颗 / 1760ms** 两值。

## 6. 交互流程

```
指针进入热区(外扩4px) ─→ hover 态（150ms OutCubic：变色+1.09+阴影浮起）
                        └→ 粒子迸发 12 颗（一次性，≤1760ms 自止）
按下 ─→ pressed（0.90、阴影消失、描边 primary）
松手 ─→ 回弹 280ms 强 OutBack（超调 ~1.11 再回落）+ onClick（220↔72 瞬时切换 + 持久化）
移出 ─→ 回常态（280ms OutBack）；粒子不补发，已发走完
Tab 聚焦 ─→ focus 环（1.5px primary）；Esc/点击他处失焦回常态
```

## 9. 与 v2 实现的差异清单（developer diff 参考，全部落 `src/app_sidebar.cpp`）

1. **粒子 dy 乘 0.55**（一处乘法，`app_sidebar.cpp:917` 处 sin 项后加系数）。
2. **粒子包络兜底**：粒子 position 计算后 clamp（x∈[3,W−3]，y∈[foldLimit,H−3]）；foldLimit 现已有局部量可复用。
3. **折叠态弥散降档**：spread 哈希区间 14~26 → 按 `collapsed` 分支 10~16（`14+12h` / `10+6h`）。
4. **hover 阴影**：`app.sidebar.toggle` 增 `.shadow()`，hover 态 blur 8 / offsetY 2 / rgba(26,26,26,0.10)，pressed/常态无；`animate` 属性集追加 Shadow|Blur。
5. **focus 态**：热区/视觉元素增焦点接入（1.5px primary 描边），具体焦点事件接线由开发按框架焦点机制落。
6. 其余（颗数/生命/延迟/粒径/透明度/颜色/触发链/热区/果冻参数）**零改动**。
7. 测试连锁：`test_app_sidebar` 现有断言不破坏（几何/热区/粒子计数口径不变）；建议新增断言——粒子包络（任一粒子中心 y≥foldLimit 且 x∈[3,W−3]）、折叠态粒子元素存在性（hover 后 ≥120ms 计数，clue79③ 口径）。
