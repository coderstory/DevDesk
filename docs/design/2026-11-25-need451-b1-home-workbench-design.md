## 2. 两遍法与关键设计决策

**第一轮（构图，不落参数）**：本页唯一性原则句 = **「首页从『数字仪表盘』改成『一天的调度台』：第一列是按时排好的今日议程，旁边是谁在干活、刚干成了什么；数字退到页底当背景。」** 色板沿用项目绿色体系（primary/primarySoftBg/primaryText + 中性灰阶 + 错误红），字体沿用项目系统字体栈，无新增颜色。

**第二轮（对照任务书自审）**：若给任何 dashboard 出方案，默认会得到「页顶 KPI 大卡 + 2×2 等分圆角卡 + 装饰图表」——那是默认脸，不是本任务书的选择。本页据此换向，落为四条决策：

| ID | 决策 | 理由（对应任务书/PRD） |
|---|---|---|
| D-01 | 页序：页头 → 今天到期 → 已逾期 → 智能体 → 最近动态 → 统计条 | PRD §5.1 首屏顺序与「今日到期首屏可见」；用户打开应用第一问是「今天要做什么」 |
| D-02 | 宽窗（可用内容宽 ≥880）双列 56/44：左列=今天到期+已逾期（主），右列=智能体+最近动态（辅）；窄窗单列按 D-01 顺序堆叠 | 主列给任务列表足够标题宽度；辅列给动态足够「标签+标题+时间」；避免 2×2 等分默认脸；1000×640 下无横向溢出 |
| D-03 | 统计卡从页顶降到页底（视觉压成背景信息条）；快捷入口「+ 新建任务 / + 新建笔记」从独立行升入页头右侧 | 信息优先：可行动的任务 > 被动数字；操作高效：高频新建动作常驻页头，不再随滚动沉底。PRD §5.2 明确统计卡「仅排版可能被 ui-ux 调整」 |
| D-04 | 本期退役页底点阵+打字机装饰层 | 其展示内容 = 最近编辑笔记，已按 F-03 并入「最近动态」，PRD 明令「不保留两份」；新区块占据原有余高，装饰层无生存空间；信息优先原则 |
| D-05 | 今天到期卡 = 日程式时间轨（时间槽 + 竖轨 + 圆点）——全页唯一「大胆」处；其余（辅助卡、统计条、错误/空态）全部克制 | 让「今天的顺序」成为记忆点：一眼看出下一件事几点；防默认列表脸 |

被否决的备选：三列（宽窗右列过窄，时间线标题被压到 <250px 不可读）；页顶保留 KPI 大卡（与「今天要做什么」优先级冲突，且把首个任务区推到首屏下半）；区块折叠（PRD Q-1 已决不做，且新增折叠态记忆成本 > 收益）。

## 3. 页面级构图

### 3.1 滚动模型

首页**整页一个滚动容器**（沿用现状 `home.scroll`），外壳（侧栏、标题栏）不滚。所有区块内容均有硬上限（到期/逾期各 5 行、运行中 3 行 + 终态 3 行、动态 8 行），卡片**不做内滚、不存在嵌套滚动**；统计条随页滚到底。与首页/智能体页等同类页的滚动模型一致。

### 3.3 空间节奏与密度预算 + 构图三问

- 节奏：页头 40 → 20 → 工作区（列 gap 20、卡 gap 20）；卡内：内边距 20 → 标题行 28 → 12 → 列表；组标签 20（上下各 4）；行 44（到期/逾期/运行中）、40（终态/动态）；底行「还有 N 条/个」36；工作区 → 24 → 统计条（卡 96~120，卡 gap 8）→ 24 页底。
- 最小窗首屏核算：页头 40+20 + 今天到期卡（20+28+12+20+8+5×44+36+20=384）= 底缘 y≈444，小于两平台客户区（Windows ≈602 / macOS ≈612）→ 完整可见。
- **构图三问**：① 滚动模型如上，整页单滚动、无嵌套滚动，与同类页一致；② 无效空白：单列为顺序堆叠、卡片按内容自适应高度，空态压缩为单行 44 高不撑白卡；宽窗两列由内容驱动不等高，差量落在页背景而非卡内空洞；统计条列数沿用既有容量算法（单卡 ≥180），不留定宽空列；③ 密度与权重：今天到期=首屏首位+主列上+唯一时间轨与绿色圆点；智能体/动态降一档（14px 标题、灰阶标签）；统计卡 30px 数字仍是全页最大字但被推到底部背景位——「先看事、再看数」。
- 年龄/弱化：不做（无时间衰减样式，避免暗示数据新鲜度）。

沿用现有 5 卡（Token 速率/今日笔记/待办任务/逾期任务/API 调用）：玻璃面、圆角 16、内边距 20、指标名 14px textTertiary 居中、数字 30px/600（逾期>0 用 errorText，Token 流式中 primary）、基准高 96、上限 120、卡 gap 8、列数按可用宽反推（单卡 ≥180，上限 5）、点击跳既有目标页、果冻按压与 Sparkline 全部保持现状。变更点仅：位于工作区之下（间距 24），不再出现在页首。

### 4.7 四态组件规格（四个区块共用）

| 态 | 规格 |
|---|---|
| 加载（无快照） | 3 条骨架行，行高与真实行一致（44/40/40）；骨架条高 14、圆角 6、底 borderMuted，宽度按 40% / 64% / 52% 交替；**静态无闪光**（避免整页周期重绘，与首页动画开销纪律一致）；骨架不覆盖标题行与计数 |
| 空 | 单行高 44；13px/400 textTertiary；x=8；文案用 PRD 钉死口径（§4.2-4.5）；无插画 |
| 错误·无快照 | 单行高 44：左「加载失败」13px/400 errorText；右「重试」文字钮（13px/400 primaryText，高 28、左右内距 8、圆角 6，hover 底 hover、pressed 底 active、按压 0.96） |
| 错误·有快照（刷新失败） | 卡片顶部错误条：高 32、圆角 6、底 error 8% 染（rgba(239,68,68,0.08)）、左「加载失败」12px/400 errorText、右「重试」12px/400 primaryText；条下 8；**旧列表保留可点**（不灰化：数据仍有效，只是未刷新） |

| 模块禁用 | 该区块整卡隐藏（待办禁用 → 今天到期+已逾期两块同时隐藏；智能体禁用 → 智能体卡隐藏；动态按来源过滤，四来源全禁 → 整卡隐藏）；整列无卡片时该列折叠、剩余列占满可用宽（不出现空列）；同列单卡缺失时其余卡上移 |

### 4.8 相对时间格式（最近动态行尾、智能体终态收尾时间）

| 距今 | 文案 |
|---|---|
| <60 秒 | `刚刚` |
| 1–59 分钟 | `N 分钟前` |
| 1–23 小时（同一自然日） | `N 小时前` |
| 昨天（自然日） | `昨天 HH:mm` |
| 同年更早 | `MM-DD` |
| 跨年 | `YYYY-MM-DD` |

智能体终态尾注时间不带相对语，只用本日 `HH:mm` / 非本日 `MM-DD`（避与「完成」状态字连读歧义）。

## 5. 逐 F-ID 设计结论

| F-ID | 设计结论 |
|---|---|
| F-01 | 两块独立卡片（今天到期 / 已逾期），共享待办模块门控；今天到期=时间轨议程（时间槽+竖轨+绿点）、按 `HH:mm` 升序；已逾期=同几何的 error 圆点 + 行尾「逾期 N 天」；每区 ≤5 行，溢出底行「还有 N 条」→ 待办页；两区空态文案按 PRD；标题单行省略。 |
| F-02 | 单卡两段：「正在运行 N 个」+ ≤3 运行行（种子绿点 + 已运行时长）+ 溢出「还有 N 个」；「最近结束」+ ≤3 终态行（完成绿✓ / 失败红✗ / 受限橙! / 取消灰–，状态字按级别着色，失败最高权重）；运行超 1 小时照实显示；可见且运行>0 时 10 秒静默刷新；标题行「查看全部 ›」→ 智能体页。 |
| F-03 | 单卡 8 行倒序时间线；四类文字胶囊（笔记/待办/智能体/定时）+ 标题 + 相对时间（§4.8）；来源禁用则该类条目不出现，四源全禁整卡隐藏；原最近笔记并入、页底打字机层退役（D-04）；定时系统触发行由数据层过滤（设计不可见）。 |
| F-04 | 每区块独立四态（§4.7）；单块失败只在本块显示「加载失败+重试」；**无快照=错误行替换列表，有快照=顶部错误条+保留旧列表**；区块内「重试」只重查本区块；模块禁用整卡隐藏；数据库未初始化时区块各自错误态、统计卡沿用既有既有空/错行为。 |
| F-05 | 手动刷新=页头 ⟳ 钮：刷新中钮禁用+图标 0.9s/圈旋转，返回即恢复；进页刷新与 10s 自动刷新=静默（无转动、无骨架闪烁，数据变化 120ms 淡入）；刷新失败按 F-04 规则保留旧数据。UI 不承诺 SQL 条数（逻辑层约束 ≤4/轮），不做进度条/计时文案。 |
| F-06 | 跳转矩阵见 §10；条目与「查看全部/还有 N 条」均整行可点；目标模块关闭 → 停留首页 + 既有 toast「该模块已关闭」；定位能力未实现则只到页面，本设计不画目标页选中高亮。 |
| F-07 | 断点=可用内容宽 880：≥880 双列 56/44，<880 单列按 D-01 页序；最小窗 1000×640 下无横向溢出（行内标题省略、右置附件定宽）、今天到期卡首屏完整可见；**不折叠**（PRD Q-1）；统计条自动减列（既有算法）。 |

## 12. 禁止项自查 + 品味自审

- 禁止项：无旧橙/陶土色（旧橙方案已废弃）；无大面积渐变/装饰色块（唯一阴影=主按钮既有绿阴影 + 卡片面板阴影）；红仅用于错误与逾期强调（沿用首页逾期统计卡既有 errorText 先例）；蓝未使用；无插画空态、无情绪化文案；无框架/库选型名（本文件零实现技术绑定；demo 以页面载体形式出现）；未假设不存在的能力（tooltip/整页滚动/按压缩放/过渡/文字省略均列入项目能力清单）；未新增折叠、筛选、写操作、键盘快捷键。
- AI 五 tell：未命中——非暖米/衬线三件套；非暗夜霓虹（绿色体系为项目铁律）；非报纸排版（14px 圆角卡、非零圆角、非密排多栏）；卡片网格接近「等尺寸圆角卡堆」但已换向：非等分（56/44）、内容驱动不等高、无渐变装饰、每卡内部结构不同（时间轨/双段/时间线），且卡片材质沿用项目既有系统而非新造；无大写眉标/中点元信息串/破折号标签/等宽小字。
