## 1. 页面级构图（先整体后参数）

### 1.1 组件在四类用法中的锚定关系

| 用法 | 锚定位置 | 滚动模型 | 密度预算 |
|---|---|---|---|
| 页面级 tab（40 高） | 页头区下缘，与内容卡上缘 gap 4（现状 `release_config` 已归 4 档）；40 = `kHeaderH` 页头归一档 | tab 行固定不滚，页面内容区各自内滚（外壳不滚） | tab 行整行高 40，不新增垂直占用 |
| 弹窗级小 tab（36 高） | dialog 标题区下缘，与标题行 gap 8 | 弹窗内容区滚动，tab 行固定在弹窗头 | 与页面级恒差 4（40/36 梯子，2026-11 老板裁决档不动） |
| notepad 文档 tab 栏（带关闭钮） | 侧树顶部（`drawNoteTabBar`，`md_module_tree.cpp:94`），非 wtab 自绘 | tab 栏固定，编辑区独立滚动 | 文档 tab 常多，密度优先，高 36 文档档 |
| wtabRow（tab 行 + 右缘计数） | 列表页工具行（release 行高 44 / schedule 行高 40），计数固定右缘 | 行固定，列表区内滚 | tab 组左聚 + 计数右聚，中间留白属分组留白（不算空洞） |

### 1.2 构图三问

1. **滚动模型**：四类用法 tab 行全部固定不滚；仅 tab 数量超容器时**轨道/条带内部横向滚动**（见 §11）。与全站「外壳不滚、内容区各自内滚」一致。
2. **无效空白**：wtabRow 中段留白 = tab 组与计数的分组留白，服务分区；其余用法 tab 紧排无空列。无定宽空列。
3. **密度与权重**：选中态是唯一高权重元素（滑块/指示条），未选态全部退到次级文字色；最小窗 1000×640 与宽窗 1600×1000 下四用法均可成立（tab 超宽走横滚兜底）。

### 1.3 demo 页构图

顶部控制条固定（方向切换 A/B/C/全部 + 深浅主题切换），下方内容区滚动；四用法区块上下排列，每区 = 区标题 + 组件演示 + 状态枚举展示行。拖窗缩放可验证自适应。

## 8. 交互流程（页面级切换主流程）

```
单击未选 tab → 按压态(scale 0.97, 100ms) → 抬起 → 激活切换
→ 滑块滑向目标 tab（OutExpo 180ms，单一动画通道取最新目标）
→ 文字色渐变（Linear 150ms）→ 内容区切换（页面自身逻辑）
```

## 9. 状态表（每数据展示区·四态）

| 区 | 空 | 加载 | 错误 | 成功 |
|---|---|---|---|---|
| tab 组 | tab 列表为空 → 整组（含轨道）不渲染，不留空壳（notepad 最后一个文档关闭同理） | tab 无加载态（切换即时，内容区加载由各页面负责，不在本组件范围） | 无错误态（纯导航控件） | 正常渲染，选中滑块就位 |
| wtabRow 计数 | tab 空则整行不渲染 | "…" | "—" | 实际计数，>999 显 "999+" |
| notepad 栏 | 全关 → 栏隐藏，编辑区显示空态引导（页面既有空态，不属本组件） | — | — | 正常 |
| 网页终端 tab（方案） | 单 tab 时关闭钮隐藏 | — | — | 正常 |

边界：**超长 label** → 截断省略号 + tooltip（§3.1）；**首次打开** → 默认激活首 tab，无动画初始位；**无权限** → 该 tab 不渲染（现行为一致，不显禁用壳）；**平台差异** → EUI-NEO 统一渲染无分叉；**禁用 tab** → 全站现无禁用用法，规格保留（§3.1）但 F3 不核验。

## 11. 自适应行为表

| 条件 | 行为 |
