## 2. 四决议点（结论 + 理由）

### 2.1 ① 常用目录存储形态 = 扩展 `terminal_settings` 单行 JSON

```json
{
  "startupDirs": ["D:\\project\\gui\\DevDesk", "D:\\project\\zems\\infomedia\\rs.host"],
  "startupDir": "D:\\project\\gui\\DevDesk"
}
```

- `startupDirs`：0–12 条字符串，按添加顺序；trim 后非空、去重（Windows 比较大小写不敏感、macOS 敏感）、保留首次出现的写法。
- `startupDir`（既有键**复用为默认目录镜像**）：恒 ∈ `startupDirs`；列表为空时 = ""。保证网页终端、旧读取方零改动即拿到合法默认值。
- 理由：模块自管单行 JSON 是既有契约（`terminal_settings.cpp:22-23`、`:130`），一读写一落库，无两行一致性风险；不新增独立键/文件，符合五维预算「能复用不新增」。代价：旧版本回退保存会丢列表（旧结构序列化不含新键）——路径可再加，接受并在 §9 记为已知降级行为。

### 2.2 ② 选择交互落点 = 管理在设置面板、消费在新建动作（分体按钮）

| 面 | 形态 | 职责 |
|---|---|---|
| 设置面板「常用目录」区 | 行内列表 + 添加/删除/设为默认 | **管理**：增（系统目录选择器）、删、设默认 |
| 工具栏「新建」分体钮·左段 | 「＋ 新建」主绿钮 | **直达**：用默认目录开新会话（0 目录 = 主目录，与现状零差异） |
| 工具栏「新建」分体钮·右段 | 24 宽的 ▾ 选择段（仅列表 ≥1 条时出现） | **点选**：展开目录弹层 |
| 目录弹层 | 锚定在新建钮下方的浮层，行级点选 | 选目录即建会话；含「主目录」行与「管理常用目录…」入口 |
| 空态「+ 新建会话」 | 同右段行为（≥1 条开弹层，0 条直达） | 空态也能进入选择 |

- 理由：老板场景是「多套代码切换」，新建瞬间选目录，不能绕设置页或系统对话框；同时保留默认目录一次点击的肌肉记忆（现状即一次点击建会话）。默认标记因此有实际用途（左段直达 + 网页镜像），不是装饰。
- 未选：新建即弹层（每次多一次点击，高频路径降级）；每次新建弹系统目录对话框（慢、违反纯点选）；全局设置页承载管理（终端设置在页内面板，need250 §2.1 已裁决）。
- 窄窗降级（page 宽 <720，桌面最小窗不可达，为侧栏折叠/未来预留）：分体合为单钮，点击开弹层（0 条仍直达），无 hover 双段歧义。

### 2.3 ③ 旧单值迁移 = 静默并入，无对话框

| 读入情形 | 结果 |
|---|---|
| 有 `startupDirs` 且非空 | 以列表为准；`startupDir` 不在列表 → 插到首位并设为默认；`startupDir` 为空 → 默认 = 首项并回写镜像 |
| 无 `startupDirs`、`startupDir` 非空 | 列表 = [旧值]，默认 = 旧值（老用户首开即见原目录带「默认」徽标） |
| 两者皆空 | 空列表，主目录语义（与现状一致） |
| 之后网页端改写 `startupDir` | 视为「设默认」：在列表内则移动默认；不在则追加为首条默认 |

理由：一次加载内收敛，无弹窗打扰；旧值语义（默认启动目录）被完整保留；网页端不改代码即可继续工作。

### 2.4 ④ 成组启动 = 本期不做（建议档默认关闭）

- 理由：老板未提；成组启动会引入「N 个目录并发建会话 + 部分失败怎么报」的新语义，需多选状态机与失败汇总通道，成本 > 当前收益。本期**不渲染任何勾选/多选入口**，避免暗示未实现能力。
- 若未来启用（建议档，仅供后续评估）：弹层行前加 24×24 复选（未选中 = 1px borderDefault 空框、选中 = 主绿底白勾），行点击改为「切换选中」；底部主按钮「打开 N 个会话」按行序遍历目录逐个建会话，失败目录并入一条 toast「N 个目录不可用」。默认关闭 = 上述控件全部不出现。

## 3. 页面级构图

### 3.1 滚动模型

终端页外壳不滚：工具栏 44 固定、会话网格占余下高度各自渲染。设置面板为页内模态卡：卡内容区超高时**内滚**（既有能力，`terminal_page.cpp:1251-1253` 的 scroll 视图），底部「恢复默认 / 完成」行固定不滚。目录弹层为工具栏附属浮层，自身不滚（12 条上限下最高 566 < 最小窗可用 590，见 §4.3 高度式）。全站同类页一致。

锚定三铁律（沿用面板既有栅格，不新造）：
- 标签列 x=16（kPanelPad）、宽 128；控件列起点 x=16+128+12=156（`terminal_page.cpp:49-52`、`:1164`）。
- 面板右缘 = 卡宽−16；所有右置控件（计数、默认徽标、删除、完成）右缘锚定该轨。
- 「常用目录」区为**全内宽块**（x=16 起，宽 innerW=卡宽−32），不落标签列——列表行需要路径展示宽度，落 128 列会把路径压到 220px 以下。

### 3.3 空间节奏与密度预算 + 构图三问

- 行高：目录行 44 / 添加行 32 / 分组头 20 / 弹层行 36 / 弹层标题行 32；间距：行间 8、分组前 12、组头下 8、添加行前 12（全取自面板既有节奏，无第四种值）。
- **构图三问**：① 滚动模型如上，设置面板内滚、弹层不滚，与页内既有模态一致；② 无效空白：列表满宽利用、路径中段截断而非留空列；0 条时用两行极简文案 + 就近添加钮，不放大白卡；③ 密度与权重：最左段「新建」是唯一鲜艳块（高频），默认徽标次之，删除/设为默认低权重灰字/图标；宽窗（page 1392）与最小窗（page 792）路径可用宽分别 ≈392/392（面板 520 恒定），无定宽空列。
- 原则句（本页为何独特）：**把「目录」从设置项变成动作旁的候选清单——管理在面板、消费在按钮，点一次就到目标目录，不打断工作流。**

### 4.4 长路径截断（统一规则，列表与弹层共用）

1. 路径以用户主目录开头 → 前缀替换为 `~`（Windows 主目录含盘符时保留盘符形式：`C:\Users\x` → `~`）。
2. 仍超显示宽 → 保留首段（盘符根或 `~`）+「…」+ 末 2 段：`D:\…\infomedia\rs.host`。
3. 仍超 → 尾部省略（TextOverflow::Ellipsis）兜底。
4. hover 400ms 出 tooltip 显示完整路径（白底、12px、最大宽 480、两行内，超出尾部省略）。
5. 不实时检查目录存在性（避免每帧文件系统 IO，违反 CPU 预算）；失效只在「点击启动」与「添加」两个动作点暴露（§5、§6）。

### 4.5 删除交互与确认 = 无二次确认

- 单击即移除该快捷方式；**不碰磁盘目录本身**，误删成本 = 重新添加一次。
- 默认行被删：默认顺延为列表首项，toast「已移除「<名>」，默认改为「<新名>」」。
- 删至空列表：默认镜像清空、回主目录语义，toast「已移除，新会话将使用主目录」。
- 非默认行：toast「已移除「<名>」」。
- 不做撤销/不做模态确认：删除对象是快捷方式而非数据，模态确认违反高效原则；toast 单实例（EUI-NEO 既有能力）足够告知结果。
- 行消失动效：200ms 淡出后移除（间距同帧收回，不做高度动画——框架无该能力，硬写会跳帧）。

### 4.6 添加目录

- 点击「添加目录」→ 系统目录选择器（`platform::folderpicker::pickFolder("选择常用目录", 初始目录)`），初始目录 = 当前默认目录，空则主目录。
- 返回有效新路径 → 追加到列表尾部，200ms 淡入+上移 8px；若原列表为空，该条自动成为默认（镜像同步）。
- 重复 → toast「已在常用目录中」，不新增；取消 → 静默无反馈；返回不可进入 → toast「目录不存在或不可进入」。
- 选择器为阻塞原生对话框（既有行为，记忆导出同款），不做自定义目录浏览器。

### 4.7 恢复默认联动

「恢复默认」= 清空 `startupDirs` + 清空 `startupDir` 镜像 + 其余设置回默认（沿用既有 `*sp = TerminalSettings{}`，`terminal_page.cpp:1482-1490`）。无二次确认（既有行为不变）；面板内列表即时转空态。

## 9. 数据与迁移细则

- 落库：沿用 `saveTerminalSettings` 单行 JSON（`terminal_settings.cpp:130`），新增键 `startupDirs`；`startupDir` 继续写默认镜像。
- sanitize（load/写入共用）：trim、去空、去重（平台大小写规则）、截断到 12 条、`startupDir` 不在列表则按 §2.3 收敛。
- **契约变更（有意）**：启动目录行原是「保存前校验可进入」（`terminal_page.cpp:1438-1449`）；列表化后改为「添加时校验 + 启动时严格校验，保存不拦截」——条目是快捷方式不是承诺，网络盘/移动盘离线时不允许阻塞保存；spawn 语义不变（非空不可用 → 失败，不静默回退）。旧行内错误文案随输入框一并移除。
- 网页终端：不改代码；`startupDir` 镜像保证其默认值语义；网页端若改写该键，按 §2.3 末行并入列表。
- 降级：旧版本保存设置会丢弃 `startupDirs` 键（旧结构不含该键），列表需重新添加；记录为已知可接受行为。

## 10. 禁止项自查 + 品味自审

- 禁止项：无旧橙/陶土色；无大面积渐变/装饰色块；红仅删除与错误（error/errorText）；蓝未使用；无插画空态、无情绪化文案；无键盘快捷键；无框架/库选型（HTML demo 为载体例外）；未假设框架不存在的 API（弹层用既有 rect/text/stack 组合绘制，与搜索条/标签栏同法；列表用既有内滚视图）。
- AI 五 tell：未命中默认脸——非暖米色/衬线、非暗夜霓虹（终端网格是既有深色内容，不在新 UI 上做荧光强调）、非报纸排版、非等尺寸圆角卡堆+统一灰影（列表行无卡片无阴影、仅 hover 底）、无句首大写眉标/中点元信息串/破折号标签。
- 大胆只花一处：新建分体钮 → 锚定目录弹层的这一下点选；其余全部克制（列表行、徽标、按钮均沿用既有面板语言）。拿掉的装饰：弹层未加图标底圆、未加分组标题下的分割线、未给删除加二次确认。
- 两遍法：第一轮构图 = 列表管理 + 动作锚定弹层（token 骨架：绿主色、白卡、6/14 圆角、8 网格）；第二轮自审——给同类页出方案是否会得到「设置里一个下拉框 + 新建弹系统目录对话框」？会，那是默认脸 → 换向为「行内快捷列表 + 默认徽标 + 分体钮弹层」，改了什么：目录不是配置值而是动作候选；为什么：老板场景是频繁切换多套代码，动作点必须一步到位。
- demo 渲染自审已过图：1000×640 默认/设置面板/目录弹层/空态、1600×1000 设置面板五态均无溢出、无遮挡、无大段空白；两档 page 宽 792 / 1392 均成立。
