## 1. 页面级构图

三个 UI 面共用同一条构图原则：**外壳固定、单一内容区滚动**。窗框不滚、不出现第二滚动容器；搜索条是浮层不进布局流（唤起/收起零回流）。

### 1.1 查看器窗（900×640 默认）

```
┌──────────────────────────────────────────────────┐
│  标题栏（系统绘制）：sample.md        ← 文件名，无路径 │ 36 逻辑px 档
├──────────────────────────────────────────────────┤
│                                    ┌───────────┐ │
│                                    │ 搜索浮层   │ │ ← 仅 Ctrl/Cmd+F 后出现
│   ┌──────────── 正文内容列 ───────┐ │[输入][n/m][×]│ │   浮于正文之上，不占布局
│   │  （max 760px 居中）           │ └───────────┘ │
│   │  h1 / 段落 / 列表 / 代码 / 表格 │               │
│   │                               │               │
│   └───────────────────────────────┘               │
│                    ▲                              │
│                    └ 唯一滚动容器（正文区）          │
└──────────────────────────────────────────────────┘
```

**构图三问**
1. 滚动模型：标题栏与搜索条固定不动，正文内容区是**唯一**内滚容器（EUI-NEO scrollview，与主窗编辑器预览同一容器族）。与全站「外壳不滚」口径一致。
2. 无效空白：正文列 max-width 760px 居中——留白只服务阅读行宽（16px 字号下 760px ≈ 45 汉字/行），窄窗时列宽随窗收缩，不产生定宽空列。
3. 密度与权重：全窗只有一个信息主体（正文），无侧栏/工具栏分散权重；搜索条是唯一浮层，权重最高时刻 = 刚唤起时（浮层 + 阴影 + 边框三重对比），符合高频操作优先原则。

**区块划分与锚定**：① 标题栏（系统绘制，窗级）② 正文滚动区（占满客户区）③ 搜索浮层（锚定客户区右上角，top 12 / right 16，不随正文滚动）。

**信息密度预算**：正文区信息密度 = 预览排版原生密度，不额外加卡片/边框包壳；空态与错误态为单行居中占位，密度归零但不产生多块碎片。

### 1.2 搜索条（唤起态）

│ ┌──────────────┐  1/5   ┌─┐ │

   220px        8px  ≥48px  8px  24px   （内边距 6px）

### 1.3 设置页「关联 .md 文件」开关行

```
┌─ 设置卡片（cardSurface + 12 圆角 + 描边）──────────────────────────┐
│  …（既有卡片内容）                                                  │
│  ┌─────────────────────────────────────────────────┐  ┌────────┐ │
│  │ 关联 .md 文件            13px                     │  │        │ │
│  │ 双击 .md 文件时用 DevDesk 只读查看器打开  12px      │  │ ⬤ 44×24│ │
│  └─────────────────────────────────────────────────┘  └────────┘ │
│         ↑ 左块（label + 说明行，flex 弹性）          ↑ 状态字 12px   ↑ 开关钉行右缘
│  （未生效态追加一行）⚠ Windows：…一键按钮 / macOS 文字指引 11px      │
└──────────────────────────────────────────────────────────────────┘
```

**构图三问**
1. 滚动模型：设置页内容区整页滚动（与现有设置页一致）；开关行是卡内静态行，自身不滚。
2. 无效空白：左块 flex 吃掉全部窗宽增量（H18 横向弹性锚先例：固定控件右锚、增量全进说明列），宽窗下状态字与开关仍钉右缘，不产生右侧死区。
3. 密度与权重：行内三个权重级——label（主，13px）、说明行（辅，12px）、状态字（状态信号，12px 彩色）；未生效时追加的引导行是第三权重级（11px 警告色），只在需要时出现，平时零占位。

## 4. 交互规格（逐元素：触发 / 反馈 / 迁移 / 边界）

### 4.1 查看器窗

| 元素 | 触发 | 反馈 | 迁移 | 边界 |
|---|---|---|---|---|
| 正文滚动区 | 滚轮 / 拖滚动条 | 内容区滚动，步进 56px | 无迁移 | 到顶/到底自然停；拖出区域松手=停在当前位 |
| 窗缩放 | 拖窗缘（系统） | 正文列宽 `min(窗宽−80, 760)` 实时重排；重排后滚动位置保持 | 无迁移 | 最小 560×400 后不再缩；无 onResize 回调，靠 compose 的 screen 参数变化触发（clue6 已核） |
| 关闭窗 | 点系统关闭钮 | 直接关，无确认 | 窗销毁；主窗与其他查看器窗不受影响 | — |

### 4.2 搜索条（交互口径=PRD D-2 定稿，逐条落实）

| 元素 | 触发 | 反馈 | 迁移 | 边界 |
|---|---|---|---|---|
| 唤起 | Ctrl+F（Win）/ Cmd+F（mac） | 浮层 150ms 淡入+下落 4px；光标已在输入框 | 阅读态 → 搜索态 | 再唤起：保留上次关键词并**全选**，直接输入即替换、Enter 即重跑 |
| 输入 | 键入任意字符 | 全部命中即时高亮（§3.4 普通命中）；计数 `n/m`（当前序号从第 1 处起）；首处即当前态 | — | 0 命中：高亮全清、计数 `0/0` +「无匹配」；清空输入=等同无关键词：高亮全清、计数位显示空 |
| Enter | 输入框聚焦时按 Enter | 跳下一处：该处叠当前命中高亮，视图滚至其垂直居中，计数推进 | — | 已在最后一处→回绕到第 1 处；`0/0` 时 Enter **无操作**（视图与计数不变，PRD 定稿） |
| Shift+Enter | 同上 | 跳上一处，其余同 Enter | — | 在第 1 处→回绕到最后一处 |
| Esc | 输入框聚焦时按 Esc（或窗级 Esc） | 高亮全清、浮层 150ms 淡出 | 搜索态 → 阅读态 | — |
| 点 × | 鼠标左键 × 按钮 | 悬停底 hover→按下底 active→抬起执行：同 Esc | 搜索态 → 阅读态 | 连点：第一次已收起，后续无目标无操作；拖出按钮松手=不执行 |
| 长按/连点 Enter | — | 每次按键推进一处，无节流无跳变 | — | 跨多窗：搜索态按窗独立，互不串扰 |
| 焦点丢失 | 点击正文 | 浮层不收起、高亮保留（浏览器惯例；收起只走 Esc/×，PRD 定稿未含点击正文收起） | — | — |

### 4.3 设置页开关行

| 元素 | 触发 | 反馈 | 迁移 | 边界 |
|---|---|---|---|---|
| 开关（关→开） | 点 44×24 轨道 | 轨道变 primary 绿、滑块右移（无过渡动画，与现有 wswitch 一致）；状态字按结果切换 | 见下方状态迁移 | 写入中无 loading 态（毫秒级本地调用，PRD §八）；连点=幂等重复写同一目标值无副作用 |
| 开关（开→关） | 同上 | 轨道变灰、滑块左移；状态字=`已停止自动维护`（曾开过）| 关联**不注销**，仅停止自愈（D-4 定稿） | 反复开关幂等 |
| 状态字 | 只读，不可点 | — | 只随查询/写入结果变 | 查询失败→显示本地保存值 |
| Win 引导按钮（未生效态） | 点按钮 | 悬停/按下色变（§3.5）；打开系统「默认应用设置」页 | 离开应用 → 用户修完返回 | 返回后设置页重获焦点自动重查一次；连点=重复跳系统页，无副作用 |
| mac 文字指引 | 只读 | — | — | 无一键入口，如实文字呈现（D-5 定稿） |

**状态字四态迁移**（PRD §八全口径）：初始=关+从未开过→无字；开+写入成功→`已关联`；开+写入失败或回查不一致→`未生效`(+引导行)；关+曾开过→`已停止自动维护`。

## 10. 禁止项自查
