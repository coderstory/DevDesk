## 4. B 段：容器形态规范

### 4.1 判据（老板给定，全站适用）

- 条目自成信息块（多字段、有状态/操作、单条可独立理解）→ **卡片式**。
- 同质简单行（一行文字+单一交互，行行等价）→ **裸行式**，行卡感由外层容器或底色承载。

### 4.2 每类列表裁决表

| 列表 | 裁决 | 依据 |
|---|---|---|
| todo 看板列内任务 | 卡片式（维持） | 标题+明细+勾选+优先级染色，自成信息块 |
| schedule 任务行 | 卡片式（维持） | 行卡含名称+chip+下次触发+状态四字段 |
| release 任务行 | **裸行式**（维持，#195 正样本） | 外层大卡承载卡片感，行底透明 hover 上色 |
| release 流水线索引 | 裸行式（维持） | 步骤名单行索引，等价行 |
| agent 任务卡 | 卡片式（维持） | 名称+状态+多字段 |
| claude profile 卡 | 卡片式（维持） | 头像+名称+状态+路径多字段 |
| memory 审核卡 | 卡片式（维持） | 标题+置信度+操作多字段 |
| memory 基线磁贴 | 卡片式磁贴（维持） | 数值+标签，双列网格（R6 替代范式） |
| mcp 工具卡 | 卡片式（维持） | 名称+描述+开关多字段 |
| 设置分组行 | **裸行式**（维持） | 分组卡内标签+控件单行，行行等价 |
| 侧栏导航 | 裸行式（维持） | 单行文字+active 底色 |

### 4.3 卡片上下间距统一档（定死）

- **卡与卡纵向间距 = 8px（spacing 档，全站统一）**，即基线「列表项 8」档；卡与卡不贴边由 8px 保证，禁止 0 间距贴边与 ≥16 的松散两种极端。
- 磁贴/网格卡 gap 同 8px；看板列间距属布局列距（维持现状，不属卡间距）。
- 裸行式无卡间距概念，行高与分隔口径见 4.4。

### 4.4 裸行分隔符口径（二选一定死）

1. **有外层容器的裸行**（release 任务行、设置分组行、流水线索引）：一律 **1px 分隔线，色 borderMuted**，画在行下层、首行不画（#195 §4.1 既有范式；R6 豁免口径覆盖）。禁用行间留白替代（同容器内留白不齐线）。
2. **无容器的裸行**（侧栏导航）：**无分隔线**，靠行高与 active/hover 底色自分组。禁加 1px 线（导航行加线=噪）。
- 同一容器内两种口径禁混用。

## 5. C 段：卡片材质规范

### 5.1 既有玻璃通路（盘点结论：通路已齐备，不新增 token）

| 通路 | 定义 | 值（theme.cpp surface 实值） | 语义层 |
|---|---|---|---|
| glassFill | src/ui_kit/glass.h:18-24 | 暗 #232120 @ α0.95 / 亮 #FFFFFF @ α0.94（3% 绿染偏移） | L2 业务卡（itemSurface，materials.h:11） |
| glassPanelFill | glass.h:27-33 | 暗 @ α0.78 / 亮 @ α0.80 | L1 容器面板（containerSurface，materials.h:8） |
| glassBorder / glassShadowColor | glass.h:36-46 | 高光边 白 α0.12暗/0.60亮；冷绿黑阴影 | 玻璃三件套配套 |
| cardSurface | src/ui_kit/card.h:17-19 | =glassFill | 组件卡统一入口 |
| cardPanel / cardPanelColored | card.h:31-41 | 玻璃面板 / 弹窗内专用可区分底色 | 弹窗内卡豁免档（弹窗底白、半透白卡会融，card.h:35-37 注释即裁决依据） |

**显式否决新增 surfaceTranslucent token**：#192（2026-11-07-上线任务编辑页重设计.md:120）提议暗 72%/亮 78%，与既有 glassPanelFill（78/80）同语义带、差 ≤6 个百分点——直接用 glassPanelFill 承接 #192 的「索引列底/面板底」，不设第二套半透常量（防止两套半透值漂移）。

### 5.2 材质裁决

1. 主窗内所有业务卡/容器卡 → 统一走 glassFill（L2）/ glassPanelFill（L1）+ glassBorder + glassShadowColor 三件套；手绘卡面（非组件通路）一律换成 itemSurface/containerSurface 取色，**描边与阴影同步换 glassBorder / glassShadowColor**，圆角参数不变。
   - **2026-11-08 老板拍板（池235）**：原 §5.2-1 与 §6-C 口径互斥——前者写「描边/阴影参数不变」，后者写「+ glassBorder + glassShadowColor」。按后者执行：玻璃三件套必须齐，只换填色不换边缘会掉出玻璃语言（灰线 + 近无影 = 实色块）。mcp 工具卡为落地样本（mcp_page_module.cpp:424-436，阴影几何 24 模糊 / 8 偏移与 md 玻璃壳、agent 摘要卡同款）。
2. **弹窗内卡豁免半透**：维持 cardPanelColored 通路（调用方给比弹窗底可辨的底色），描边阴影仍走全站统一；理由=弹窗底为不透明白/近白，半透白卡叠加后边界不可辨，可读性优先。
3. 语义染色卡（todo 优先级染色、schedule 逾期红染 10%、memory kindColor 磁贴）= 玻璃基底的 mix 语义色变体，允许保留，混合基色必须取 glassFill 而非裸 surface（schedule :236 已是正确写法，todo :65 待核基色）。
4. 状态胶囊底（surface ⊕ 语义色 12–14%）维持 #195 §4.3，不属卡面材质。

### 5.3 主窗材质三档可读性自查表（关闭/半透/磨砂都成立）

玻璃 α≥0.94 时混底结果与不透明面差 <2%，文字对比度由文字 token 保证：

| 文字档 | 亮色（on ~#FBFCFB 玻璃面） | 暗色（on ~#222120 玻璃面） | 判定 |
|---|---|---|---|
| textPrimary #1F2937 / #FAF9F5 | ≈14.8:1 | ≈13.5:1 | ✓ |
| textSecondary #4B5563 / #C9C5BD | ≈7.6:1 | ≈9.8:1 | ✓ |
| textTertiary #6B7280 / #9A948A | ≈4.6:1 | ≈4.9:1 | ✓（贴线） |
| textDisabled #6B7280 / #908A82 | 4.8:1 / ≈4.1:1 | — | 暗档仅用于禁用态，可接受 |

**规则（入规范）**：α<0.85 的容器面板（glassPanelFill 档）上禁放 12px 以下 textTertiary 明细小字——明细小字必须落在 L2 卡内（α≥0.94）或升 textSecondary；三档窗材质下玻璃卡近不透明，无追加约束；磨砂档底噪不影响 α≥0.94 面内文字。
