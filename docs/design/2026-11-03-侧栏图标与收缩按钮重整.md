## 0. 页面级构图（构图门禁三问）

侧边栏是常驻左栏，**垂直五个锚定区块**，外壳不滚：

```
┌─侧栏 220 / 72──────────────┐
│ topPad（32/16/12，随高变）   │ ← 区块A 品牌锚点区
│ ┌────────────────────┐     │
│ │  终端窗 logo 44×44   │ 常量 │ ← 两态同尺寸（bug165）
│ └────────────────────┘     │   行高 56 恒定
│ brandNavGap（28/16/12）     │
│ ───────────────────────    │ ← 区块B 导航列表（内让位，不滚）
│ ▸ 行 40（极紧 36）×N        │   越让位线整行不画（守卫保持）
│ ▸ …                        │
│ ······（让位线，随 H 浮动）· │ ← kNavFoldLimit = H−56−gap
│ ┌──┐                       │
│ │◯ │ ← 区块C 圆形收缩按钮     │ ← 预留区 56 恒定（守卫锚）
│ └──┘   直径 40，区内垂直居中  │
└────────────────────────────┘
```

- **①滚动模型**：侧栏不滚、外壳不滚——高度不足时靠「让位线守卫」藏行（宁可矮窗下藏行不压按钮，b9b99f02 既有口径），本次**不改变**该模型；压缩分档只是推迟触线。
- **②无效空白**：品牌区上下留白（56 行内 6px、topPad/brandNavGap）服务「品牌锚点」分组语义，非空列；矮窗下由分档压缩消除稀疏感，宽窗下留白恢复呼吸感。
- **③密度与权重**：导航列表是高频区、权重最高（40px 触达行高不动，仅极紧档 36）；品牌 logo 44px 是锚点但不抢眼（对 16px 导航图标 2.75:1，低于旧展开态 3:1 跳变）；底部按钮是低频辅助区（40px 圆、常态低对比描边）。最小窗（1200×720 → 侧栏可用高 680）与宽窗（1080P 最大化 → 可用高 ≥1000）两档下三区块比例均成立（见 §3 分档表）。

## 2. 方案

### 2.1 品牌图标两态统一（bug165）

- **单值常量 `kLogoSize = 44`**，两态同值，删除 `collapsed ? 32 : 40` 分档。
- 44px 在折叠 72 栏内：左右各留 14px（占 61%）；在展开 220 栏内：居中，对导航图标 2.75:1。
- 对比旧值：展开 40→44（+10%）、折叠 32→44（+37.5%），两态「都更大且一致」。
- `kBrandH = 56` 不变：44 瓦上下各留 6px；**导航起点连锁不动**（正常档仍 32+56+28=116），`test_app_sidebar` 现有 brand/导航 y 断言在正常档不受影响。

### 2.2 高度自适应间距分档（need171）

判定基准 = **侧栏可用高 H**（`drawSidebar` 收到的 `screen.height`：窗高 − 标题条 40，macOS 系统标题栏 30 同口径）。**离散三档**，档位切换无过渡动画（构图档位切换，非数值过渡）：

| 档位 | 触发条件 | topPad | brandNavGap | 行距 gap | 行高 itemH | 导航起点 | 全 12 行所需 H |
|---|---|---|---|---|---|---|---|
| 正常档 | H ≥ 712 | 32 | 28 | 4 | 40 | 116 | 709 ✓ |
| 紧凑档 | 680 ≤ H < 712 | 16 | 16 | 4 | 40 | 88 | 681 ✓ |
| 极紧档 | H < 680 | 12 | 12 | 2 | 36 | 80 | 601（<601 起守卫藏行，既有口径） |

- 压缩顺序：**先压品牌区上下留白 → 再压行距 → 最后压行高**（品牌瓦 44 与品牌行 56 恒不缩——锚点不塌）。
- 默认注册 12 行（9 平铺 + release 分组父项 + Settings + About，分组收起态）+ 组间分割线 ≈ 12×44+5=533px。
- 最小窗 1200×720 → H=680 落紧凑档：**全部 12 行可见、不破版**（现状正常档在同高藏 1 行——need171 的直接收益）。
- 分组展开 +4 行（release 两子页等）时守卫照常兜底，行为不变。

### 2.3 收缩按钮重整（need172）

几何：直径 40 圆形（`kToggleSize` 36→40），位于 56 高预留区**垂直居中**（`toggleY = H−48`，上下各 8px）；水平：折叠态 `(72−40)/2=16`、展开态 `padX=16`——两态均 16，与导航左缘对齐。图标不变：`fa-angles-left`(0xF100)/`fa-bars`(0xF0C9)，字号 `fontSizeBody`(14) 档。

| 状态 | 底填充 | 描边 | 图标色 | 形变 |
|---|---|---|---|---|
| 常态 | 透明 | 1px `borderDefault`（圆框常显） | `textSecondary` | scale 1.0 |
| hover | `primarySoftBg` | 1px `primaryHover` | `primary` | scale 1.04（≤1.045 基线） |
| pressed | `primarySoftBg` | 1px `primary` | `primary` | scale 0.96（果冻先例档内） |
| 移出 | 回常态 | 回 `borderDefault` | `textSecondary` | 回弹 180ms `Ease::OutBack`（jelly 同款） |

弥散绿粒子（**hover 进入沿触发一次**）：

| 参数 | 值 |
|---|---|
| 粒子数 | 8 颗（确定性索引分布：角度 = i×45° + hash 抖动 ±12°，帧间/会话稳定不闪） |
| 起点半径 | 圆环外缘 r=20，向径向外弥散 |
| 弥散距离 | 10~16px（hash 决定，不做整齐圆圈） |
| 粒径 | 2~4px 正圆（`.radius` = 半宽，fluid 卫星同款手法） |
| 颜色 | 三档轮替：浅色档 `#07C160` / `#34D399` / `#A7F3D0`（fluid 背景 `kLightHalo` 同款三色口径）；深色档 `primary` / `primaryHover` 双色轮替 |
| 生命 | 480ms，缓出（先快后慢），透明度 0.55 → 0 |
| 移出 | 已发射粒子自然走完不补发；空闲零绘制零泵 |

**性能口径：hover 驱动一次性迸发（8 个矩形元素、480ms 自止），非持续动画、无常驻帧泵；不 hover 时零粒子元素零成本**——果冻效果老板拍板先例（hover 驱动才上）同口径。

### 2.4 让位线守卫保持声明（约束）

`kToggleZoneH = 56`、`kNavFoldLimit = H − 56 − gap`、越线整行不画——三者**数值与逻辑均不动**；新按钮直径 40 仍在 56 预留区内（8+40+8），多级菜单展开时导航行避让底部按钮的守卫行为不变，`test_app_sidebar` 相关断言不破。

## 4. 交互流程

```
hover 进入按钮 ─→ 底/描边/图标变色（150ms Out）+ scale 1.04
              └→ 粒子迸发 8 颗（480ms 缓出淡去，一次）
按下 ─→ scale 0.96（100ms Out）
松开 ─→ 侧栏宽度切换 220↔72 + 图标 0xF100↔0xF0C9 + scale 回弹 1.0（180ms OutBack）
hover 移出 ─→ 回常态（150ms Out），粒子不补发
窗口高度变化 ─→ 重算档位（离散切换）+ 让位线浮动
```

## 8. 禁止项自查

- 无 emoji 图标（FA 字形 + 矢量 logo）；demo 图标用内联 SVG/字形占位。
- 无裸 hex 进实现口径——实现一律走 `t.colors.*` token；文中 hex 仅标注 token 现值便于对照。
- 无框架/库名绑定实现（demo 为 HTML 原型载体，属唯一例外）；粒子可行性已对照 EUI-NEO 能力事实（`.transition/.animate(Opacity|Transform)`、`AnimatedValue` 时长缓动+delay、fluid 卫星矩形正圆先例）。
- 绿=操作+高亮、无红/蓝越界；无大面积渐变、无装饰色块（粒子仅 hover 一次性、低透明度 ≤0.55）。
- 让位线守卫、折叠持久化、自动展开闩等既有行为零破坏。

## 9. 验收清单

1. 展开/折叠两态下品牌 logo 均为 44px（同一常量，无分档分支）。
2. 窗高 720 时（H=680）侧栏 12 行导航全部可见，品牌区留白为紧凑档（16/16）。
3. 窗高降到 660 → 极紧档（起点 80、行距 2、行高 36）；降到 <601 → 底部行隐藏但按钮恒可见、无行压按钮。
4. 按钮常态有 1px 圆框描边；hover 变绿底绿框 + 放大 1.04 + 8 颗绿粒子弥散一次；按下 0.96 回弹。
5. hover 停在按钮上粒子只迸发一次不循环；移出再进重新触发。
6. 多级菜单全展开 + 矮窗：行不盖按钮（守卫保持），回归通过。
7. 粒子不产生常驻帧泵；非 hover 帧无粒子元素。
