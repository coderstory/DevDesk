### 1.2 总设计原则（老板 321 原话落地）

> 「突出当前节点的内容，但也能查看别的节点」——禁止全节点平铺等权展示。

**焦点式双栏构图**：左侧节点索引列（一级概览：环境分组 + 服务精简条目，可随时切换焦点），右侧焦点区（二级明细：当前服务的步骤/配置全量，唯一放大展示区）。一次只强调一个节点；其余节点以精简条目形式常驻索引列，点击即切换焦点。

节点粒度裁决：节点=**服务**（步骤的载体）。环境是分组头不是节点；步骤是节点内部行。理由：老板 318「流水线展示太长」的痛点主体是步骤行逐行竖排；按服务聚焦后，焦点区一次只显示 3-6 行步骤，天然收敛。

### 1.3 构图三问

| 问 | 答 |
|---|---|
| ① 滚动模型对吗 | 外壳（页头 56 + 警示带 40 条件 + 前置带 44 折叠）固定不滚；左索引列独立内滚；右焦点区内滚。与全站「外壳不滚、内容区各自内滚」一致。 |
| ② 有无大段无效空白 | 无。左索引条目=56px 双行精简条（名称+mini 进度），间隙 6；焦点区步骤行 44px 满铺、配置行 40px 满铺；两栏间 gap 16 是显式常量非弹性吸管；焦点区宽度 = 总宽 − 264 − 16 − 页边距，内容按锚点链排布无空列。 |
| ③ 密度与权重 | 高频信息=焦点区当前服务步骤（字最大 18/600 头 + 15px 行），权重最高；佐证信息（环境/进度/单号）在索引条目与头部小一档。最小窗 1200×720：索引 264 + gap 16 + 焦点区 ≥ 872，步骤行结构不破；宽窗下焦点区内容列 max 1120 居中，不无限拉长。 |

## 3. 区块规格：节点索引列（一级概览）

### 3.1 索引条目（56px 双行精简条）

```
（主行 24px）  ▎ 服务名···························· 3/4
（副行 20px）  ▎ 环境名 · mini进度条32×4
```

| 参数 | 值 |
|---|---|
| 条目高 | 56px（=上下内边距 8×2 + 主行 24 + 副行 20，节奏同 #195 行卡推导式） |
| 主行 | 服务名 fontSizeBody+2=15px / 600 / textPrimary，弹性区唯一占用者；行尾 n/m 计数 12px textSecondary 右锚 |
| 副行 | 环境名 12px textTertiary + mini 进度条 32×4（右锚小部件档，R6 合规） |
| 选中态 | 浅染底 primarySoftBg + 左 2px primary 竖条（基线选中态规范，禁粗边框） |
| hover | 底 hover 色，120ms OutCubic |
| 全部完成条目 | 尾部 12px success「已完成」替代计数 |
| Voided 条目 | 整条 opacity 0.7 |
| 分组头 | 环境名 13px/600 textSecondary + 完成度，高 32px，不可点 |

### 3.2 交互

点条目 → 焦点区切换至该服务（焦点区内滚回顶）；索引列滚动位置保持。切换动效：焦点区 120ms OutCubic 淡入。

### 4.3 双层警示模型（诉求③红字重排）

| 层 | 位置 | 形态 | 内容 |
|---|---|---|---|
| 页级警示带 | 页头下方，横贯全宽，高 40px | error 10% 浅染底横带 + 13px errorText 文字 + 右端「去处理」文字钮 | 同一时刻只显示**最高优先级一条**（校验不通过 > 时间窗未开 > 写库失败）；多条轮换或计数「还有 N 条」 |
| 字段级 | 所属对象头部右侧 | 13px/600 errorText 状态胶囊（invalid/超时态）或 label 红字（仅前置带行内，禁用在 hint 档） | 就近标红，不再扩散到正文行 |

- 红字一律不进正文行内（现状 :337/:434/:732 标签变红模式废止）；标签红字仅保留前置带内「必填未填」一景。
- error 语义纪律：红=仅告警/危险/删除（基线四色），进行中/待执行一律黄/蓝/灰，不挪用红。

### 4.4 步骤行与配置行重排（诉求⑩，按 #195 锚点链五规）

**步骤行（44px，单行锚点链）**：

```
│ ●  合并分支 ································ [查询] [跳过□] [完成□] │
│ 12px状态点  15px L2 弹性区唯一          右锚组：文字钮+勾选框×2     │
```

| 锚 | 元素 | 规格 |
|---|---|---|
| A1 | 状态点 | 12px 圆点：未做=空心 borderDefault；进行=warning 实心；完成=success 实心；跳过=灰底横线（复用 release_checkbox glyph 形状，draw.cpp:133 同源） |
| A2 | 步骤名 | 距状态点 12px，15px L2；invalid 时名字后缀 13px/600 errorText「异常」小胶囊（不是整名变红） |
| A3 | 弹性区 | 唯一，占用者=步骤名（长名省略号截断）；无内容时被右锚组自然压回 |
| R | 右锚组 | 依视觉权重排布：[查询]（文字钮 13px primaryText，仅 Deploy/Verify）→ [跳过] 勾选框（32px 框+字）→ [完成] 勾选框（32px 框+字）→ 行尾 x=宽−20 |

### 4.5 复选框常显语义（诉求⑤ + note 316 澄清）

**§4.5.1 现有复选框语义实测**（release_checkbox.h 头注释 + draw.cpp 用点）：

| 用点 | 语义 | 现状 |
|---|---|---|
| 步骤行行尾「完成」勾 | 步骤完成确认 | 常显，可点 |
| 前置带行尾「完成」勾 | 前置项完成确认 | 常显；单据号未填时禁用+hint「请先填写单据号」（老板所见「不能勾选」即此场景） |
| 新建弹窗环境列表勾 | 环境多选（包含语义） | 常显，可点 |

结论：**无「启用开关」语义，也无批量选择**。裁决：
1. 完成勾选与多选语义保留不动；
2. 「需要点击展开的操作」（「···」菜单内的**跳过**）提为行内常显复选框——「不启用某步骤/配置」由「跳过」反向表达，不新引入「启用开关」（避免同一行出现两个对立开关）；
3. 「···」菜单裁撤后仅保留破坏性项（移除服务），配置行「···」整体取消（上移/下移→拖拽，跳过→常显勾，查看→行内钮）。

### 4.6 公告字段摘要行（note 317）

```
│ 上线公告 │ 本次发布包含 XX 系统灰度切流与网关配置变更，共 486 字… │ [查看/编辑] │
│ 定宽96   │ 15px 摘要单行省略，弹性区                              │ 文字钮      │
```

## 5. 拖拽排序交互规格（诉求④，完整）

**现状骨架**：ReleaseDetailDragState（release_detail_ui.h:63-77，锚点+目标插位+deltaY，松手才写库）、drawDragHandle（draw.cpp:96-120，⋮⋮ 手柄）。本规格在其上补全交互闭环并裁撤上移/下移。

### 5.1 能力边界（EUI 实测）

| 能力 | 现状 | 影响 |
|---|---|---|
| 元素级拖拽回调 | `mouseArea.dragThreshold(8.0)` / `suppressClickAfterDrag(true)` / `onDragStart/onDrag/onDragEnd`（totalX,totalY）；底层 `rect.interactive().onDrag(DragEvent)` | 拖拽判定与位移换算可直接实现，W8 Todo 已落地同型先例（dragDropTarget 纯函数换算落点） |
| 框架级 DnD / drop target API | **无**（EUI-NEO-CAPABILITIES.md:627「拖拽跨列 ❌ 不支持，元素级回调自实现」） | 落点判定/占位线/自动滚屏全部模块内自实现 |
| 滚动容器拖拽边缘自动滚屏 | 无现成 API | P2 增强：拖至容器上下缘 32px 内按帧递增 scrollOffset；首版可不做（列表短，一屏可容） |

### 5.2 交互全流程

| 阶段 | 规格 |
|---|---|
| 触发 | 仅把柄（⋮⋮ 24×32）承担拖拽：按下位移 >8px（dragThreshold）进入拖动态；行体点击不触发拖拽（suppressClickAfterDrag 防误触） |
| 可拖条件 | Draft/Pending 态；Running/Done/Voided 把柄隐藏（现状契约：执行中锁定，ui.h:19） |
| 把柄反馈 | hover 浅染（textPrimary 6% alpha，现有）；拖动态光标 grabbing |
| 被拖行 | opacity 0.45 + 轻微 scale 1.02 + shadow 加深一档，跟随指针 Y（仅垂直，X 锁列） |
| 原位 | 半透明灰色行骨架（同尺寸）+ 插入位 2px primary 圆角占位线（宽=行宽−40） |
| 落点判定 | dragDropTarget 纯函数：指针 Y 对可视序列逐行求中线，穿越中线即换算插位 targetIndex（0..n，去源后）；与现有 DragState.sourceIndex/targetIndex 契约一致 |
| 松手落库 | targetIndex 有效且 ≠ 原位 → 写库（配置：upsertTaskConfig.order；服务：记 TaskLog scope=环境名 step=reorder，ui.h:15-17 契约不变）→ 120ms 行归位动画；无效 → 回弹原位 160ms OutCubic |
| 取消路径 | Esc 键 / 松手在索引列或容器外 / targetIndex=无效 → 全部回原位不写库 |
| 反馈提示 | 落库成功 toast「顺序已更新」1.5s；失败 notice 红字（写失败经 Result 回显，ui.h:20 契约） |
| 上移/下移按钮 | **移除**（「···」菜单不再含上移/下移；菜单仅剩移除类破坏项） |

### 5.3 边界

- 拖拽进行中禁用其它输入焦点（防光标闪烁竞争）；
- 配置行拖拽与服务行拖拽互不跨容器（DragKind 已分 ServiceOrder/ConfigOrder，ui.h:64）；
- 长列表拖至视口边缘自动滚屏=P2 增强（§5.1）。

## 6. 强确认门规格（note 319，每步完成必过）

### 6.1 触发链

点步骤行 [完成] 勾选框 → **先弹确认门，确认后才落态**（二次确认前不写库，ui.h:20 契约）；前置带完成勾同链路。取消/不匹配 → 勾选框回弹不生效。

### 6.2 弹窗结构（按 #156 三段式，420 Compact 档，最小尺寸档）

```
┌──────────────────────────────────────┐
│ 执行确认 · 合并分支                    │ 20/700，上缘16，左24
│ ──────────────────── 分隔线 1px       │ y=52
│                                      │
│ 即将标记完成：                        │ 14px textPrimary
│   生产环境 / order-service / 合并分支  │ 14px/600
│ 完成后系统将：继续后续步骤判定与提醒    │ 14px textSecondary
│ ⚠ 完成后需撤回才能修改，撤回记入任务日志 │ 13px errorText
│                                      │
│ 输入「确认」以继续                     │ 12px textSecondary
│ [确认____________________]           │ 36px 输入框
│ 请输入「确认」二字                     │ 12px errorText（仅输错时）
│                                      │
│ ──────────────────── 细线 1px        │
│                 [取消(次)] [确认执行(主)]│ 右锚 gap 8
└──────────────────────────────────────┘
```

### 6.3 文案模板（三要素，note 319 要求）

| 要素 | 模板 | 样式 |
|---|---|---|
| 当前步骤 | 「即将标记完成：{环境} / {服务} / {步骤名}」 | 14px/600 textPrimary |
| 将执行什么 | 「完成后系统将：{后续影响}」——Deploy=「判定后续步骤与触发完成提醒」；Verify=「计入任务完成度」；MergeBranch=「计入任务完成度」；前置项=「计入前置完成度并解锁提交校验」 | 14px textSecondary |
| 风险提示 | 「完成后需撤回才能修改，撤回将记入任务日志」 | 13px errorText，前置 ⚠ |

### 6.4 输入校验与按钮状态

| 态 | 条件 | 表现 |
|---|---|---|
| 未输入 | value=空 | 主按钮**禁用**（primarySoftBg+textDisabled 档）；提示字「输入「确认」以继续」 |
| 匹配中 | value≠「确认」且非空 | 主按钮仍禁用；输入框下 12px errorText「请输入「确认」二字」 |
| 匹配 | trim(value)==「确认」（逐字匹配，全半角敏感） | 主按钮激活（primary 档）；错误字消失 |
| 确认 | 点主按钮 / 输入框内回车 | 关窗 → 勾选落态+写库 → toast「已完成」1.5s |
| 取消 | 副按钮 / Esc / 点遮罩（#156 取消路径） | 关窗，勾选框回弹，无副作用 |

- 输入框 autofocus；36px 高、focus 绿边（基线输入框规范）。
- 同视口唯一主按钮原则：确认门打开期间焦点区无其它绿填充钮可达（遮罩阻断）✓。
