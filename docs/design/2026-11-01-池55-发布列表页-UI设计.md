## 一、设计立场：四条病灶，四条决策

| 病灶（池 53 同款：硬堆、不现代、不合理） | 对症决策 |
|---|---|
| 瀑布流多列卡片，同质内容被拆进参差列基线（列数随窗宽 1→4 跳变） | **瀑布流 → 单列行卡列表**：发布任务是「以发布日为轴的同质有限集合」（周二/周四节奏），非异质海量内容；单列白卡 + 细分割线即微信 PC 列表语言，节奏与详情页 44px 行体系同源（§四） |

- **结构不变式**：外壳（页头 + Tab 行 + 内容区）固定不滚，内容区内滚动，无分页器（沿用现状触底追加，列表底部加载/失败提示见 §九）。
- 内容列 max-width **1040px** 居中（与池 53 §5.1 同值）；两侧 12px 页面外边距。
- 整行点击 → 打开任务详情（对应详情页双模式；行本身无行内按钮，导航唯一出口，低干扰）。

| 元素 | 规格 |
|---|---|
| 页头 | 白底 56px，下缘无独立线（与 Tab 行连体白壳，分割线画在 Tab 行下）；左内边距 12px |
| 标题 | 「上线任务」17px/700 #1A1A1A（身份词与详情页标题「上线任务 M/D」同源；不放状态/计数，状态已由 chip 专属表达，计数归 Tab 行） |
| 新建任务 | 主按钮：绿填充 #36D399 白字，高 36px、圆角 6px、字 14px，右缘 12px；**同视口唯一绿填充**（空态就近操作降级为次按钮，§九）；hover #2EC48F / 按下 #23B07F + 果冻按压 |

| Tab 文案 | 「全部」「发布中」「准备中」「已归档」——后三档即池 53 模式徽标词，映射：发布中 = Pending+Running，准备中 = Draft，已归档 = Done+Voided；**不显示计数徽章**（低干扰） |

**不设排序器**：现状 SQL 排序 plan_date DESC, id DESC（release_store.cpp:641-647）已等价「发布日在前的靠上」= 用户默认心智；排序控件属低频需求，不加（操作高效：不为低频功能加视觉权重）。**不设日期分组头**：同日任务通常 1–3 条且日期已在每行主行首列，分组头是重复信息。

### 5.2 五状态 × 列表行矩阵

| 状态 | 主行弹性区 | 副行进度 | 特殊视觉 |
|---|---|---|---|
| Draft（草稿） | 留白（提交门禁在详情页，列表不重复表达） | 不显示（对齐池 53 §十三「Draft 页头不显示进度」） | 无 |
| Pending（待执行） | 「下一步 · {步名}」 | 显示实时 n/n | 无 |
| Running（执行中） | 「下一步 · {步名}」 | 显示实时 n/n | **左缘 3px #36D399 全高竖条**（扫视锚点；与池 53 当前步左竖条同语言——「这里是活的」；同视口允许多行，因每行是独立任务） |
| Done（已完成） | 留白 | 显示满 n/n（对齐池 53 §十三 Done 进度满） | 无 |
| Voided（已作废） | 留白 | 显示冻结 n/n（对齐池 53 §十三 Voided 进度冻结） | 整行内容 opacity 0.7（背景保持白，语义沿用现状 release_list_ui.cpp:173 的 0.68 → 统一 0.7 对齐池 53） |

- **列表不引入模式徽标**：模式词（准备中/发布中/已归档）已由 Tab 承载，行内再加徽标 = 与状态 chip 重复表达（信息优先：一处信息一处载体）。
- **主行绿点不加**：Running 行已有左竖条做扫视锚，指引文字不再加绿点（同视口绿色元素克制）。

### 5.3 与 44px 体系的协调声明

- 详情页 44px = 表单/轨道**内容行**；列表 64px = **导航行**（双行承载，微信 PC 列表同款密度，如聊天列表项）。
- 换算对齐 8px 网格：64 = 24（主行）+ 20（副行）+ 20（内边距）。列表行内不再嵌 44px 行；两档并存、各司其职，不混用。
- 分割线：行间 1px #EDEDED（二级线），首行上方与末行下方无线（由外层卡边承担）；hover 行底 #EDEDED 覆盖分割线区域。

### 5.4 数据可用性声明（给 developer 的边界）

- 「下一步 · {步名}」需要装配层为 ReleaseTaskCard 新增字段（如 nextStepLabel；Pending/Running 取首个未完成且已解锁步骤名，与详情页页头主动作文案同源；Draft/Done/Voided 为空）。**字段缺失时主行弹性区留白，不破版**——本设计定义的是展示契约，字段供给归实现。
- 其余字段（planDate/status/envNames/progressDone/progressTotal）现状数据模型已具备（release_list_ui.h:110-118），无需数据层改动。

### 5.5 行交互
