# 窗口效果三档验收（半透 / 磨砂）+ 历史问题验证覆盖核对（2026-11-01）

## 一、为什么补这件事

用户指出：**「之前你说只测了半透和磨砂都关闭的场景，没测完」**。

核对属实：`evidence/` 下所有历史截图目录里，**没有一张半透档或磨砂档**——
全部是窗口效果「关闭（默认）」档。设置页把窗口效果做成三档分段控件
（`关闭（默认）` / `半透` / `磨砂（Mica）`），后两档从未被任何离屏证据覆盖过。

## 二、离屏为什么拍不出来（不是没配，是机制限制）

离屏探针 `uat62_page_shots_probe` 走 `probe::FrameCapture::readFrame` → **GL 帧缓冲读回**。
半透 / 磨砂的实现在 **AppKit 层**（`EUI-NEO/core/platform/window_effect_macos.mm`）：
`NSWindow` 背景置 `clearColor` + 挂 `NSVisualEffectView` 材质视图。**材质视图根本不在 GL 帧缓冲里**，
帧缓冲读回只能拿到 clearColor 的混合色，拿不到系统合成结果。

离屏三档的实测像素（首页同一采样点）：

| 档位 | clearColor alpha | 采样像素 | 结论 |
|---|---|---|---|
| off | 1.00 | `(235,246,239)` | 不透明基线 |
| translucent | 0.85 | `(238,247,241)` | alpha 生效，观感几乎无差 |
| frosted | 0.15 | `(244,249,246)` | alpha 生效，底更透 |

即：离屏能验「切档后 UI 不崩 / 不错位 / alpha 数值生效」，**验不了「透出真实壁纸 + 材质模糊」的观感**。

> `screencapture` 路线此前被判为不可用（需屏幕录制 TCC 授权，agent 会话拿不到）。
> 2026-11-01 用户已解锁授权 → 改走**真机 + 系统截图**。

## 三、真机验收结果（Release 0.5.0，macOS）

方法：改 `~/Library/Application Support/DevDesk/config.json` 的 `windowEffect` /
`themeMode` → 重启 DevDesk → `screencapture -x -o` 抓全屏（真实桌面合成）。
证据：`evidence/2026-11-01-window-effect-tiers/`。

### 半透档（`translucent`）✅ 生效

- 窗口主体透出桌面壁纸（紫色调大面积透入）✓
- **标题栏同步透出壁纸** —— macOS `extendContentIntoTitleBar` 与窗口效果叠加正常 ✓
- 侧栏铺色按档带 alpha（`core::window_effect_state::surfaceAlpha`），未把壁纸挡死 ✓
- 页面内动态背景光晕与壁纸叠加正常，无脏边 ✓

### 磨砂档（`frosted`）⚠️ 名不副实

- 标题栏区域能透出壁纸 ✓（材质视图挂在标题栏）
- **但内容区几乎看不到材质模糊** —— DevDesk 页面自绘动态背景层 + 页面底色几乎铺满全窗，
  材质视图只在标题栏/边缘露出。
- 对比半透档，磨砂档内容区反而**更不透明**（clearColor alpha 0.15 → 底下透出的是
  DevDesk 自己的浅色动态背景，而不是模糊后的桌面）。

**结论**：macOS 上「磨砂」档当前实质 = 「比半透更不透明的内容区 + 透出壁纸的标题栏」。
若产品期待的是「内容区也透出模糊桌面」，需要让页面动态背景层在磨砂档降透明度
（当前动态背景是应用自绘的实色光晕，天然遮住材质）。**登记为待办，不在本轮改。**

### 顺带发现的两个真机缺陷（离屏看不到）

| # | 现象 | 判断 |

| 2 | 首页「切换 Claude Profile」按钮的图标渲染成**绿色方块** | 图标码点在该字体里缺字形（离屏与真机一致 → 是真 bug，不是截图链路问题） |

## 四、探针补的档位参数

- `uat62_page_shots_probe --window-effect off|translucent|frosted`
  （必须在 `router.startAll()` 之后设置：settings onStart 会按配置恢复档位并覆盖探针值）
- `schedule_ui_probe --window-effect ...`（同坑同解）

用途：档位切换后的**布局/崩不崩**回归；**观感**一律以真机系统截图为准。
