## 2. 页面级构图

### 2.1 滚动模型
设置页外壳不滚：左侧导航固定（208 逻辑 px，全站侧栏同宽），主内容区 `padding 40`，长内容在主内容区内滚。「网页终端」tab 为单卡全宽，卡高随状态派生（layout() 单一来源），卡本身不内滚。与全站设置页其它 tab 一致。

### 2.2 区块划分与锚定
```
┌ 侧栏 208 ┐┌──────────── 主内容区 padding 40 ─────────────┐
│  设置导航 ││  ┌──────────────── 卡片（白底，自适应宽）────┐ │
│          ││  │ 网页终端 19/600                            │ │
│          ││  │ 副提示 12 tertiary                         │ │
│          ││  │ ── 服务 ──                                  │ │
│          ││  │ 启用网页终端            [开关] ←右缘锚定    │ │
│          ││  │ 端口            [96输入][应用64] ←右缘锚定  │ │
│          ││  │ ┌ 验证器绑定（左列）┐┌ 自诊信息（右列）──┐ │ │
│          ││  │ │ [QR 160]│倒计时  ││ 监听地址 │ 值      │ │ │
│          ││  │ │         │[刷新]  ││ 在线设备 │ 值      │ │ │
│          ││  │ │         │说明    ││ 最近登录 │ 值      │ │ │
│          ││  │ │（或绑定信息+删除）││ （防火墙提示行）   │ │ │
│          ││  │ └──────────────────┘└───────────────────┘ │ │
│          ││  └─────────────────────────────────────────────┘ │
└──────────┘└──────────────────────────────────────────────────┘
```
锚定关系三铁律（全卡统一，F4 核心）：
- **标签列**：x = 卡左内边距 28，宽 **110px**（与 `ui_kit/form_row.h` 定宽同源，spec §4.15 区间取中值），左对齐，垂直居中于行。
- **值/控件列起点**：x = 28 + 110 + 8 = **146**。
- **右缘**：x = 卡宽 − 28。所有右置控件（开关 / 应用按钮）右缘一律锚定此处，形成全卡唯一右轨；**并排带内**（见下）右置控件锚定各自列右缘。

并排带（2026-11-24 用户验收返工定稿）：「验证器绑定」与「自诊信息」两分组左右并排——左列验证器绑定（QR/绑定信息），右列自诊信息；两列分组标题同基线顶对齐。

### 2.3 空间节奏与密度预算
垂直节奏三档行高 + 两档间距，全卡无第四种值：表单/开关行 44 / 信息行 32 / 分组标题行 28；行间 8 / 分组间 24。删除 F2/F3 后卡高显著缩短（已绑定态约减 160px+），信息密度反而提升——高频操作（开关、端口）全部落在 44px 行与右轨上，权重最高；验证器绑定与自诊信息并排后纵向再省一组间距，辅助信息（自诊 13px 两列式）与操作区（QR/删除绑定）左右分区权重清晰。两档窗口核过：1000×640 最小窗卡宽 ≈ 712（1000−208−80），146 起点值列仍有 ≥560px，并排带 innerW ≈656 ≥560 保持并排（左列收缩至 QR+说明列，右列 ≈270+）；1600×1000 卡宽 ≈ 1312，并排两列均富余，无大段空白、无定宽空列。

## 4. 交互流程（逐元素四项）

| 元素 | 触发 | 状态反馈 | 迁移 | 边界 |
|---|---|---|---|---|
| 启用开关 | 点击开关行 | 轨色 150ms 缓出过渡；启动中 label 变「正在开启…」 | 开→服务启动流程；关→服务停止 | 启动失败自动回弹关位 + 错误行透出人话原因；启动中禁再点（webStarting 锁） |
| 端口输入框 | 点击聚焦 | focus 绿边 1px | 改草稿 | 仅服务停止时可编辑；Enter=应用 / Esc=弃稿；运行中该行转只读值+「服务运行时不可修改」 |
| 应用按钮 | 点击/Enter | 主绿按下 #23B07F + 果冻 0.96 回弹 | 写配置 | 非法值（<1024 或 >65535 / 非数字）不迁移，反馈红字就近显示；连点幂等 |
| 刷新按钮 | 点击 | 次级按钮 hover #EDEDED / 按下果冻 | 重取二维码+倒计时 | 倒计时>0 时为次级样式（低权重），过期转主绿（提示必须操作）；连点防抖 |
| 删除绑定 | 点击 | 危险红 hover 加深 + 按下果冻 | 展开/收起行内确认行 | 不直接删除；确认行展开时再点删除绑定=收起确认 |
| 确认删除 | 点击 | 主绿按下果冻 | 删绑定，所有网页登录立即失效；卡切回未绑定态（出 QR） | 行内确认，无弹窗（EUI-NEO 弹窗留给更重场景） |
| 取消 | 点击 | 次级反馈 | 收起确认行 | — |

## 8. 禁止项自查

- 无旧橙 #D97757 及任何橙色档。✔
- 绿=操作+高亮、红=仅告警、蓝=未用（无链接场景）、灰=中性。语义无越界。✔
- 无渐变、无装饰色块、无大面积深底。✔
- 全部参数取自 theme.h / ui_kit 现行口径（110 标签列=form_row 同源、圆角 10/14、8px 网格、正文 15px）。✔
- 无「大气美观」类描述；无框架/库名（demo 载体除外）。✔
- EUI-NEO 能力核对：switch/button/input/text/rect 全在支持清单；未用 Collapse/skeleton/Toast 队列。行内确认不依赖弹窗。✔
- 果冻按压为一处大胆点，无多余装饰。✔
