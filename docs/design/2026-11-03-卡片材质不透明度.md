## 2. 参数方案（核心交付）

### 2.1 填充两层 alpha（必改）

| Token | 主题 | 现状 | **建议值** | 依据 |
|---|---|---|---|---|
| `glassFill`（L2 功能卡） | Light | 0.72 | **0.94** | 落老板区间 0.90~1.0 上段；留 6% 透保住玻璃呼吸感，不拍纯不透明 |
| `glassFill`（L2 功能卡） | Dark | 0.92 | **0.95** | 已接近实体，微调对齐 Light 档 |
| `glassPanelFill`（L1 容器） | Light | 0.55 | **0.80** | 落 0.75~0.85 中段 |
| `glassPanelFill`（L1 容器） | Dark | 0.55 | **0.78** | 落 0.75~0.85；暗色略低于 Light 保底色可辨 |

- **层差校验**：Light 0.94−0.80=**0.14**，Dark 0.95−0.78=**0.17**，均 >0，两层深度保持（现状 Light 差 0.17 / Dark 差 0.37，收敛但仍可辨）。
- **绿染 3%：保留**，公式不动（`s.r*0.97+0.001 / s.g*0.97+0.023 / s.b*0.97+0.011`）；0.94 实底上 3% 染色感知极弱但保持品牌一致，无成本。
- 实现落点提示（developer）：只动 glass.h 四处 alpha 字面值，RGB 与公式不变；同步更新 glass.h:11 注释（原注释「浅色 0.72 让底色透出来」已过时）。

### 2.2 hover/pressed 派生 mix（结论：不动）

mix 发生在填充色合成前，有效加深 ≈ alpha × mix 比。alpha 上调后：Light hover 3.6%→**4.7%**、pressed 6.5%→**8.5%**；Dark hover 9.2%→**9.5%**、pressed 14.7%→**15.2%**。均仍在克制按压反馈区间（≤10% / 暗色 ≤16%），不会显脏。改比例只会增加 churn，**维持 materials.h 现值 0.05/0.09、0.10/0.16**。

### 2.3 高光边与冷阴影（可选，建议采纳）

fill 变实后卡与背景明度差增大，0.72 白高光边在高亮 halo 处易显奶白：

| Token | 主题 | 现状 | 建议（标注：可选） | 理由 |
|---|---|---|---|---|
| `glassBorder` | Light | 白 0.72 | **0.60** | 更实的底边缘已自带对比，降白边防「奶圈」 |
| `glassBorder` | Dark | 白 0.10 | **0.12** | 暗底更实后补 1 档边缘定义力 |
| `glassShadowColor` | Light | 0.06 | **0.09** | 卡更实、重量感上升，阴影微增维持「浮起」，仍属极淡档 |
| `glassShadowColor` | Dark | 0.34 | 不变 | 已足够 |

不采纳的回退面：若实装后观感偏硬，仅回退本节（0.72/0.10/0.06），不影响 2.1 主参数。

### 4.2 区块规格表

| 区块 | 现状 | 建议值 |
|---|---|---|
| 列底（columnId.bg） | `t.colors.background` 不透明 | **删除**（动态背景直接透到壳后） |
| 纸卡（columnId.paper） | `t.colors.surface` 不透明 + radiusLarge + 1px 边 | **删除** |
| 列壳 | 无（由①+②拼成） | **新增单层**：`glassFill`（0.94/0.95）+ radiusLarge 16px + `glassBorder` + `glassShadowColor`。用 L2 不用 L1：编辑是主工作面，需接近实体保打字可读性 |
| 编辑框 input | 组件默认不透明底 | 填充 alpha 0（全透明依附壳上）+ 1px 底边 `borderDefault` + radius 6px；focus 态=绿边（主色）+ 浅染底 `primarySoftBg` |
| tag chips | chip 底 `t.colors.hover` | 不变，直接铺壳上（浅灰底在 0.94 壳上对比充分） |
| 状态条 | `cardSurface` 0.72 半透独立卡 | 透明填充 + 顶部 1px `borderDefault` 分割线，字 `textTertiary` 12px |
| 大纲浮面板（md.outline.panel） | cardSurface + borderDefault | 不改结构，随 2.1 alpha 自动提实 |

### 4.3 交互流程（md 编辑框）

default（透明+底边线）→ focus（绿边 1px + primarySoftBg 浅染底，过渡 120ms 缓出）→ 失焦回 default（失焦提交逻辑现状保留，不动）。

## 13. F2 笔记选项卡几何归位（池130）

现状：drawNoteTabBar（md_module_tree.cpp:62-70）以整页 contentW 自 x=0 横跨树列上方（markdown_module.cpp:231），且 32px 从全局 bodyH 扣——树列也跟着变矮。

**裁决：tabBarH=32 只从编辑列扣；树列恢复满高。**

几何公式（单一来源，全部随字号缩放常量派生）：
- tabBar 左缘 x = sideW + gap（sideW=树面板动画宽 0~220，折叠时 x=gap=16）
- tabBar 宽 = 编辑列宽：双栏 midW = (contentW − sideW − 2×gap)/2；单栏 = contentW − sideW − 2×gap
- tabBar 高 32 置编辑列顶部，下距 8（与 kHeaderGap 同档）；编辑列总高 = root 列体高
- 树列高 = root 列体高（不再扣 32+8）

两档数值（100% 字号；pad=32、gap=16、kHeaderH=40、kTreePanelWidth=220）：

| 窗口 | root 列体高 | tabBar x | 双栏宽 midW | 单栏宽 | 树列高 | 编辑列构成 |
|---|---|---|---|---|---|---|
| 1000×640 | 560 | 236 | 342 | 684 | 560（满高） | 32 tab + 8 + 520 内容 |
| 1600×1000 | 920 | 236 | 642 | 1284 | 920（满高） | 32 tab + 8 + 880 内容 |
| 1000×640 树折叠 | 560 | 16 | 452 | 904 | —（折叠 0） | 32 tab + 8 + 520 内容 |

- 折叠联动：tabBar x/宽随 sideW lerp 逐帧连续（沿用树面板动画泵），无跳变。
- tab 本体样式不动（S2.2 块面 Tab：选中 primarySoftBg+描边，未选中透明）。
