## 2. 页面级构图（先构图后参数）

### 2.1 滚动模型（不变）
沿用池140 口径（`mcp_page_module.cpp:228-238`）：外壳不滚；页头五行（标题/副标题/状态行/记忆模块行/区头）固定；工具网格是唯一滚动区、容器内自滚。本设计只改卡内构图，滚动模型零改动。

### 2.2 卡面构图：单列左文本 + 单列右图标轨

构图三问：
① 滚动模型——不变（同上），与全站同类列表页一致。
② 无效空白——卡高 120→96，消除原 y=84 以下的 20px 无信息空带；文本三行占满 16..80，留白只剩 16px 呼吸边距，全部服务行分组。
③ 密度与权重——工具名是高频识别信息，权重最高（mono 600 14px 一级字色）；状态/chips 次之（11px 600 / 11px 400）；描述最低（12px 400 三级字色）。最小窗 340 宽下文本列 256px 可容纳全部信息，构图成立；宽窗 420 下同一构图不散（右轨恒 40px，文本列弹性）。

```
新版工具卡（340–420 × 96）：
┌──────────────────────────────────────────────┐
│ web_fetch            ┌────┐                  │
│ ● 可用 ▢内置 ▢服务    │图标 │  ← 图标 40×40    │
│ 抓取网页内容为 Markdown…        └────┘  ›    │
│ ↑文本列全部左对齐 x=16          ↑hover 箭头图标 │
└──────────────────────────────────────────────┘
   文本列：x=16，宽 = 卡宽−84（16+56+12）
   右轨：x=卡宽−56..卡宽−16（仅图标/操作位，零文本）
```

- 一条左缘：名称、状态行、chips、描述全部从 x=16 起（消灭 P3/P4 两基线问题）。
- 一条右轨：工具图标（40×40）+ hover 操作箭头（16×16 纯图标），右侧不出现任何文字（消灭 P1/P2）。
- 本页独特性原则句：MCP 卡是「工具清单行」不是「海报卡」——所有字靠左成列扫读，右侧只留一枚可点的图形锚点。

### 2.3 信息密度预算
卡高 96 = 上边距 16 + 标题行 22 + 隙 4 + 状态行 18 + 隙 4 + 描述行 16 + 下边距 16。网格列间距 8、行间距 8（沿用 `mcp_page_module.cpp:365` gap 8），一屏 1080P 高度约可见 5 行卡（5×96+4×8+页头 ~230+边距 64 ≈ 856 < 1080 减标题栏），密度与 schedule/todo 行卡同档。

## 8. 两遍法自审记录

- 第一轮构图备选：A) 图标左上+文本右移列（=现状，P3/P4 病根）✗；B) 文本列左 + 图标右轨（本选）✓；C) 全行单行式（名+状态同行、无描述）——描述是工具识别关键信息 ✗。
