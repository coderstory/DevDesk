## 1. 页面级构图（先整体后参数）

### 1.1 构图三问

| 问 | 答 |
|---|---|
| ① 滚动模型 | 应用侧栏（200px，应用级）固定；Git 页顶栏 48px 固定不滚；左变更列表卡独立内滚；右 diff 主区卡独立内滚（含头部 44px 粘顶）。与全站「外壳不滚、内容区各自内滚」一致。滚动条视觉全无（老板口径：滚动保留、滚动条不显示）。 |
| ② 无效空白 | 无。左卡 320px 内列表行 28px 满铺、组头 32px 分节；右卡 diff 行 22px 满铺全宽（等宽行自然长度决定视觉终点，不设内容 max 列——diff 代码行是本页唯一允许全宽横铺的内容）；空态居中块 ≤320px 不留空列。两卡间 gap 12 为显式常量。 |
| ③ 密度与权重 | 高频=右 diff 主区（占余宽 ~724@1280，字最大内容、唯一全宽区）；次高频=左列表（28px 紧凑行、13px 名）。佐证信息（路径段/计数/hunk 头）12px 降档。最小窗 1200×720：左 320+gap 12+右 644，unified 四列（24+48+48+代码 ≥524）不破；720 高减顶栏 48 减页边 24 后两卡高 648，各自内滚。 |

- 两面板=外层白卡承载卡片感（全站卡片基准）：radius 16 + 1px borderDefault + shadow(3,1,0.02,0.04 档)，行内不包盒、行底常态透明。
- 折叠态：左卡宽 0 隐藏，顶栏左端出现展开图标钮（32×32）。

### 1.3 本页独特性原则句

> 「变更列表是本页唯一导航对象，diff 是唯一内容终点——任何文件行点击 ≤1 次交互即达 diff，同一数据绝不在两处呈现。」

大胆单点=右栏 unified diff 大画布（增行绿底/删行红底全宽横铺，全页唯一大色块区）；其余全部安静档（列表无彩底、组头无徽章底、空态无插画）。

## 6. 交互规格（逐元素四项：触发/反馈/迁移/边界）

### 6.1 文件行点击（主动线）

| 项 | 规格 |
|---|---|
| 触发 | 单击文件行（树形态/平铺形态同链路）；键盘 ↑↓ 焦点移动同效 |

| 边界 | 连点同行=幂等不重载；200ms 内快速切换多行=取最后目标（前请求作废）；diff 加载中切行=骨架延续至新文件数据；选中文件被后台刷新删除=右栏回 §5.5 空态+列表去行 |

|---|---|
