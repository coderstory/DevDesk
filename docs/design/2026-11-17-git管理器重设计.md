- 两面板=外层白卡承载卡片感（全站卡片基准）：radius 16 + 1px borderDefault + shadow(3,1,0.02,0.04 档)，行内不包盒、行底常态透明。

### 1.3 本页独特性原则句

> 「变更列表是本页唯一导航对象，diff 是唯一内容终点——任何文件行点击 ≤1 次交互即达 diff，同一数据绝不在两处呈现。」

大胆单点=右栏 unified diff 大画布（增行绿底/删行红底全宽横铺，全页唯一大色块区）；其余全部安静档（列表无彩底、组头无徽章底、空态无插画、过滤输入框安静灰档）。
