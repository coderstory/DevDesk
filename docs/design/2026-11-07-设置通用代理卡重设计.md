## 4. 两遍法记录

**第一轮（构图）**：核心色板——微信绿 primary #07C160（亮档实值，theme.cpp:84）、success #10B981（:97）、warning #F59E0B（:98）、中性 textPrimary/Secondary/Tertiary #1F2937/#4B5563/#6B7280（:91-93）、底 surface #FFFFFF（:80）；字体角色——L1 标题 fontSizeLarge 19/600、L2 表单 13/14、L3 胶囊 11/600、L4 提示 12；布局概念一句话——「状态先行两带横带卡：状态胶囊挂标题旁当扫视锚点，配置双右锚收纳，警告按需染底出现」。本页独特性原则句：**「让『在不在跑、接管了没』成为卡片的第一眼答案，其余一切安静。」**

**第二轮（换向自审）**：问「给同 tab 其它设置卡出方案是否也会得到同样结果」——
- 默认向是照抄 MCP 卡「FormRow+状态行+命令行」三行 kv 式（settings_ui_cards.cpp:742-833）→ 换向：两条状态并标题带胶囊，撤独立接管行。理由：MCP 式把最高频状态压到第二行且与低频端口同权重，违反基线「高频功能视觉权重最高」。
- 默认向是警告用全站胶囊枚举五态 → 换向：条件染底横带。理由：警告是可变长正文（含路径/原因），胶囊 11px 装不下也读不了；染底带同时治 D6 的无兜底问题。
- 默认向是「应用」沿用 primary（家族惯性）→ 换向次按钮（D5）。
- AI 五 tell 检查：无暖米+衬线+陶土三件套、无暗夜霓虹、无报纸式零圆角、卡片形态由全站家族约束（非 SaaS 套件默认）、无眉标/中点元信息串/破折号标签/等宽小数据。大胆只花一处：标题旁双状态胶囊（扫视锚点），其余全部安静。

## 7. 交互流程

1. 常态扫视：标题 → 双胶囊读状态（tooltip 见路径/机制）→ 无操作即离开（低干扰）。
2. 改端口：点 input → 编辑（草稿）→ 回车或点「应用」→ 反馈位回显结果；Esc 丢弃草稿回落已应用端口（现链路 :596-597 保留）。
3. 切自启开关：即时生效（applyProxyAutoStart，settings_module.cpp:432-436）。
4. 出警告：带3 染底带展开出现（动效 §8）；最多 2 条。
5. 去 profile 管理：走侧边栏 claude_proxy 模块（卡内无导航捷径，§ 域界声明）。
