## 3. 页面级构图

### 3.1 滚动模型（构图三问①）

弹窗是固定高外壳（552，视口钳制），**外壳不滚**；「运行详情」内容区按既有二态：
- 余高充足（`dh − 卡片高 − 消息头 32 − 12 ≥ 96`）：详情卡固定 + 消息区独立内滚，**错误区在卡片内再独立滚**（有界 96，嵌套但方向与层级分离：消息区在卡片外，错误区在卡片内）。
- 余高不足（有错误+长计划时必然）：整栏 `.detail.scroll` 内滚，错误区仍保持 96 内滚（双滚动同时存在；沿用现状实现，不新增滚动层）。
不做分页器，不做横向滚动。

### 3.3 空间节奏与密度预算（构图三问②③）

**两档落值（fontScale=1）**：

| 量 | 最小窗 1000×640 | 标准窗 1600×1000 | 公式 |
|---|---|---|---|
| 弹窗 w × h | 720 × 552 | 800 × 552 | `max(720, screen.w×0.5)` 钳制；h=552 钳制 |
| 内容内宽 innerW | 672 | 752 | `w − 48` |
| 内容高 dh | 284 | 284 | `h − contentY(208) − 60`（沿用既有计算，本次不改） |
| 卡片内宽 cw | 644 | 724 | `innerW − 2×14` |

**卡片高度公式**（`hasErr` = 该 run 有非空 error；`hasPlan` = 计划数据存在；`hasHint` = 配置类错误）：

```
cardH = 28 + pad(14)                   // 上下内边距
      + 28 + 8 + 17                    // 状态带 + gap8 + 指标带
      + (hasPlan ? 4 + 17 : 0)         // 计划行
      + 4 + 17                         // 时间行
      + (hasErr ? 8 + 17 + 4 + errH + (hasHint ? 8 + 20 : 0) : 0)
      + pad(14)
errH  = min(自然文本高, 96)
```
落值：无错无计划 **98**；无错有 plan **119**；短错误（34）**176**；长错误（96）**238**（含引导行 254）。
消息区固定条件：`284 − cardH − 32 − 12 ≥ 96` → 无错两档都成立（余 142/121）；有错不成立 → 整栏滚（与现状降级一致）。

**无效空白自查**：行卡右侧空洞已由「成本摘要右对齐」填补（左信息右摘要两端锚定，与微信列表行同语言）；卡片内不再有定宽空列——原 meta 网格的「label 64 定宽 + value」两列已撤除，改为连续排布。**密度与权重**：高频（状态/耗时/错误）占最高权重（600 + 16px 主数字/红字），中频（迭代/token）12px 灰字一行，低频（起止时间/计划）12px tertiary；主体卡（98-238）与消息区（≥96）在两档均成立。

### 3.4 本页独特性原则句（两遍法第二轮）

> **「一行读结论（状态·耗时），一行读成本（迭代·token），错误永远完整可读；时间是一等公民。」**

自审「给同类页是否同样结果」：通用执行详情默认脸是「键值表格平铺」（现状正是它）。本设计换了三处非默认的选择——①耗时从元数据升为与状态并列的主数字（16/600，读秒感是本卡唯一大胆点）；②起止时间合并为区间行、降为 tertiary；③错误区从「最后一块」升为「有错即主块」。其余全部安静克制，无渐变、无眉标、无中点串（指标带用 12px 段落间距分隔，不用「·」串联）。

## 9. 禁止项自查

- 无框架/库名出现在规格正文（demo 载体例外）；参数全部取自 `core::theme` token 或既有量（无新造色/新造间距体系）。
- 无「大气美观」类描述；禁用旧橙（#D97757 全域未出现）；无大面积渐变/装饰色块。
- 语义四色不越界：绿=操作/成功、红=错误、蓝=运行中（既有槽）、灰=中性。
- 无死组件：全部复用 `stack/text/row/column/scrollView/cardPanelColored/toast`，零新增组件。
- 大胆只花一处（耗时主数字），其余克制；无全大写眉标、无「·」元信息串、无等宽字体装饰。

## 11. 未采纳方案（有意识放弃）

1. **错误折叠展开**：需手搓 Collapse（状态位 + 高度重排 + scrollView contentKey 管理），换一次点击；错误主体仍需滚动。放弃。
2. **「复制错误」chip**：项目无文本选择能力时复制有实用价值，但超出本次范围且新增剪贴板路径；记入 backlog 候选，不在本设计内。
3. **卡片标题「执行详情」**：与 tab 名重复、占 25px 高度。放弃。
4. **行卡耗时右对齐但收窄**：仍与状态分离，未解决「太靠右」的语义问题。放弃。
