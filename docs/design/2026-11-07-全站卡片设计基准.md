## 1. 页面级构图（先整体后参数）

### 1.1 构图三问

| 问 | 答 |
|---|---|
| ① 滚动模型对吗 | 外壳（页头 40px + Tab 行 44px）固定不滚，列表内容区整体内滚（release_list_ui.cpp:357-362 内容区高度 = 视口 − 页头 − Tab − 边距；scrollView 触底追加）。与全站「外壳不滚、内容区各自内滚」一致。 |
| ② 有无大段无效空白 | 无。行卡是 64px 定高双行，主行弹性区唯一且**挂了内容**（下一步指引，:207-221）；副行环境 chips 流式靠左、进度+计数右锚，中间不留无主空列。 |
| ③ 密度与权重 | 高频信息（日期/下一步/状态）在主行、字号最大（19/600）；佐证信息（环境/进度）在副行、小一档（11-12px）。内容列 max-width 1040 居中（:84），超宽窗口下两侧留白对称、行内容不无限拉长。最小窗 1200×720 下：内容列宽 1136−96 页边内缩后仍 ≥1040 满档，行卡双行结构不破。 |

├─ 内容区（灰底，唯一内滚区）──────────────────────────────────┤

│   │ ▓ 64px 行卡（主行24 + 副行20 + 上下内边距10×2）          │  │
│   │ ├ 1px borderMuted 分割线（画在行下层，hover 底可覆盖）    │  │
│   │ ▓ 64px 行卡                                              │  │
│   │ …                                                        │  │
│   └──────────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────────┘
   内容列 max 1040 居中（:84）；页面外边距 12（:70）

- 行卡自身无边框无底色：行底常态透明（透出外层大卡白底），hover/按压才上底色（:167-175）——**卡片感由外层大卡统一承载，行内不再包盒**，这是「看上去舒服清晰」的第一来源。
- 整行命中点击 → 打开详情（:172-174），行内不放行内按钮，导航唯一出口、低干扰。

### 2.1 横向锚点链（从左到右）

## 3. 锚点链六规（反 #154 / #192 的对治规则 + 全站形态红线）

> #154 病灶：内容挂四角、中间空白——四角各自绝对定位，中间没有内容承载区。
> #192 病灶：双端撑开（space-between）——左右两坨互推，中间空列随窗宽无限变宽。
> 形态红线（老板 2026-11-07 令：「UI 设计方面，别再出现又细又长的布局设计」）：落为 R6，全站适用。

| 规 | 内容 | 对治 |
|---|---|---|
| R1 | **左锚点链显式常量**：左侧元素依序紧邻，间距用固定值（8/16），不许互相推让 | 日期→8→星期→16→指引（:156） |
| R2 | **弹性区唯一且必须挂内容**：一行最多一个弹性区，且必须有高频信息占用（本样本=下一步指引）；该行确无内容可挂时（Draft 留白），弹性区宽度被右锚元素自然压回，不留装饰性空列 | 指引文字 flex-1（:157、207-221） |
| R3 | **右锚成组、右端=最重**：右侧元素按「最右=视觉最重」排布，相互间距固定（进度与计数 gap 8，:268），整组右端对齐卡内边距 16 | 状态胶囊（主行）/ 进度+计数（副行） |
| R4 | **禁双端撑开**：所有间隙是显式常量，禁止把弹性区放进两个内容块中间当「吸管」；弹性区只能贴在左锚点链末尾 | R2 的逆命题 |
| R5 | **双行定高预算**：行高 = 上下内边距 + 主行 + 副行，恒为常数（64）；任何新增信息先回答「进主行还是副行、挤掉谁」，不许加高行也不许加第三行 | :74 |
| R6 | **禁又细又长布局（全站硬禁项）**：① 竖条形态——任何**内容容器/列**不得 高:宽 > 3:1 且宽 < ~200px（细高窄列 / 窄条竖带一律违例）；② 发丝细条——条形仪表 / 进度带高度统一 **10–12px 档**，禁全宽 ≤6px 发丝条（尤其禁成排出现）；紧凑迷你表 80×4 档仅限行内右锚小部件（正样本 release 行卡进度 80×4 即此用法） | 红线口径 |

R6 替代范式：**横带分区**（信息横向铺开、高度收敛成带）/ **宽卡**（高:宽 ≤ 1:2 的横向比例卡）/ **双列网格**（窄内容并排成对，不单列吊挂）。
R6 豁免口径（非布局容器，不在禁列）：功能性微元素——扫视锚条（正样本 Running 3×64 绿竖条）、仪表刻度（≤3px 阈值标线）、1px 分隔线；单行文本标签列（弹窗 kv 标签、滑条标签——内容为单行文字，非堆叠承载）。新增侧栏 / 纵向面板 / 窄列卡片一律先过 R6 再谈参数。

## 7. 自适应行为表

| 条件 | 行为 |
|---|---|
| 窗宽 ≥ 1064 | 内容列满 1040 居中 |
| 1064 > 窗宽 ≥ 最小窗 1200×720 档 | 内容列 = 窗宽 − 24（页边距×2），行卡横向跟随 |
| 窄窗挤压顺序 | 弹性区（指引）最先饿（省略号截断）→ 日期列不缩（身份）→ 右锚组不缩 |
| 跨年日期 | 日期列 72→104 自适应，星期列顺移（:151-152） |
| 环境超宽 | 先留「+N」宽度再放可见 chips（:231-256），不许溢出压进度区 |
| 长内容 | 副行/主行均单行省略，行高恒 64 不撑高 |

## 8. 反样本对治对照（修 #154 / #192 时的对齐动作）

| 反样本 | 病灶 | 按本基准的对齐动作 |
|---|---|---|
| #154 | 卡片内容挂四角、中间空白 | 重新分区为「左锚点链 + 唯一弹性区 + 右锚成组」（§3 R1–R4）；中间空白区必须由高频内容（指引/摘要）占用，否则删层级 |
| #192 | 双端撑开 space-between、中间全空白 | 禁双端撑开（R4）；两端内容改为一侧锚定链 + 一侧右锚组，间隙显式常量化 |
| 通用 | 卡内多行等权重平铺 | 字级四档（§4.2）：一行只允许一个 L1 元素；L4 细节不得与 L1 同字号同色 |
| 通用 | 卡高随内容随意生长 | 双行定高预算（R5）；第三行信息一律先答「收进哪一行/收纳到哪」 |
| 通用 | 又细又长形态（细高窄列 / 窄条竖带 / 全宽发丝条成排） | 过 R6：改横带分区 / 宽卡 / 双列网格；条带仪表归 10–12px 档；功能性微元素按 R6 豁免口径处理 |

## 10. 禁止项自查

- 四色语义：绿=完成/进行、黄=运行中/警告、蓝=待命、红=未用（告警域）、灰=中性 ✓ 无越界
- 无渐变、无装饰色块、无「大气美观」类不可执行描述（全值可对照） ✓
- 不绑定实现技术：本文组件名/文件行号仅作现状实测出处与语义沿用声明，非实现指令 ✓
- 构图先行：§1 三问已答，参数全部挂在已定构图之下 ✓
- 又细又长红线：正样本行卡与外层大卡均为横带形态（64×~1136），无竖条内容容器、无全宽发丝条（行内进度 80×4 为右锚小部件档）；Running 3px 竖条按 R6 豁免口径属扫视锚条 ✓
- 正样本事实全部带 file:line 锚点，未掺入推测值 ✓
