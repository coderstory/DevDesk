# 设计文档：调度页瀑布流卡片重设计（池140）· v4

- 日期：2026-11-03 ｜ 角色：ui-ux-designer
- 来源：池 140。**v1~v3 行卡方案整体推翻**，老板给死新方向（7 点）：① 系统任务/用户定时改页头顶部分类 TAB；② item 瀑布流多列卡片，列数随宽自适应；③ 卡面零操作按钮，点击卡片打开编辑，启停/删除收进编辑弹窗；④ 页头+TAB 固定、瀑布流区自滚动；⑤ 融合池137（唯一新建入口）与池139（顶部空白对齐全站）；⑥ 七态 pill 语义色沿用 v3 映射，特殊态保留；⑦ 构图门禁照旧，demo 三档。

## 1. 构图（页面级三问先钉住，再落参数）

### 1.1 骨架分区（问一：页面骨架是什么）

```
┌ page（满高，禁止滚动，padding 20/12）─────────────────────────┐
│ 页头 40：【定时】标题顶格 ─ 弹性 ─ 运行历史 · 新建(主钮) 【固定】│
│ gap 8                                                        │
│ TAB 行 36：[系统定时] [用户定时] · 共 n 个         【固定】     │
│ toast 20+8（仅 error_ 非空时插入，顶缩下方）        【动态固定】 │
│ ┌ 滚动区（flex:1，min-height:0）──────────────────────────┐  │
│ │  瀑布流卡片 masonry（列数随内容列宽自适应，§3）           │  │
│ │  归档折叠段（仅用户 TAB，瀑布流之后：标题+归档卡瀑布）     │  │
│ │  空态：贴左灰字纯提示（段空时，无任何按钮，池137）         │  │
│ └ 自身滚动 · 独立滚动条 6px ──────────────────────────────┘  │
│ 页 pad 下 20                                                  │
└──────────────────────────────────────────────────────────────┘
```

- 现状「双列表双段标题 + 整页滚」结构废除：段标题消失，分类进 TAB；同一滚动区随 TAB 切换内容。
- 归档行属于用户规则：归档折叠段只出现在「用户定时」TAB 滚动区尾部（标题 32 + 归档卡入同规则瀑布容器）。

### 1.2 滚动模型（问二：什么滚什么不滚）

| 区 | 行为 |
|---|---|
| 外壳/页面 | 不滚（`overflow:hidden` 语义） |
| 页头 + TAB 行 | 固定全程可视 |
| 瀑布流滚动区 | 唯一滚动区，自身滚动、6px 圆角滚动条 |
| TAB 切换 | 滚动区 scrollTop 重置 0，内容 120ms 淡入 |
| toast | 插入时滚动区高度顶缩（动态固定区） |

### 1.3 密度预算（问三：列数/卡宽/高度预算）

固定区高度预算（全部随 `scaled()` 派生）：

| 区 | 100% | 150% |
|---|---|---|
| 页 pad 上 | 20 | 30 |
| 页头 | 40 | 60 |
| 页头→TAB gap | 8 | 12 |
| TAB 行 | 36 | 54 |
| TAB→滚动区 gap | 8 | 12 |
| 页 pad 下 | 20 | 30 |
| **固定区合计** | **132** | **198** |
| **滚动区 @1000×640** | **508** | **442** |
| **滚动区 @1600×1000** | **868** | **802** |
| toast 插入时滚动区再减 | −28 | −42 |

卡高区间 140~176（摘要 1~2 行 + 数据区两行块，§4）；150% 档卡高 ~210~264。1000×640 滚动区 508 ≈ 2 列 × 3 行卡可见；1600×1000 滚动区 868 ≈ 3 列 × 5 行卡可见。150% 档 442 ≈ 2 列 × 2 行——可用不破版。

## 2. 顶部分类 TAB

**口径裁决**：老板主锚「跟随全站」「参考既有页面 Tab 用法」→ 采用**全站 wtab 块面式现行口径**（2026-11-01 全站统一裁决：release_list_ui.cpp:301-303 注释明确「淘汰下划线式……同模块两页两种 tab 形对撞」；材质文档 §13 同口径「选中 primarySoftBg+描边，未选中透明」）。老板括号复述的「底部 2px 绿下划线」为基线旧档，已被该裁决淘汰；「禁实心按钮当 Tab」两案皆合规。若老板坚持下划线式，仅换 tab 面样式参数，骨架不变。

| 项 | 值 |
|---|---|
| Tab 文案 | 「系统定时」「用户定时」（跟随现状段标题文案） |
| Tab 本体 | 高 32、圆角 6、内边距 0 14、字 14（组件默认几何以 ui_kit wtab 为准，本表为视觉校准档） |
| 选中态 | 底 `primarySoftBg` #E8F8EE + 1px 描边主色 + 字 `primaryText` #157E4E 600 |
| 未选中 | 透明底 + 字 `textSecondary` #666666 400；hover 底 #F2F2F2 |
| 计数 | 选中 Tab 之后紧跟「共 n 个」12px `textTertiary`（release drawTabRow 同口径） |
| 切换 | 120ms 淡入 + 滚动重置顶（§1.2） |

## 3. 瀑布流规格

### 3.1 列数断点与卡宽区间（按内容列宽 W = 窗宽 − 侧栏 200 − 页边 40）

| 内容列宽 W | 列数 | 列宽区间 | 两档实值 |
|---|---|---|---|
| <520（低于最小窗） | 1 | 全宽 | 兜底 |
| 520 ≤ W < 1080 | **2** | 340~620 | **1000×640：W=760 → 列宽 374** |
| 1080 ≤ W < 1660 | **3** | 352~470 | **1600×1000：W=1360 → 列宽 445** |
| ≥1660 | 4 | 330~400 | ≥1860 窗：列宽 ~394 |

- 列间距 12 / 卡纵距 12（8px 网格半档，与页边同档）。
- 实现落点提示：按列数分 N 个纵向列容器、新卡入最短列（高度均衡）；demo 用 CSS 多列布局做视觉校准，不作实现蓝图。

### 3.2 密度保证（不留空洞）

- 卡面排版数据区占满卡宽（§4.2 两块横排），头区名称行名称左、类型 chip 右顶——卡内无大段横向空白。
- 卡高随内容（瀑布流本质），列内错位由摘要行数/有无上次记录自然产生，列底对齐差 ≤ 一张卡高。

## 4. 卡面规格（参数全填，100% 字号档）

### 4.1 卡容器与头区

| 项 | 值 |
|---|---|
| 材质 | L2 `glassFill` 0.94 Light / 0.95 Dark + 1px glassBorder + glassShadow |
| 圆角 / 内边距 | `radiusLarge` 14 / **16**（基线卡片内边距档；多列密度优先，非行卡 24 档） |
| 头区 | 名称行：名称 14/500 `textPrimary`（系统卡前置锁 16×16 #999；停用卡后置「已停用」tag；归档卡后置「已归档」tag）+ 类型 chip 右顶（「单次/间隔/周期/cron/事件/常驻」11/500，底 #F2F2F2 字 #666，高 20 圆角 10） |
| 摘要 | 12/400 `textSecondary`，最多 2 行省略，上距 6 |
| 可点 | 用户/归档卡整卡可点（cursor pointer，点击=打开编辑）；系统卡只读不可点（cursor default，hover 仅浏览反馈） |

### 4.2 数据区（占满卡宽，两块横排）

上距 12 + 顶部 1px `line2` #EDEDED 分割线 + 下距 10；左块 55% / 右块 45%，各为「引导字行 + 值行」纵向堆：

| 块 | 引导字行 | 值行 |
|---|---|---|
| 下次（左块） | 「下次」11 `textTertiary` | 「今天 HH:MM / 明天 HH:MM / MM-DD HH:MM」**15/600 `textPrimary`**（卡内第一数据锚）；无值「—」12 灰 |
| 上次（右块） | 「上次」11 `textTertiary` | 七态 pill（§4.3）+ 6 + 时间戳 11 `textTertiary`；无记录「无记录」12 灰占位 |
| 系统卡右块 | 「来源」11 灰 | 模块名 12 `textSecondary` + 4 + 「只读」11 `textTertiary`（超长省略） |

### 4.3 状态 pill（沿用 v3 映射，值域=runStatusZh）

高 22 / 行高 22 / 圆角 11 / 内边距 0 10 / 字 12/500：

| 状态 | 底 | 字 |
|---|---|---|
| 成功 / 运行中 | `primarySoftBg` #E8F8EE | `primaryText` #157E4E |
| 失败 | #B91C1C @ α0.10 叠白 ≈ #F8E8E8 | `errorText` #B91C1C |
| 待执行 | #F2F2F2 | `textSecondary` #666666 |
| 已跳过 / 已错过 / 已抑制 | #F2F2F2 | `textTertiary` #999999 |

Dark：底/字换对应 dark token（primarySoftBg #0D3326 / primaryText #36D399；errorText #F87171 底同式叠卡面）；demo 只做 Light 校准。

### 4.4 特殊行态（语义保留）

| 态 | 处理 |
|---|---|
| 停用 | 名称后「已停用」tag（#F2F2F2/#999）+ 数据区整体 0.55 灰化（头区不灰，名称可读） |
| 归档 | 名称后「已归档」tag + 数据区 0.70 灰化；点击仍开编辑（交互不变原则） |
| 系统只读 | 锁图标 + 来源块；不可点、无果冻 |

## 5. 交互流程

| 交互 | 编排 |
|---|---|
| 点击卡（用户/归档） | 打开编辑弹窗（现状 drawEditDialog；卡面无任何操作钮） |
| **启停开关去向（二选一裁决：进编辑弹窗）** | 理由：① 瀑布卡交互模型单一——整卡唯一动作=进编辑，无命中区挖洞与误触；② 启停状态卡面以「已停用」tag+灰化表达，可读性与开关等价；③ 定时规则启停是低频管理动作，编辑弹窗把启停开关置为表单首行，点卡后一步直达；④ 卡面留唯一控件会破坏「信息浏览卡」的纯净度，与老板「卡面最纯净」首选方向一致 |
| 删除 | 编辑弹窗底部操作区「删除」（danger 文字钮，左侧）→ 触发现有删除确认小弹窗（链路不变） |
| 弹窗底部操作区 | 删除（danger 文字）+ 弹性 + 取消（次钮）+ 保存（主钮）；弹窗宽 460（现状档） |
| TAB 切换 | 选中态切换 + 计数更新 + 滚动区回顶 + 120ms 淡入 |
| 果冻 | 用户/归档卡 + 页头「新建」钮：按下 ~70ms 缩至 0.965、松手 ~160ms 回弹（贝塞尔 0.34/1.56/0.64/1）；demo 用 pointer 事件显式驱动（v3 结论：:active 不可靠） |
| 空态 | 池137：滚动区内贴左灰字 12px `textTertiary`（缩进 16 与卡对齐），无卡无任何按钮；唯一新建入口=页头「新建」 |
| 池139 | 页头高 40 全站统一、标题顶格（页 pad 顶 20 起算，无额外上边距） |

## 10. 禁止项自查

- 参数全落具体值（px/token/α/ms/断点/值域）；无不可执行描述；正文无框架库名（demo 为原型唯一例外）。
- 四色语义未越界（绿=选中 Tab/启停/成功反馈、红=删除/失败告警、蓝未用、灰=中性）；图标零新增（FA 0xF023/0xF105/0xF107）。
- 池137 合规：空态无任何按钮，唯一新建入口在页头。池139 合规：页头高 40、标题顶格、页 pad 20。
- Tab 采用全站块面式现行口径（2026-11-01 统一裁决），与老板括号复述的下划线旧档差异已在 §2 显式记录，交主会话汇报提示。
- 工作区 AGENTS.md：不涉平台代码；只动 module_schedule 页面视觉与结构层。
