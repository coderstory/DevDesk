# 全量 UI 审计整改交付说明（2026-11-01）

## 做了什么

对 DevDesk 全应用（12 页 + 30 组弹窗 + 2 套 toast + 5 组右键菜单 + 托盘菜单）做了一次
完整 UI 审计，产出 19 条问题清单 + 6 条硬规则 + 12 张工单，然后按规则整改并用离屏渲染逐页验收。

**重点模块**：上线（release）、MCP、记忆（memory）。

完整方案与逐条落点见 `docs/design/2026-11-01-全量UI审计与统一整改.md`。

## 四条硬规则的落地

| 规则 | 内容 | 落点 |
|---|---|---|
| **R1 Tab 只有一种** | 块面式（`ui_kit::wtab`）；选中底用主色 14% 派生、选中字用 `primaryText` + 600 字重；高度全站收敛 36/32 两档 | `ui_kit/wtab.*` + 7 个模块 |
| **R2 页头不加壳** | 标题行直接落在页面底上，tab 行独立随内容滚动 | release 列表页白壳移除 |
| **R3 空态只有一种** | 图标 + 主句 + 引导句 + 行动钮，整体垂直居中，不套大白卡 | `ui_kit/empty_state.*` + 8 处接入 |
| **R4 卡片只有两档材质** | 玻璃（页面浮层）/ 实心（表格·工具卡），两档都带描边 + 低阴影 | 新增 `ui_kit::cardPanel`，记忆页 15 处补阴影 |
| **R5 反馈只有一套** | 无标题的轻反馈走居中微信式轻提示；带标题的重要反馈与错误走右下通知式；四态图标 + 统一时长 | `ui_kit/toast.*` + `light_toast.*` |
| **R6 调色板不越界** | purple/pink/blue 只用于用户选定的强调色，不借用为类别标签色 | MCP「服务」chip 去紫色 |

## 重点模块的具体改动

### MCP
- 工具卡列宽 340 定值 → **自适应 340–420 撑满内容宽**（原 1600 窗内右侧空 210px）
- 描述列宽由状态列反推，**间距恒 ≥16px**（原 8px，长描述末尾的「…」与「未启用」咬合成一句）
- 计数 chip 量出标题实际宽度后紧随其后（原贴在页面最右，相距 700px）
- 「服务」chip 由 purple 软底 → 中性灰底 + 主色字
- 空态接入统一组件

### 记忆
- 15 处卡片补阴影 —— 此前只有 1px 浅描边，在动态光晕上边界完全不可辨（只见文字不见容器）
- 健康格四卡统一为「标题 + 数值 + 单位 + 细节」结构（脱敏闸补了数值行 0/110）
- 「最近调用记录」空表不画孤儿表头；「最近动态」卡高按行数自适应（原写死 268）
- 审核台 / 已裁决 / 最近调用记录 / 最近动态四处空态接入统一组件

### 上线
- 列表页自绘下划线 Tab → `ui_kit::wtab`（该页是全站唯一违规者）
- 页头不透明白壳移除（此前把动态背景光晕挡死）
- 配置页空列表不画表头；空态接入统一组件

## 额外修掉的两个真缺陷（审计清单外，截图实证）

1. **release 列表页计数文字压住下一个 Tab** —— 计数画在选中 tab 右缘 +10，但后续 tab 的 x 按「无计数」排，
   选中「全部」时「0 个任务」压在「发布中」上。改为计数插入 tab 流内、后续 tab 顺移。
2. **release 配置页卡高公式未跟随 Tab 高度 40→36**，底部留白少 4px（`release_probe` 抓到）。

## 复核后不成立的结论

**F-19「设置页双栏卡顶/底不对齐」不成立** —— 像素级扫描 Release 截图，两卡顶边同在 logical y=112、
底边同在 y=295，严格对齐。原读数来自被查看器缩放后的目测，故未改代码。
