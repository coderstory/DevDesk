## 1. 现状（已核实源码，可直接采信）

### 1.1 可用工具区（池 170 对象）
src/module_agent/agent_module.cpp:523-663：页内可展开**区块**（非悬浮卡，简报「悬浮卡片展示」与源码不符，见 §12 回流）——头部行「可用工具（N） 展开▼」（toolsOpen_ 收起默认）+ containerSurface 面板内 scrollView 平铺工具卡。工具卡 = 全宽横条：卡高 `kToolCardH=40`（agent_module.cpp:97）、行 1 工具名 14px/600、行 2 描述+「参数：…」12px 三级字截 80 字符，cardSurface 实底 + 1px borderDefault。
问题定性：1000 窗下卡 ≈ 936×40 横条，两行短文本居左、右侧大片空白——老板「卡片中间一大批空白，看上去就不稳定」成立；且区块常驻页内挤压任务列表（toolsH 从 listH 中扣除，agent_module.cpp:463-466）。

### 1.2 详情弹窗明细 item（池 162 对象）
- 消息明细 src/module_agent/agent_module_dialogs.cpp:136-283（renderMessageRow）：**无卡面裸文本列**——头行（角色 badge 44px + 时间 110px + 展开/复制 chip）+ 折叠预览行，展开后 Text/Plain/ToolUse（绿字一行截 120）/ToolResult（标签行+全文）四类块直接平铺在弹窗底上，块间无容器、无边界，「结构很乱、缺少卡片的 UI 效果」成立。
- 摘要三卡（最近一次/下一次/近 7 天）agent_detail_dialog.cpp:346-409：有 cardSurface + radiusLarge，**无边框无阴影**，与全局卡片语言脱节（同批补齐）。

### 1.3 任务卡 hover 操作组（池 169 对象）
agent_module.cpp:87-160、841-895、1003-1029：卡上 hover 操作组 = 五个 28×28 图标钮（间距 4，组宽 156，组右缘=卡右缘−14）+「启动」常驻钮 56×32；显隐靠 `hoveredTaskIds_` 集合，onHover 由「真正接住指针的元素」代报（F-66-4b 机制）。症状：指针在悬浮钮之间移动、或从启动钮移出时菜单闪没——触发点多、无离开去抖、缝隙归属不明。
**与 170 的关系**：可用工具弹窗化移除的是页内工具区块，**不触及任务卡 hover 操作组** → 169 无法连带销账，按 §8 显隐状态机口径独立修复。

## 4. 交互流程

### 4.1 工具弹窗
页头钮点击 → 打开（入场 160ms）→ forceReload 工具缓存 → 加载中骨架（§5）→ 网格浏览/内滚 → ✕ / backdrop / ESC → 关闭（出场 120ms）→ 回到 Agent 页（焦点回落页头钮）。
### 4.2 明细消息卡
折叠卡整卡点击 → 展开（块列淡入 120ms）→ 头行出现「复制」chip → 再点收起；「复制」写入剪贴板 + toast「已复制」（沿用现状）；时间线 tab 点运行行自动切运行详情 tab 的现状行为不变。
### 4.3 任务卡 hover（§8 状态机）
指针进入卡联合命中域 → 操作组淡入 120ms；在组内钮间移动/停留缝隙 → **保持显示**；离开联合命中域 → 120ms 去抖后淡出；期间重入 → 取消隐藏。

| 150% 字号 | 行盒随字号缩放（scaled 派生现状规则沿用），弹窗高钳 min(560,…) 内滚兜底 |

## 8. 池 169 处置口径：hover 操作组显隐状态机

**结论：170 弹窗化不移除任务卡 hover 操作组（两者无耦合），169 独立按下述口径销账。**

状态机（每卡独立实例）：

| 状态 | 进入条件 | 动作 | 离开条件 |
|---|---|---|---|
| Hidden | 默认；或 Shown 且离域计时器 120ms 到期 | 操作组 opacity 0 + disabled | 联合命中域 enter |
| Shown | 联合命中域 enter（立即，无需去抖） | 操作组 opacity 1 + enabled | 联合命中域 leave → 启动 120ms 去抖计时器 |

口径三条（给 developer 的验收定义）：
1. **联合命中域 = 卡全矩形 ∪ 操作组矩形 ∪ 启动钮矩形**（三者几何上均含于卡矩形内 → 等价于「指针在卡内即 Shown」）；leave/enter 以该域为唯一裁决，**缝隙（钮间 4px）属域内**，不得产生 leave。
2. **hover 上报唯一来源 = hoveredTaskIds_ 集合代报机制（F-66-4b 现状保留）**：所有可点子元素 onHover 一律代报所属卡 id；禁止 hoverOpacityFrom 类局部 hover 通道。
3. **离场去抖 120ms**：leave 不立即隐藏，120ms 计时期间任何域内 enter 取消隐藏——消除快速掠过与缝隙穿越的闪烁；enter 即时显示不去抖（响应优先）。

验收：指针从启动钮移到卡身、在五钮间横移（含缝隙）、快速掠过卡——操作组均无闪没；移出卡 120ms 后消失。
