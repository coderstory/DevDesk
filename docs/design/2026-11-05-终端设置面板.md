## 0. 门控与范围

- **必经设计门**：新面板形态（弹窗 + 7 行控件布局 + 即时生效语义）。
- 范围：面板形式与几何、5 项设置（6 行布局）、控件规格与状态、空/错误态、即时生效语义、窄窗自适应、持久化字段面、EUI 映射。

## 2. 面板级构图

### 2.1 形式裁决：**终端页内模态弹窗**（拍板 A 案 + 模态）

```
页面区（终端页 v2 构图不变）
├─ scrim 黑 α0.35 盖整页面区（含 TAB 栏带，模态独占）
│   ┌──────────── 终端设置 卡 480×~500 居中 ────────────┐
│   │ 标题行：终端设置                          [×关闭]   │
│   │ ── 外观 ──────────────────────────────            │
│   │ 字体        [默认（内置等宽）        ▾]            │
│   │ 字号        [−] 13 [+]                             │
│   │ 配色主题    [跟随应用|独立]  [亮色 ANSI ▾]（灰）    │
│   │ ── 会话 ──────────────────────────────            │
│   │ 默认 shell  [pwsh ▾]      对新会话生效              │
│   │ 启动目录    [____________________] [浏览]           │
│   │ 回滚行数    [−] 1000 [+]                           │
│   │ 光标        [块|线]  闪烁 [○─]                      │
│   │ ──────────────────────────────────────            │
│   │ 恢复默认                              [完成]       │
│   └────────────────────────────────────────────────────┘
```

- **模态理由**（写死）：终端页键盘事件语义优先会话（v2 §5.7）——模态焦点独占 = 面板打开期间按键归面板、Esc 关闭即归还会话，零焦点仲裁复杂度；非模态侧滑面板需要焦点路由 + TUI 按键冲突面，不值。
- **点 scrim 不关闭**（防误触；关闭通道 = Esc / 标题行 × / 「完成」）。
- **会话不中断**：面板打开期间会话照常 poll/输出（scrim 半透 α0.35，字体/配色即时生效可透过 scrim 直观感知——即时生效的可感知性设计）。

### 2.2 滚动模型

外壳不滚；面板卡固定居中；卡体内容区超高时**内部滚动**（同 v2 全局纪律：滚动条视觉隐藏）；最小窗下卡高钳 `页面区高−64`。

### 2.3 构图三问

1. **滚动模型**：模态卡 + 内容区内滚，与全站弹窗一致（MCP/memory 弹窗先例）。✅
2. **无效空白**：7 行 44px 满排，行间距 8 服务分组（外观/会话两组），无定宽空列。✅
3. **密度与权重**：高频改字体/字号（前两行置顶）；低频「恢复默认」弱化为文字钮；「对新会话生效」约束就近微字。最小窗与宽窗两档均成立（§6）。✅

## 4. 逐区块规格

### 4.1 面板几何

| 参数 | 值 |
|---|---|
| 宽 | 480（基线弹窗 420–760 档）；窄窗 `min(480, 页面区−32)` |
| 高 | 内容派生 ≈ 500；钳 `min(内容高, 页面区高−64)`，超出部分内容区内滚 |
| 位置 | 页面区内水平垂直居中 |
| 内边距 | 16（基线卡片内边距） |
| 标题行 | 「终端设置」15px textPrimary 600 字重 + 右侧 × 关闭钮 24×24（fa-xmark 0xF00D 12px，hover 底 `hover`，图标 textSecondary→textPrimary）；行高 28，下间距 12 |
| 分组头 | 「外观」「会话」12px textSecondary，字间距 1px；行高 20，上间距 12 下间距 8 |
| 设置行 | 行高 44；行间距 8（基线列表项 8）；label 定宽 128 左对齐 14px textPrimary；控件区 flex 起 x=128+12 |
| 底部行 | 上方 1px `borderMuted` 分隔线，间距 12；左「恢复默认」文字钮（13px textSecondary，hover textPrimary）+ 右「完成」次按钮（高 32、圆角 6、底 #F2F2F2/hover #E5E5E5、字 textPrimary 14px，内边距 20） |

### 4.2 设置行明细（5 项 → 7 行）

**① 字体（dropdown）**

| 参数 | 值 |
|---|---|
| 选项 | Windows：`默认（内置等宽）` / `Cascadia Mono` / `Consolas` / `JetBrains Mono`（若已装）；macOS：`默认（内置等宽）` / `Menlo` / `SF Mono` / `JetBrains Mono`。默认 =「默认（内置等宽）」（v2 字体栈方案 A 的打包字体；其它选项 = 路径/别名直落 v2 fontFamily） |
| 宽 | 200 |
| 生效 | 即时：切字体 → v2 度量链重算 cellW/cellH → 全会话 resize（既有量化→resize 链路） |

**② 字号（stepper）**

| 参数 | 值 |
|---|---|
| 范围/步进 | 10–24，步进 1，默认 13（现状值） |
| 即时生效 | 同字体行（度量重算）；<10/ >24 输入钳制并就近红字「支持 10–24」 |

**③ 配色主题（segmented + dropdown 联动）**

| 参数 | 值 |
|---|---|
| 模式 segmented | `跟随应用`（默认）/ `独立`，控件宽 ~160 |
| 色板 dropdown | 独立时启用：`亮色 ANSI`（v1 亮表）/ `暗色 ANSI`（v1 暗表）；跟随应用时置灰禁用（textTertiary）并显示当前继承值 |
| 语义 | 跟随应用 = 网格 ANSI 表随主题切换（现状行为）；独立 = 锁定所选色板不随主题 |
| 生效 | 即时（当前帧起，全会话） |

**④ 默认 shell（dropdown）**

| 参数 | 值 |
|---|---|
| Windows 选项 | `pwsh`（默认）/ `powershell` / `cmd` / `wsl` |
| macOS 选项 | `zsh`（默认）/ `bash` / `sh`（双平台一等公民，选项表按平台各写死一套） |
| 生效 | **仅新会话**；行内右缘微字「对新会话生效」12px textTertiary |
| 错误态 | 选中但启动失败的 shell（如未装 wsl）：开新会话失败 → 该 TAB Failed 覆盖卡显示错误详情（既有链路）；面板侧不预校验（写明取舍：启动时才可知，预校验成本 > 收益） |

**⑤ 启动目录（input + 浏览按钮）**

| 参数 | 值 |
|---|---|
| input | 宽 flex（约 260），高 32，圆角 6，1px `borderDefault`，focus 变绿边（基线）；placeholder「默认（用户主目录）」；空值 = 用户主目录（paths 既有语义） |
| 浏览按钮 | 次按钮 高 32、宽 64、字「浏览」13px，与 input 右间距 8；点击 = 系统目录选择对话框，选中回填 |
| 错误态 | 输入路径不存在：input 红边（`error`）+ 行下红字「目录不存在」（13px `errorText`，行高补 +20）；不阻断输入 |
| 容错 | 开新会话时无效目录 → 回退用户主目录（不弹卡阻断） |
| 生效 | 仅新会话（同 shell 行微字） |

**⑥ 回滚行数（stepper）**

| 参数 | 值 |
|---|---|
| 范围/步进 | 100–100000，步进 100，默认 1000 |
| 生效 | 即时改上限；已有 scrollback 超新上限时**裁掉最旧行**（边界写死）；开新会话按新值分配 |
| 超大值警示 | >50000 时行下 12px textSecondary 提示「较大回滚占用内存」 |

**⑦ 光标样式（segmented + switch 同行）**

| 参数 | 值 |
|---|---|
| 样式 segmented | `块`（默认）/ `线`，宽 ~120 |
| 闪烁 switch + label | 「闪烁」12px textSecondary + switch（开=绿轨白滑块，基线），默认开；与 segmented 右间距 16 |
| 生效 | 即时（当前帧）；光标绘制规格：块 = cellW×cellH 实心 α0.85（主题 textPrimary 色）/ 线 = 2px 宽 × cellH；闪烁周期 1100ms 阶跃（现状 steps 惯例） |

### 4.3 持久化字段面（SettingsStore terminal 段，落库口径 need250 已定）

| 字段 | 类型 | 默认 | 约束 |
|---|---|---|---|
| terminal.fontFamily | string | ""（空=内置等宽） | 枚举外值容错回退默认 |
| terminal.fontSize | int | 13 | 钳 [10,24] |
| terminal.colorMode | enum | followApp | followApp / independent |
| terminal.colorPalette | enum | light | light / dark（独立模式生效） |
| terminal.shell | string | 平台默认 | 无效值回退平台默认 |
| terminal.workDir | string | ""（空=用户主目录） | 无效值开新会话时回退 |
| terminal.scrollback | int | 1000 | 钳 [100,100000] |
| terminal.cursorStyle | enum | block | block / bar |
| terminal.cursorBlink | bool | true | — |

字段名是接口面示意（命名以 developer 落库为准），**语义/默认/钳制范围是设计契约**。

## 5. 交互流程与状态表

1. **打开**：点齿轮钮 → scrim + 卡淡入上移（§7）；焦点落第一控件（字体 dropdown）；Esc/×/完成 关闭。
2. **即时生效**：改字体/字号/配色/回滚/光标 → 身后网格当帧变化（scrim 半透可感知）；改 shell/目录 → 行内微字提示仅新会话生效。
3. **恢复默认**：左下文字钮 → 9 字段回默认值并即时生效（二次确认？**不弹**——低风险可逆操作，低干扰）。
4. **关闭**：完成/Esc/× → 无保存语义（即时已生效）；焦点归还会话（终端区）。

| 态 | 表现 |
|---|---|
| 空 | 目录 input 空 = placeholder；无其它空态（下拉必有选项） |
| 加载 | 无异步加载（本地面板打开即全量就绪；下拉选项静态） |
| 错误 | 目录不存在（红边+红字）/ shell 启动失败（身后 TAB Failed 卡既有链路）/ 字号越界（钳制+红字「支持 10–24」） |
| 成功 | 即时生效 + 无成功提示（低干扰：变化本身可见） |

## 6. 自适应行为表

| 页面区 | 行为 |
|---|---|
| ≥560 宽且高 ≥564 | 卡 480×~500 居中，行横排（label 左控件右） |
