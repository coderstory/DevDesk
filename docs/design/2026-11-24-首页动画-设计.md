## 1. 页面级构图

### 1.1 层叠与锚定（读自 `src/module_home/home_module.cpp` 几何事实：页头 40 → gap 20 → 5 统计卡（96 基准封顶 120）→ gap 20 → 操作行 44 + margin 16 → 留白区，1600×1000 典型窗余高约 700px）

| 层 | 内容 | 锚定 | z 序 |
|---|---|---|---|
| 底层 | 点阵波纹 | 留白区全域：上缘 = 操作行底 + 14px，下缘 = 页底 − 40px，左右 = content 内缩 20px | 内容之下，`pointer-events none` 点击穿透 |
| 内容层 | 打字机组（标签 + 垫板主行 + 副语 + 轮换指示条） | 留白区水平垂直居中，主行最大宽 ≤ 70% 留白区宽 | 点阵之上 |

避让关系：打字机主行带**白色半透明垫板**（物理遮挡，点阵照常波动不挖洞）——文字可读性与波纹连续性两全。

### 1.2 构图三问

1. **滚动模型**：整页 `home.scroll` 外壳不滚；两层全部锚定留白区、不进 `baseContentH`、不触发滚动条。
2. **无效空白**：700px 空洞由点阵全域覆盖（低对比但结构可见），中央由打字机给「信息焦点」——留白服务分组（焦点居中、波纹铺场），无稀疏弹性区。
3. **密度与权重**：统计数字 48px 档权重最高不动；点阵单点 alpha ≤0.98 但点径小（10px）、整体低吵；打字机 28px 字重 600 为留白区唯一高权重元素——视觉重心唯一，不与统计卡抢。

## 4. 数据源规格

- **来源**：markdown 模块「最近打开」记录（SQLite 已有打开历史；按最近时间倒序），取前 4 条**文件标题**（不含路径，含扩展名与否随列表现值，不做二次加工）。
- **边界处理**：

| 边界 | 画面 |
|---|---|
| 空列表（0 条） | 主行直显占位语「最近打开的笔记会出现在这里」（13.5px muted，不打字不轮换），垫板保留，点阵照常 |
| 仅 1 条 | 打一次 → 停留 → 光标保留，指示条只 1 条常亮，不轮换不擦除 |
| 超长标题（>26 字符） | 截断加「…」（§3） |
| 加载中（列表未就绪） | 主行空 + 光标闪烁（同打字中态），≤500ms 一般无感 |
| 取数失败 | 同空列表画面，日志记 warn，不弹错 |

## 5. 性能方案

- **泵**：20fps 限帧（`app_fluid` 同款机制），留白区不可见（滚出 / 最小化 / 设置档=关）→ 泵停，零出帧。
- **点阵首选路径（零每帧成本）**：每点 = 独立循环动画（周期/delay 一次性下发，相位 = `(r+c)*100ms`），运行期交合成器；泵只管可见性开关与降档。EUI-NEO `animate` 不支持独立 delay/iteration 时的降级路径 = 泵驱动逐帧重算相位（同公式，O(n) 遍历）。
- **点数上限量化**：600 点封顶。点数 = clamp(留白区面积 ÷ 28², 200, 600)；典型 1500×700 区按 28px 间距自然密度约 1300 点 → **密度优先降档**：间距从 28 逐级放大到 40/52px 直至 ≤600 点（1600×1000 典型窗 ≈ 36×17=612 → 间距 29px 一档即达标）。600 点 @20fps 泵驱动估算：每点相位计算 + 圆填充 ≈0.3-0.5μs → 每帧 ≤0.3ms，帧预算 50ms 占比 <1%，安全余量大。
- **减动效降级**（系统「减少动态效果」/ Windows 动画效果关）：点阵**静止**——取波中间态一帧（错落 scale/alpha 保持构图重心，运动归零）；打字机**直显**——第一条标题完整显示、光标停、不轮换不擦除。
- **设置档位**：设置页新增「留白动画」单选：组合（默认）/ 关。对齐 `fluidBackgroundEnabled` 先例扩档位枚举。

## 10. 禁止项自查
