## 3. 问题清单（修复方案见 §4）

### BUG-114-1（P1·撤销链断）
- 现象：`createUndoCard(prop_..._000001)` 失败，文案「不可撤销：原新增卡未回填引擎条目 id」。库内 `target_ids=[]`，而 S7 后加的卡回填成功。
- 根因（已实证到字符级）：采集合段文本尾带 `\n`（`session_reader.cpp` extractMessageText 每块固定补换行）；telemem/mem0 存储时剥尾空白；`telemem_client.cpp:460` `findMemoryIdByText` **精确比对**差 1 字符 → 回填空。凡段尾=文本块（生产常态）必现，Windows 上次通过属侥幸（其伪造数据段尾无换行）。
- 影响：新增记忆无法撤销（用户点了「接受」即永久，卡片给的是死循环拒绝）。

### BUG-114-2（P1·注入无相关度门槛）
- 现象：三个 prompt（改写×2 + 「今天天气怎么样」）返回**逐字节相同**的 396 字注入——负对照也把库里全部记忆塞给模型。
- 根因：telemem search 恒返回 top-k 融合段，无相似度下限；且融合段形态无逐条 score（已知坑，需-3 §5）→ DevDesk 侧事后过滤不可行，注入层照单全收。
- 影响：每次提问都被污染上下文 + 白付 token；记忆越多越严重。这是「能不能带来实际价值」的**最大单点**。

### IMP-114-3（P2·pip 包管理维护）
- `buildPipInstallArgs` 装的是**未钉版本**的 `telemem anthropic`——上游发版即漂移（telemem 1.10.1 的会话缝/工具形参/融合段形态都是 live 对账钉出来的，升级即行为面全变）；装后**无任何升级/版本检查路径**（`import telemem` 只判有无）。
- pip 失败文案只有「退出码 N，可重试」：无网络诊断、无镜像/代理指引（CN 网络 pip 官方源慢是常态，10 分钟超时后用户只会无限重试）。
- 无 PIP_INDEX_URL / 代理透传缝。

### IMP-114-4（P2·py 检测提示）
- 探测链本机动态验证 ✓：uv 管 3.12.14 命中、PATH python3.12 命中、默认 `python3`=3.15 正确拒收（本机形态：homebrew 默认已升到 3.15，**PATH 首选不合格是常态**，uv 路径命中是关键路径）。
- 失败文案「未找到 Python 3.10~3.12：请安装后点『启动引擎』重试（3.13 及以上版本暂不支持）」——**无具体安装指路**（brew install python@3.12 / uv python install 3.12 / 官网安装器三选一都没给）。主控台卡片的「点『首次安装向导』引导安装」有出口，向导内指引未逐字验。

### IMP-114-5（P2·UI 打磨）
- 主控台「跑评测」按钮在引擎未启动时未置灰（点击才报「引擎未运行」，伪可用态）。
- 「未知日期 来源:telemem」标注（融合段无 createdAt）——已知引擎侧边界，随需-3 一并对账。

## 4. 改进方案（按投入产出排序）

1. **BUG-114-1（S 级一行修+单测）**：`findMemoryIdByText` 比对前两侧 `trim()`（或 addDirect 前统一 trim 正文）；补钉版单测「尾换行文本回填」+ 重跑 e2e 探针（S4 undo 链转绿）。
2. **BUG-114-2（M 级，先 POC 后实现）**：三选一路线 POC 定案——①POC telemem search 工具是否接受阈值/min_score 参数（有则最干净，引擎侧截断）；②DevDesk 侧词面预闸：查询与记忆正文做字符 bigram / 分词重叠率阈值，低于阈值整段不注入（纯函数可单测，与需-3 注入分组渲染同一落点 `inject.cpp`）；③面板加「记忆注入」总开关（兜底，建议随②附带）。推荐 ②+③（不赌上游）。
3. **IMP-114-3（S/M 级）**：`telemem==1.10.1 anthropic` 钉版本；pip 失败文案补「检查网络/可在 PIP_INDEX_URL 配镜像后重试」并把 `PIP_INDEX_URL` 透传进安装环境；版本检查从「import 有无」升级为「import + 版本比对，不符提示面板更新」（升级机制可后置）。
4. **IMP-114-4（S 级文案）**：失败 detail 追加一句「macOS：`brew install python@3.12` 或 `uv python install 3.12`；Windows：官网安装器或 `uv python install 3.12`」（按平台拆文案，遵守平台拆文件纪律——文案可同源常量）。
5. **IMP-114-5（S 级 UI）**：引擎非 Running 态「跑评测」置灰 + tooltip。
6. **测试体系固化（debt）**：把本次配方脚本化为 `scripts/run-memory-e2e.sh`（起引擎→探针→hook 三问→红线 grep→落 evidence），纳入阶段节点回归；伪造数据含「段尾换行」形态（正好钉住 BUG-114-1 回归）。

## 5. 价值判定（用户问的「能否带来实际价值」）

- **能，但有条件**：检索质量硬数字合格（Recall@5 100%，改写问句命中——问「改完代码怎么验证」能召回含「增量构建/build-test-run.sh」的记忆，字面零重叠也命中）；脱敏闸在真实形态数据上拦截正确（多抓了 ipv4）；fail-open 不伤主链路。
