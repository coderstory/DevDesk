# 07 智能体

> 手册走查底稿。以源码实况为准（核对基准日 2026-11-18）。

## 一句话

把「提示词 + 触发（cron/手动）+ 可用工具」配成任务，由应用内调度器到点自动跑或手动跑，LLM 直连当前 Profile，带工具调用与完整运行记录；单次运行有迭代/墙钟/token 三重硬上限。

## 入口与前置（模块开关/门控）

- 侧边栏「智能体」，受模块开关控制（设置页模块卡描述：「任务列表 + 手动触发运行（依赖 Claude 代理提供模型通道）」，settings_ui_cards.cpp:397）。
- LLM 直连激活 Profile 的上游（src/module_agent/direct_llm_client.cpp）；页面无可用 Profile 时有「去 Claude 页 →」引导链（agent_module.cpp:658）。
- 数据库未就绪时页面提示「数据库未就绪（Agent 模块服务未装配）」（agent_module.cpp:699）。

## 主流程步骤（编号：操作→预期可见结果）

1. 进入页面→标题「智能体」+右上角「+ 新建任务」与「可用工具」钮（agent_module.cpp:610、635、207）。
2. 「+ 新建任务」→ 新建弹窗，第一步可一键套用 13 张出厂模板（日报草稿/发版 Changelog/测试环境巡检/…/一键系统晨检；巡检类默认每天 09:00），套用后名称/触发/提示词预填可改（docs/USER_GUIDE.md §3.7）。
3. 保存→任务列表出现任务卡（三行卡，agent_module.cpp:93）：药丸徽章（「一次性」/「限 N 次」，agent_module.cpp:112-113）、异常徽章「配置异常」「已停用」（agent_module.cpp:1062-1069）、最近运行「未运行过」或「最近运行 <相对时间>」（agent_module.cpp:1095-1096）、右下「启动」钮（运行中变「运行中…」并禁用重复点击，agent_module.cpp:1128、1035）。
4. 点「启动」→ 立即手动触发一次运行：卡片运行态；运行结束发系统通知（失败「智能体任务失败」/受限「智能体任务受限」/正常「「<任务名>」运行结束（<状态>）」，agent_module_schedule.cpp:978-984）+ 应用内提醒（agent_module.cpp:394）。
5. 「可用工具」→ 弹工具清单弹窗（随各模块启用自动注册：schedule.runs / agent.runs / memory.stats / memory.health / mcp.health / net.fetch / app.now / app.notify / app.stats / claude.* 等；模块关闭后工具消失）；工具异常回喂不中止运行（agent_loop.cpp:308、325）。
6. 点任务卡→详情弹窗：运行记录列表（状态/起止/迭代数/输入输出 token/错误，agent_store.cpp:436-437），可看逐条消息与工具调用明细（docs/design/2026-11-03、2026-11-11 三份智能体 UI 重设计文档）。
7. 触发配置编辑（agent_module_schedule.cpp）：支持 cron 与一次性触发；「试运行」= 创建临时任务「<名称>（试运行）」跑一轮后自动删除（agent_module_schedule.cpp:668-699，失败 toast/红字「试运行失败/启动失败」）。
8. 启停切换失败时页面级红字「启停切换失败：<原因>」（agent_module_schedule.cpp:711）。

## 运行硬上限（用户可见文案）

| 上限 | 值 | 触达时 run 状态与文案 | 锚点 |
|---|---|---|---|
| 迭代数 | 任务配置值，硬顶 50 | limited +「达到迭代上限 50」 | src/module_agent/agent_loop.cpp:35-36、212-213 |
| 墙钟 | min(迭代×60s, 30 分钟) | limited +「达到墙钟上限 <N>s」 | src/module_agent/agent_loop.cpp:40-41、206-208 |
| token | 累计 200K | limited +「token 累计超上限 200K（input …」 | src/module_agent/agent_loop.cpp:237-240 |
| 单条工具结果 | 32KB 截断 | 不中止，截断回喂 | src/module_agent/agent_loop.cpp:48 |
| 单次 LLM 请求 | HTTP 超时 120s | 请求失败→run failed | src/module_agent/direct_llm_client.cpp:24、287 |

## 空态·错误态

- 任务空态：「暂无任务 / 新建一个任务，让智能体按你的规则盯这件事。」+「新建任务」按钮（agent_module.cpp:715-719）。
- 运行记录空：「未运行过」（agent_module.cpp:1095）。
- 读取失败：页面/弹窗红字「读取任务失败」「读取 run 列表失败」等（agent_module_schedule.cpp:836-902）。

## 设置项联动

- 依赖 Claude 模块的激活 Profile（模型通道）；无 Profile 时页面引导「去 Claude 页 →」。
- 工具集随其它模块开关联动注册/注销（schedule/agent/memory/mcp 巡检工具，USER_GUIDE §3.7）。
- 调度依赖应用进程存活（见异常表首行）。

## 演练卡壳点

1. 「试运行」会真实创建临时任务再删除——走查断言需容忍列表瞬时出现「<名称>（试运行）」卡（agent_module_schedule.cpp:668）。
2. 手动「启动」钮运行中禁用（busy 守卫），脚本连续点击断言需先等态（agent_module.cpp:1035、1128）。
3. 系统通知依赖平台通知通道，无人值守走查时通知可能被系统聚合——以运行记录为准核。
4. 运行中的实时刷新走轮询+兜底轻查询，脚本断言状态迁移需留 wait 余量（agent_module_schedule.cpp:796-800）。
