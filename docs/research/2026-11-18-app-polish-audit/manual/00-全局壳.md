# 00 全局壳（启动 / 主窗 / 侧边栏 / 托盘 / 主题 / 数据目录 / 快捷键）

> 手册走查底稿，以源码实况为准（核对基线 commit 64378979，2026-11-18）。与 `docs/USER_GUIDE.md` 口径冲突处以本章为准，差异已标注。

## 一句话

DevDesk 主窗壳负责：启动链（splash→装配）、侧边栏页面导航、自绘标题栏（Windows）/系统标题栏（macOS）、系统托盘、模块开关门控、主题/字号/窗口效果三档与统一数据目录 `~/DevDesk`。

## 入口与前置（模块开关/门控）

- 无模块开关——壳（侧边栏/标题栏/托盘/设置/关于）恒在。
- 页面模块装配门控：登记表 `src/app_registry.h:49-68`，每行带 gatingKey；恒注册 = 首页/设置/关于（`gatingKey == nullptr`）。装配只收「开关开启」的模块（`src/app_assembly.cpp:102-108`），关闭的模块工厂不调用、侧边栏无入口。
- 模块开关默认档（`src/module_settings/settings_config.cpp:120-122`）：agent / wallpaper / mcp 默认关闭；memory 默认开启；其余页面模块默认开启。开关改动**重启应用生效**（设置页模块卡内有此提示文案）。
- wallpaper 平台能力不支持时工厂返回 nullptr、整页不注册（`src/app_registry.h:26-27`）。
- 「上线」是分组父项：父项「上线」不可导航（工厂恒 nullptr），子页「任务」「基础配置」可导航，三行同属 release 门控（`src/app_registry.h:61-65`）。

## 主流程步骤（编号：操作→预期可见结果）

1. **启动应用**（Windows：`DevDesk.exe`；macOS：`DevDesk.app`）→ 依次自动完成：创建数据目录与日志 → 打开 `devdesk.db`（首次建表）→ 数据库迁移（失败则 LOG_FATAL 终止，`src/main.cpp:210-212`）→ 按模块开关装配页面（`src/app_assembly.cpp:102-108`）→ 进入主窗。
2. **看 splash** → 启动画面总长 1.2 秒 = 0.2s 淡入 + 0.9s 进度 + 0.3s 交叉淡化；全遮盖期（0~0.9s）主界面不布局，交叉淡化期主界面照画、splash 盖顶递减（`src/app_sidebar.cpp:1330-1340`）。
3. **冷启即托盘态**（如关联启动 .md 的场景）→ 主窗不出现、仅托盘图标；此时 splash 不露脸（`src/app_sidebar.cpp:1313-1314`）。
4. **认主窗布局** → 根布局 = 自绘标题条（仅 Windows 参与，40px）+ row(侧边栏, 页面内容)（`src/app_sidebar.h:90-92`）。macOS 用系统标题栏，无自绘条（`src/app_sidebar.h:22-25`）。
5. **看侧边栏** → 展开宽 220px / 折叠宽 72px（`src/app_sidebar.h:15-17`；USER_GUIDE 写 260px 已过期）。当前页高亮；点击项切页。
6. **折叠/展开侧边栏** → 左下角折叠按钮或快捷键 Ctrl+B；折叠后只显图标，悬停出名称 tooltip；折叠态跨重启记忆（`src/app_sidebar.h:33-38`，落 `app_config` 表）。
7. **看分组** → 「上线」父项默认折叠（展开态是进程内状态、不落库）；点击父项只切换展开、不进页（`src/app_sidebar.h:53-58`）。
8. **点 ✕ 关主窗** → 隐藏到托盘，进程不退出；左键单击托盘图标唤起主窗（USER_GUIDE §2 口径，托盘行为由 `platform/tray_icon_win.cpp` 等平台实现）。
9. **右键托盘图标** → 弹托盘菜单（内容见下方清单；菜单唯一数据源 `src/core/tray_menu_spec.h:41-60`，styled 菜单窗与原生降级菜单都从它生成，文案/顺序不漂移）。
10. **二次启动程序** → 不出第二个实例，唤起已有实例（`platform/single_instance.h`；关联启动 .md 时主窗保持托盘态、仅开查看器，`src/main.cpp:534` 一带裁决）。
11. **设置页改外观** → 主题（深色/浅色/跟随系统）、字号缩放、窗口效果三档全部即时生效并持久化（`src/module_settings/settings_config.h:94-101,123`）；页面不自铺底色，半透/磨砂档由主窗 clearColor 透出（`src/module_home/home_module.cpp:384`）。
12. **设置页拨模块开关** → 卡内提示「需重启生效」；重启后侧边栏入口增减、托盘短名提示同步（关闭提示 toast 用模块短名，`src/app_assembly.cpp:326,359`）。

## 空态·错误态

- 数据库打不开且无备份：还原失败弹窗 → 应用退出（见上表）。
- 数据库损坏但有备份：自动从备份还原，损坏库隔离为 `*.db.corrupt-*` 文件，日志记「已从备份还原数据库，损坏库隔离于: <路径>」（`src/main.cpp:141-150`；隔离文件被数据根 `.gitignore` 屏蔽，`src/core/paths.cpp:56-66`）。
- 迁移失败：LOG_FATAL 终止启动（`src/main.cpp:210-212`）——用户可见形态（崩溃窗/闪退）未在代码中定义，见演练卡壳点。
- 主题/配置读取：`themeMode`（auto/light/dark）为用户意图档，`theme` 双写启动直读；字段损坏/越界自动收敛到合法范围（`src/module_settings/settings_config.h:94-96`，USER_GUIDE §3.5 口径沿用）。
