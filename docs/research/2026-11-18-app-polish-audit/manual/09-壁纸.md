# 09 壁纸

> 手册走查底稿。以源码实况为准（核对基准日 2026-11-18）。

## 一句话

视频 + 图片混合的动态桌面壁纸：轮换/随机播放、系统事件（锁屏/熄屏/睡眠/全屏/电池）自动让路暂停、解除后断点续播；片库页管理素材并支持 macOS 一键「从花見导入」。

## 入口与前置（模块开关/门控）

- 设置页模块卡「壁纸」（描述「动态桌面壁纸（视频 / 图片），开启后随 DevDesk 启动」，settings_ui_cards.cpp:413-414）——**默认关闭**，开启并重启应用后侧边栏出现「壁纸」。
- 播放引擎 mpv；平台能力不支持时模块不注册（app_registry.h 门控）。

## 主流程步骤（编号：操作→预期可见结果）

1. 进入页面→顶部页签「播放 / 片库」（wallpaper_ui.cpp:1213）；模式切换段钮「视频 / 图片」（wallpaper_ui.cpp:1200）。
2. 播放页：
   - 状态卡：当前壁纸预览 + 按钮「继续 / 暂停」（两态切换，wallpaper_ui.cpp:454）与「下一个」（wallpaper_ui.cpp:462）。
   - 播放模式卡（视频叫「播放模式」，图片叫「轮播方式」，wallpaper_ui.cpp:582）：单循环（「只播放一个视频，不轮换。」）/ 顺序循环（「按顺序播完一圈再回到第一个。」）/ 随机（「每次从清单里随机挑一个。」；图片档文案对应替换，wallpaper_ui.cpp:285-296）。
   - 「轮换间隔」卡（wallpaper_ui.cpp:618）；单循环/单张不变时提示「单循环 / 单张不变时不轮换，间隔不可用。」（wallpaper_ui.cpp:673）。
   - 「音频」折叠组：「静音」开关 +「静音时视频照常播放。」（wallpaper_ui.cpp:722-763）。
   - 「这些情况会让路」规则组：chip「全屏 / 最大化、屏幕锁定、显示器熄屏、系统睡眠」+「电池供电」开关（「关闭后，用电池时也继续播放（更费电）。」）；让路发生时组内亮显「让路中」与原因（wallpaper_ui.cpp:275-281、777-811）；说明行「前四项不可关闭。任何一项解除后自动续播，播放位置从暂停处继续——不会从头开始。」（wallpaper_ui.cpp:823）。
3. 片库页：
   - 「壁纸文件夹」卡：路径展示（未配置显「尚未选择文件夹」；目录丢失追加「 · 目录不见了」）+「选择…」「重新扫描」按钮（wallpaper_ui.cpp:902-959）。
   - macOS 额外「从花見导入…」按钮（wallpaper_ui.cpp:969）：导入中显「正在从花見导入… <done>/<total>」，完成后自动重扫；同名同大小跳过（USER_GUIDE §3.6）。
   - 扫描计数：视频参与轮播数 / 图片「参与轮播」「低于档位」计数（wallpaper_ui.cpp:1056-1060）；扫描中显「正在扫描…」（wallpaper_ui.cpp:1033）。
   - 格式说明卡：「仅扫描 mp4 / mov / m4v；其他格式不会出现在片库，也不会自动转码。」（图片档「仅扫描 jpg / jpeg / png / webp / heic；低于分辨率档位的图片不参与轮播。」，wallpaper_ui.cpp:1085-1086）；补充「目录里的 MKV / AVI / WEBM 不会被扫描。需要其他格式时，请先自行转成 mp4。」（wallpaper_ui.cpp:1105）。
   - 「分辨率筛选」卡（1080P/2K/4K 档，各档有阈值说明文案，wallpaper_ui.cpp:328-332）；「图片适配」卡四选一「填充（默认，铺满裁边）/ 适应（留黑边）/ 居中 / 平铺」（wallpaper_ui.cpp:339-347、1144）。
4. 页脚「壁纸引擎 mpv · GPL v2 · 设置即时生效」（wallpaper_ui.cpp:1176）。

## 空态·错误态

- 未选文件夹：状态卡主按钮变「选择文件夹…」、次按钮「重新扫描」（wallpaper_ui.cpp:504-505）。
- 目录丢失：路径行追加「 · 目录不见了」（wallpaper_ui.cpp:919）。
- 扫描空/全被过滤：计数行显示「参与轮播 0 / 低于档位 N」。
- 播放错误：播放页状态卡显示 playbackError 文案（如「显示壁纸宿主失败」或 mpv 上抛错误，wallpaper_service.cpp:698-701、812-819）。

## 设置项联动

- 模块开关默认关、开启后随应用启动（settings_ui_cards.cpp:413-414）。
- 让路规则与系统事件联动：锁屏/熄屏/睡眠/全屏窗口/电池供电（电池项可关，前四项不可关）。
- 设置即时生效（页脚文案，wallpaper_ui.cpp:1176）。

## 演练卡壳点

1. 「从花見导入」仅 macOS 且依赖花見 App 与完全磁盘访问权限——Windows 机走查此路径只能验证按钮不出现。
2. 让路场景（锁屏/熄屏/睡眠）无法在 UI 驱动脚本里模拟，需人工或系统事件触发后回看「让路中」亮显。
3. 壁纸引擎依赖 mpv：走查前需确认目标机 mpv 可用，否则「播放错误」空态无法区分引擎缺失与素材问题。
4. 「选择…」弹的是系统文件夹选择对话框（原生控件，不在 devdesk_ui_driver 射程）。
