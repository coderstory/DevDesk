# 03 Git（Git 模块）用户手册

> 依据源码实况编写（2026-11-18）：src/module_git/。**与任务简报预期的差异**：本模块是只读查看器，无 stage/unstage/commit/分支操作/网络操作——以实现为准（git_views.cpp:215「只读查看器…不做任何修改」）。

## 一句话

侧边栏「Git」是本地仓库只读查看器：选择仓库目录后浏览文件树、查看工作区变更与 unified diff、全仓内容搜索；不做任何写操作、无网络功能。

## 入口与前置（模块开关/门控）

- 入口：侧边栏第 3 项「Git」（`src/app_registry.h:52`）。
- 门控：设置页模块开关 `kModuleIdGit`（`src/app_registry.h:40,52`）。
- 仓库记忆：上次选择的仓库持久化记忆（`src/module_git/git_repo_store.cpp`），下次进入自动打开。

## 主流程步骤（编号：操作→预期可见结果）

1. 点侧边栏「Git」→ 首次为空态页：标题「查看你的 Git 仓库」、说明「只读查看器：浏览文件、查看变更与 diff，不做任何修改。」、绿色主按钮「选择仓库目录」（`git_views.cpp:205-253`）。
2. 选择仓库：点「选择仓库目录」→ 系统目录选择器（标题「选择 Git 仓库目录」，`git_page_controller.cpp:191`）→ 校验通过进入三栏主界面；目录无效 → 错误条「该目录不是 git 仓库」/「没有权限访问该目录」（`git_page_controller.cpp:23-24`）。
3. 主界面三栏：左侧文件树（Tab「全部文件 / 仅修改」，`git_views.cpp:564-567`）；中部变更列表（分「变更 / 未跟踪」两组，`git_changes_model.cpp:64`）；右侧「内容 / diff」双 Tab（`git_views.cpp:1315`）。顶栏为路径 + 搜索框「搜索全仓内容…」+「↻ 刷新」+「切换仓库」（`git_views.cpp:315,379-381`）。
4. 状态刷新：点「↻ 刷新」手动刷新；文件保存后列表自动更新（1s 节流，提示「保存文件后列表会自动更新（1s 节流）」，`git_views.cpp:770`）；FileWatcher 不可用降级 2s 轮询（`git_module.cpp:44`）。
5. diff 查看：右侧切 diff Tab → unified diff，行号/高亮六类；hunk 头或折叠条单击折叠/展开；「··· 展开早期未变更行（N 行）」（`git_views.cpp:1072`）。重命名文件头显示「old → new」，树中显「← 原 <旧路径>」（`git_views.cpp:698`）。
6. 全仓搜索：顶栏搜索框输入，Enter 提交、ESC 或清空取消（`git_views.cpp:306`）→ 头部「正在扫描… X/Y 文件」→「N 处命中 · M 个文件」；结果浮层逐条显示 文件:行 + 高亮预览，点击跳转；单文件 5 条上限（「· 此文件还有更多」）；超 200 条提示「结果过多，仅显示前 200——请细化关键词」（`git_views.cpp:1438-1446,1521`）。
7. 切换仓库：点「切换仓库」→ 重新走目录选择器。
8. stage/unstage/commit/分支操作：**不存在**（只读模块）。

## 空态·错误态

- 文件树行内状态：「空目录」「不可访问」「子仓库」「无法读取：<原因> + 重试」（`git_views.cpp:429-438,466,509,519`）。
- 变更列表：「工作区无变更」（仅修改 Tab：「无可显示文件」）；「无法获取变更：<原因>」（`git_views.cpp:600,749,762`）。
- 内容页：「空文件 / 文件无内容。」「二进制文件 / 不预览二进制内容。」「文件过大，未加载内容（>1 MiB）/ 仅预览 1 MiB 以内的文本文件。」「暂不支持该编码 / 文件不是有效的 UTF-8 文本。」「无法读取文件 + 重试」「内容已过期，点击重载」（`git_views.cpp:918-956,1368`）。
- diff：「二进制文件，未显示内容差异」「无内容变更」「无法计算差异 + 重试」（`git_views.cpp:1202-1250`）。
- 搜索：「搜索失败」「无法完成搜索」「未找到匹配内容」（`git_views.cpp:1441,1475,1493`）。

## 设置项联动

- 无模块专属设置项；仅模块开关门控。仓库记忆文件损坏按无记忆处理（仅日志，用户不可见，`git_repo_store.cpp:46-51`）。

## 演练卡壳点

1. 冲突文件（双方修改）在变更列表的具体分组与文案需实操确认（见异常表「未知」）。
2. 「切换仓库」后右侧 diff/搜索浮层是否清空复位需实操确认。
3. 「仅修改」Tab 与全仓搜索结果跳转的组合行为需实操核对。
4. 记忆仓文件损坏仅日志可见（git_repo_store.cpp:46-51），走查时用户视角无法触发可见反馈。
