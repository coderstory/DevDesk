## 一句话

全局配置页：外观（主题/字号/窗口效果）、模块开关、笔记目录、Claude 代理、MCP 服务、提醒弹窗、日志（保留/级别/查看）、GitHub 同步、md 关联、项目卡等，按模块开关动态显隐部分卡片。

## 入口与前置（模块开关/门控）

- 侧边栏「设置」（恒开，无开关）；或首页右上「⚙ 设置」。
- 卡片动态显隐：笔记目录卡仅 Markdown 开启时出现；Claude 代理卡仅 Claude 开启时出现（docs/USER_GUIDE.md §3.5）；MCP 服务卡、GitHub 同步卡、md 关联卡等亦随对应模块/平台条件显隐。

## 主流程步骤（编号：操作→预期可见结果）

1. 进入→卡片区可滚动，自上而下常见卡：
2. **外观卡**：主题「深色 / 浅色」；字号缩放「小 85% / 标准 100% / 大 115% / 特大 130%」全局即时生效；窗口效果「关闭（默认）/ 半透 / 磨砂（Mica）」，系统不支持自动回退并提示（docs/USER_GUIDE.md §3.5）。
3. **模块卡**：标题「模块」，说明「开关即时生效：关闭后该模块代码不再执行，侧边栏入口与页面当帧更新」（settings_ui_cards.cpp:430-433）。9 个开关网格排列：Markdown 笔记本 / Todo 看板 / 定时 / Claude 配置切换器 / 智能体 / 记忆 / 壁纸（默认关）/ MCP / 上线；每项带描述（智能体「任务列表 + 手动触发运行（依赖 Claude 代理提供模型通道）」、记忆「telemem 记忆引擎面板（引擎未安装时仅显示引导，无后台成本）」、MCP「MCP 服务器接入配置与管理」、上线「任务执行与基础配置（两个子页同开同关）」、壁纸「动态桌面壁纸（视频 / 图片），开启后随 DevDesk 启动」，settings_ui_cards.cpp:397-414）。
   **差异**：USER_GUIDE §3.5 写「重启应用生效」；实现卡内文案为「开关即时生效…当帧更新」。以实现为准走查（但注意 ClaudeService 等服务类模块会话内重开可能未装配——Claude 页有「本会话内开启的模块需重启后才能提供代理服务」提示，claude_module.cpp:107-108）。
4. **Markdown 笔记目录卡**（仅 Markdown 开启时）：只读路径 +「打开目录」（目录不存在先创建再打开）。
5. **Claude 代理卡**：「随应用启动代理」开关；运行胶囊「运行中 :<端口> / 未运行」+ 接管胶囊「已接管 / 未接管」+「接管文件：<路径>」（未运行时提示「启动代理后自动接管 Claude Code，停止时还原原配置」）；「代理端口」输入框 +「应用」（说明「改后回车或点「应用」；运行中自动重启」）；认证 Token 只读脱敏、眼睛按钮临时显形、离开本页恢复掩码、「重新生成」；「同步警告」区透出接管/还原警告（settings_ui_cards.cpp:563-734）。
6. **MCP 服务卡**：状态「运行中 127.0.0.1:<端口> / 已停止 / 启动失败：<原因>」；「MCP 端口」+「应用」（「改后回车或点「应用」；运行中自动重启」）；「运行状态」行（settings_ui_cards.cpp:808-883）。
7. **提醒弹窗卡**：说明「到期与调度事项弹全屏置顶窗，默认关闭」；开关「上线提醒弹窗」「调度全屏弹窗」（settings_ui_cards.cpp:947-985）。
8. **日志卡**：「日志保留」下拉「永久保留 / 7 天 / 30 天（默认）/ 90 天 / 180 天 / 365 天」（切换立即清理一次，hint「0 = 永久保留；30 天为默认。切换档位立即清理一次。」）；「日志级别」DEBUG/INFO（hint「DEBUG 最详尽（排障）；默认 INFO。切档即时生效。」）；「运行日志（末尾 100 行）」+「刷新」钮（空态「（暂无日志内容，或日志文件尚未生成，或均低于所选级别）」）（settings_ui_cards.cpp:1029-1191）。
9. **GitHub 同步卡 / md 关联卡 / 项目卡**：随 Git/Markdown 模块显隐（github_sync_card.cpp / md_assoc_card.cpp / project_cards_card.cpp；md 关联四态状态字+平台引导，git log 382eed93）。

## 空态·错误态

- 日志空态：「（暂无日志内容，或日志文件尚未生成，或均低于所选级别）」（settings_ui_cards.cpp:1191）。
- MCP 启动失败：状态胶囊「启动失败：<原因>」（settings_ui_cards.cpp:819）。
- 端口配置非法：自动回落默认 8888 并 LOG_WARN（proxy_runtime.cpp:112-115）；config.json 损坏/字段缺失自动回退默认值、数值越界收敛（docs/USER_GUIDE.md §3.5）。
- 保存失败类：记忆/MCP 等卡内红字透传 Result 错误。

## 设置项联动（本页即联动枢纽）

- 模块开关 → 侧边栏入口与页面当帧更新；各模块卡显隐联动。
- Claude 代理卡 ↔ Claude 页代理状态/接管状态同源。
- MCP 服务卡 ↔ MCP 页服务状态同源。
- 日志保留 ↔ 调用日志清理；日志级别 ↔ 运行日志查看过滤。
- 提醒弹窗 ↔ 上线模块提醒窗与调度全屏弹窗（默认关闭）。
- 外观 ↔ 全局主题/字号/窗口效果；终端「配色主题·跟随应用」联动主题档。

## 演练卡壳点

1. 模块开关「即时生效 vs 重启生效」与 USER_GUIDE 矛盾——走查逐个开关验证：页面/侧栏是否当帧更新、服务类是否需重启，并回填结论。
2. 「打开目录」「浏览」等走系统资源管理器/文件对话框，UI 驱动射程外，需人工验证。
3. 「重新生成 Token」会换 Token——代理运行中替换后，手工配置过 Token 的客户端需同步更新（走查留意是否自动重接管）。
4. 提醒弹窗卡默认关闭：走查上线提醒需先在此开启。
