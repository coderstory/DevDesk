# 01 首页（工作台）

> 手册走查底稿，以源码实况为准（核对基线 commit 64378979，2026-11-18）。与 `docs/USER_GUIDE.md` 差异：统计卡为 **5 张**（新增「Token 速率」）、页头标题为「工作台」、右上角**只有「刷新」按钮（设置按钮已移除）**。

## 一句话

首页是导航枢纽：5 张统计卡 + 今日 token 图表卡 + 最近编辑列表 + 底部快捷按钮，全部数据直读本机库，点击跳转到对应模块。

## 入口与前置（模块开关/门控）

- 恒注册模块（`gatingKey == nullptr`），无开关、侧边栏第一项（`src/app_registry.h:50`）。
- 应用启动后默认落在首页；托盘「显示主窗口」唤回的也是主窗当前/默认页。
- 首页自身不可被关闭；它引用的**目标模块**可被关闭——快捷按钮按模块注册态显隐，统计卡与图表卡**恒显**（need270：统计是事实，与开关无关，`src/module_home/home_module.cpp:377-405`）。

## 主流程步骤（编号：操作→预期可见结果）

1. **进入首页**（启动落首页，或侧边栏点「首页」）→ 页面标题「工作台」+ 右上「刷新」按钮（Standard Outline 绿描边，`home_module.cpp:459-504`）；**每次进页自动重查全部统计**（`onPageEnter`→`refreshStats`，`home_module.cpp:324`）。
2. **看 5 张统计卡**（一行网格，窄窗自动减列、超宽屏最多 5 列，`home_module.cpp:408-413`）：
   - `Token 速率`：最近一次成功代理调用的速率（tok/s），无成功调用显 `--`；流式中数字主色 + 绿 badge + sparkline 实时曲线（`home_module.cpp:513-528`）。
   - `今日笔记`：今日修改过的笔记数。
   - `待办任务`：未完成总数。
   - `逾期任务`：已过截止时间未完成数。
   - `API 调用`：今日代理调用次数。
   - 数据源 = home_service 直读 `claude_call_logs` / `markdown_index` / `todo_tasks`（`home_module.cpp:378-379`）。
3. **点击任一统计卡** → 跳转到对应模块页（Token 速率/API 调用→Claude 页，今日笔记→Markdown 页，待办/逾期→Todo 页，`home_module.cpp:244-250` 的 target 列）。
4. **看今日 token 图表卡** → 小时用量分布图（基准高 220，折叠态只剩标题行 64 高；折叠状态**跨会话记忆**，`home_module.cpp:311-314`）；卡高随窗口余高伸展，矮窗由整页滚动条吸收（`home_module.cpp:386-431`）。
5. **折叠/展开图表卡** → 点卡内折叠钮 → 只留标题行；再点恢复。
6. **看最近编辑列表** → 最近编辑过的前 5 篇笔记（`kRecentNoteLimit = 5`，`home_module.cpp:992`）：标题（无标题显文件名）+ 相对时间 + 所在目录。
7. **点击最近编辑一行** → 跳 Markdown 页并直接打开那一篇。
8. **点底部快捷按钮**（按模块注册态显隐，`home_module.cpp:402-406`）：
   - `+ 新建笔记` → 跳 Markdown 页并自动弹出新建笔记弹窗（payload `action:new_note`）。
   - `+ 新建任务` → 跳 Todo 页并自动弹出新建任务弹窗（payload `action:new_task`）。
   - `切换 Claude Profile` → 跳 Claude 页（Profile 列表在该页）。
9. **点右上「刷新」** → 重查全部统计与最近速率；停留页内期间数字不自动更新，需要时手动点（`home_module.cpp:323-324,501`）。

## 设置项联动

- 首页无独立设置项；字号缩放影响全部卡片高度与网格行数（统计行高按 `fontScale` 派生，`home_module.cpp:407`）。
- 主题/窗口效果：页面不铺底色，透出主窗材质（`home_module.cpp:384`）。
- 模块开关：只影响 3 个快捷按钮的显隐（`home_module.cpp:402-406`）；统计卡/图表卡恒显。

## 演练卡壳点

1. 「Token 速率」与「API 调用」两张卡都跳 Claude 页，口径差异（速率=最近一次成功调用；调用数=当日计数）只在 tooltip/数字层体现，走查时确认卡片悬停说明是否把口径讲清。
2. 最近编辑行的「相对时间/目录」具体文案格式以实机截图为准（本稿沿用 USER_GUIDE 口径，列字段由 `home_service.cpp` 查询、逐字文案未逐行核对）。
3. 图表卡标题行的完整文案与折叠钮位置未逐字核对（走查时截图对照）。
4. 首页在 85% 字号 + 超宽屏（5 列）组合下的行数/留白表现需实机看一眼（网格公式已处理，视觉档未截图验证）。
