# 04 待办（Todo 看板）用户手册

> 依据源码实况编写（2026-11-18）：src/module_todo/。**与任务简报预期的差异**：列模型为固定四列，「建列/列改名/列右键菜单」入口已随固定四列删除（`todo_module.cpp:1083`）——以实现为准。

## 一句话

侧边栏「待办」是固定四列看板（待办/进行中/已完成/已归档）：建任务、拖拽或键盘移动、优先级/截止/标签/搜索、逾期提示与归档；数据存应用数据库 devdesk.db。

## 入口与前置（模块开关/门控）

- 入口：侧边栏第 4 项「待办」（`src/app_registry.h:53`）。
- 门控：设置页模块开关 `kModuleIdTodo`（`src/app_registry.h:40,53`）。
- 数据位置：`<数据根>/devdesk.db`（`src/core/paths.cpp:42`，数据根 = `~/DevDesk` / `%USERPROFILE%\DevDesk`）。默认四列由 schema 种子创建：「待办」「进行中」等（`src/core/schema.h:541-545`，kind = todo/doing/done/archive）。
- 智能体工具 todo.list/create/update/move/complete/delete 共用同一数据面（`todo_tools.cpp:176-465`）。

## 主流程步骤（编号：操作→预期可见结果）

1. 点侧边栏「待办」→ 页头「Todo 看板」+ 搜索框（placeholder「搜索」）+「逾期 N」chip +「新建任务」按钮（`todo_ui_board.cpp:121-202`）。
2. 新建任务：点「新建任务」→ 弹窗「新建任务」：提示「将创建在「<列名>」列」、标题框 placeholder「任务标题，回车直接创建」、描述「补充说明…」、优先级 无/低/中/高、截止日期「今天 / 明天 / 选择…」、标签（`todo_ui_dialogs.cpp:219-330`）→ 创建后卡片出现在目标列；标题为空拒绝「任务标题不能为空」（`todo_module.cpp:274`）。
3. 拖拽跨列：按住卡片拖动 → 跟手副本 + 目标列插入行 placeholder → 松手落位（插到该卡前；列尾空白区 = 追加，`todo_ui_logic.h:299,327-332`）。归档列不可拖出（`todo_module.cpp:537`）。
4. 键盘与右键：点击卡片选中 → Ctrl/Cmd+↑↓ 上移/下移（未选中提示「先点击卡片选中任务，再用 Ctrl+↑/↓ 移动」，`todo_module.cpp:1030`）；右键卡片菜单：编辑 / 上移 / 下移 / 移到「<其他列>」（每列一项）/ 删除（`todo_module.cpp:876-907`）。
5. 完成/取消完成：详情弹窗按钮「标记完成 / 取消完成」（`todo_ui_dialogs.cpp:895`）；跨列拖入/拖出「已完成」列等效（`todo_service.cpp:751-770`）。
6. 截止与逾期：卡片显示截止「MM-DD」；按自然日口径——截止日=今天整卡橙黄（不算逾期），逾期未完成红（`todo_ui_logic.h:498,509-518`）。页头「逾期 N」chip 点击 → 弹窗「逾期任务（N）」，行=「任务名 · 所属列 · 截止 · 逾期天数，点击行跳转详情」，超量提示「仅显示前 N 条」（`todo_ui_dialogs.cpp:589-598`）。
7. 标签：详情弹窗「标签」区输入添加（placeholder「+ 添加标签，回车添加」，`todo_ui_dialogs.cpp:1155`）；新建弹窗亦可带标签。
8. 搜索：页头搜索框输入 → 仅保留命中卡片（列内排序不变，`todo_ui_logic.h:397`）；无命中 → 列空态「无命中任务 / 换个关键词，或清掉搜索条件。」（`todo_ui_board.cpp:612-613`）。
9. 归档：拖入「已归档」列即归档；归档列折叠为窄条（约 25% 宽），点列头「展开归档」展开（`todo_ui_board.cpp:593`）；归档详情为「任务详情（只读）」（`todo_module.cpp:818`），显示「归档时间: …」；仅展示最近 N 张「另有 N 张较早归档未展示」（`todo_ui_board.cpp:709-711`）；按归档时间倒序，不支持手动移动（`todo_module.cpp:569`）。
10. 关联文档：详情弹窗「关联文档」→「选择文档…」→ 弹窗「关联文档」（「选择一篇笔记作为任务的详细说明（点击即关联）」；Markdown 未启用 → 「无可用笔记（Markdown 模块未启用或笔记目录为空）」，`todo_ui_dialogs.cpp:1345-1352`）；可「解除关联」。

## 弹窗·菜单·浮层清单（名称/触发/内容/关闭方式）

| 名称 | 触发 | 内容 | 关闭方式 |
|---|---|---|---|
| 新建任务 | 页头「新建任务」/跨模块跳转 | 见主流程 2 | 取消 / 创建（回车直达） |
| 任务详情 | 点卡片 / 右键「编辑」 | 标题、描述、优先级、截止日期（「选择日期…/清除」）、标签、关联文档；归档列内只读；底部「删除 / 标记完成(取消完成) / 保存 / 取消 / 关闭」（`todo_ui_dialogs.cpp:862-1302`） | 关闭 / 取消；未保存改动点遮罩 → 警告「有未保存修改：点「保存」落库，或再点一次遮罩放弃」（`todo_ui_dialogs.cpp:729`） |
| 删除任务确认 | 详情「删除」/右键「删除」 | 「将删除任务「<标题>」，不可恢复。」按钮「删除/取消」（`todo_ui_dialogs.cpp:447-461`） | 取消 / 删除 |
| 逾期任务（N） | 页头「逾期 N」chip | 逾期任务行列表，点击行跳详情（`todo_ui_dialogs.cpp:589`） | 关闭弹窗 |
| 关联文档 | 详情「选择文档…」 | 笔记列表点选关联 | 关闭 |
| 任务右键菜单 | 卡片右键 | 编辑/上移/下移/移到「X」/删除 | 点项执行 / 点外关闭 |

## 空态·错误态

- 加载失败：看板横条「数据加载失败：<原因>（点击重试）」+「重试」按钮（`todo_ui_board.cpp:221-238`）。
- 数据库未就绪：「数据库尚未就绪，数据未加载」（`todo_ui_board.cpp:221`）。
- 空列：「暂无任务」；归档空：「暂无归档」；搜索无命中：「无命中任务」。
- 零列（固定四列下正常不可达）：「还没有任何列 / 列是任务的分组…」（`todo_ui_board.cpp:257-259`）。
- 写操作失败走页头状态条：「移动失败：」「删除失败：」「保存失败：」「标记完成失败：」「新建任务失败：」「未找到待办列，无法新建任务」「关联文档需要 Markdown 模块启用」（`todo_module.cpp:278-373,618,828`）。

## 设置项联动

- 模块开关门控；视图状态（上次选中任务、列折叠）存 app_config（`todo_module.cpp:439,451`）；跨模块跳转负载打开新建弹窗（`todo_module.cpp:607`）；GitHub Sync 导入库后自动重载「检测到库导入，已重载看板数据」（`todo_module.cpp:913-915`）。

## 演练卡壳点

1. 页头「新建任务」弹窗「将创建在「X」列」——顶栏入口时目标列是否恒为「待办」需实操确认。
2. 卡片标题/描述超长的显示（截断 or 撑高）需实操确认（见异常表「未知」）。
3. 逾期弹窗「仅显示前 N 条」的具体上限值需实操确认。
4. 归档入口除「拖入已归档列」外是否还有按钮（详情弹窗未见「归档」按钮）需实操确认。
5. 固定四列后「还没有任何列」空态是否仍可达（正常不可达）。
