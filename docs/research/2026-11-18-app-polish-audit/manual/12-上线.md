# 12 上线（任务 + 基础配置）

> 手册走查底稿。以源码实况为准（核对基准日 2026-11-18）。

## 一句话

按日期跟进发布准备的上线任务管理：任务子页管「哪个服务、哪天、走到哪一步」，基础配置子页维护「服务目录 + 环境定义」，到期事项弹「上线提醒」。

## 入口与前置（模块开关/门控）

- 侧边栏「上线」为**分组父项，不可导航**；子页「任务」「基础配置」两项可点（src/app_registry.h:49-68）。
- 模块卡「上线」描述「任务执行与基础配置（两个子页同开同关）」（settings_ui_cards.cpp:403-404）。
- 新建任务前需在「基础配置」至少建好一个环境（否则弹窗内提示「基础配置里还没有环境」，release_dialogs.cpp:418）。

## 主流程步骤（编号：操作→预期可见结果）

### 任务子页

1. 进入→页签「全部 / 发布中 / 准备中 / 已归档」（release_list_ui.cpp:707-710）+「新建任务」钮（release_list_ui.cpp:349）；标题区「上线任务」（release_list_ui.cpp:340）。
2. 任务卡：状态 chip「草稿 / 待执行 / 执行中 / 已完成 / 已作废」（release_list_ui.cpp:659-663；已作废半透明 kVoidedOpacity）、副行「下一步 · <步骤>」（release_list_ui.cpp:211）、迷你进度条与 n/n 计数、环境 chip。
3. 「新建任务」→ 弹「新建上线任务」：「计划上线日期」选择 + chip「常规发布日 / 非常规发布日」（周二/周四为常规）；「加入环境（可多选）」；底部预览「已选 N 个环境，将带入 M 个服务」/「尚未选择环境」（release_dialogs.cpp:339-460）。
4. 选了非常规发布日→先弹「非常规发布日」二次确认：「所选日期不是周二/周四，确定要建吗？」按钮「确定要建 / 取消」（release_dialogs.cpp:523-537）；换日期后旧确认作废（release_dialogs.cpp:509）。
5. 点任务卡进详情：按环境分节展示步骤；步骤确认/跳过操作；修改已确认内容触发自动撤回——「配置已修改，已自动撤回 N 项旧确认」（release_detail_ui.cpp:100）；撤回失败显 notice「自动撤回合并分支失败：<原因>」/「自动撤回配置步骤失败：<原因>」（release_detail_ui.cpp:57、85）。
6. 到期/调度事项→「上线提醒」弹窗（全屏置顶，可开关）：标题「上线提醒 · N 个任务」、分组行「上线日 <日期> · …」「环境 · <名>」、按钮「去处理」（release_reminder.cpp:586-780、816-831）；「Esc 或右上角关闭；全部处理完成后本窗自动关闭」（release_reminder.cpp:961）。

### 基础配置子页

7. 页签「服务目录 / 环境定义」（release_config_ui.cpp:576）；「新增服务 / 新增环境」钮（release_config_ui.cpp:567）。
8. 服务弹窗（「新增服务 / 编辑服务」）：「名称」（占位「必填，同一目录内不可重名」）、「类型」（后端类型显示「该类型固定 5 项配置：nacos · 数据库 · 定时任务 · 菜单 · 网关」，其他类型「该类型无配置项」）、「默认分支」（占位「新建任务时预填，可改；不做格式校验」）；按钮「保存 / 取消」（release_config_ui.cpp:691-775）。
9. 环境弹窗（「新增环境 / 编辑环境」）：「名称」（占位「如 EM / EU / AM / US」）、「包含服务」多选（「已选 N 个」）、「时间窗」开始/结束 HH:MM（说明「结束 ≤ 开始 = 次日」「跨零点示例：22:00–02:00 显示为 22:00–02:00(次日)；09:00–09:00 = 24 小时窗」）（release_config_ui.cpp:800-954）。
10. 删除服务/环境→确认弹窗（「删除服务 / 删除环境」）：被环境引用的服务显「「<名>」被 N 个环境引用；删除后将自动从这些环境摘除。确认删除？」，否则「将从服务目录移除，此操作不可恢复。」（release_config_ui.cpp:975-1012）。

## 空态·错误态

- 任务空态：「还没有上线任务 / 创建一个上线任务，按日期跟进发布准备」+「新建任务」（release_list_ui.cpp:427-430）；某页签空：「暂无<页签名>的任务 / 切回「全部」查看其它任务」+「查看全部」（release_list_ui.cpp:441-444）。
- 列表加载失败：「无法加载任务列表 + <原因>」+「重试」（release_list_ui.cpp:461-483）；追加加载失败：「加载失败 + 重试」（release_list_ui.cpp:567-590）；首屏「加载中…」骨架至少 100ms（release_list_ui.cpp:752）。
- 详情读取失败：loadError「任务 id 无效 / 读取任务失败：<原因> / 任务不存在 / 读取任务日志失败：…」等逐级文案（release_detail_ui.cpp:155-211）。
- 基础配置空：「服务目录为空，请先到「服务目录」新增服务」（release_config_ui.cpp:866）；环境空进新建任务见前置。
- 服务重名/时间格式错：表单内红字「名称已存在，请换一个」「名称不能为空」「开始/结束时间格式应为 HH:MM（00:00–23:59）」（release_config_ui.cpp:602-653）。

## 设置项联动

- 模块开关「上线」两子页同开同关。
- 「上线提醒弹窗」开关（设置页「提醒弹窗」卡，默认关闭，settings_ui_cards.cpp:947-985）；与「调度全屏弹窗」并列。
- 提醒的到期判定基于任务的计划上线日期与环境时间窗（release_reminder.cpp）。

## 演练卡壳点

1. 分组父项「上线」不可导航——脚本需直接点子页项，别按父项定位。
2. 「新建任务」依赖基础配置已有环境；走查顺序必须先建环境再建任务，否则断言空态文案。
3. 非常规发布日弹窗是双层弹窗（新建弹窗之上再叠确认），脚本按最上层元素定位。
4. 追加加载是触底触发（余量 24px），脚本需 scroll 到底部再等「加载中…」（release_list_ui.cpp:85、495）。
