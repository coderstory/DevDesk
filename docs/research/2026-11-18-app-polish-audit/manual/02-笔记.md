# 02 笔记（Markdown 模块）用户手册

> 依据源码实况编写（2026-11-18）：src/module_markdown/。与 USER_GUIDE 概述冲突处以本稿为准。

## 一句话

侧边栏「笔记」以普通 .md 文件方式管理笔记：目录树 + 四态视图（编辑/实时/双栏/预览）+ 标签 + 中文全文搜索 + 大纲跳转，400ms 自动保存落盘，写盘后在后台静默 git 自动提交。

## 入口与前置（模块开关/门控）

- 入口：侧边栏第 2 项「笔记」（`src/app_registry.h:51`）。
- 门控：设置页模块开关 `kModuleIdMarkdown`，关闭后侧边栏不显示该项（`src/app_registry.h:40,51`，gatingKey 机制）。
- 数据位置：笔记为普通 .md 文件，根目录启动时自动创建（`src/module_markdown/md_file_open.cpp:41`）；全文索引存应用数据库 `markdown_fts` 表（`src/module_markdown/markdown_service.cpp:405`）。
- 仅 .md 进树/索引（`src/module_markdown/md_file_open.cpp:71` 注释）。

## 主流程步骤（编号：操作→预期可见结果）

1. 点侧边栏「笔记」→ 三栏布局：左栏目录树（顶部搜索框 placeholder「搜索」+「标签」筛选区，`md_module_tree.cpp:222,302`）、中部内容区、页头（标题、四态 Tab、问号快捷键帮助、「大纲」开关、「新建笔记」绿色主按钮，`markdown_module.cpp:389,416-459`）。未打开笔记时中部空态「还没有打开笔记 / 从左栏选一篇笔记开始编辑。」（`markdown_module_internal.h:553-554`）。
2. 新建笔记：点「新建笔记」→ 弹窗「新建笔记」，输入框 placeholder「笔记名，可用 / 分文件夹，如 工作/周会」，提示「保存到：根目录 · 名字可带子目录，如 工作/周会.md」（`md_module_menu_poll.cpp:34-52`）→ 点「创建」→ 树中出现新笔记并打开。
3. 编辑与自动保存：编辑器 placeholder「在这里写 Markdown…」（`md_module_editor.cpp:46`）。停止输入 400ms 自动落盘（`markdown_module_internal.h:985`），底部状态栏依次「● 未保存」→「✓ 已保存 HH:MM」（`md_module_editor.cpp:276-281`）；右侧状态「行:列 · N 字 · N 篇笔记」（`md_module_editor.cpp:307,335-339`）。
4. 四态切换：页头 Tab「编辑 / 实时 / 双栏 / 预览」（`markdown_module.cpp:389`）。实时态：点击渲染块就地编辑、Ctrl+Z/Y 撤销重做、IME 组字期间冻结切块（`md_module_preview.cpp:923-930,1108-1127`）；预览态：点击块跳回编辑器对应行（`md_module_preview.cpp:1179-1183`）。
5. 目录树操作：右键文件 → 菜单「重命名 / 删除笔记」（`md_module_menu_poll.cpp:367`）；右键文件夹 → 「新建子目录 / 新建子笔记 / 重命名 / 删除」（`md_module_menu_poll.cpp:403`）。树顶「根目录」组常显（`md_tree.cpp:71,96`）。
6. 标签管理：编辑器标签区输入框 placeholder「添加标签」，回车添加（`md_module_editor.cpp:247`）；toast「已添加标签 / 已删除标签」（`md_module_editor.cpp:484,504`）；点标签筛选左栏列表（`md_module_editor.cpp:449`）。
7. 搜索：左栏搜索框输入 → 标题/正文过滤，FTS5 MATCH + LIKE 双路（`markdown_service.cpp:888-913`），中文按子串匹配。
8. 大纲跳转：开「大纲」开关（`markdown_module.cpp:439-446`）→ 右侧「大纲」面板列出标题（空态见下），点击跳转（`md_module_preview.cpp:1222`）。
9. 外部编辑冲突：应用外改文件 → toast「检测到外部修改，已自动重载」（`md_module_menu_poll.cpp:316`）；本地有未保存编辑时不覆盖，冲突提示「…与未保存的本地编辑冲突。✕ 关闭 = 保留本地编辑」（`markdown_module.cpp:518`，`md_module_menu_poll.cpp:329`）。
10. git 自动提交：写盘成功后 5 分钟节流，后台线程 git add -A + commit（`md_note_git.h:2-3,89-91`）。全程无 UI；git 不在 PATH 或 init 失败 → 功能整体静默禁用（`md_note_git.h:4,86`）。

## 空态·错误态

- 无笔记：树仅「根目录」组 + 空态提示（`md_tree.cpp:96`）。
- 未打开笔记：「还没有打开笔记 / 从左栏选一篇笔记开始编辑。」
- 大纲面板：「先打开一篇笔记」/「没有标题\n用 # 开始一行即可加入大纲」，无标题条目显「(无标题)」（`md_module_preview.cpp:75-76,131`）。
- 预览空态：「选择笔记后在这里看到渲染结果」（`md_module_preview.cpp:177`）。
- 保存失败：状态栏「✕ 保存失败，自动重试中」+ toast「保存失败…已自动重试」（`md_module_editor.cpp:273,531-540`）。
- 其他 toast：「标签筛选失败」（`md_module_tree.cpp:627`）、「加载标签失败」（`md_module_editor.cpp:431`）、「自动重扫失败」（`md_module_menu_poll.cpp:199`）、「重载失败」（`md_module_menu_poll.cpp:243`）。

## 设置项联动

- 设置页模块开关（门控见上）；编辑器字号偏好落库（`md_module_editor.cpp:417-419`，页内步进）；视图状态存 app_config（`md_module_tree.cpp:721`）；git 自动提交无开关，git 不可用即静默禁用（`md_note_git.h:4`）；智能体工具 notes_search/notes_read/notes_write 共用同一笔记库（`notes_mcp_tools.cpp`）。
